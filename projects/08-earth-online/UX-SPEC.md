# 地球 Online：冒险者公会大厅 UX Specification

状态：`SECOND-PASS UX SPEC`

## 1. 体验目标

- 5 秒：`主线不用着急，先来领一个小任务。`
- 20 秒：完成时间、精力、预算、环境和组队意愿登记。
- 30–60 秒：拿到一件现在恰好能做的任务，并理解为何匹配。
- 完成后：获得文字徽记和可回看的冒险日志，不被连续打卡绑架。

## 2. 流程

```text
公会大厅 → 今日状态 → 领取任务
→ 接受 / 换一个 → 执行页
→ 完成 / 放弃 / 不适合 → 文字徽记 → 冒险日志
```

同一时刻一个 activeQuest。领取即写 activeQuestId；换一个记录跳过并冷却；完成才写完整日志；放弃无惩罚。

## 3. 页面规格

### E01 公会大厅｜首次

品牌、主标语、`登记今日状态`。大厅视觉是现实城市中的想象公会：公告板、日常背包、车票、便签等，不做中世纪武器酒馆。

### E02 公会大厅｜有进行中任务

第一视觉是当前支线和预计时间；主动作 `继续任务`。次入口：重新登记状态、冒险日志、已接取收藏。

### E03 今日状态

20 秒大按钮/滑块：可用时间、精力、预算、室内外/环境、社交意愿。每项显示当前值；允许快速使用上次状态但要求确认今天仍适用。

主动作 `去任务板`。

### E04 匹配中

短暂展示正在考虑的条件标签，不是假百分比。匹配完成后立即写 activeQuestId，再揭晓。

### E05 任务揭晓

任务纸包含：等级、任务名、描述、时间、预算、环境、社交程度、为什么推荐、退出条件。

主动作 `接取这项支线`；次动作 `换一个`、`这类任务不适合我`。

不使用老虎机滚动、宝箱、稀有闪光。

### E06 换一个

第一次可直接换；连续多次换显示已经应用的冷却和可调整条件入口，不责备。新任务不能与近期跳过重复。

### E07 条件回退

没有精确匹配时先展示解释：`你的条件很具体，先给你一件不受地点和预算限制的小任务。` 列出未放宽的安全/明确偏好和已放宽项。

### E08 执行页

只显示当前任务目标、预计时间、退出条件和 `完成 / 放弃 / 不适合`。不要求开启计时器、定位或上传证明。

### E09 完成

完成确认防误触。结算显示 XP、等级进度、完成文案和文字徽记。没有金币、战斗力或连续签到惩罚。

### E10 放弃

无失败惩罚；可选结构化原因。回大厅或领新任务。日志记录 abandoned 状态。

### E11 不适合

解释只调整软权重，不永久删除任务类别；允许撤销反馈。

### E12 冒险日志

日期、任务、类别、状态、有限备注。筛选完成/放弃/类别；空状态 `第一项支线还在公告板等你。`

### E13 已接取收藏/徽章

收藏任务 ID 和文字徽记，不保存图片。等级徽章是分类/纪念视觉，不暗示能力优劣。

### E14 存储错误

localStorage 失败时不允许假装 activeQuest 已保存；可进入当前会话临时任务并明确关闭会丢失。IndexedDB 失败时可完成任务，但冒险日志保存前提示降级。

## 4. 状态矩阵

| 功能 | Empty | Error | Success | Partial |
|---|---|---|---|---|
| 匹配 | 无精确结果进入解释回退 | 规则错误给安全通用任务并标说明 | 推荐+理由 | 某标签缺失不展示错误值 |
| 当前任务 | 无任务回登记 | ID 无效清理单项 | 继续 | 内容更新显示新版任务，不伪造旧文案 |
| 完成 | 不适用 | 日志失败保留内存重试 | XP/徽记 | XP 写入而日志失败需一致性恢复 |
| 日志 | 暖空态 | 重试/有限降级 | 可筛选 | 某条损坏隔离，不清空全部 |

## 5. 响应式/无障碍

- 375/390：状态登记一屏 2–3 条，按钮至少 52px；任务纸留安全边距。
- 430：任务纸最大 390px，不无意义放大。
- 桌面：大厅背景可扩展，任务纸仍保持阅读宽度。
- XP 有数字文字；等级不只靠颜色。
- 完成、放弃、不适合三动作视觉有层级但均可键盘访问。

## 6. 资源候选

- 大厅主视觉：先完成无位图高保真版本，再判断是否需要一张现实公会氛围图。
- 10 类别徽章、E/D/C 等级章、完成徽记、五类状态符号：统一 SVG。
- 任务纸和公告板：CSS/SVG 纹理，不为 100 任务逐个生成图片。
- 若生成大厅图，现实器物和城市空间要有参考；不出现武器、魔法和中世纪酒馆陈设。

## 7. 高保真门槛

- [x] activeQuest、换任务冷却、条件回退、完成/放弃/不适合和日志失败完整。
- [ ] 完成状态登记→揭晓→执行→结算连续高保真。
- [ ] 验证大厅位图是否真正提高品牌；没有功能价值则用 SVG/CSS。
- [ ] 先做 3 个徽章基准，二次检查后扩展。
