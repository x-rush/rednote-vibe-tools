# 当时这样说就好了｜首发内容与数据契约

状态：CONTENT READY / 词库、规则与 32 组情境已完成，待转 JSON、语气盲审和安全关键词测试。

## 1. 产品边界

- 不上传聊天记录或截图。
- 不判断谁对谁错，不推断对方人格和动机。
- 不保证“这样说”就能改变对方或修复关系。
- 默认无痕；只有用户主动保存才进入 IndexedDB，最多三份。
- 暴力、威胁、跟踪、控制和自伤威胁场景优先提示安全，不鼓励独自对质。

## 2. 五步内容定义

| 步骤 | 用户要做的事 | 不要做的事 |
|---|---|---|
| fact | 写摄像机可以记录的行为、时间和话语 | 猜动机、使用“总是/从不” |
| feeling | 选择或填写自己的情绪与身体体验 | 把“被忽视”直接当纯感受 |
| interpretation | 承认脑中出现的故事和判断 | 把解释包装成客观事实 |
| need | 找到自己在意的价值或条件 | 把“需要你道歉”写成需要 |
| request | 提出具体、可执行、可拒绝的下一步 | 威胁、测试、模糊要求或强制承诺 |

## 3. 感受词库

### 愉快/获得支持

### 悲伤/失落

### 害怕/不确定

担心、害怕、紧张、不安、忐忑、迷茫、警觉、慌乱、无措、脆弱、犹豫、压力很大。

### 生气/受阻

共 48 个首发感受词。界面允许搜索和多选，不把词分成好坏。

## 4. 容易混淆的“感受式判断”

以下词可以描述真实体验，但通常也包含了对他人行为或动机的解释，产品应引导用户继续区分：

| 用户可能写 | 可以追问 |
|---|---|
| 被忽视 | 具体发生了什么？你更接近失落、生气还是孤单？ |
| 被背叛 | 哪个约定或信任被打破？你感到震惊、受伤还是害怕？ |
| 被控制 | 对方做了什么限制选择的行为？你感到紧张、反感还是无助？ |
| 被否定 | 哪句话或行为让你这样理解？你感到挫败、羞愧还是难过？ |
| 被抛弃 | 发生了怎样的离开或失联？你感到害怕、孤单还是无措？ |
| 不被尊重 | 哪个边界或约定没有被遵守？你感到恼火、委屈还是受伤？ |
| 被利用 | 哪件交换或责任让你觉得不对等？你感到反感、失望还是疲惫？ |
| 不被重视 | 有什么具体期待没有被回应？你感到失落、孤单还是沮丧？ |

引导区分不等于否认用户体验；涉及明确伤害时不要求用户用更温和的词淡化事实。

## 6. 请求检查规则

一个请求需要同时满足：

- 有具体行为，而不是“对我好一点”。
- 有可观察时机，而不是“以后永远”。
- 对方可以回答愿意、不愿意或提出替代方案。
- 不以惩罚、羞辱、离开或伤害为交换条件。
- 目标是帮助沟通，不是伪装命令。

### 请求改写示例

| 原句 | 问题 | 可尝试改写 |
|---|---|---|
| 你以后尊重我一点 | 不具体 | 下次讨论我的决定时，你愿意先让我完整说完，再提出不同意见吗？ |
| 你必须每天主动找我 | 不可拒绝、长期绝对 | 我希望一周里有几次主动联系，你愿意和我商量一个双方都舒服的频率吗？ |
| 你别再让我失望 | 不可观察 | 如果计划要改变，你愿意在知道时尽早告诉我，并一起定新时间吗？ |
| 你应该知道我想要什么 | 要求读心 | 当我没有说清时，你愿意直接问我现在需要倾听还是建议吗？ |
| 你不道歉就别来找我 | 惩罚式条件 | 我现在需要暂停联系；如果要继续谈，我希望先讨论这件事造成的影响。 |
| 你保证永远不再这样 | 绝对承诺 | 你愿意告诉我下一次遇到类似情况准备采取哪一个不同动作吗？ |
| 你冷静一点 | 评价对方状态 | 我现在很难继续听清，我们能暂停二十分钟，再回来谈这一点吗？ |
| 你不要这么敏感 | 否定体验 | 我可能还没理解你在意的部分，你愿意告诉我哪句话影响最大吗？ |

## 8. 三十二组情境示例配额

首发不需要为每组写长剧情，但必须覆盖以下组合，每组提供事实、感受候选、需要候选、请求示例和反例：

- 朋友：迟到、临时取消、玩笑越界、长期不回复、借物未还、秘密被转述。
- 伴侣：改计划、家务分工、需要独处、公开亲密细节、消费决定、争论暂停、纪念日期待、身体边界。
- 家人：催促决定、评价外貌、未经同意整理物品、代替答应事情、比较他人、探问隐私。
- 同事：遗漏交接、会议打断、任务边界、功劳归属、临时加急、反馈含糊、公开批评、休息时间联系。
- 通用：道歉没有行动、承诺延期、误解动机、请求被拒绝。

## 9. 安全提示规则

出现以下明确描述时显示固定安全提示，但不自动诊断：

- 威胁伤害用户、他人或自己来迫使服从。
- 限制用户离开、工作、就医、财务或联系他人。
- 跟踪、监控设备、强迫提供密码。
- 持续羞辱、恐吓或破坏物品。
- 用户表示当前处于立即危险。

固定提示原则：优先考虑人身安全，联系可信任的人或当地紧急支持；不要因为工具生成了一段“更好的话”就鼓励用户进行可能升级风险的单独对质。正式上线前按目标地区核对可展示的紧急资源，不硬编码可能过期的号码。

## 11. 表达模板

基础模板不是强制句式，至少提供：

1. “当我看到/听到……，我感到……，因为我很在意……。你愿意……吗？”
2. “我现在脑中出现的解释是……，但我不确定它是不是事实。我想先确认……”
3. “我需要暂停，不是为了惩罚你。我希望在……之后，再继续谈……”
4. “我听见你的请求是……。我现在不能答应，但我可以……”
5. “我接受你的道歉，同时还需要看到……这个具体变化。”
6. “这件事对我的影响是……。即使你的出发点不同，我也希望这个影响被看见。”
7. “我愿意说明自己的需要，但我不能承担猜测和管理你全部反应的责任。”
8. “如果这个请求不适合你，我们可以讨论替代方案；如果边界持续被越过，我会采取……”
