# 旋龟参考证据包（生成前冻结）

## 用途与命名结论

- 项目：SHBTI 山海兽格
- 结果型：`HTLS 负图型`
- 用户可见名称：**旋龟**。
- 稳定数据 slug：继续使用 `xuangui`，只作为工程兼容标识，不把展示名改成“玄龟”。
- 原典句式先说水中“多玄龟”，随后明确“其名曰旋龟”；本项目采用专名“旋龟”，避免与玄武、一般黑龟混淆。

## 原典硬字段

1. **其状如龟**：完整龟甲、龟身与可信的四足龟类结构；三分之四视角允许远侧后足被龟甲自然遮挡，不要求为了“核数”破坏构图；
2. **鸟首**：独立可辨的鸟头、鸟喙和短颈，不是普通龟头，也不采用龙头；
3. **虺尾**：恰好一条细长蛇形尾，从龟甲后部自然延伸；尾端不带第二颗蛇头；
4. **其音如判木**：只用水面震纹、木裂般节奏线和警觉姿态表达，不添加斧头、木材、文字或拟声字；
5. “佩之不聋，可以为底”等效验只作为古籍旁注，不转写成现实医疗、佩戴或捕食建议。

## 艺术化边界

允许：

- 将两种历史线描转译为工笔矿物色水岸异兽；
- 用玄青、龟甲褐、石绿、少量朱砂表现水光和甲片；
- 让甲纹具有“反复核验、证据咬合”的秩序感，但不画文字、八卦或现代网格；
- 使用三分之四侧视，使鸟首、龟身运动关系和虺尾清楚；可见足的连接、方向和数量不得自相矛盾。

禁止：

- 用户可见名称写成玄龟；
- 玄武式龟蛇相缠、蛇有独立头部、龟背盘蛇；
- 龙龟、赑屃、龙首、角、须、碑座、钱币或风水摆件；
- 普通乌龟头、双尾、多尾、多足或翅膀；
- 斧头、劈木、法器、盔甲、文字、Logo、水印；
- 对听力或足部疾病作现实功效承诺。
