## 3. 统一资源完成定义

一项资源只有同时满足以下条件才可标为 `approved`：

1. 页面槽位和必要性已经由高保真页面证明；
2. 规格、尺寸、格式、透明背景和裁切安全区已明确；
3. 现实／历史对象具备参考证据和不可修改字段；
4. 文件本体已生成或绘制；
5. 单资源完成形态、事实、版权、透明边缘和技术检查；
6. 已压缩到包体预算；
7. 已装回实际 UI；
8. 已在 375×812、390×844、430×932 验证裁切和可读性；
9. 加载失败时有合法降级；
10. `asset-manifest.json`、制作／提示词台账和 `VISUAL-QA.md` 均已更新。

## 4. 当前禁止事项

- 不把概念占位图列为正式资源；
- 不因 AI 图“看起来不错”跳过参考门禁；
- 不为每个内容项机械生成一张图片；
- 不把截图总览当作响应式验收；
- 不使用未核对文字的 AI 印章、招幌、古文字或标签；
- 不在 Windows 视觉分支直接覆盖 WSL 八项目并行开发成果，合并前先比较差异。
