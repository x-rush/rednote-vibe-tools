# 溪边淘金｜当前玩法与视觉规格

2026-09-19。项目 18，纯前端离线小游戏。完整内容规格见 CONTENT-PLAN.md，验收证据见 qa/RELEASE-QA.md；当前提供离线验收包，尚未完成宿主真机放行。

## 体验目标

站在真实质感的溪岸边，自己选沉积点、舀砂、浸盘、分层、洗掉轻砂，再拾起留下的每一颗。未知来自固定生成的样本，技巧决定保留和洁净程度；不在洗的过程中偷偷重新抽奖。名称、重量、价值与分布为游戏设定，不是矿物鉴定、现实淘金指导或回收价格。

## 连贯操作

| 阶段 | 输入 | 画面与状态 |
|---|---|---|
| 选地点 | 点击溪边手记，在六处溪岸间选择 | 独立背景、砂色和沉积条件；所有地点可直接探索 |
| 取样 | 在三处砂纹之一按住划动；至少 35% 一铲后可松手 | 铲中砂量增长、浅坑留痕；半铲与满铲影响数量和洗砂时间 |
| 装盘 | 松手完成取样 | 1.2 秒抬盘、铲头倾下、砂砾落盘；此时不接收淘洗输入 |
| 浸水 | 盘心向下拖入溪水，停留浸满，松手提盘 | 盘体下移、水位增长、接触涟漪；不直接跳过浸水 |
| 分层 | 盘内缓慢绕圈 | 金属盘有限跟手、水与砂分别滞后，重物较稳；过快有提示 |
| 倾洗 | 从近侧盘沿向下拖住，松手回平 | 水与表层砂从同一出口流出；过猛先预警，再实际跨沿流失 |
| 补水 | 从远侧盘沿向下拖入水中 | 水量回升，缺水时不能凭空洗砂 |
| 拾取 | 细砂≤6%、粗砾和叶屑基本清除后，逐颗点击 | 金样飞向瓶子，矿物飞向盒子；随后显示写实标本、介绍及游戏收藏价值 |
| 精洗 | 检查阶段在空处继续绕圈/倾洗 | 可进一步提高洁净度；风险规则仍成立，不强制停在同一分数 |
| 下一盘 | 收齐后轻点空盘 | 回到当前溪岸，再次选择位置 |

主场景只保留提示和实际物件入口，无倾洗、整盘收集、自动演示、下一盘按钮。图鉴、手记内部允许正常导航按钮，底部出口始终可见。

## 模拟规则

- 业务固定 1/60 秒步进；单帧补算有界。平盘绕圈只提高沉降，不直接减少砂。水量、坡度、沉降程度、地点和取样量共同影响洗砂。
- 粗砾和浮叶是有限杂物量；石窝和雨后粗砾需先分层倾出，苔岸轻漂浮叶。它们不生成收藏奖励。
- 每个收藏实体有稳定 ID 和唯一归属：盘内、流失、已入藏。金粒沿边缘滑出后才损失；极端坡度下有 400 ms 预警宽限。
- 隐藏样本在取样完成时确定。地点、取样点、种子、取样量相同，实体相同。首次公开标记的练习样本有三粒细金砂；普通样本允许没有金，伴生物独立产生。
- 每颗拾取立刻保存；全部收齐仅结算一次。重洗仅记练习成绩；固定挑战/今日样本领取状态用位图记录，避免仅依赖最近历史去重。
- 金样与伴生物分别展示。所有价值属于游戏内收藏评价。

## 视觉与声音

六处独立本地摄影风格溪岸，透明浅水与暖光。钢盘、湿砂和 18 种标本采用本地素材；水波、折射近似、砂密度场、颗粒运动、装盘和拾取轨迹由运行时绘制。砂层为 40×40 密度场，水/砂惯性分别计算。实现是二维/2.5D 受控视角，不声称完整三维流体或矿物回收预测。

9 段真实拟音剪辑用于水、砂、玻璃接触；相邻轮换，声音不会提前泄露盘中物件。手记中显式开启或关闭，缺少音频能力保留无声流程。音频来源、编码与生命周期见 AUDIO-DESIGN.md。

## 记录、辅助与边界

24 项技巧挑战、6 条收藏系列、最近 20 盘、最好洁净度、最大金粒、无流失盘数；本地日期决定今日 seed，跨日不打断当前局。慢速辅助允许直线划动协助分层，减弱动画取消明显位移，不改变产出。

进行中盘、收藏、成绩及设置只保存结构化数据。后台暂停、丢失指针捕获/取消/旋转终止手势，不把取消当完成取样。不调用陀螺仪、振动、全屏或其他未经确认的设备 API。
