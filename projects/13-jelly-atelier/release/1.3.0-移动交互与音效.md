# 果冻慢慢 1.3.0

- 操作区阻止 contextmenu、selectstart、dragstart，增加 iOS touch-callout 样式；输入框保留文本编辑。
- 戳动力度系数提升为 2.2，新增更强的摇晃动作；连续操作的形变幅度设有上限，减少动态模式仍降低幅度。
- 成品可左右拖动触发摇晃，或点击「摇一摇」按钮。
- 新增持续倒入声，松手、完成本层、切换页面与静音时停止；轻点加量有短倒入声。
- 戳动音效采用低频下坠、回弹和高频泛音，限制并发声音数量，并加入动态压缩避免连续戳动时过响。
- 声音默认关闭，通过顶部声音按钮开启。切换至后台时停止并暂停声音。

摇晃手机的传感器功能未加入离线包：项目端能力规范明确禁用 DeviceMotionEvent / DeviceOrientationEvent。使用触摸摇晃作为替代，并非手机传感器触发。

验证：22 项现有回归测试、lint、build、离线能力扫描通过；浏览器实际点击声音开关、摇晃、戳动、加量和右键操作未报错。375/390/430px、顶部模拟安全区44px下，完成态按钮均在视口内且无横向溢出。未用真实 iOS/Android 长按和手机扬声器实测。
