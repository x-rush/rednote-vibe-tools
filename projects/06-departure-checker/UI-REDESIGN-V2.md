# 出门检查官 UI/UX V2 设计规格

状态：已确认并完成实现
日期：2026-08-26
适用范围：`projects/06-departure-checker/**`

## 1. 设计结论

V2 采用“轻户外检查板”方向：暖白纸面、森林绿主色、雾蓝路线色与陶土橙完成色，强调可靠、清楚、低压力。产品首先是一件一分钟内能完成的工具，路岚是可跳过、可召回的解释助手，不是阻挡主流程的角色封面。

旧设计继续保留三项核心资产：三视图同源、空间巡视、最后一分钟。以下旧设定废止：

- 删除独立封面页，首页直接展示最近清单和八个场景。
- 不展示“实时天气不可用”；天气始终由用户手动选择。
- 不复用旧预览中已失效的 28 个 SVG 和路岚资源引用；V2 资源按真实内容重新制作并落盘。
- 资源数量以真实 JSON 为准：8 个场景、11 个类别、9 个位置。
- 不为 83 个物品分别绘制图标；清单行使用类别图标和文字。

## 2. 成功标准

- 新用户在首屏 5 秒内能选择场景。
- 用户跳过全部可选问题时仍能生成基础清单。
- 典型流程在 30–90 秒内进入可勾选清单。
- 重要程度、类别、空间巡视只改变分组和排序，不复制勾选状态。
- 最后一分钟只显示未完成的必带项和关键确认，不出现倒计时或安全保证。
- 条件重算后明确显示新增、移除、保留勾选数量。
- 最近清单达到三份时，保存第四份前必须确认覆盖对象。
- 非关键内容损坏时显示可用基础结果；存档损坏时保留原数据直至用户明确清空。
- 375、390、430 CSS px 无横向溢出，主要操作位于单手可达区。

## 3. 信息架构

```text
首页（最近一份 + 八场景）
├─ 首次轻引导（可跳过，仅首次）
├─ 条件追问（对应场景的四个真实问题）
├─ 生成过渡
└─ 清单工作台
   ├─ 重要程度
   ├─ 类别
   ├─ 空间巡视
   ├─ 项目解释抽屉
   ├─ 修改条件 → 变更摘要
   ├─ 自定义项编辑
   ├─ 最后一分钟
   └─ 完成结果

首页 → 最近清单
       ├─ 继续勾选
       ├─ 复制并重算条件
       ├─ 删除
       └─ 第四份覆盖确认

任意加载入口 → 部分可用 / 坏存档恢复
```

## 4. 页面与状态

### S01 首页

- 顶部使用小型品牌签和“只在本机处理”说明，不设置独立开始按钮。
- 最近一份存在时放在场景网格上方，显示场景、完成比例和“继续”。
- 八个场景固定两列。每卡包含场景 SVG、名称和一行描述，整卡可点击。
- 页底用一句话说明天气由用户选择，不调用定位、天气或在线 AI。

### S02 路岚首次轻引导

- 首次选择场景后弹出底部说明板，不遮住场景选择结果。
- 只解释三步：去哪里、补条件、只留下容易忘的项目。
- 操作为“跳过”和“继续”；跳过状态以一个结构化布尔值保存在本机。
- 路岚主图只在首次引导出现，后续使用头像。

### S03 条件追问

- 顶部固定所选场景、返回入口和 `1/4` 至 `4/4` 进度。
- 每一步只呈现一个真实 `scenarioQuestion`，不合成 JSON 中不存在的“同行者”等通用问题。
- `boolean` 使用“需要／不需要／暂不确定”选择卡；`single` 使用选项按钮；`number` 使用预设时长加数字输入。
- 每题可以跳过。底部主按钮在最后一步变为“生成我的清单”。

### S04 生成过渡

- 过渡文案分三阶段轮换：基础项、条件项、去重排序。
- 总时长保持 360–600ms，仅用于状态理解，不伪装远程计算。
- 减少动态效果时直接显示静态进度和最终结果。

### S05 重要程度视图

- 顶部摘要显示场景、已选条件标签和“必带还剩 N 项”。
- 三视图标签紧邻摘要；标签切换不改变页面滚动之外的业务状态。
- 顺序为必带、确认事项、建议、可选。每组同时显示文字和数量。
- 行内包含原生复选框、类别图标、项目名、首条原因和“解释”按钮。
- 已完成行降低对比但保持可读，不整行删除，支持取消勾选。

### S06 类别视图

- 使用真实 11 个类别，仅显示当前存在的非空类别。
- 每组标题使用类别图标、名称、完成比例。
- 同一 `entryId` 直接复用，不创建类别视图副本。

### S07 空间巡视

- 顶部突出“下一站”和该位置未完成数。
- 路线顺序使用真实位置 `sortOrder`，不读取户型和设备位置。
- 默认展开当前站，已清空站点折叠并显示完成标记；用户可回看任意站。
- 自定义项没有有效位置时进入“待归位”，不重复出现在其他位置。

### S08 项目解释抽屉

- 从清单底部弹出，背景保持原视图和滚动位置。
- 展示优先级、全部原因、拿取位置、建议动作与正式通知提示。
- 路岚头像作为解释来源入口，但解释内容只来自当前条目的结构化数据。

### S09 条件变更摘要

- 重算前保存旧清单快照，按稳定 item ID 比较新旧结果。
- 展示新增、移除、保留勾选三个计数，并分别列出最多三项代表内容。
- 仍存在条目保留勾选；内置移除项离开清单；自定义项始终保留。
- 用户确认后才替换当前工作台结果。

### S10 最后一分钟

- 过滤为未完成的 `must` 携带项与 `must` 确认项。
- 每次突出一项，同时允许查看完整剩余列表。
- 主操作高度至少 64px，位置避开底部安全区。
- 始终提供“退出最后一分钟”，不锁定流程。

### S11 全部完成

- 使用绿色与陶土橙完成章，不使用警报红。
- 提供“返回完整清单”和“回到首页”；不制造连续打卡、积分或分享压力。
- 如果只完成关键项而仍有建议项，明确说明建议项仍可返回查看。

### S12 自定义项

- 支持名称、优先级、类别和位置；名称最多 30 字。
- 编辑复用添加表单；删除自定义项需二次确认。
- 不保存图片、Base64、音视频或 Blob。

### S13 最近清单

- 最多三份，按更新时间排序。
- 每份显示场景、完成比例、更新时间，以及“继续”和“复制并重算”。
- 删除只影响该实例，不影响内置内容。

### S14 覆盖确认

- 第四份保存前展示默认覆盖的最旧记录。
- 用户可以选择另一个覆盖对象或取消。
- 存储层接收明确的目标 ID，不再静默截断第四份。

### S15 无精确匹配

- 使用场景基础清单并说明“未找到更多条件建议”。
- 提供调整条件和继续使用基础清单两个动作。

### S16 部分内容可用

- 非关键规则或条目失效时排除坏引用，展示基础清单和可用建议数量。
- 不展示坏项目，不把错误包装成安全保证。
- 提供本地诊断编号，编号不包含用户输入。

### S17 坏存档恢复

- 明确原数据尚未覆盖。
- 提供返回空白首页和“清空本工具数据”两个层级不同的操作。
- 清空前二次确认；不影响其他项目的 localStorage。

### S18 路岚召回帮助

- 清单页头像打开帮助抽屉。
- 入口为“为什么出现”“怎样精简”“最后一分钟是什么”。
- 关闭后恢复原视图、滚动位置和焦点。

## 5. 视觉系统

### 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#F6F2E8` | 页面底色 |
| `--paper-raised` | `#FFFCF5` | 卡片与抽屉 |
| `--ink` | `#24312D` | 主要文字 |
| `--muted` | `#68736E` | 次要说明 |
| `--forest` | `#386B59` | 主操作与必带摘要 |
| `--forest-dark` | `#244A3E` | 最后一分钟背景 |
| `--mist` | `#577C87` | 空间路线与辅助状态 |
| `--clay` | `#C77C45` | 当前步骤与完成动效 |
| `--line` | `#CFD4CC` | 分隔线 |
| `--danger` | `#9A4E45` | 仅删除和不可逆确认 |

颜色不单独承载优先级；`必带 / 建议 / 可选` 始终有文字或图形差异。

### 字体与密度

- 界面正文使用系统无衬线字体；大标题允许使用系统中文衬线回退，避免外部字体依赖。
- 大标题 32–40px，页面标题 28–32px，清单项 16px，辅助文字不小于 12px。
- 圆角控制在 12–20px，保持检查板而非软糖卡片感。
- 清单行最小高度 64px，普通按钮至少 48px，最后一分钟主按钮至少 64px。

### 图形

- SVG 统一 `24×24` viewBox、2px 线宽、圆角端点和连接、正视系统。
- 场景图标可使用一处低饱和填色；类别和位置图标以线性为主。
- 列表中图片加载失败时隐藏图形并保留文字，不显示 asset ID。

## 6. 组件边界

- `HomeScreen`：最近清单、场景入口和隐私说明。
- `GuideSheet`：路岚首次引导和召回帮助。
- `ConditionWizard`：问题进度与类型化输入。
- `GenerationTransition`：本地生成反馈。
- `ChecklistWorkspace`：摘要、视图切换和共用条目状态。
- `PriorityView`、`CategoryView`、`LocationRouteView`：只生成分组 view model。
- `ChecklistRow`：复选、类别图标、理由和解释入口。
- `ItemDetailSheet`：条目完整解释。
- `ConditionDiffSheet`：重算差异确认。
- `LastMinuteMode`：关键项过滤和单手推进。
- `SavedListsScreen`、`OverwriteDialog`：最近清单与显式覆盖。
- `RecoveryScreen`：空结果、部分可用和坏存档。

业务内容仍只来自 `src/content/content.json`；组件不硬编码场景名、问题、项目名或规则理由。

## 7. 状态与数据调整

- 页面状态增加 `lastMinute`、`conditionDiff`、`customEditor` 和覆盖确认状态。
- 新增纯函数：视图分组、未完成关键项过滤、清单差异计算、下一位置计算。
- 当前清单保留自定义项、勾选状态和视图模式；重算时只按稳定 ID 合并。
- 最近清单存储增加显式覆盖目标接口；旧 schema 可读取并迁移。
- 路岚首次引导只保存布尔偏好，不保存任何图片或自由文本。
- 内容校验失败不能在 React 挂载前导致白屏；初始化错误转换为可恢复页面状态。

## 8. 响应式与无障碍

- 375px：页面左右 12px，场景两列间距 8px，清单操作允许换行。
- 390px：基准宽度，页面左右 16px。
- 430px：页面左右 20px，场景仍为两列，不放大图标。
- 桌面最大内容宽度 560px；仅最近清单允许双列。
- 使用原生 checkbox、button、input；抽屉使用 `dialog` 语义或等价焦点管理。
- 所有可点击区域至少 44×44px；键盘焦点使用 3px 高对比轮廓。
- 打开抽屉时焦点进入标题，关闭时返回触发按钮。
- 状态变化使用 `aria-live="polite"`；错误使用 `role="alert"`。
- `prefers-reduced-motion` 下取消位移、旋转和循环动画。

## 9. 验收矩阵

- 8 个场景均能从首页进入并生成非空基础清单。
- 32 个问题均通过对应输入类型显示，不出现未定义条件。
- 三视图切换前后所有 `entryId` 的勾选状态一致。
- 空间巡视不会重复条目，当前站随勾选推进。
- 条件重算正确计算新增、移除、保留勾选。
- 最后一分钟不显示建议或可选项，退出后完整清单状态不变。
- 第四份保存未确认前不修改存储。
- 损坏 JSON、未来 schema、失效非关键引用均进入对应恢复状态。
- 超长中文、连续英文和 30 字自定义项不造成横向溢出。
- 375×812、390×844、430×932 全流程通过。
- lint、42 项既有测试和新增测试、生产构建全部通过。

## 10. 非目标

- 不接入天气、地图、定位、账号、后端或在线 AI。
- 不提供医疗、交通、宠物或儿童安全保证。
- 不增加商品写实图、3D 图标、每项物品图标或分享海报。
- 不保存用户图片、Base64、音视频或 Blob。
- 不依赖 Service Worker、运行时 CDN、Node API 或未经确认的设备 API。
