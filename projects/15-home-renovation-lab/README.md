# 项目 15 · 住进想象 / ROOMISH

一个可以直接动手玩的纯前端 3D 装修工具。打开就是一套已经布置好的小家：选家具、拖动摆放、换材质和风格，随时进入房间看看，再把设计和清单导出。

## 已实现

- 六种可编辑单层户型：开放单间、一室一厅、两室一厅、两室两厅、三室两厅、转角小家。
- 空白起步、添加矩形房间、移动与拖角缩放、精确宽深输入、共享墙和门窗。
- 26 款原创程序化家具，覆盖起居、卧室、餐厨、卫浴和装饰；目录缩略图由同一家具模型生成。
- 点击落点、桌面目录拖入、家具移动、旋转、复制、删除、颜色和规格编辑，地毯允许与家具合理叠放。
- 12 种程序化材质，三种整屋风格组合；支持独立地面和墙面、纹理尺度与方向。
- 新手 / 进阶两种模式，切换不丢方案；精确位置、规格、墙体属性在进阶面板提供。
- 全屋与俯视、房间近景、前后对比、日光 / 暖夜、完成展示。
- 室内体验：拖动环顾、点击可达地面移动、选择房间切换观察点；支持基本墙体和家具阻挡。
- 本地自动保存、另存方案、打开方案、撤销 / 重做、JSON 导入导出。
- 家具和材料自动清单、用户选填单价、CSV 导出、无操作选中框的 PNG 导出。
- 375 / 390 / 430 CSS px 手机布局和安全区适配。

## 运行

开发和预览使用项目内脚本：

```sh
pnpm dev
pnpm lint
pnpm test
pnpm build
pnpm preview
```

默认地址为 `http://127.0.0.1:4311`。默认端口被占用时可设置 `PORT`。测试请使用 Node.js 22 或以上；本次验收使用 Node.js 24。

`dist/` 是可直接部署在静态主机上的完整产物，支持子目录。ES Modules 需要通过 HTTP 服务打开，不使用 `file://` 双击方式。

## 纯前端与资源

运行技术为原生 JavaScript ES Modules、Three.js 0.186.0、DOM / CSS 和 localStorage。没有运行时 CDN、业务后端、必需外部 API、Service Worker 或设备权限依赖。

原需求拟采用 TypeScript / Vite；为适配当前独立静态项目和共享依赖约束，实际采用浏览器原生模块和项目内静态复制构建。未增加包管理依赖，未改动根 package.json、工作区配置或锁文件。Three.js 官方发行文件及许可证存放在 `src/vendor/package/`；OrbitControls 仅将包名导入调整为相对本地路径。

家具几何、木纹 / 石纹 / 方砖 / 壁纸、品牌图标和界面均为本项目设计生成。无需在线图片、第三方家具 API 或外部字体。模型和缩略图保持一致；缩略图仅存在于运行内存，不写入本地存储。

本地存储只保存已知结构化字段。导入 JSON 时校验版本、几何、目录 ID 和数值，并剥离未知字段。导出暂时创建的 Blob / Object URL 不持久化，下载后释放 URL。

## 尺寸口径

初始户型为设计比例，默认未标定，不展示真实平方米。用户逐房间确认宽、深后计算室内面积；部分标定只显示已标定小计。墙面用量还需要在进阶属性里明确确认墙高，计算时扣除门窗洞口。

建筑面积仅保留用户填写值，不从房间尺寸推算公摊或建筑面积。清单金额只根据用户输入单价计算，不含未填写项、人工或施工费用。

## 文件职责

- `src/content/content.json`：业务文案、户型、家具、材料、风格目录。
- `src/core.js`：几何、碰撞、面积、清单、历史、导入校验和行走判断。
- `src/scene.js`：原创家具建模、材质生成、相机、交互、渲染和图片导出。
- `src/app.js`：编辑界面、模式、方案管理、存储和清单导出。
- `src/style.css`：桌面 / 手机布局、视觉与安全区适配。
- `tests/core.test.mjs`：实际业务逻辑测试；原 bootstrap 测试保留。
- `scripts/browser-check.mjs`：真实浏览器交互验收，使用环境提供的 Playwright。
- `artifacts/`：验收截图与浏览器检查报告，不参与产品构建。

浏览器验收脚本接受 `PLAYWRIGHT_PACKAGE` 指定测试环境的 Playwright 路径，`PREVIEW_URL` 可切换测试地址；产品本身不依赖 Playwright。

## 使用边界

这是单层、矩形房间组合的装修搭配工具。家具为统一低多边形美术，不是品牌实物模型或施工级效果图。进入体验为轻量观察和移动，不包含 VR、人物动画或云端协作。自建户型修改后不适配的家具会保留并标红，便于重新摆放。

设计需求见 `PROJECT.md`，实际完成范围及运行方式以本文件为准。

## 小红书容器离线 ZIP

按照仓库 `minitool-zip-builder` skill 适配后的上传包为 `release/roomish-1.0.0-minitool.zip`，其入口位于 ZIP 根目录。此版本使用经典脚本、内置目录数据、容器相册接口和可选中的方案 / 清单文本，禁止运行期网络请求及文件下载。详见 `release/DELIVERY.md` 和 `release/container-check.json`。

`node scripts/package-minitool.mjs` 可使用工作区现有工具重新打包，不安装新依赖。容器版与普通网页 `dist/` 独立，保留原网页的功能和预览方式。
