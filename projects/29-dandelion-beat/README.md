# 小草，别服！——3D节奏小游戏

当前版本：v13。50秒试玩，前10秒出场，96 BPM，22次攻击。醉酒社畜连续跳街舞，扇巴掌、踢击、托马斯回旋和头槌顺势带出；点击画面或按空格，在接触拍点回避。

## 从仓库运行

在本项目目录执行 `pnpm lint`、`pnpm test`、`pnpm build`，再执行 `pnpm preview`，打开 http://127.0.0.1:4329 。无新增依赖，产物为经典JS静态页面。

仓库不分发《West Ride》音频。缺少本地音乐素材时仍可构建，点击开始后可选择“无声试玩”。需要带音乐进行本地开发时，在取得相应使用权后将50秒素材放至 `src/content/content.json` 中 `music.file` 指定的开发路径；构建会生成静态Web Audio字节。原始音频、带原曲的ZIP/录屏/成片均被Git忽略，保留在开发者本机。

- 原生WebGL骨架/连续曲面角色、衣服和肚腩惯性、醉态承重补救、22个实际接触拍点。

# 小草，别服！——40 秒 3D 节奏试玩

## 已确认范围
原创荒诞节奏演出；单击瞬间回避；扇巴掌与托马斯回旋；真正 WebGL 3D；纯静态、离线，无新增依赖。120 BPM / 40 秒 / 28 次命中，首击 4 秒。

## 运行
在本目录运行 `pnpm build`，再运行 `pnpm preview`，打开 http://127.0.0.1:4329 。部署资源位于 dist，使用经典脚本，不依赖模块或运行时网络。

## 控制与判定
点击橙色回避按钮或按空格；按住不重复触发。成功窗口 ±130ms，完美 ±65ms。空点清空连击，不计分；漏点扣血，8 点血。偏移为正时判定允许更晚点击（最多 200ms），设置保存在本机。前 4 秒鼓点导入；落点条为练习辅助。

## 技术与限制
音频使用 AudioContext 合成鼓、贝斯与旋律，音频时钟同时控制程序关节动画、谱面及判定；每 250ms 一个调度步、提前 180ms 安排声音。切后台自动暂停，手动继续。无声模式使用 performance.now。声音启动失败提供无声试玩。无 WebGL 时给出提示。

模型为原生 WebGL 参数几何与程序动画。没有使用原作音乐、模型、名称、台词。托马斯为风格化单手撑地旋转，后续可用 Blender 骨骼动画提升运动质量。当前不是动作捕捉或精细人物。
