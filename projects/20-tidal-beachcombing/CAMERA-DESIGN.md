# 退潮赶海｜玩法视角与运镜

日期2026-09-19；状态：设计补充，待可操作原型与实机验收。

## 视角与玩法对应

默认约45°～55°斜俯视近景，能读出坑深和石头翻转；远海晚霞是窄背景带。挖/翻/追时给玩家稳定参照。

| 阶段 | 构图/运动 | 玩家操作 |
|---|---|---|
| 看海滩 | 石/沙/潮池三景导航，全景可见可探索线索 | 选区域/工具 |
| 进区域 | 用户选择后1.1～1.2倍推进300ms | 进入后交互 |
| 翻石 | 锁镜头，只移动石头、阴影和水 | 翻动/翻回 |
| 挖沙 | 固定镜头与挖掘平面，坑的深度改变材质/侧壁 | 连续铲挖 |
| 抓蟹 | 当前R内活动，镜头不突然追蟹 | 按住拖取或辅助点取 |
| 蟹到边缘 | 先停在可见边缘附近；用户点邻景提示才平移 | 不在抓取过程中触发切景 |
| 看收获 | 主动打开桶的近景，再回原挖坑位置 | 查看/记录放回 |

不能一露宝贝就强制拉近，不能小蟹一跑相机把铲子拖走。已锁定抓取时边缘导航禁用，但暂停仍可用。远处水面反射与近区相机有一致世界方向。
减弱动态：区域间淡切，所有工具动作不变。
样板：选湿沙→连续挖坑→拾壳→切石滩→翻石抓蟹→回湿沙，镜头必须回到同一坑而非刷新地图。

## 通用镜头契约

本文件为PROJECT.md的视角细化；存在冲突时以本文件的镜头规则为准。所有数值是原型调参起点，未经过实机验证。
- 镜头由游戏状态驱动，维护viewState、position、target、zoom/FOV、transition、sessionId；不修改物理、奖励、随机流和判定时间。
- 输入用当前camera矩阵逆变换至世界/局部操作坐标。抓取开始锁定交互平面；操作中不偷偷换镜头。相机变化不能造成挖掘路径突跳、错选、自动抛投。
- 转场先终止或完成当前手势，再切新视角；pointercancel是取消，禁止当松手提交。不可操作转场不接收积压点击，允许立即暂停。
- 相机用渲染插值后的模型位置和时间步无关平滑，避免不同帧率跟随速度不同；不得按“每帧加固定距离”移动。暂停/后台冻结相机，恢复重置dt，不补跑轨迹。
- 默认不摇晃地平线、不自动滚转、不用全屏运动模糊、不反复改变焦距。近景展示停留可跳过，收获弹窗不遮关键动作。
- 所有屏幕目标位置相对于扣除系统安全区、宿主左右按钮及底部控件后的有效场景矩形R定义；再检查物体包围盒与宿主矩形不相交。不是简单给整个场景加一段顶部留白。
- 实际横屏重算R及构图距离，不仅把竖屏裁宽；首版无CSS模拟横屏。横竖切换时暂停手势和模拟、重建投影，再由用户继续。
- 相机和手势的调参写入src/content/content.json的cameraProfiles/transitions/inputBounds；运行期只保存结构化阶段/参数，不存图像。
- DOM工具和提示固定屏幕空间，不随3D相机漂移。减弱动态模式是用户选择；低画质不得自行改用另一种相机导致游戏线索变化。
- 声像/远近声使用当前相机的相对位置，不能还按旧岸边观察点衰减；关键声保留最低可听清层，平滑更新。声音不跟镜头转场重复触发。
- 验收必须录完整一局，不用单张截图代替。检查默认/减弱动态、30/60fps渲染、375/390/430竖屏、真实横屏、安全区与宿主覆盖层。
