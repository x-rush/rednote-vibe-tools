# 物华录：文物收集猜谜实现规划

## 产品定义

一句话：根据剪影、局部和生活线索认出文物，把它收入自己的“物华录”。

正式名建议：**《物华录：文物寻踪》**。避免在公开名称和 UI 中使用 Pokémon、宝可梦、精灵球等受保护品牌元素；只借鉴“猜测—揭晓—收集”的循环。

参赛标签：`#国风vibecoding #小红书vibecoding大赛 #vibeknow`。

## MVP 范围

- 第一季主题：“古人的日常”，20 件文物。
- 每局随机 5 件；每件提供 3 级线索。
- 四选一；线索越少答对，获得的星级越高。
- 答对或完成揭晓后解锁文物档案。
- 图鉴、分类筛选、收藏进度、收藏家类型结果。
- 所有事实、图片或重绘素材均有来源/许可台账。

不做：3D、AR、在线排行榜、文物 AI 对话、跨设备账号。

## 核心循环

```text
今日寻踪 → 看剪影 → 请求线索/直接作答 → 文物恢复原貌
→ 反常识知识 → 收入图鉴 → 五件结算 → 收藏家类型
```

## 文物数据模型

```ts
type Artifact = {

```

## 游戏规则

- 未使用线索答对：3 星；使用 1 条：2 星；使用 2 条以上：1 星。
- 错误答案必须解释“为什么容易混淆”，避免只有红叉。
- 同一局不出现外形过于接近且无法凭线索区分的文物。
- 每日局面可用日期种子生成；自由练习允许重开。
- 图鉴解锁不要求答对，避免挫败；星级用于精通度。

## UI 与美术

- 风格：现代博物档案柜，而非仿古网页。
- 核心高光：剪影在答对后被光扫过，逐层恢复材质和细节。
- 图鉴使用抽屉或标本标签视觉；未解锁只显示轮廓。
- AI 重绘图必须带“创意重绘/示意图”，不能冒充馆藏图。
- 每件文物控制 3 张以内资源，优先复用原图裁切生成局部图。

## 资料工作流

1. 先选有权威资料和可用图片的候选文物。
2. 记录名称、时期、材质、用途、馆藏、来源与许可。
3. 人工写 3 条由难到易的线索。
4. 为每件文物选择有逻辑的干扰项。
5. 专人复核事实；AI 只辅助整理，不作为事实来源。

## 测试

- 所有文物至少能在一种题局中出现。
- 每题答案唯一；干扰项不与别名冲突。
- 每局类别分布不过度重复。
- 资源路径、来源和许可字段完整。
- 图鉴进度刷新后正确；数据版本升级不会丢失。
