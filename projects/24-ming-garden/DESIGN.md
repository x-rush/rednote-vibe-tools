# v2 视觉设计

淡彩工笔江南园景，象牙白地面、灰青瓦与低饱和草木，统一俯视方向。四张完整插画底图替代旧 CSS 网格：兰庭、水庭、书窗竹院、山石庭院。曲径和边缘建筑组织构图，留出疏密有别的地面。

景物使用同向插画，白底正片叠底融合；按地面位置排序遮挡。点击选中才显示名称，落位期间才显示预览与占地提示。容量是经营规则，不是可见方格。

标题居中、操作下移，区分状态栏安全区与宿主按钮占位。园笺从底部打开，无强制剧情弹窗。赏园模式隐藏经营控件。

参考江南百景图的线描、桃源深处有人家的园居氛围、Tiny Glade 的环境整体性，没有复制其素材。本版是二维插画拼景，尚不支持水系与桥梁自动连接、建筑自动拼接或三维地形编辑。

## v3 当前视觉

四小幅底图已替换为一幅连续园林：上方大型主宅、外围林木粉墙与右侧水岸，中部和下部为开阔地面。四庭名称只是经营分区定位，不再切换背景。场景内坐标统一映射到大地图，缩放和平移只改变相机，收益和容量不受视觉缩放影响。初始全园视角，添景时定位至当前庭，支持 100%–350% 缩放。移动景物时隐藏原位置的图像，用虚影预览，取消恢复。
