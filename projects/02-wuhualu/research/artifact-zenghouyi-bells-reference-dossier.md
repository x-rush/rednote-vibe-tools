# 物华录 · 曾侯乙编钟参考证据包

状态：`REFERENCE READY WITH COUNT GATE / OFFICIAL OVERVIEW ONLY / PROMPT FREEZE NEXT`。馆方主图分辨率有限，但能约束整体钟架与悬挂层级；正式重构必须以文字资料核销数量和分组，不能让模型自由增加或删减钟体。

## 1. 内容与权威来源

- 正式 ID：`artifact-zenghouyi-bells`；正式名称：曾侯乙编钟。
- 湖北省博物馆馆藏页：https://m-www.hbww.org.cn/p/4695.html 。
- 1978 年湖北随州曾侯乙墓出土，战国早期。
- 馆方记录钟架长 7.48 米、高 2.65 米，呈曲尺形；全套 65 件，分三层八组悬挂。
- 分组字段：上层三组共 19 件钮钟；中、下层五组共 45 件甬钟；另有一件楚惠王赠送的镈钟。19＋45＋1＝65。
- 钟、钟架和挂钟构件上共有铭文 3755 字，内容涉及编号、记事、标音和乐律理论。AI 图不得生成或临摹可读铭文。
- 每件钟能奏出呈三度音程的双音；整套音域跨五个半八度，中心音区十二个半音齐备。页面不把“双音”误写成同时敲击必然发两个音，而应说明不同敲击部位可得双音。
- 内部形态参考：`references/artifact-zenghouyi-bells/official-01.jpeg`，来自上述馆藏页；只供曲尺形钟架、三层悬挂、大小递变、红黑漆木横梁与青铜支架关系核验，不进入发布包。

## 2. 不可改变的结构

1. 整体是呈曲尺形转折的铜木钟架，不是单排乐器墙、拱门、舞台布景或对称祭坛。
2. 三层悬挂关系必须清楚：上层钮钟体量较小，中下层甬钟逐渐增大；不得把所有钟画成同一尺寸。
3. 数量事实为 65 件、八组。由于移动端和合理遮挡，正式主图不要求每一件都可被肉眼逐数，但提示词必须避免明显少量化、无限复制或错层；页面以文字核销数量，不宣称用户能从图像准确数出 65 件。
4. 钟架为铜木复合结构，横梁具有红黑漆木视觉，承重支架为青铜构件；不能全部变成金属脚手架或现代木架。
5. 钟体应保持先秦编钟的合瓦形／扁椭圆截面和钮钟、甬钟差异，不能变成圆口西式钟、教堂钟、铜锣或风铃。

## 3. 事实与解释边界

- “改写世界音乐史”“世界第八大奇迹”等属于传播评价，不作为题目硬事实。
- 不将现代演奏复制件、舞台演出布景或灯光秀照片当出土原器参考。
- 铭文数量和音乐性能由馆方文字卡呈现；AI 画面只负责整体结构和尺度感，不能生成伪铭文来证明知识点。
- 馆方 65 件统计包括 19 件钮钟、45 件甬钟和 1 件镈钟；其他页面若写“64件编钟”通常只统计钮钟与甬钟，项目采用馆方本页的整套 65 件口径并解释组成。

## 4. 项目需求适配卡

- `projectStyle`：闭馆后的现代博物大展厅／暗柜延伸，深炭背景、克制暖光、红黑漆木横梁和旧青铜形成唯一大幅横向场景。
- `pageRole`：物华录中唯一超宽大型组合器揭晓主图；派生“曲尺钟架／三层分组”和“钮钟／甬钟大小递变”两级线索。
- `interactionMoment`：用户从“不是一口钟，而是一整套礼乐系统”确认答案。
- `emotionalGoal`：恢宏、秩序、肃穆、有尺度感；不做音乐节舞台、金色宫殿或奇幻召唤阵。
- `seriesBaseline`：沿用物华录暗柜、象牙藏品签和 AI 性质标签；因器物约 7.48 米长，正式 UI 需要横向主图或可平移观察，不能强塞成竖向小物件。
- `avoid`：钟数明显过少、无限复制、全钟同尺寸、直线单排、现代脚手架、教堂钟、风铃、铜锣、舞台演员、灯光秀、可读伪铭文、金色仙宫。

## 5. 资源与验收计划

- 首选生成 16:9 或更宽的完整组合母版，再确定性派生 4:5 分享档案版；UI 揭晓展柜使用横向母版 `contain`，避免 65 件在手机屏缩成噪点。
- 线索 A 裁钟架转折、三层横梁和支架；线索 B 裁上层小钮钟与下层大甬钟的尺度递变，不重新生成钟体。
- SVG fallback 只表达曲尺转折、三层和由小到大的悬挂关系；不绘制 3755 字铭文，也不假装精确复刻 65 个轮廓。
- 生图通过条件：整体曲尺形、三层、上小下大、铜木复合关系和密集但有序的成套感成立；明显少于合理规模、变成直墙或舞台即拒绝。
