# 浏览器验证

运行 `node qa/browser-check.mjs`。最新截图和报告生成在 `qa/output/`，不进入构建和版本控制。测试使用独立浏览器配置，运行结束清理本次配置。

验证 375 / 390 / 430 CSS px 的首页、人物列表与选择、来电设置、来电与通话、聊天和朋友圈编辑与预览。另验证 844 × 390 实际横屏。每种状态叠加 24px 系统安全区和左右宿主按钮。

功能覆盖：新增和编辑人物、跨画面同步名字与头像、点赞多选、指定评论人、临时照片、文字持久化、通话静音与挂断。音频播放顺序、等待实际播放结束、暂停及取消由单元测试覆盖。

没有实际 MP3 或小红书真机验收。没有 CSS 旋转模拟横屏入口。

根 QA 目录中的历史 PNG 与 `profile/` 仅为旧版生成物，删除被环境自动审批拦截，已排除版本控制；它们不参与运行和构建。
