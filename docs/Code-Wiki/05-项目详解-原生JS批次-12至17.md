# 05 · 项目详解 · 原生 JS 批次（12-17）

> 2026-10-18 维护：当前仓库有 30 个项目目录、29 个工作区包（28 个 H5 工程、1 个 Skill、1 个静态原型）。本册原有实现细节主要覆盖 01–25；新增项目见 [10 分册](10-项目详解-新增批次-26至29.md)，当前目录与状态见 [仓库现状记录](../00-总控与共用/57-仓库现状与文档维护记录.md)。具体版本与验收以对应项目现状文件和证据为准。


这一批为压缩包体放弃了 React：**零 npm 依赖**，源码为 ES Module 原生 JS，构建/测试全靠项目内 Node 脚本。命令统一为 `dev / preview / lint / test / build`（12-15 走 `scripts/*.mjs`，16-17 走 `tools.mjs`），测试用 Node 原生 `node --test`。

## 12-tomato-garden · 番茄小院

- **定位**：专注计时种番茄：专注时长养植物、收进小院图鉴。
- **结构**：`src/app.js`（主循环与交互）、`src/engine.js`（纯逻辑）、`src/art.js`（程序化 SVG 植物）、`content/content.json`。
- **关键函数**（[src/engine.js](../../projects/12-tomato-garden/src/engine.js)）：
  - `freshState()` — 存档信封默认值（`STORAGE_KEY = 'tomato-garden-v1'`）。
  - `startSession / togglePause / settle / collect` — 专注会话生命周期：开始（校验分钟数）、暂停（剩余时间换算）、结算（分钟→植物进度→记录）、收获（进图鉴、进度清零）。
  - `stageOf(plant, minutes)` — 累计分钟映射生长阶段。
  - `remaining(session, now)` — 兼容暂停态的剩余时间。
- **特点**：47 号文档用它当首屏构图诊断样本（植物应为视觉中心）；`art.js` 程序化 SVG 是"代码画植物"的参考。

## 13-jelly-atelier · 果冻慢慢

- **定位**：制作、装饰、把玩和收藏果冻的 3D 观感工坊（Canvas 伪 3D）。**48 号"捏捏工坊"的直接分界对象**（果冻=凝固的透明；捏捏=会变形的软体）。
- **结构**（`src/` 下 20+ 个扁平模块）：`engine.js`（纯逻辑+动效数学）、`studio.js`（工坊主控）、`pour.js`（倒液）、`press.js`（按压）、`mold-editor.js` / `custom-geometry.js` / `contour.js`（自定义模具轮廓）、`decorations.js` / `toppings.js`（装饰）、`collage*.js`（拼贴收藏）、`share-card.js`、`sound.js` / `sound-texture.js`、`drawing.js`。
- **关键函数**（[src/engine.js](../../projects/13-jelly-atelier/src/engine.js)）：
  - `clamp / smooth` — 基础 easing 工具。
  - `sampleUnmold(progress)` — **脱模全时间线**：moldY/moldX/moldAngle/moldOpacity/jellyLift/stretch/bounce/camera 多通道，bounce 用衰减正弦 `sin(elapsed*15)*exp(-elapsed*2.5)`。47 号 §4"动效描述受力"的落地范本。
  - `pokeWave(age, height, distance)` — **按压形变波**：随时间与距离双衰减的正弦波，乘按压高度权重。
  - `pourAmount(amount, seconds, layer, rules)` — 倒液速率积分（分层上限）。
  - `mulberry32(seed)` — seed PRNG。
  - `cleanCollection / addCollection / cleanRecipe / cleanRecipeCollection` — 存档清洗（id 白名单、上限 18、逐字段校验）。
- **content.json**：molds / flavors / toppings / craft 规则 / customRules / limits / ui。

## 14-tongfu-rhythm · 武林外传：同福客栈风波再起

- **定位**：四键节奏挑战与分段练习（武侠主题曲目）。
- **结构**：`src/engine.mjs`（判定引擎）、`studio.mjs`（练习模式）、`audio-clock.mjs`（音频时钟）、`verse-chart.mjs`（谱面）、`chart-io.mjs`（谱面导入导出）、`gesture-audit.mjs`、`verse-lab.js`；`scripts/build-minitool.mjs`（音频打包）。
- **关键类与函数**（[src/engine.mjs](../../projects/14-tongfu-rhythm/src/engine.mjs)）：
  - `RhythmEngine` — 判定核心：`hit(lane, t)`（pending→holding，perfect/good 判定、双押 tapChords 去重）、`release(lane, t)`（长条结算/broken）、`accrue(n, t)`（长条按秒积分）、`suspend(t)`（页面切出挂起+resumeDeadline）、`update(t)`（miss 扫描）、`drain()`（事件队列）、`get maxScore / accuracy`、`phraseSuccess / phraseResolved`（乐句达成率 ≥75%）。
  - `validateChart(notes, duration)` — 谱面静态校验（id 唯一、时间合法、同 lane 重叠检测，孤立双击豁免）。
  - `StageTimeline` — 演出时间线：结算展示跟随分数，**不**门控音乐/音符/输入。
- **音频打包**（[scripts/build-minitool.mjs](../../projects/14-tongfu-rhythm/scripts/build-minitool.mjs)，仓库参考实现一）：ffmpeg 转 80k MP3 → Base64 → `release/package/audio-data.js`（`window.TONGFU_AUDIO`）→ 替换 `loadAudio` 为 `atob → Uint8Array → decodeAudioData` → 产物禁止 `fetch/import/import.meta`，单段 ≤ 1 MiB。
- **content.json**：曲目 src、时长、BPM、beatOffset、audioSha256。

## 15-home-renovation-lab · 住进想象 / ROOMISH

- **定位**：纯前端三维装修工具，包含可编辑户型、程序化家具、材质与风格、室内体验、本地方案和清单导出。当前功能与 1.4.12 交付记录见 [README](../../projects/15-home-renovation-lab/README.md)；下列模块地图保留对应实现阶段的入口。
- **结构**：`src/core.js`（几何与平面数据）、`scene.js` / `container-scene.js`（场景渲染）、`interaction.js`、`orientation.js`（横竖屏）、`circulation.js`（动线算法）、`app.js`。
- **关键函数**（[src/core.js](../../projects/15-home-renovation-lab/src/core.js)）：
  - `bounds(rooms)` / `roomAt(plan, x, z)` / `validRoom(plan, room)` — 户型包围盒、房间命中、房间合法性（尺寸界、房间不重叠）。
  - `corners(o, pad)` / `overlap(a, b)` — 旋转包围盒角点 + **SAT 分离轴碰撞**。
  - `placement(plan, item, catalog)` — 家具放置合法性（房间内、留边、非 overlay 家具互不重叠）。
  - `findSpot(plan, def, room, catalog)` — 网格扫描自动找位。
  - `makePlan(template, catalog)` — 按房间类型模板自动布家具（客厅/卧室/厨房/卫生间/餐厅/书房各有默认布置）。
  - `improveTemplate`（[circulation.js](../../projects/15-home-renovation-lab/src/circulation.js)）— 动线改进建议。
- **宿主避让**：本项目是真机截图反馈的主要来源（AGENTS.md 共享记忆由此立项）。

## 16-flower-werewolf · 花少有狼

- **定位**：7 人单机狼人杀（2 狼 1 预言家 1 女巫 3 村民），旅行主题。
- **结构**：`src/engine.mjs`（游戏引擎）+ `src/app.mjs`（UI）。
- **关键函数**（[src/engine.mjs](../../projects/16-flower-werewolf/src/engine.mjs)）：
  - `createGame(seed, characters, roles)` — 角色分配 + **rng 内嵌状态**（`s.rng` 随存档保存，事件序列可回放）+ 玩家 bias 参数。
  - `PHASES = ['deal','night','day','vote','roundEnd','over']` — 回合状态机。
  - `emit(s, event)` — 事件流（id+day 自动编号）；`winnerOf(players)` — 胜负判定。
  - 内部 `ensure()` — 非法动作抛错防御。
  - `s.events / s.audit / s.evidence` — 三个日志数组支撑复盘与测试。
- **测试**：`tests/engine.test.mjs` + `tests/audit.test.mjs`。

## 17-call-stories · 捡手机文学局

- **定位**：来电、聊天与朋友圈叙事创作，包含人物库、单聊/群聊、丰富消息与图片导出。来电播放仍是其中一个模块，以下保留其音频链路说明；完整行为见 [项目 README](../../projects/17-call-stories/README.md)。人物库头像的本机压缩存储按根 AGENTS.md 的 2026-10-13 例外执行，不能再沿用早期“所有头像刷新丢失”的结论。
- **结构**：`src/app.mjs`（主入口）、`src/model.mjs`（剧情模型）、`src/audio-bank.mjs`（音频库）、`src/call-player.mjs`（播放器）、`src/export-image.mjs`（导出图）、`tools.mjs`（构建+音频打包+白名单）。
- **音频链路**（仓库参考实现二，详见 [03 分册 §8](./03-共享架构模式与技术方案.md)）：
  - [src/audio-bank.mjs](../../projects/17-call-stories/src/audio-bank.mjs) — `decode(file)`：Base64 → atob → Uint8Array → decodeAudioData；`create(file)`：play/pause/volume/muted/currentTime + onended 清理 source/gain。
  - [src/call-player.mjs](../../projects/17-call-stories/src/call-player.mjs) — `generation` token 防幽灵响铃、`stop()/setMuted()`、脚本片段调度。
  - `app.mjs` — `createAudioBank(embeddedAudio)` → `createCallPlayer(...)` → ringtone（loop/volume）。
- **构建**（[tools.mjs](../../projects/17-call-stories/tools.mjs)）：`assets/audio/*.mp3` 扫描 → 白名单 + ≤1 MiB → Base64 注入 rolldown 虚拟模块 `embedded-audio` → `dist/app.js`；产物扩展名白名单校验。
- **测试**：[tests/audio-bank.test.mjs](../../projects/17-call-stories/tests/audio-bank.test.mjs) 覆盖停止/清 buffer/WebAudio 缺失/loop/音量/静音/自然结束。
- **历史教训**：本项目上传时 MP3 被平台拒绝，催生了 AGENTS.md 音频门禁。
