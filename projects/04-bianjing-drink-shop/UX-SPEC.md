# 汴京饮子铺：开店一百天 UX Specification

状态：`SECOND-PASS UX SPEC`

## 1. 体验目标

- 5 秒：明确这是能跨多次打开的 100 天经营游戏。
- 前 30 秒：看懂四项状态、天气/情报和今天能做的三类决策。
- 前 5 天：经历经营选择、事件和账簿反馈，理解不是纯随机故事。
- 第 100 天：资产、人物回响和经营路线共同形成结局。

## 2. 主循环

```text
封面/存档位 → 开张 → 晨间状态 → 备货与定价
→ 开门锁定 → 营业 → 当日事件 → 选择（不可撤销）
→ 日终结算 → 账簿 → 自动存档 → 下一日 / 结局
```

完整日结算保存主存档；事件提交后保存安全快照。损坏时优先回上一日安全快照。

## 3. 页面规格

### B01 封面/存档位

主标题、经营承诺、100 天目标。存档位显示：第几日、资金、口碑、更新时间、当前剧情短标签。

- 空存档主动作 `今日开张`。
- 最近存档主动作 `继续第 N 日`。
- 覆盖/删除存档二次确认。
- 结局册为次入口，不抢主流程。

### B02 开张设定

店名若允许自定义须有长度限制和默认名；选择基础经营倾向时不得伪装成不可逆职业。确认后创建 seed、基础状态和第 1 日存档。

### B03 晨间状态

层级：第 N 日/天气 → 四状态（资金、口碑、体力、人情）→ 今日情报 → 店铺场景 → `准备开门`。

- 数字变动有昨日对比，但不预告事件。
- 四状态必须同时有名称、数值和趋势，不只靠图标。
- 背景不能承载关键文字。

### B04 备货与定价

6–8 种饮子按商品行展示：图/名称、库存、成本、备货数量、售价、预计占用。顶部实时显示现金和体力预算。

- 开门前可反复修改，不写完整日存档；离开页保留草稿。
- 不能购买超过资金/体力的数量；说明限制原因。
- 不显示精确销量预测，只给需求线索。

### B05 经营策略

当日最多选择冻结数量的策略项。显示代价与方向，不提前显示精确随机结果。与备货共同在开门确认页汇总。

### B06 开门确认

汇总备货、售价、策略与剩余资金/体力。主动作 `开门营业`；提交后锁定当天晨间决策并保存。

### B07 营业

店铺场景、时段、客流反馈、商品售出简讯。不是实时烹饪，不要求连续点击。提供 `快速结算营业过程`。

低性能/减少动画模式使用静态场景和文字流水。

### B08 当日事件

人物/场景 → 事件正文 → 2–3 选择。先选中，显示选择摘要；确认前可换，确认后不可撤销并立即保存安全快照。

不预告精确数值，允许显示定性风险如“会消耗一些体力”。快速双击只提交一次。

### B09 日终结算

先给一句经营反馈，再按可解释顺序列：销售收入、原料成本、固定成本、事件影响、净变化。四状态显示前后值。

异常数值不能只显示 NaN/空白，应进入恢复页面。

### B10 账簿

按日期查看有限历史、商品表现、事件摘要和剧情 flags 的用户可懂结果。不展示开发内部 flags。

### B11 里程碑

第 5/10/25/50/75/100 日或冻结节点展示短回顾。可跳过，不改变数值。里程碑美术优先复用场景与人物，不增加无必要插画。

### B12 破产/提前结局

清楚解释导致关门的资金链/体力等状态，显示关键转折而非羞辱。主动作 `带着经验重新开店`；次动作 `查看本局账簿`。

### B13 第 100 日结局

层级：结局名与主画面 → 最终资产/状态 → 经营路线 → 人物回响 → 解锁结局册 → 重开/回封面。

不只按钱排序好坏；8 结局各有条件与代价。

### B14 结局册

已解锁显示名称、关键图和达成摘要；未解锁显示朦胧场景与非剧透提示。新结局不覆盖旧收藏。

### B15 存档损坏

优先提供 `恢复到第 N 日安全快照`，说明会失去哪一天未完成进度。安全快照也坏时才提供重开；结局收藏独立保护。

### B16 IndexedDB 不可用

允许重试；如进入临时试玩模式，明确只能体验当前会话前若干天，不能假装完整存档已保存。

## 4. 状态矩阵

| 功能 | Loading | Empty | Error | Success | Partial |
|---|---|---|---|---|---|
| 存档 | 读取短状态 | 暖空档+开张 | 安全快照/重试 | 继续 | 结局册可独立读取 |
| 备货 | 即时计算 | 库存为零是正常状态 | 数据异常阻止开门 | 草稿可确认 | 某商品图失败文字可用 |
| 事件 | 事件选择骨架 | 无事件走普通日结 | 引用错误回普通日结并记录 | 选项效果应用 | 插图缺失不影响选择 |
| 日结 | 短结算 | 不适用 | 回安全快照 | 保存下一日 | 动效跳过仍显示完整明细 |

## 5. 响应式与无障碍

- 375px：HUD 两行，四状态 2×2；决策区滚动，底部按钮不遮最后一项。
- 390px：基准单屏场景；事件和账簿使用底部页/独立页而非嵌套小弹窗。
- 430px：增加场景宽度，数值列仍可扫读。
- 桌面：主场景和经营面板可左右并排，核心移动体验不改变。
- 所有数字变化有文本和正负号；声音不是唯一反馈。
- 商品数量控件可键盘调整并有上下限说明。

## 6. 页面反推的资源候选

| 槽位 | 媒介 | 数量判断 | 考据门禁 |
|---|---|---|---|
| 主店铺场景 | 分层 WebP | 先 1 个白日基准，再反推 3 时段是否用色调变体 | 宋代店铺、招幌、家具参考 |
| 天气/时段 | 透明覆盖层/CSS | 晴/雨/夜等按页面需要 | 不改变建筑事实 |
| 饮子与器皿 | 透明 WebP 或核验 SVG | 6–8 | 原料、器皿、盛装参考 |
| 顾客 | 透明半身 WebP | 先 3 个身份基准，再确认 12–16 与表情差分 | 宋代身份服饰/发式参考 |
| 事件类别 | SVG | 系统一套 | 不需要 AI |
| 结局 | 场景+角色合成或独立图 | 高保真结局页后决定是否 8 张独立 | 与既有角色/场景一致 |
| 声音 | 短音效 | 开门、倒饮、铜钱、雨/市声 | 来源/许可记录，可静音 |

## NPC 增量状态

首次三句可跳过；晨间一句风险、事件后果方向、濒危取舍与百日回顾均按经营状态生成；头像召回账目规则；存档失败允许本日继续。详见 `NPC-SPEC.md`。
