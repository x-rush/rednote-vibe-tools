# 花少有狼

七人单人旅行主题狼人杀。玩家随机嘉宾与身份，其余六位由本地规则驱动。所有玩家界面只显示化名，发言为原创游戏文案。

## 运行

使用现代 Node.js（建议 22+）及 pnpm，不需要安装项目依赖：

```sh
pnpm lint
pnpm test
pnpm build
pnpm dev
```

默认预览 http://127.0.0.1:4316 。可用 PORT 环境变量调整端口。将 dist/ 发布到任意静态 HTTP(S) 托管即可；不需要后台服务。

## 玩法

七张嘉宾卡和两狼、一预言家、一女巫、三平民的身份牌独立洗牌。首轮讨论后，玩家可质疑、引用公开证据、支持、辩护或声称预言家。电脑会回应并结合公开记录、自己的技能信息选择投票。身份仅在自己手牌和终局复盘中展示。

平票复投一次，再平票无人出局。女巫每夜最多用一瓶药，仅首夜自救。所有夜间效果统一结算。出局可旁观到结局。

## 工程边界

- 无项目依赖、外部模型、运行时 CDN、Service Worker 或必需外部 API。
- tools.mjs 仅用于本地构建、静态预览与检查，不是线上业务后台。
- src/content/content.json 是业务内容唯一源。构建按白名单导出，排除原名、研究映射及图片生成提示词。
- 浏览器只保存结构化游戏状态，不存用户媒体。持有开发工具者可读本地状态，单机游戏不宣称防作弊。
- assets/portraits 为优化后的正式展示素材；assets/candidates 保留生成原图与提示词记录。
- 自动化策略只读取 observe() 返回的合法信息视图，不能访问对手隐藏身份。
- 不支持任意自由聊天或真人联网。
