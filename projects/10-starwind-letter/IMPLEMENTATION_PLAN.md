# 实施计划（供后续 WSL Agent 使用）

## 0. 开始前

- 阅读本目录全部 Markdown 文档和根 `AGENTS.md`。
- 检查同工作区已有项目的技术栈和脚本约定，只借鉴结构，不复制业务内容。
- 确认不新增依赖；如现有工作区无法满足，先报告，不修改根锁文件。
- 建立需求核对表，逐条映射到实现和测试。

## 1. 项目骨架与内容

- 在本目录建立与工作区一致的纯前端项目骨架。
- 提供 lint、test、build 脚本。
- 将所有 60 条以上星语写入 `src/content/content.json`。
- 建立内容解析、校验、洗牌和近期去重逻辑。
- 不在组件或样式中硬编码业务句子。

## 2. 场景静态构图

- 完成深蓝房间、窗外星空、月亮、窗框、窗扇、线帘、月光和句子区域。
- 先在 375/390/430 三种宽度验证构图，再开始复杂动画。
- 建立明确的窗外、窗口、帘子、室内和文字图层关系。

## 3. 状态机与轮播

- 实现 `loading → spinning → slowing → selected → wind → window-opening → stars-entering → result → resetting`。
- 以统一时间线或明确阶段事件驱动 CSS/SVG/Canvas，避免各自动画失步。
- 实现一次点击、立即反馈、减速、随机落句和连续点击锁定。
- 实现最近 8 次结果去重。

## 4. 自动开窗动画

- 线帘使用适合独立线条形变的 SVG、Canvas 或等效方案。
- 动画只由状态机启动，不响应用户拖动。
- 窗框先颤动，窗扇再向室内打开；月光随角度扩大。
- 以真实设备触控测试，确认点击不会被透明帘子或 Canvas 拦截。

## 5. 星粒子

- 实现星尘、拖尾粒子、主角星三层。
- 使用窗口蒙版或裁切区保证粒子从窗外穿过开口。
- 将所有主角星生成点限制在窗外区域。
- 保证文字可读，并在重置时清理全部粒子和动画句柄。
- 根据视口和性能等级调整粒子数量。

## 6. 结果与重置

- 星星围绕句子减速，主角星落位。
- 显示辅助文案和“再听一次星空”。
- 重置中锁定操作；窗户合拢、帘子垂落、场景恢复一致首帧。
- 连续完成至少 10 次循环，检查内存、帧率和状态。

## 7. 声音、降级与可访问性

- 音效必须在用户首次点击后才尝试启用。
- 音频失败或静音不影响动画。
- 实现 `prefers-reduced-motion` 简化版本。
- 为可点击元素提供语义、焦点和键盘触发；焦点样式不能破坏最终截图状态。
- 页面失焦时暂停或安全同步统一时间线。

## 8. 测试要求

至少覆盖：

- 内容文件可解析、ID 唯一、句长和类别合法。
- 点击只触发一次减速和一次主动画。
- 状态转换顺序正确，非法状态不响应操作。
- 最近结果去重。
- 重置清理定时器、粒子和动画状态。
- reduced-motion 分支仍保持正确叙事。
- 窗户打开前主角星不得进入室内。
- 页面失焦和恢复不会造成状态分裂。

## 9. 视觉 QA

- 在 375、390、430 CSS px 宽度逐一截图首屏、选中态、开窗态、星星进入态和结果态。
- 用非零 `--safe-area-inset-top` 验证音效等顶部控件。
- 确认星星有连续“窗外 → 窗口 → 室内”的轨迹。
- 确认句子始终清晰，不被帘子或粒子遮挡。
- 确认窗口、月亮和帘子在短屏及长屏上不被关键裁切。

## 10. 完成门槛

- `pnpm lint && pnpm test && pnpm build` 全部通过。
- 无运行时网络依赖、控制台错误、横向滚动或未清理的调试代码。
- 不删除测试、不降低断言、不修改工作区根文件。
- 最终交付说明列出改动文件、测试结果、三种宽度验证证据和仍存在的风险。
