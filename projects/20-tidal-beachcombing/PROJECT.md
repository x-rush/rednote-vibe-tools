# 项目20｜退潮赶海：详细立项

> 首版范围更新：用户要求增加首版内容。正式交付数量与耐玩机制以 [CONTENT-PLAN.md](./CONTENT-PLAN.md) 为准；下文原小P0数量改作内部视觉/手感切片，不代表最终首版范围。原玩法规则继续生效。

日期2026-09-19；状态：已实现可玩版本；完成范围与待完善项以 [当前实现核对](CURRENT-IMPLEMENTATION.md) 为准，以下详细设计仍是验收目标。所有生物行为、概率和潮汐为本地游戏规则，不提供真实潮汐或采捕指导。

## 1. 体验目标和范围

黄昏退潮，玩家观察沙孔、石边水纹、露出的壳尖，选择翻石或挖沙，看到躲藏物后亲手抓取。核心是“每次翻开都有悬念”，空点也有沙、水和小生物运动的反馈。
每次海滩游玩3～6分钟，无涨潮强制驱逐；收获即记，随时结束。P0一片海滩包含石滩/湿沙/浅潮池3个连通小景，6种可发现海边生物+4种贝壳/海玻璃收藏物，采用插画写实外观与简化行为。
首15秒内完成第一次翻石，45秒内体验一次挖沙；首次引导样本明确固定一只小蟹，不强制稀有收获。

## 2. 完整循环和状态

观察→锁定石头或沙区→翻石/挖掘→逐步露出→抓取/捞取→入桶或记录后放回→继续。
- 全屏可互动海岸，首屏无选择玩法菜单；底部只有手/铲/小网、桶、暂停。
- 手可翻石/拾壳/抓可见蟹；铲只挖湿沙；网只捞浅池，光标随工具变化，目标有轻轮廓反馈。
- 工具自动建议但不自动替玩家切换；点不适合目标一次出现短提示。
- 石头翻开后保持位置，允许翻回；铲坑持久，不每次切景填平刷新。
- 生物入桶展示后提供“记录并放回”，放回不撤销发现，不复制奖励；不引入售卖价值。
- 结果显示收获实物布局、遇见记录、挖过/翻过的数量；相同种类按个体外观变体展示。

## 3. 操作与手感

| 操作 | 手势 | 反馈和初值 |
|---|---|---|
| 翻石 | 按住石边向一侧拖 | 前10px轻受阻，随后围绕另一侧支点旋转；约60%完成度越重心，自动落稳200ms |
| 挖沙 | 铲模式短划 | 沿路径减去局部沙高，每铲深1层，沙粒沿划动方向抛出，凹坑边缘保留湿痕 |
| 拾壳 | 点已露出的静态物 | 轻抬起沥水，300ms入桶 |
| 抓蟹 | 按住附近，再拖到桶 | 手/夹具影子与蟹同平面，按下时才判抓住；落点看得见，有约80ms宽限 |
| 捞池 | 拖网扫过水域 | 网前缘产生水纹，网口中心经过实体才捕获，不是整段轨迹任意吸附 |

翻石松手未过重心就回落，先有阴影和水纹预警；不会压伤已出现生物。pointercancel直接安全复位，不当正常松手。石头重心阈值需随投影大小归一化。
挖掘宽度为当前铲口宽，路径插值防快速划动漏挖；一次划动上限等价3铲，避免连续乱画瞬间清空全地图。每处3～6层上限，挖到底清楚显示砂砾基底与“这块已经挖到底”。
小蟹露出后先停350～700ms，再侧走；活动区域限定在可见操作区，可追到邻石，逃逸前有可见路线，不瞬移消失。新手与辅助模式将速度降到65%，收藏不扣分。
辅助：翻石长按后拖短距离；挖沙点按铲一次；蟹可点选短暂锁定再点桶，免高速拖拽。按下即有实体反馈，手工具不作长滞后。

## 4. 未知生成与线索公平性

生成海滩seed时固定每个石下/砂层/池底的个体ID、深度与轮廓；每次翻动/开抽屉不重新抽。
普通生成每景10～14个候选点，50%～70%有效；有效点包含常见/少见/特别条件权重70/25/5。具体生物按生境过滤再归一化；每点0～3个实体，群体出现有因果关系。
- 沙孔对应浅层活物概率提升但不保证必中；露出的壳角对应静态贝壳，不生成一只完全无关巨蟹。
- 石下潮湿阴影、小水纹提示活物；空石也可能有小气泡/沙底纹，但不能用罕见发光骗玩家。
- 掩埋深度在生成时确定。挖错地方就是沙，不在铲落下才把奖励刷进坑。
- 约20%收藏物部分可见，50%有弱线索，其余需要探索；最终比例用新手实测调整。
- 游戏奖励只来自真实暴露并抓到的实体；生物运动用独立随机流，装饰海浪不能影响出货。
- 累计发现和持有分开，放回后仍保留图鉴，禁止重复抓同一ID刷次数。

## 5. 视觉材质设计

色板：湿沙#A98D70、干沙#D9BE92、浅水#78A7A0、礁石#515B57、晚霞#E8AA86。
固定低斜俯视近景，以水/砂/石交界为中心；远处晚霞水带占上部约15%，不用天空挤掉可挖面积。
- 水：清澈浅水底纹+折射偏移+低频反射；石头入水线有暗湿边，浪来时反光增加，退去后沙保持湿润。
- 挖沙：高度/深度场驱动凹坑遮罩和边缘阴影；每铲揭露一点壳面，不能均匀擦除整张图片。湿沙以成团碎粒为主，干边有少量散粒。
- 翻石：顶部/侧面/底面材质不同，转动时阴影形状变化；底部更暗更湿，滴落2～4颗水珠。
- 生物：蟹有停顿、试探、侧移；壳表有少量湿亮高光，避免橡胶玩具质感。
- 揭晓：先见局部轮廓或细腿，再随遮挡减少显露，完整出现后才出物种小标签。
- 声音：沙铲摩擦、石头落地低响、浅水咕噜、壳碰桶，按操作强度微变。
- 视觉样板一镜串联翻石→蟹侧走→抓取→挖出半枚贝壳→潮水漫过浅坑，不能只做静态沙滩。

## 6. 技术栈与方案

TypeScript + WebGL1专用2.5D渲染 + DOM/CSS，Canvas2D同逻辑降级；Rolldown经典IIFE。
- 地形以CPU 96×96高度格+稀疏实体记录；挖掘更新局部格，上传遮罩小区域。被埋物暴露用格覆盖比例，不读回GPU。
- 石头为小网格/多面精灵翻转，定支点，不需要通用刚体引擎。
- 水用天空反射图+低幅法线+池底纹理，局部波源≤16；潮水采用慢速边界遮罩，不做流体体积模拟。
- 生物用精灵分段或少量帧图集，状态机 hidden→startled→moving→caught/released；逻辑最多16个活动生物。
- 沙粒默认≤350、低档≤100，网格更新≤20Hz，输入/模拟60Hz；纹理+FBO默认≤40MiB。
- 低档保留所有坑洞、隐藏深度和蟹的路线，只降低水纹/沙粒/阴影精度；Canvas版本用带坑遮罩的精灵层，逻辑结果相同。

## 7. 数据、存档与内容

content.json：zones、spawnTables、creatures、collectibles、terrain、tools、gestureTuning、visuals、copy、audio、layout、quality。
实体字段：id、speciesId、zoneId、position、buriedDepth、sizeVariant、behaviorProfile、collectionStatus。
保存海滩seed/版本、挖掘高度量化数组（数字/短字符串结构化编码，非图像Base64）、石头姿态、实体状态、桶/图鉴；逻辑格分块保存，总结构化存档≤200KiB。
网格状态不得保存成canvas截图。生物运动在暂停时冻结，重载按已存可见状态恢复，不让未操作的生物后台逃掉。

## 8. 实施与验收

P0：翻石手感+固定小蟹→局部挖沙/揭露→抓取→完整单景→湿沙水质切片→三景内容→图鉴/辅助/存档→交付。
P1：夜潮光照、更多壳纹、固定seed挑战。无真实潮汐API、无联网竞赛、无一键清屏。
专项测试：
1. 每铲只改目标附近的沙深；未到深度不能点击穿透。
2. 快速划动/低帧率与慢划等距离下挖掘量受相同预算约束。
3. 石头反复翻动只揭同一组内容；取消不导致石头/生物卡死。
4. 蟹逃逸路线始终在可见可操作区域，不穿宿主按钮区；辅助路径能抓同样个体。
5. 捕获、放回、再捕获不重复图鉴统计，满桶展示不会丢数据。
6. 水纹、阴影、坑深在高低档都对齐，不能一降档贝壳浮在沙上。
7. 首次体验5人中4人无需文字教程能翻第一块石头，3人能根据线索决定下一处挖哪里；记录无目的乱划比例。
