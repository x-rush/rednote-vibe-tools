# 八项目美术资源考据与参考图门禁

状态：`MANDATORY ASSET POLICY`  
生效日期：2026-08-24  
最近修订：2026-08-25（项目需求与画风适配升级为逐资源硬门禁）

## 1. 总原则

任何具有现实、历史、典籍或固定文化原型的美术资源，均不得只凭文字印象或模型自由想象直接生成发布稿。AI 负责艺术化转译，不负责创造事实；同时也不得脱离项目设计系统任意选择画风。事实准确与项目适配必须同时成立。

适用对象包括但不限于：

- 《山海经》异兽与神祇；
- 博物馆文物、器型、纹样和材质；
- 古代服饰、发式、官职标识和人物身份；
- 古建筑、店铺结构、家具、器皿和招幌；
- 历史饮子、原料、制作工具与盛装方式；
- 甲骨文、金文、篆书及其他古文字形；
- 有具体生态原型的动物、植物与自然物；
- 现实场景、用品和职业装备。

## 2. 参考证据包

每类主资产在生成前必须建立 reference dossier，至少包含：

1. **文字一级证据**：原典、馆藏著录、考古报告或权威机构说明。
2. **图像一级参考**：馆藏实物图、公共领域古画/刻本、权威数字馆藏扫描。
3. **图像二级参考**：学术论文中的版本比较、可靠复原图或专业出版物。
4. **形貌不可变项**：数量、结构、器型、材质、纹样位置等不能艺术化改变的部分。
5. **可艺术化项**：姿态、构图、气氛、有限配色、纸张质感和不改变事实的细节整理。
6. **争议项**：版本差异、后世混入、学界未定或常见误传。
7. **版权与用途**：参考图是否仅供内部研究，能否在产品中直接展示或改编。

没有参考证据包的资产状态只能是 `planned` 或 `reference-required`，不得标记为 `reviewed`、`shipped`。

## 2.1 项目风格适配包

每个生成任务除 reference dossier 外，还必须引用对应项目的 `DESIGN.md`、页面角色和已批准系列基准，并明确：

1. 资源出现在哪个页面、哪个交互时刻，承担说明、情绪、叙事、识别还是装饰功能。
2. 对应项目的世界观、时代、媒介、色板、轮廓、材质、光照与审美禁区。
3. 在同页面中必须让位给哪些信息，例如题干、证据、选项、经营数值或主按钮。
4. 在 160px 缩略、结果卡、分享卡或背景裁切中的最低可识别条件。
5. 与同系列基准图一致的项目特征，以及必须避免的跨项目风格串用。

没有明确项目风格与页面角色的提示词，即使拥有现实参考图，也不得进入正式生成批次。

适配包不得只写抽象风格词。每张正式资源必须填写并在二检中逐项核销：`projectStyle`、`pageRole`、`interactionMoment`、`emotionalGoal`、`seriesBaseline`、`avoid`。字段定义与通过标准以《34-八项目 UI 与美术自检验收规范》的“项目需求适配卡”为准。

通过事实考据不代表通过项目适配；通过单图审美不代表通过页面适配。资源必须在目标 UI 的真实尺寸和状态中复检后，才能从 `generated` 升级为 `reviewed`。

## 3. 参考优先级

从高到低：

1. 博物馆、图书馆、档案馆、大学数字典藏与权威古籍数据库。
2. 可追溯到具体馆藏号、版本、卷页的扫描图。
3. 同行评审论文、研究专著和权威出版物。
4. 有明确作者与创作说明的现代复原图，仅作为构图或当代接受史参考。
5. 普通资讯网站、社交媒体、素材站和无来源转载，只能作为“常见误读/流行形象”对照，不能作为事实依据。

禁止把 Pinterest、堆糖、花瓣、无来源自媒体图作为唯一参考。

## 4. 异兽专门规则

每只异兽必须分别整理：

- 原典原文和具体篇章；
- 形貌要素清单；
- 行为、职掌、征候与栖息事实；
- 明清或其他可追溯历史图本中的形象；
- 不同版本的形貌差异；
- 后世传统与正文的边界；
- 现代审美调整的允许范围。

生成时至少输入一张可追溯历史图像参考；如早期图像失传，应明确写“现存参考来自明清或后世图本”，不能宣称是先秦原貌。

允许艺术化：

- 改善比例与可读性；
- 调整姿态与构图；
- 使用统一墨线和矿物色；
- 让面部不至于猎奇丑陋；
- 在不改变关键结构的情况下提高审美辨识度。

禁止艺术化：

- 改变头、尾、足、翼、角、眼等关键数量；
- 把原典危险性完全洗成治愈萌宠；
- 将其他异兽的职掌、器官或后世故事移植过来；
- 为“好看”加入盔甲、王冠、法器、现代饰品或仙侠特效；
- 把争议说法伪装成唯一历史事实。

## 5. 文物与古文字专门规则

- 文物猜谜的器型、纹饰、缺损和比例必须以具体馆藏实物为准。
- AI 重构图必须显著标明“艺术化重构”，不能冒充馆藏照片。
- 古文字形优先使用可追溯拓片、字编或权威字形数据库；不得让图像模型自由书写甲骨文、金文或篆字。
- 字形演变图使用人工核验的 SVG/高分辨率线稿，不用 AI 猜写。

## 6. 生成与验收流程

```text
内容 ID 冻结
→ 建立参考证据包
→ 锁定不可变形貌
→ 选定可艺术化范围
→ 生成一张基准图
→ 逐项对照参考图审核
→ 修订
→ 资源尺寸/格式优化
→ 写入 manifest
→ 才可接入正式 UI
```

审核表至少包含：

- [ ] 对应正确内容 ID。
- [ ] 关键形貌与一级证据一致。
- [ ] 数量和结构准确。
- [ ] 未混入其他对象特征。
- [ ] 争议项没有被写成定论。
- [ ] 艺术化提升审美但未改写事实。
- [ ] 参考来源和访问日期已记录。
- [ ] 版权状态允许当前用途。
- [ ] 无文字错误、伪古文、乱码或水印。
- [ ] 移动端缩略图仍可辨认。

## 8. 当前陆吾处理

2026-08-24 生成的陆吾图只使用了冻结原典文字约束，未向生成模型输入可追溯历史图像，因此：

- 可用于确认墨线、纸感、矿物色和 UI 合成方向；
- 不得视为陆吾历史形象已经验收；
- 不得进入发布包；
- 补齐陆吾 reference dossier 后重新生成或进行参考驱动修订。
