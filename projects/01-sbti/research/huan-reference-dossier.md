# 讙参考证据包（生成前冻结）

## 用途与结论

- 项目：SHBTI 山海兽格
- 结果型：`RVES 定声型`
- 正名：`讙`（读 huān），不是现代动物名“獾”。代码目录继续使用稳定 slug `huan`。
- 用途：结果卡、接近型对照卡、图鉴与分享卡主视觉依据。
- 事实优先级：以《山海经·西山经》翼望山条文字为硬约束；清代佚名《山海经图》与后世图像只帮助理解狸形、独眼和三尾的构图，不覆盖数量字段。

## 原典硬字段

冻结形制为：

1. **状如狸**：采用野猫／豹猫一类的细长猫科轮廓，不画成现代蜜獾、浣熊、犬或虎；
2. **恰好一目**：唯一一只眼位于面部中轴，不保留成对眼眶、闭眼痕迹或额外眉眼；
3. **恰好三尾**：三条尾巴从同一尾根自然分出，三条尾端均可独立计数；
4. **声拟百声**：只用环绕声纹、回声层次和张口呼号的动态表达，不画一百张嘴、乐器、文字或人形歌者；
5. “可以御凶”“服之已瘅”只作为古籍记载展示，不转写成现实疗效、护身保证或食用建议。

## 文字与版本证据

- 《山海经·西山经》翼望山条：“其状如狸，一目而三尾，名曰讙，其音如夺百声”。
- 中国哲学书电子化计划字词条可定位同一段原文。
- 识典古籍《山海经图·兽族三》标注为清代佚名本，并列出“讙，状如貍，一目三尾，出翼望山”。
- 《太平御览》等后世引文可见二尾、《事林广记》等又有五尾／獂的记法。这些只记为版本异文，正式主图不混入。

## 艺术化边界

允许：

- 将后世图中的扑跃狸形转译为克制、俊逸的国风幻想猫科；
- 使用暖灰、墨黑、石青或少量朱砂表现毛色层次；
- 用三条尾巴形成扇面式声场节奏，但尾根必须符合解剖结构；
- 以淡金声纹表现“百声”，不生成文字或具象动物头像。

禁止：

- 两只眼、隐藏的第二眼、眼罩式处理或额头眼加正常双眼；
- 少于或多于三尾；
- 九尾狐、独眼虎、浣熊、蜜獾、犬科、Q 版宠物或恐怖怪物化；
- 多口、多头、翅膀、角、甲胄、法器、文字、印章和水印；
- 将“御凶／治瘅”包装成现实功能承诺。
