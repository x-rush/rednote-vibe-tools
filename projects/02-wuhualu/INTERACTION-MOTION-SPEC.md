# 《物华录》V2 交互与动效规格

状态：`MOTION HANDOFF / PURE FRONTEND`
基线：`390×844 CSS px`

## 1. 动效命题

V2 的动效不是奖励爆炸，而是“档案被操作、证据被发现、展柜被点亮”。每段运动必须回答一个问题：用户刚做了什么、状态改变在哪里、下一步可以做什么。

四条原则：

1. **物理来源明确**：推、拉、揭、压、移、落；不凭空漂浮。
2. **信息先于装饰**：状态文字与可操作区域先成立，动画只是确认。
3. **文物保持稳定**：观察时不晃动、弹跳或旋转文物图。
4. **随时可降级**：所有结果在无动画下仍可理解和完成。

## 2. 运动令牌

```css
--motion-instant: 0ms;
--motion-micro: 140ms;
--motion-fast: 200ms;
--motion-base: 320ms;
--motion-flow: 440ms;
--motion-reveal: 620ms;
--ease-out: cubic-bezier(.22, .72, .24, 1);
--ease-paper: cubic-bezier(.2, .8, .3, 1);
--ease-stamp: cubic-bezier(.2, 1.25, .36, 1);
```

- 微反馈 120–240ms：按钮、观察签、封签、选项。
- 流程转场 280–480ms：抽屉、故事分页、入藏。
- 仪式高潮 500–650ms：开柜、专题完成；同屏最多一个。
- 连续操作不累计等待。动画进行中，系统状态必须已经锁定，避免重复提交。

## 3. 空间语法

| 方向 | 含义 | 示例 |
|---|---|---|
| 从右向左 | 新卷宗进入工作台 | 接案、下一件 |
| 从下向上 | 抽出／取出 | 线索索引、离柜一问 |
| 从中心向外 | 灯光与证据被看清 | 聚光命中、开柜 |
| 从观察台向右下 | 收回个人图录 | 入藏 |
| 从许照一侧向工作台 | 搭档提供材料 | 递线索、恢复说明 |
| 原位压下 | 做出不可逆判断 | 盖章确认 |

返回动作使用相反方向，但不倒放已完成仪式。揭晓后返回只回故事／图鉴，不回未提交状态。

## 4. 输入模型

### 4.1 指针与触控

- 观察签使用单次轻触，不监听 pointer move；观察台保持 `touch-action: pan-y`，纵向浏览不会被游戏手势截断。
- 每枚观察签的实际按钮不小于 48×48 CSS px，视觉圆环可以小于点击区域。
- 三枚观察签共享同一张坐标校准的 `observation` 底图；拆线索印不触发换图或坐标重算。
- 长按盖章阈值 320ms；轻点立即触发等价提交。
- 其他装饰性拖动都有点击替代，不依赖设备方向、陀螺仪或振动 API。

### 4.2 键盘

- `Tab` 按图上 01／02／03 顺序访问观察签，`Enter` 或 `Space` 点亮当前签。
- `Enter` 打开当前线索印或提交按钮；`Escape` 关闭帮助层、来源抽屉与章节目录。
- 观察签点亮后焦点不被强制抢走；札记和 `n / 3` 进度通过 `aria-live="polite"` 播报。

### 4.3 屏幕阅读器

- 图上观察签直接使用原生 `button` 和稳定观察点 ID，不另造一套重复入口。
- 动画中间帧不播报，只播报稳定结果，例如“已观察 2 / 3：钟体大小递变”。
- 猜谜阶段替代文本不出现文物名称；揭晓后更新名称与器形描述。

## 5. 全流程时间线

### M01 首页闭馆灯

**触发**：首次进入且允许动画。

1. 0–180ms：背景由纸灰转为深炭，顶栏先稳定出现。
2. 120–440ms：三处环境灯依次降至 20%，工作台暖光保持。
3. 240–560ms：许照半身从桌后淡入，把卷宗沿 24px 短路径推到主动作旁。
4. 560ms：主按钮获得可操作强调，不自动聚焦。

重复访问不重播完整灯序，只做 140ms 工作灯淡入。

### M02 接案拆绳

**触发**：点击“接取今晚五件”。

- 档案绳结随拖动沿预定义 72px 轨道移动，不模拟真实打结物理。
- 拖到 80% 或点击“拆封”后完成；五格任务签以 50ms 间隔露出。
- 许照主立绘的手部与档案袋对齐；不让人物覆盖任务格。
- 不拖动也可点击按钮完成，不设置失败惩罚。

### M03 任务板抽屉

**触发**：切换今晚五件、专题、时代、自由寻踪。

- 当前抽屉前移 10px、纸签上抬 4px，200ms。
- 内容区交叉淡化 160ms；不做整页横滑，避免模式切换产生方向误导。
- 许照头像随推荐项移动到抽屉边缘，停留区不遮标题。

### M04 首枚观察签引导

**触发**：进入包含 `observationSpots` 的观察台，且当前尚未点亮任何观察签。

- 01 号签使用 1200ms 低幅度外环呼吸，02／03 降低到 46% 强调度但仍可点击。
- 许照头像与提示固定在观察图下方，不遮住器物、按钮或页面滚动区域。
- `prefers-reduced-motion: reduce` 下取消呼吸，只保留 3px 静态外描边。

### M05 观察签点亮

**触发**：轻触、`Enter` 或 `Space` 激活预定义观察签。

1. 观察签由金色转为朱砂色，260ms 内从 0.72 回到 1；图像本身不缩放。
2. 对应观察札记在观察台外原位展开，进度更新为“已观察 n / 3”。
3. 第一次点亮后，许照改说其余两处可任意查看；三处点亮后引向线索印。

每个观察签每次会话只播放一次首次动画；重复点击只保持已发现状态。观察签不是继续游戏门槛。

### M06 三枚线索印

**触发**：选择 `看形／辨材／问来历`。

- 未开封：纸签略压低 2px，显示信息成本。
- 确认后：封签绕顶部边线翻开 8°→0°，200ms；文字在 80ms 后淡入。
- `看形` 配合轮廓基线从左向右出现。
- `辨材` 只改变纸签边线与小面积材质色，不给文物套滤镜。
- `问来历` 的索引条由下向上抽出 24px。
- 星级变化与封签同时更新文本，例如“最高 3 星 → 2 星”；不能等动画结束才告知。

### M07 选项对照

**触发**：选择档案标签。

- 标签原位向左移 6px，右侧露出朱砂选中条，140ms。
- 干扰理由标签在同一行下方展开，最大两行；其他选项不重排到新列。
- 切换选项时旧标签退回，新的进入；不使用绿色／红色预判正误。

### M08 问许照排除

**触发**：用户主动点“问许照”。

1. 头像札记扩展为半宽纸条，200ms。
2. 许照铅笔从四项中划掉一个干扰项，线条绘制 240ms。
3. 被排除项移入“排除”侧轨 12px，保留可读理由。

只排除一个选项；关闭后当前观察签、线索和选择全部保留。

### M09 盖章确认

**触发**：轻点或按住“盖章确认”。

- 按住时章面随按压从 1 降至 0.94，最多 320ms。
- 松手／轻点：章面压下 10px，90ms；朱印由 0.72 放至 1，180ms。
- 180ms 内锁定输入并显示“已落印”；结果计算不等待动画。
- 不调用振动 API，不播放默认音效。

### M10 答错回看

**触发**：错误答案提交。

- 错误标签不抖动；朱印降低至 55% 并移动到“已排除”轨道，240ms。
- 观察台亮度从 70% 回到 100%，320ms。
- 许照半身从侧边淡入，证据纸条沿 20px 路径压在观察台外缘。
- 用户选择“再观察”后立绘退为头像，不重复扣除已开线索。

### M11 开柜揭晓

**触发**：正确提交，或答错后主动选择揭晓。

同一观察台原位转化：

1. 0ms：锁定答案，显示稳定结果文字。
2. 0–180ms：玻璃反光向两侧收窄。
3. 120–520ms：窄光从中心扩展到完整暖光。
4. 180–620ms：完整资源透明度 0→1；始终 `contain`。
5. 420–620ms：名称藏品签从下方进入 16px。
6. 许照只在 0–240ms 说故事钩子，随后向侧边退 18px，透明度降至 0.72。

禁止粒子、金币、爆闪、镜头震动和由暗到纯金的稀有度光柱。

### M12 故事分页

**触发**：点五段书签。

- 默认使用原生平滑滚动到章节；持续时间交给浏览器，最大不强制。
- 当前书签底线从 0→100%，180ms。
- 插图在进入视口前不加载；出现时 140ms 淡入，不做视差。
- 许照章节书签随当前章节换位，移动不超过 20px。

### M13 相关文物穿插

**触发**：故事正文进入关联段落。

- 档案棉线从当前文物标签延伸至 1–2 个相关标签，320ms。
- 关系理由先出现，缩略图后出现，避免图片替代解释。
- 未解锁相关文物只显示可信剪影或“需要权威参考”，不提前显示名称以外的答案信息。

### M14 离柜一问

**触发**：五段故事至少阅读到末段，或用户选择稍后读完。

- 小卡从正文底部抽出 36px，280ms。
- 选择答案后卡片沿 Y 轴做 4°→0°的纸卡翻面感，不使用 3D 透视大翻转。
- 正确：观察札印记显现；错误：解释区展开。两者时长相同，不做失败红屏。

### M15 入藏

**触发**：完成离柜一问或选择跳过无惩罚问题。

1. 揭晓缩略标签复制为运动代理，原图保持不动。
2. 代理沿不超过 180px 的短曲线缩至专题藏格，400ms。
3. 藏格边线亮起 180ms，显示 `已归档 n / 4`。
4. 许照主立绘局部扶住图录，编号笔画在 220ms 内出现。

图片加载失败时运动代理使用带文字的档案标签，不生成轮廓。

### M16 专题完成

**触发**：专题第四件首次入藏。

- 四个藏格边线同时对齐，240ms。
- 柜门线框向两侧展开 18px，360ms。
- 许照主立绘进入，专题印原位压下，180ms。
- 最终停留至少 900ms，用户可以立即跳过；不使用彩带、粒子或自动循环。

### M17 断点续玩

**触发**：首页点击“继续上次”。

- 旧卷宗从桌边滑回 24px，280ms。
- 恢复摘要先显示“第 3 / 5 件 · 已用 1 枚线索印 · 故事第 2 段”等稳定文本。
- 进入目标状态后不补播此前完成的拆签、落印或揭晓动画。

### M18 资源失败恢复

**触发**：图片加载错误。

- 失败图在同一帧移除，不能停留破图图标。
- 已核验剪影 140ms 淡入；剪影也失败则切换 CSS 通用结构和文字。
- 许照半身递出“重新加载／文字模式”纸条；无自动无限重试。

### M19 坏存档恢复

**触发**：结构校验失败。

- 完好页被档案夹固定，损坏页从右侧抽出 20px，320ms。
- 动画开始前先列明保留项目和重建范围。
- “重建剩余”与“放弃本轮但保留图鉴”分开；不出现一键清空全部。

## 6. 许照动作编排

### 6.1 首发复用动作

现有主立绘不进行骨骼动画。使用 CSS 裁切、短距离位移和道具层表达：

- `idle`：静态半身＋工作灯。
- `noticing`：头像上移 3px＋铅笔圈线。
- `thinking`：头像旁出现三点纸签，不摇头晃脑。
- `explaining`：半身入场 18px，台词结束后退侧。
- `archiving`：主立绘手与图录区对齐，档案代理移动。
- `celebrating`：主立绘＋专题印；不生成跳跃动作。

### 6.2 遮挡规则

- 文物主体安全区内不放人物、气泡、印章或固定按钮。
- 头像和气泡总宽不超过观察台 42%；必要时置于观察台下方。
- 许照台词超过两行时进入纸签抽屉，不扩大覆盖图像。
- 横向器物优先把许照放在观察台下；高型器优先放左／右下角。

## 7. reduced-motion 映射

| 常规效果 | reduced-motion |
|---|---|
| 闭馆灯依次变化 | 直接显示工作台最终明暗 |
| 首枚观察签呼吸 | 3px 静态外描边 |
| 观察签点亮 | 朱砂底色和状态文字即时出现 |
| 封签翻开 | 120ms 透明度切换 |
| 选项位移 | 原位描边和朱砂条 |
| 盖章压下／回弹 | 朱印即时出现 |
| 开柜光束展开 | 120ms 完整图交叉淡入 |
| 许照推入／退让 | 静态裁切切换 |
| 故事平滑滚动 | 立即跳到章节标题 |
| 入藏飞行 | 藏格直接更新＋120ms 描边 |
| 专题柜门展开 | 直接显示完成印章 |

减少动态是系统偏好优先；设置页若提供手动开关，只能进一步减少，不能强行覆盖系统减少动态偏好。

## 8. 性能与实现边界

- 首选 `transform`、`opacity`、CSS mask 与伪元素；避免动画 `width/height/top/left` 导致布局抖动。
- 观察台不监听 `pointermove`；单次点击只更新对应稳定 ID，避免连续触控触发 React 全树渲染。
- 同时运行的持续动画最多 2 个；背景没有无限粒子和自动呼吸光。
- 非当前题、非当前故事图使用懒加载；动效不能预加载 20 件完整图阻塞首页。
- 不新增动效库依赖；不使用 Canvas 绘制文物、WebGL、Service Worker 或设备振动。

## 9. 验收方法

### 9.1 三宽度

在 375×812、390×844、430×932 下逐项验证：

- 三枚观察签完整落在观察台内，点击目标不小于 48px；札记在图下展开而不遮主体。
- 线索印、四选项和盖章可以自然滚动到达。
- 许照头像／半身不遮答案和按钮。
- 入藏目标格处于可见范围或先滚动定位再播放。
- 长故事最后一段、来源和主操作可以到达。

### 9.2 交互状态

- 快速双击盖章只提交一次。
- 在观察台上纵向滑动可正常滚页，轻触观察签不触发横向滚动。
- 同一观察签、同一线索不重复计费或重复播放首次动画。
- 动画中退出再恢复，状态按稳定结果恢复，不停在中间帧。
- 图片、剪影连续失败仍可答题、揭晓、读故事和入藏。

### 9.3 reduced-motion

使用浏览器模拟 `prefers-reduced-motion: reduce` 走完：首页 → 接案 → 观察 → 线索 → 盖章 → 揭晓 → 故事 → 离柜一问 → 入藏。任何信息不得依赖移动轨迹、方向或闪光才能理解。
