# 当时这样说就好了 UX Specification

状态：`SECOND-PASS UX SPEC`

## 1. 体验目标

- 5 秒：明确不上传聊天记录、不判断谁对谁错。
- 30 秒：体验“他不在乎我”从事实栏移动到推测栏的认知高光。
- 3–8 分钟：依次整理事实、感受、推测、需要和请求，得到可编辑表达。
- 退出时：用户清楚无痕内容会消失；保存必须主动确认。

## 2. 流程

```text
封面 → 无痕说明 → 空白整理 / 示例
→ 事实 → 感受 → 解释/推测 → 需要 → 请求
→ 表达草稿 → 编辑
→ 不保存退出 / 保存本机 → 最近三份
```

默认只在内存。危险关键词只触发安全提示，不生成诊断或风险评分。

## 3. 页面规格

### V01 封面

标题、一句话、`不上传聊天记录`。主动作 `从一个情境开始`；次动作 `先看示例`。保存模式不是默认营销卖点，而是隐私说明的一部分。

### V02 无痕说明

显示：当前内容只在本次会话；关闭/退出会消失；系统使用选项而非读取聊天记录。主动作 `使用无痕模式`；次动作 `使用本机保存`，后者需主动确认。

### V03 情境选择

选择关系、目标和大致事件，不自由粘贴聊天记录。示例模式使用明确虚构内容并标示。

### V04 事实

只选择可观察行为。每个选项可展开“为什么算事实”。主动作前显示当前选择摘要。

### V05 感受

选择自己的感受词和可选强度；强度不是好坏评分。避免只用表情脸谱。

### V06 推测/解释

核心动效：一句解释从事实区移动到推测区，并显示原因。用户可以撤回/调整分类。减少动画时使用静态前后对照。

### V07 需要

把需要与对方必须做什么分开；提供价值/需要词和一句说明。

### V08 请求

请求必须具体、可执行、可被拒绝。选项引导时间、行为和边界，不生成操控性语言。

### V09 表达草稿

标题固定：`如果再说一次，我想这样表达`。先展示一段综合稿，再切换柔和/直接/坚定三种语气；三者视觉同权，不用红绿排序。

允许逐句编辑、隐藏和删除。编辑有长度限制，所有内容仍遵守本地模式。

### V10 对比

原表达风险点与新表达结构并列；不写“错误/正确”，用“容易被听成”和“更明确表达”。

### V11 无痕退出

退出前显示具体将消失的内容；选项 `继续整理` / `不保存退出` / `改为本机保存`。最后一个需确认存储范围。

### V12 保存第四份

明确显示将覆盖的最旧记录：日期、情境标题；可取消。保存只保留结构化选择和有限编辑文本。

### V13 安全提示

当冻结规则触发危险提示时，暂停普通沟通建议，显示克制的安全优先说明和可信支持建议。不诊断、不评分、不把“说得更好”当唯一解法。

### V14 存储/数据错误

无痕模式不依赖持久化。IndexedDB 失败时仍可无痕完成；保存动作失败明确提示复制/截图当前结果后再退出。

## 4. 状态矩阵

| 功能 | Empty | Error | Success | Partial |
|---|---|---|---|---|
| 五步选择 | 暖提示+示例 | 内容键缺失用安全通用项 | 下一步 | 可返回修改 |
| 表达稿 | 信息不足定位缺失步骤 | 不输出半句乱码 | 可编辑 | 某语气无模板时不伪造，显示综合稿 |
| 无痕退出 | 不阻塞空草稿 | 不适用 | 清内存 | 已编辑内容明确提示 |
| 保存 | 最近为空 | 失败仍保留内存 | 写最近三份 | 第四份等待确认 |

## 5. 响应式/无障碍

- 375/390：一屏一个认知任务，底部动作随内容滚动，不遮输入。
- 430：编辑稿最大 390px，批注可在右侧小栏。
- 桌面：前后对比可双栏；移动端按先后纵排。
- 句子移动动效有静态等价；所有分类有文字标签。

## 6. 资源候选

- 五步符号、隐私、安全、编辑标记：SVG。
- 纸张、删除线、批注、移动轨迹：CSS/SVG。
- 不需要人物位图、聊天气泡截图或情绪化插画。
- 若封面需要视觉锚点，优先排版与句子重排动效，不生成“吵架情侣”。

## 7. 高保真门槛

- [x] 无痕默认、保存确认、覆盖最旧、安全提示和编辑完整。
- [ ] 完成事实→推测核心动效与减少动画版本。
- [ ] 完成无痕退出、保存失败、三语气等权高保真测试。

## NPC 增量状态

首次三句可跳过；四步各只提供结构提示；高冲突时给暂停/离开路径；头像召回句式说明；失败时保留已选项并允许复制。详见 `NPC-SPEC.md`。
## NPC 异常恢复补充

生成或本机保存失败时，迟言先确认五步结构化选择、三个语气草稿和手工修改仍在当前内存，再提供复制最终表达、生成本地截图、重试保存和返回编辑。不得清空当前会话、改用云端或要求上传聊天记录。
