# 项目21｜湖边打水漂：详细立项

> 首版范围更新：用户要求增加首版内容。正式交付数量与耐玩机制以 [CONTENT-PLAN.md](./CONTENT-PLAN.md) 为准；下文原小P0数量改作内部视觉/手感切片，不代表最终首版范围。原玩法规则继续生效。

日期2026-09-19；状态：立项设计，未实现未实测。弹跳为可调游戏模型，所有距离/重量为游戏数值，不宣称真实水动力精度。

## 1. 核心定位

黄昏湖岸，玩家先从脚边挑石，查看扁平度、大小和手中姿态，自己调好出手角度并甩出去，看水面连续开出一串水花。选石、投掷、飞行、结果四段都可感知。
一投15～35秒，连续一组5投可选，默认无限自由练习。无体力、商店或自动升级替代技术。第一分钟完成至少2投，第一投有轻引导但不自动完美投掷。
P0：1个黄昏湖景，3种石形×尺寸/厚度/表面参数生成变体，每轮脚边6块石；自由练习、5投挑战、本地个人纪录。

## 2. 流程和页面状态

岸边挑石→手中查看/调倾角→拖拽蓄势→松手出手→连续弹跳/沉水→结果→回岸再挑。
- 岸边六块石自然散布，点选捡起；可放回，不扣次数。颜色无稀有度，扁薄更易连跳、稍重更易保速等取舍通过手感说明。
- 检查：石头放在画面下方安全区域，横向轻拖可转动查看；“握好了”进入投掷，防检查旋转误发射。
- 投掷：底部小倾角弧线滑杆控制石面入水姿态，主操作区拖后向目标瞄准并蓄力，松手投出。空白点击不投。
- 飞行中观测为主，不空中控制；允许收起数据沉浸观看，不提前遮挡连续水花。
- 最终显示跳数、距离、最长单跳、与个人纪录的差值，以及一条有依据的反馈（如入水过陡/速度不足）。
- “同一块再试”使用相同石参数和风场便于练习；“再捡一块”更换选择。重试不偷换风向。

## 3. 操作方案与初始手感

默认采用稳定可控的拖拽蓄势，另可选直觉划甩模式；两者不能混在同一手势里。
- 默认：按住已准备石，往后拖，位移映射力量；左右偏移映射方位角；辅助弧线只显示首段大致落点，不预告总跳数。
- 力量为有效操作区归一化距离d，p=clamp(d/0.35,0,1)，速度取vMin+(vMax-vMin)*smoothstep(p)。具体vMin/vMax归content.json，初值7～18游戏米/秒。
- 石面倾角独立滑杆8°～35°，初始18°；短期容错“较平/合适/较陡”用石头姿态呈现，不标一个绝对完美角度。
- 方位角±22°；投掷轨迹仰角初值固定低弧度，由力量作很小关联，不能把方位/轨迹/石面倾角混成一个参数。
- 松手前最后80ms轨迹平均，抑制触摸噪声；超过起投距离才发射，低于阈值回手。
- 划甩模式：最近100ms位移速度映射力量，限速，方向映射方位；石面倾角仍提前调节。提供明确切换说明。
- 辅助模式即默认拖拽蓄势，可用底部±按钮调石面角，完全不要求高速划动。
- 蓄势时石头跟手，松手0～60ms离手，镜头仅有≤2px短促位移；第1次触水清晰，第2次之后水花逐渐变小。
- pointercancel、第二触点、横竖屏改变、移出有效区均取消蓄势，不能自动投掷或扣投数。

## 4. 游戏化飞行与弹跳模型

使用3D逻辑坐标，固定1/60步积分位置/速度，渲染用受控透视投影。石面倾角是独立姿态；旋转稳定量spin由石形与本次释放质量确定，有衰减但不是手指画圈输入。
飞行包含重力、线性/二次阻力的简化项、已固定风场的弱横向作用。由上一帧与下一帧的水面距离做连续过零插值，求真实接触时刻，避免高速穿水。
每次触水：
1. 计算垂直/水平速度比得到入射角alpha；读取石面姿态beta与spin。
2. 由石面面积/质量、扁平度、alpha/beta匹配及spin得到support，范围0～1。
3. 水平速度保留系数eH在0.60～0.88，竖直反弹速度clamp(k*vx*support-loss,0,vBounceMax)，损耗随入射过陡增大。
4. support不足、水平速度低于阈值或反弹高度过小则沉水；禁止随机判定“这一跳失败”。
5. 飞行总机械能在无外部输入时不增加；旋转只调支撑/损耗，不凭空注入无穷能量。上限60跳/20秒仅作异常保护，不作为常态结果截断。

石参数：mass、area、flatness、edgeRoundness、roughness、spinRetention；用有限合理范围生成，避免极端神石。初值目标：新手1～4跳、理解角度后4～10跳、熟练8～18跳；必须靠批量模拟和试玩调参，不能写死按评分播放某个跳数。
小风浪每投之前生成并提示，接触处波高/法线以同seed时空函数算出；首版幅度小，技能主导，随机不翻盘。标准练习场固定弱风，挑战场每组固定seed。切换画质绝不能改变水面碰撞函数。

## 5. 视觉、水质与黄昏设计

色板：深湖蓝灰#4D7079、反光金#E9BA75、天际粉#D4A8A0、山影#54606A、湿石#66655E。
准备阶段地平线在上部约1/3，近岸石头和手部操作占下部；出手后进入石头后上方略偏侧的自动跟拍，持续看清石头与触水区域。详细分镜、相机参数和特殊情况以CAMERA-DESIGN.md为准。
- 湖面：远处波频更密，近处波纹清晰；反射颜色依视角变化，晚霞反射随法线破碎，不把一条金色透明矩形叠在水上。
- 天空：本地渐变/云图+远山剪影反射贴图；静态环境避免昂贵实时镜面，不用在线HDR。
- 水花：首触较大扇形喷溅、之后逐次减小，喷溅朝运动方向；落点椭圆涟漪按水面透视拉伸，不能是屏幕正圆。
- 倒影：石头临水影子随高度变软变淡；岸石接触水面有湿暗线。金色光只出现在受光面。
- 沉水：最后一点泡与渐散涟漪，停留约600ms再出结果，不骤停切卡片。
- 默认镜头跟随石头水平行程，不跟弹跳上下颠簸；出手衔接、沉水停留和回岸淡切按CAMERA-DESIGN.md实现。减弱动态可选岸边远观，低画质仍保留跟拍逻辑。
- 音效每跳位置与水花对应，音高随余速/力度弱变化，无强制背景音乐。

## 6. 技术栈和资源

TypeScript + 原生WebGL1专用水面/简易石网格 + DOM/CSS + Canvas2D降级；Rolldown IIFE。
水面为规则低面数网格或透视四边形，着色器负责小波法线和反射混合；逻辑水面独立固定解析函数。最多24组涟漪、250颗外观水滴，低档8组/60颗，不可影响跳数。
石形程序化生成低面数椭圆网格，局部纹理来自小图集；不打包GLB/Draco/WASM。石头检查转动与飞行复用同一模型参数。
默认三角形≤20k、draw calls≤30、纹理/FBO≤32MiB。所有结果由CPU模拟，GPU仅显示。Canvas降级用透视投影水面颜色分带、反射纹和粒子，保留挑石/姿态/完整轨迹。
结果页记录轨迹关键点用于展示，不保存逐帧图像；最多最近20投，防历史无限增长。

## 7. 数据、记录与存档

content.json：stoneProfiles、generationRanges、physicsTuning、inputTuning、windProfiles、modes、feedbackRules、visuals、copy、audio、layout、quality。
每投：throwId、seed、石参数、风参数、释放输入、simulationVersion、跳数、距离、终止原因。距离为从第一触水点至沉点的水平路径/直线须明确定义；首版选择水平路径长度，结果标为“水面滑行距离”，跳数第一次有效反弹计1。
收藏为喜欢的石形参数（最多12）及个人最好纪录，不做在线排名或不可验证“超过全国99%”。一组5投展示最高与平均，可截图，不依赖发帖桥接。

进行中存档保存候选石参数、当前选择、风场seed、模式、已用投数与当前throwId。蓄势未释放不持久化手指轨迹，重开回到准备状态；飞行中暂停记录模拟时间、位置/速度/姿态、已计跳数和关键接触点，恢复先给准备提示再继续。投掷完成后用throwId原子去重提交本地纪录；结果动画中退出不丢已完成成绩。存档采用与其他项目相同的版本迁移、配额失败和损坏恢复策略。

## 8. 实施和验收

P0顺序：可重复弹跳纯模型→输入标定→单石水面样板→6石挑选→结果/练习复投→音画同步/降级→挑战与记录→打包。
P1：阴天湖、更多石面纹理、幽灵轨迹比较。禁止首版加入强化装备或空中技能。
专项测试：
1. 同石同风同输入给相同跳数，30/60fps渲染差异不改模拟。
2. 角度、力度、扁平度参数扫描形成合理连续区间，不能“越大越好”，临界点只在接触阈值发生。
3. 能量不增、无NaN、无穿水、无无限跳；连续接触每次仅计数一次。
4. 常见输入分布确实可得到0～多次跳数，不只是随机脚本。
5. 摸石、调角和取消不触发投掷；5投挑战只在有效发射时扣一次。
6. 同步录像逐帧抽查水花起点、计数与声音事件一致；画质切换不重置风浪时间。
7. 5位新手4位在两次内学会投掷，至少3位能通过选石/调角改善自己的结果；不是强行保底第二投更远。
8. 首次选择和飞行落点都避开宿主控件，真实横屏可观察全轨迹。

性能和真机表现尚未实测，通用标准见DELIVERY.md。
