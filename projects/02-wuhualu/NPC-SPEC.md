# 许照（阿照）｜引导 NPC 规格

- 身份：物华馆修复学徒兼图录助理；好奇、细致、尊重证据。
- 视觉：现代青年馆员/修复学徒，靛青工作罩衣、棉质内搭、无粉尘手套常态不穿戴而妥善收起，持铅笔与无馆标记录夹；以真实文物修复工作服和工具为参考，不伪装成古人。
- 首次三步：看轮廓 → 看用途与痕迹 → 猜错会得到事实线索；支持跳过。
- 节点：错答只指出一个可观察事实；收录时强调年代、用途与证据链。
- 召回：猜谜页头像打开“可观察线索／图像性质／收录规则”。
- 异常：资源未载入时不要求盲猜，提供重新加载或换一题。
- 资源同统一 900×1200 母版及三种降级；人物不遮挡文物主图。
