# 八项目页面地图与交互状态

状态：FLOW CONTRACT FROZEN（2026-08-23）。视觉设计可以调整布局与动效，但不得改变本文的业务状态、存档时机和返回行为。

## 1. 共用页面规则

- 每项目都有：封面、玩法说明、主流程、完成页、设置/数据管理、来源与说明。
- 首次进入显示必要说明；再次进入优先显示“继续”与“重新开始”。
- 浏览器/平台返回优先关闭当前弹层，其次回到项目定义的安全页面，不依赖多层 History。
- 关键选择提交后立即保存；纯预览、悬停或展开说明不写存储。
- 所有“重新开始”“清空数据”“覆盖最旧记录”都有二次确认。
- 加载失败显示文字降级，不以白屏结束。

## 2. SBTI 山海兽格

### 页面地图

```text
封面
├─ 开始入境 → 娱乐性说明 → 本轮题目生成 → 四章答题 → 显形 → 结果卡
├─ 继续上次 → 当前章节/题目
├─ 最近结果 → 结果卡
└─ 设置/来源
```

### 关键状态

| 页面 | 状态 | 行为 |
|---|---|---|
| 答题 | 未选/已选未确认/已确认 | 确认后写答案和下一题索引 |
| 答题返回 | 有上一题 | 允许修改；修改后重算，不重抽题 |
| 章节过场 | 默认/减少动态 | 可跳过，跳过不改变进度 |
| 结果 | 明显/平衡/边界 | 显示连续倾向、主兽和相邻兽 |
| 数据损坏 | 可恢复/不可恢复 | 丢弃无效非关键答案；关键题序损坏则重新开始 |

### 存档时机

生成本轮题序、每题确认、完成结果时保存。重新开始生成新 seed 和题序。

## 3. 物华录

```text
封面 → 本轮藏品匣 → 猜谜
  ├─ 直接作答
  └─ 查看线索 → 扣减可得星级
→ 揭晓 → 下一件 → 本轮总结 → 图鉴
```

- 作答提交后不可撤销，防止看揭晓再修改。
- 看同一线索不重复扣星。
- 退出后保留本轮文物顺序、当前文物、已看线索和答案。
- 图鉴有未解锁、1/2/3 星、内容更新后新增四种状态。
- 图片失败时显示轮廓 SVG 和完整文字线索。

## 4. 大理寺字案录

```text
卷宗架 → 案件封面 → 开场对话 → 初判
→ 调查地图 → 对话/证据节点 → 证据簿
→ 满足结案条件 → 终判 → 判词比较 → 结案文书 → 来源
```

- 对话节点只能选择预设选项；没有自由文本框。
- 已读节点允许回看，不允许撤销已经获得的事实证据。
- 调查顺序可变；关键证据齐全后解锁终判。
- 初判提交后锁定，仅用于最后比较。
- 节点引用缺失时回到调查地图并标记内容错误，不写坏存档。

## 5. 汴京饮子铺

```text
封面/存档位 → 开张 → 晨间状态 → 备货与定价
→ 开门 → 当日事件 → 选择 → 日终结算 → 账簿
→ 自动存档 → 下一日 / 结局
```

- 晨间备货在“开门”前可修改；开门后锁定。
- 事件选择提交后不可撤销，提交前展示选择但不预告精确数值结果。
- 每个完整日结算后保存；事件提交后另做安全快照，避免切后台丢失。
- 存档损坏时优先回到上一日安全快照。
- 结局页可以重新开店或查看结局收藏，不覆盖旧结局收藏。

## 6. 我希望被这样对待

```text
封面 → 使用边界 → 关系情境 → 分章问答
→ 生成说明书 → 编辑/隐藏/排序
→ 完整预览 / 简洁预览 → 本机保留 / 清空
```

- 问答允许返回修改，输出实时重算；用户手工改写的句子不可被重算静默覆盖。
- 当答案变化使原句不再适用时，标记“需要确认”，让用户选择保留编辑稿或采用新建议。
- 拖动排序每次结束后保存，不在拖动过程中频繁写 localStorage。
- 简洁预览默认排除敏感项。

## 7. 出门检查官

```text
封面 → 场景 → 条件 → 生成清单
→ 重要程度 / 类别 / 空间动线
→ 勾选与自定义 → 完成提示 → 最近三份
```

- 条件修改后重新运行规则，但保留仍存在物品的勾选状态。
- 三种视图只改变排序和分组，不复制清单数据。
- 自定义项可编辑和删除；内置关键项可以隐藏但需确认。
- 最近三份按更新时间排序；第四份覆盖最旧记录。

## 8. 当时这样说就好了

```text
封面 → 无痕说明 → 空白整理 / 示例
→ 事实 → 感受 → 解释 → 需要 → 请求
→ 表达草稿 → 编辑
→ 不保存退出 / 保存本机 → 最近三份
```

- 默认内容只在内存；切换“保存到本机”必须主动确认。
- 返回上一步保留内存草稿。
- 退出无痕流程前提示内容将消失。
- 保存第四份时明确显示将覆盖哪一份；取消则不保存。
- 危险关键词只能触发安全提示，不在本地生成诊断或风险评分。

## 9. 地球 Online

```text
公会大厅 → 今日状态 → 领取任务
→ 接受 / 换一个 → 执行页
→ 完成 / 放弃 / 不适合 → 文字徽记 → 冒险日志
```

- 领取时写 `activeQuestId`；换一个时记录跳过反馈并应用冷却。
- 同一时刻只有一个进行中任务。
- 完成后才写完整日志；放弃也写状态，但不做失败惩罚。
- “不适合”影响软权重，不永久删除。
- 条件过窄时展示回退原因：“先给你一件不受地点和预算限制的小任务。”

## 10. 页面验收共同用例

每项目必须通过：

1. 首次完整路径。
2. 中途刷新继续。
3. 切后台再回来。
4. 返回键逐层关闭弹层。
5. 关键按钮快速点击两次不重复提交。
6. 静态图片失败仍能完成流程。
7. localStorage 读取到非法 JSON 时出现恢复页面。
8. IndexedDB 打开失败时显示明确降级或重试，不永久转圈。
9. 清空本项目数据不影响其他小工具。
