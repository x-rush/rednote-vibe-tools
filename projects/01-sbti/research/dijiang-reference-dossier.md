# 帝江参考证据包（生成前冻结）

## 用途与结论

- 项目：SBTI 山海兽格
- 结果型：`RVLM 无界舞型`
- 用途：结果卡、近邻型对照卡和图鉴页的主视觉依据。
- 事实优先级：先以《山海经·西山经》的文字形制为硬约束，再用明代胡文焕本《山海经图》的构图帮助理解体量和翼足关系；古图不能覆盖文字中的数量要求。

## 文字锚点

核心形制冻结为：

1. 身体如黄色囊袋，整体浑圆、无明显首颈分界；
2. 色彩“赤如丹火”，成图可用黄赭主体叠加丹朱红光和纹理，不做现代荧光红；
3. **恰好六足**；
4. **恰好四翼**；
5. **无面目**：不得出现眼、口、鼻、人脸、兽脸或暗示五官的花纹；
6. “识歌舞”只通过腾跃、回旋、翼足节奏和流动气韵表达，不添加乐器、文字或拟人舞者。

## 艺术化边界

允许：

- 将版画轮廓转译为参赛级国风幻想插画；
- 适度美化羽毛层次、赭黄与丹朱的矿物色泽、云气和纸本颗粒；
- 采用三分之四侧视或轻微俯视，让四翼与六足都不互相遮挡；
- 用姿态表现“先感受整体节奏，以理路辨方向，却不急于定形”。

禁止：

- 少于或多于六足、四翼；
- 任何脸、眼睛、嘴、鼻、角、兽首或人首；
- 把帝江画成鸟、龙、狮、猪、章鱼、天使或现代吉祥物；
- 铠甲、王冠、兵器、乐器、文字、标识、水印；
- 以“混沌”二字为由擅自加入后世形象特征。

- [ ] 四翼可见且可逐一计数
