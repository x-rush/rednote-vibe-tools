## 第一轮拒绝与返工

### 关系说明书／陪伴

初稿在 16px 下像链环或情侣符号，可能制造关系类型暗示。已改为两个无性别并肩人物和一条中性连接线。

### 关系说明书／编辑冲突

初稿缩小后像羽毛或装饰笔画，无法稳定表达“文档需要确认”。已增加明确文档轮廓、折角、正文线和修订笔。

### 地球 Online／联系熟人

初稿过于接近聊天气泡，与“不模仿聊天 App”的视觉规则冲突。已改为两个抽象节点、双向连接和外围回应刻线。

## 仍需验证

1. `currentColor` 必须以 inline SVG 或 SVG 组件方式进入应用；`<img>` 外链无法继承宿主颜色。
2. 16px 下应在真实 DPR 设备再检查，当前浏览器总览只证明形态没有明显坍塌。
3. 完整图标系统扩展后做重复语义盲审，例如“证件／文件”“手机／电子”“陪伴／关心”。
4. 图标不能替代文字标签；关键优先级、安全和隐私状态必须同时有文字。
5. C 级章只用于未来展示，不得出现在首发 100 项任务实例上。

## 扩展门槛

基准系统可以扩展，但每批新增资源必须：

- 通过 XML、viewBox、stroke、title 自动检查；
- 在 16/20/24/32px 或 20/32/48/64px 尺寸板渲染；
- 同时检查浅色和深色背景；
- 记录语义冲突和返工；
- 更新项目 `asset-manifest.json` 与 `PROMPTS.md`；
- 装回真实 UI 后再次检查，不以独立图标板代替页面验收。
