# 地球 Online｜交互与动效规格

日期：2026-08-26
状态：待书面规格复核

## 1. 原则

动效只服务状态理解、空间连续和完成反馈。每次动画都必须回答“发生了什么”：任务纸从公告板被选中、被接取、被放回或被收入日志。禁止用随机闪烁、稀有光柱、宝箱、金币雨和老虎机滚动制造刺激。

## 2. 动效令牌

```css
--motion-instant: 100ms;
--motion-fast: 160ms;
--motion-base: 240ms;
--motion-slow: 420ms;
--motion-ritual: 760ms;
--ease-out: cubic-bezier(.2, .8, .2, 1);
--ease-paper: cubic-bezier(.22, .72, .18, 1);
--ease-stamp: cubic-bezier(.3, 1.45, .55, 1);
```

持续循环仅允许公告板上极弱的光尘或纸边呼吸，并在 2 次后停止。一次页面转换的总仪式时间不超过 1100ms，核心操作结果不得因动画延迟超过 150ms 才被计算。

## 3. 状态动效

### 3.1 首次进入大厅

- 背景 240ms 淡入。
- 弥拉从下方 12px 进入，420ms；对话卡延后 80ms 淡入。
- 三句切换只做文字交叉淡化，不横向轮播。
- 跳过立即结束，不等待离场动画。

### 3.2 公告板

- 四张任务纸以 35ms 错峰、6px 位移进入。
- hover/press 只产生 1.5deg 内旋转和 2px 抬升；移动端按下缩放不得低于 .985。
- 图钉在纸张出现后做一次 120ms 弹性回位。

### 3.3 条件选择

- 选中 chip 时底色 160ms 过渡，黄铜边框从 60% 到 100%。
- 不使用大幅缩放；震动或设备反馈不在范围内。
- 提交时已选条件聚合成标签，向公告板方向上移 8px 并淡出。

### 3.4 匹配仪式

- 真实条件标签按固定顺序逐个确认，总时长 700–1100ms。
- 公告纸只做两次轻微重排，不显示假进度或滚动任务名。
- 算法更快完成时仍可保持最短 480ms 以避免闪屏；用户点击“跳过动画”立即揭晓。
- 算法或保存失败立即终止仪式并进入恢复状态。

### 3.5 任务揭晓

- 选中纸张从公告板层上移 16px、旋转归零、扩大到阅读宽度，420ms。
- 任务内容整体出现，不逐字打字；信息标签可在 80ms 内错峰淡入。
- `stage !== exact` 时，回退说明在任务纸之前展开，避免用户先误认完全匹配。

### 3.6 换一张

- 当前纸向右上方平移 24px 并淡出，240ms。
- 公告板纸张做 6px 重新排布，下一张从左下方进入，420ms。
- 不连续旋转、不出现随机计数器；快速重复点击由交互锁阻止。

### 3.7 接取压印

- 点击后立即禁用按钮并显示保存状态。
- 保存成功：黄铜印章从 1.18 缩放到 1，240ms；纸张边缘加深一次后回落。
- 保存失败：不出现印章，任务纸保持原位，恢复面板从底部进入。
- 动画完成后进入执行页；键盘焦点落到任务标题。

### 3.8 进行中

- 页面不使用持续倒计时或进度动画。
- 完成、放回、不适合打开底部 sheet，背景只降低明度，不做强模糊以保证低端性能。

### 3.9 完成与结算

- 确认完成后先执行幂等结算。
- 完成印章 240ms 落下，最大旋转 4deg；纸面出现一次 320ms 墨迹扩散。
- XP 数字从旧值过渡到新值，最多 600ms；同时保留最终文本供辅助技术立即读取。
- 新徽章使用 420ms 亮度和边线变化，不发射粒子。
- “收入日志”时纸张缩小到 .92 并向下移动 16px 淡出，下一屏日志对应条目淡入。

### 3.10 放弃与不适合

- 放弃使用纸张平放回公告板的向上 10px 淡出，不使用破碎、红叉或失败音效。
- 不适合反馈保存后，软权重标签以 160ms 出现；撤销后原位消失。

### 3.11 导航、抽屉和列表

- 页面间使用 160ms 淡入和 6px 位移，不建立左右层级假象。
- 弥拉帮助抽屉从底部进入，最大宽度 520px；桌面端仍居中而不是侧边远离内容。
- 日志筛选只重排现有条目，240ms；空态与列表交叉淡化。

## 4. 交互锁与重复动作

- 匹配、保存、接取和完成期间相应主按钮进入 busy 状态；不锁住返回和安全退出。
- 完成动作使用 `acceptanceId` 幂等保护；重复点击不得重复 XP、日志或徽章动画。
- 换任务在新 match 返回前保持当前纸可读，失败时恢复原纸。
- 所有异步结果必须忽略已经离开该页面的陈旧响应。

## 5. Reduced motion

`prefers-reduced-motion: reduce` 时：

- 所有位移、旋转、缩放、错峰和循环动画取消。
- 匹配仪式不设置人为最短时长；结果就绪后直接显示。
- 压印、收入日志和徽章点亮替换为 100ms 透明度变化。
- XP 直接显示最终数值。
- 页面状态、live region 和焦点管理保持不变。

## 6. 性能预算

- 动画只使用 `transform` 和 `opacity`；避免连续改变布局和大面积滤镜。
- 同时动画元素不超过 12 个。
- 首屏不加载非当前场景的大图；弥拉母版使用响应式尺寸和预先声明宽高。
- SVG path 数量保持克制；CSS 纹理不使用高频大面积动画。
- 低端设备掉帧时允许跳过装饰动效，不影响任何业务状态。

## 7. 验收

- 每个动效都能在动画关闭后完整理解。
- 快速重复点击、刷新和后退不会产生重复结算或丢失当前任务。
- 375 / 390 / 430px 与 200% 缩放下，动效元素不造成横向溢出。
- 非零顶部安全区下，进入动画的元素不会从状态栏下方开始或停留。
- reduced-motion 下不存在超过 100ms 的装饰性运动。
