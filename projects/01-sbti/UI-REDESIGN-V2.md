# SBTI｜山海兽格测试 UI/UX v2

状态：已实现

日期：2026-08-25

## 设计结果

本轮把原有测评表单整理成“入山—行卷—收卷—显形—阅志”的山海识灵流程。题库、抽题、四维计分、十六型映射和本地存储结构不变；优化集中在用户表达、闻山的陪行职责、交互反馈和动效节奏。

正式产品定义如下：

- 正式名：`SBTI｜山海兽格测试`
- 英文释义：`Shanhai Beast Temperament Indicator`
- 中文解释：`山海异兽性格倾向指标`
- 产品边界：娱乐性自我探索工具，不是专业心理测评。

英文释义只进入测前完整说明。答题、显形、结果、历史和分享的主要阅读路径使用中文；评分所需的内部字母代码不向用户展示。

## 体验结构

### 入山

首页以夜间守卷案为主场景。闻山负责说明当前状态：首次来访时迎接，存在未完成进度时提示续卷，已有结果时提示可重阅兽志。主操作仍是开始或继续，不把 NPC 做成额外流程门槛。

测前说明补齐正式名称、中文解释、英文释义和产品边界。用户在作答前能知道这是什么、会做什么、不会做什么。

### 行卷

24 道题分为入境、寻迹、异变、归来四卷。每题都是四个同层级的情境行动，选择表现为“行动签落印”，需要用户主动确认进入下一问。

闻山的紧凑守卷席常驻题页上方，台词按章节位置、是否已选和是否返回旧题变化。台词只说明操作与行程，不评价选择，不暗示计分方向。

点击闻山打开“问闻山”，提供三个固定问题：

1. 这一题应该怎么选？
2. 落印以后还能修改吗？
3. 答案会保存到哪里？

问题切换留在同一卷页，关闭后焦点回到入口。没有自由聊天、后端调用或询问记录。

### 收卷与显形

每卷开始由闻山递卷，前三卷结束时收卷。过场可以跳过，且不会改变题目或答案状态。

最终显形依次呈现四枚中文卷印：

- 与世界相遇：应世 / 隐世
- 理解线索：察微 / 观象
- 衡量选择：衡理 / 感应
- 面对变化：守形 / 化生

显形只建立阅读框架，不提前泄露最终偏向；用户点击“展开兽志”后才进入结果。

### 阅志

结果身份统一显示为“异兽名 · 中文兽格名”。首屏先稳定展示结果和异兽，再出现闻山的次级解释入口，避免 NPC 与结果主角争夺注意力。

“三问闻山”提供：

1. 四种倾向应该怎么读？
2. 为什么会有相邻兽格？
3. 古籍记录和产品创作如何区分？

结果页同时解释连续倾向、相邻兽格、古籍记录与创作边界，并再次声明娱乐性边界。

## NPC 使用规则

闻山承担五类明确职责：迎接、守卷、递卷、解释、恢复。普通题页的反馈在原位置更新，不弹窗打断；只有首次说明、章节交接和最终显形形成仪式性停顿。

闻山永远不说“选得对”“这很像你”“吉凶已定”一类判断，也不根据某个选项暴露维度。异常状态下则明确说明内容损坏、存档清除、存储不可用或写入失败，避免用同一句泛化错误文案。

## 视觉与布局

- 夜墨用于首页、答题和显形，暖纸用于说明、历史和结果。
- 朱砂表示已落印状态；孔雀石绿表示行程、当前卷和帮助入口。
- 题目保留纵向四签，触控区不小于 48 CSS px，长文案允许自然增高。
- 375、390、430 CSS px 均使用单列主流程；不依赖横向滑动。
- 正式异兽图和闻山图都有占位图与 CSS 墨影降级，交互不依赖新增图片。

## 状态覆盖

交付预览覆盖 16 个手机状态：首次首页、续卷首页、测前说明、未选题、已选题、返回改题、问闻山、递卷、收卷、显形中、显形完成、结果首屏、三问闻山、图片降级、坏存档、减少动态。

对应静态预览见 `design/preview-v2.html`。

## 无障碍

- 行动签继续使用原生单选按钮语义。
- 当前卷使用 `aria-current="step"`，完成、当前、未开始均有文本名称。
- 帮助卷页使用对话框、焦点陷阱、Escape 关闭、背景不可交互和关闭后焦点归还。
- 显形过程提供跳过按钮；减少动态时直接进入相同语义终态。
- 图片替代文字不包含内部代码，图片失败后仍有异兽名或闻山身份。
- 状态不只靠颜色表达：选择有“选”印，章节有状态文字，按钮文案随状态改变。

## 范围边界

本轮没有新增题目、计分维度、剧情分支、存储字段、依赖或运行时服务。用户追加授权后，生成并接入了递卷与阅卷两张闻山姿态；它们都有现有 placeholder 与 CSS 墨影降级，缺失时不影响流程。生成提示词、规格、体积和后续可选姿态见 `ART-REQUEST.md`。
