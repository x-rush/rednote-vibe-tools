# 《物华录》许照全流程引导系统 V2

## 角色定位

- 姓名：许照
- 身份：闭馆整理员、玩家的档案搭档
- 作用：帮助玩家学会“观察—推理—理解”，不替玩家公布答案
- 语气：克制、温和、懂行；像真正喜欢文物的年轻馆员，不说网络烂梗，不卖萌打断故事

许照不是悬浮帮助按钮。她必须参与一轮游戏的开始、推进、收束，并根据玩家进度改变台词。形象资源优先复用现有 `guide-master-v1.webp`、`guide-avatar-v1.webp` 与后续表情差分，不为每句台词重复加载大图。

## 大立绘与普通提示分工

- 首页、玩法引导、答错复盘、文物揭晓和专题完成使用 900×1200 主立绘与底部姓名／对话框，形成 GALGAME 式关键剧情节点。
- 玩家主动点击顶部“问许照”时，打开接近全屏的大立绘对话层；背景页面压暗但保留上下文，关闭后焦点回到原按钮。
- 任务选择、观察签、线索印、故事书签和普通入藏提示继续使用小头像，不让角色频繁遮挡文物与操作。
- 大立绘统一 `object-position: center top`，优先保证头部、发型和上半身完整；320–430 CSS px 不得出现横向溢出。
- 弹层支持遮罩关闭、明确关闭按钮、Escape、焦点约束与页面滚动锁定；减少动画模式取消推入，只保留可理解的静态状态。

## 出场矩阵

| 场景 | 画面用法 | 交互职责 | 变化条件 |
| --- | --- | --- | --- |
| 首页 | 半身主视觉或桌边立绘 | 报告今晚任务、继续上次档案 | 初访、已有收藏、存在未完局分别说不同台词 |
| 任务选择 | 头像批注 | 推荐“今晚五件”或专题册 | 根据已收藏套组推荐未完成内容 |
| 开局接案 | 全身立绘 + 档案袋 | 解释本轮目标，不重复完整教程 | 首局完整，后续一句话带过 |
| 聚光观察 | 小头像贴近观察台 | 提醒看轮廓、工艺、使用场景 | 根据尚未发现的热点给方向，不报位置 |
| 线索印 | 头像 + 手写便笺 | 解释“看形 / 辨材 / 问来历”的差别 | 玩家连续两题总先点同一类时提示换角度 |
| 选项判断 | 不主动遮挡画面 | 长按或点“问许照”获得排除法 | 只排除一个干扰项且说明理由，不直接报答案 |
| 答错 | 大幅主立绘，不做沮丧表情 | 指出混淆点，允许回看 | 针对本题 `wrongAnswerExplanation` 输出 |
| 揭晓 | 大幅主立绘从侧边轻推入 | 用一句“故事钩子”带入五段身世 | 正确与错误使用不同开场 |
| 故事阅读 | 小头像作为章节书签 | 每段末尾补一个观察问题 | 默认收起，避免打断长文 |
| 离柜一问 | 头像主持 | 提出无惩罚记忆题并解释答案 | 答对肯定证据，答错补关键事实 |
| 入藏 | 立绘 + 盖档案章动作 | 宣布入藏、提示所属套组 | 新入藏、刷新星级分别处理 |
| 套组完成 | 全身庆祝差分 | 总结四件文物之间的关系 | 每套仅首次播放完整仪式 |
| 图鉴 | 头像筛选助手 | 推荐下一件、提示相关文物 | 根据空缺时代与套组动态推荐 |
| 回访 | 首页进度台词 | 欢迎回来、续接未完成内容 | 记录最近游玩但不制造签到压力 |

## 台词规则

1. 同一场景至少准备 3 条等义台词，按最近使用记录去重。
2. 每条 18–52 个汉字；故事钩子可到 70 字。
3. 不使用“恭喜获得 SSR”“金币 +1”等破坏博物馆世界观的表达。
4. 不把未经核实的传说借许照之口说成事实；推测必须标注“可能”“研究者据此推测”。
5. 帮助分三级：方向提示、排除一个干扰项、解释混淆点；永不直接代答。
6. 玩家可关闭非必要语音式弹层；必要信息必须仍以文字和无障碍标签存在。

## 首发状态与动作

- `idle`：正常讲解
- `noticing`：发现观察热点，轻微抬眼或指向
- `thinking`：玩家请求提示
- `explaining`：揭晓与故事钩子
- `archiving`：盖章、入藏
- `celebrating`：套组完成；克制而有仪式感

首发允许用同一主立绘配 CSS 位移、裁切、光影和档案纸层完成状态变化；表情差分属于增强项，不能阻塞 20 件文物内容上线。

## 验收

- 完成一局五件时，许照至少在 6 个不同节点产生有效引导。
- 连续游玩两局，首页、接案、观察、揭晓台词不能完全重复。
- 375 / 390 / 430 CSS px 下，头像和气泡不得遮挡文物主体、答案与主按钮。
- `prefers-reduced-motion` 下取消立绘推入、盖章弹跳，仅保留淡入和状态文字。
- 许照的任何建议都不能让事实审核状态倒退，也不能泄露答案。
