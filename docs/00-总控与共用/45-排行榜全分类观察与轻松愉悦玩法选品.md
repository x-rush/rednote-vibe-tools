# 排行榜全分类观察与轻松愉悦玩法选品

调研日期：2026-09-06。用户本轮偏好：能玩起来、轻松愉悦。状态：选品建议，未立项。

## 1. 调整结论

44 号文档偏重生活实用工具，没有充分贴合用户这次明确的“轻松玩起来”。本轮优先级改为：**直接动手 → 立即变化 → 小惊喜 → 留下一件自己的作品 → 愿意再来一遍**。

最推荐先做 **果冻脱模研究所**，其次是 **毛绒地毯修剪店** 和 **口袋雪景球**。不是照搬上榜产品，而是从已有受众信号出发，设计新的核心操作。

需要修正上一轮的一点：不能泛化地说“测试不值得做”。本次累计使用榜前两名都是测试，说明它依然有很强的传播表现；只是用户已经有 SBTI，并且这次明确要动手玩，所以当前不再优先加一套答题测试。

## 6. A1：果冻脱模研究所

**一句话卖点：做一只舍不得吃、忍不住戳的果冻。**

### 30 秒体验脚本

0–3 秒：首屏直接放一个软模具和一杯粉色果冻液；用户点杯子就开始倒。

3–10 秒：选第二种颜色，放两片水果；流体表现采用预设填充与波纹，不做昂贵真实流体。

10–18 秒：短暂凝固表现后，拉模具边缘、翻扣盘子；每一步都有形变响应，可用点击替代拖动。

18–25 秒：果冻“啵”地脱出、左右晃动；此刻是演示视频核心。

25–30 秒：戳它会弹，盘子可换颜色，进入作品架或再做一只。

### 首发内容与边界

- 4 个模具、6 组配色、8 个装饰、3 个盘子；先做 1 套验证手感再扩。
- 自由模式，无倒计时、失败、过期、货币和每日签到。
- 首发不加入客户订单与长经营线，避免与汴京饮子铺重复。
- 成品可反复戳动，不能结束后只剩分享按钮。
- 保存配方 ID、装饰位置、颜色与随机种子，最多 20 件；重开时重绘，禁止保存图片或 Blob。
- 声音作为增强项，静音时仍能从形变与波纹理解操作。

### 值得做与停止条件

有戳泥、虚拟食物及果冻相关高使用样本支持相邻需求。搜索索引中的“果冻啵啵爆”为 245,602 累计使用（搜索索引口径），但“爆破”和“脱模制作”并非同一玩法。

先验证“拉边—脱模—戳动”三段。若测试者觉得只是点按钮播放视频，不继续做大量模具；调整动作与形变后再决定。

## 7. A2：毛绒地毯修剪店

**一句话卖点：把毛茸茸的一团，修成刚刚好的可爱。**

### 核心流程

选一张云朵、荷包蛋或原创猫爪图案 → 粗绒铺满轮廓 → 推着修剪工具沿边移动 → 多余绒毛飞落 → 用软刷扫净 → 地毯放进小房间看效果。

### 首发内容与边界

- 6 个简单图案、8 组配色、修边与刷毛 2 种操作、3 张展示背景。
- 默认不会剪坏主体，偏离边缘时工具停止推进；用户可以重新刷过，不扣分。
- 不做整套簇绒机器、真实纤维物理和自由导图，聚焦最解压的修整部分。
- 成品可摸出倒绒方向的小色差，保持可把玩性。
- 用分区进度和确定种子重建绒面；限制毛绒粒子数，对低性能设备用贴图或短线簇降级。
- 首发作品架上限 20 件，只保存图案、配色和完成状态。

### 值得做与停止条件

借鉴戳泥的电子触感与剪纸、拼豆的作品完成感；“毛毡”“地毯”在本次名称/简介关键词检索中没有匹配，仍需避免把这解释为竞争真空。

验证重点是静音状态下用户是否仍愿意把一个边修完。若必须依赖声音才能产生反馈，或者手机滑动明显卡顿，先解决手感与性能，不扩内容库。

## 8. A3：口袋雪景球

**一句话卖点：亲手装好一场只属于你的雪。**

### 核心流程

选小屋或街角底座 → 拖入树木、路灯、小动物 → 配黄昏/夜晚 → 装上玻璃球 → 手指拨动产生局部旋流 → 雪停后点击房屋亮灯。

### 首发内容与边界

- 3 个底座、12 个原创摆件、4 组配色、雪/花瓣/星屑 3 种粒子。
- 采用二维或 2.5D 分层，不追求自由视角三维编辑。
- 球内同时最多 8 个摆件，可点选替换或用位置按钮移动，保证小屏可操作。
- 不申请陀螺仪，不要求用户摇手机；用手指拖动和“再下一场雪”按钮触发。
- 作品架最多 12 个，保存摆件 ID、坐标、配色与种子，重新绘制。
- 用户可以布置、拨雪、开灯，区别于已有星风来信的一次性揭晓动画，也区别于鱼戏莲叶间的水景交互。

### 值得做与停止条件

“养一片海”的短时造景与数字手工成品提供相邻参考。本次“水晶球”检索只匹配到两个测试方向，不代表所有造景产品已被覆盖。

若用户只愿意看默认场景、不愿意尝试摆放，先检查材料选择是否太多、拖放是否费力。应把自由度压缩到容易做出好看作品的程度。

## 10. 不优先照做的“热门”

- 阴湿恋人、恐怖后室、出轨推理：有高使用样本，但情绪体验与“轻松愉悦”不一致。
- 同人爱豆、知名影视角色、品牌复刻：可观察玩法，不依赖这些角色与名字作为新品卖点；使用原创内容。
- 开蚌换成开另一种矿石：榜内已有“阿玉开石坊”等相邻方向，不能只换揭晓物品。
- 奶茶店、美甲店、普通拼豆：可以做，但当前应该先说明区别在哪里，避免仅换 UI。
- 复杂经营：排行榜显示有吸引力，但我们已有经营项目。若做新手工，先让一次制作本身成立，再决定是否加店铺。
- 纯氛围动画：已有鱼戏莲叶间和星风来信，新增产品要提供更明确的动手过程和个人作品。

## 11. 先做哪一个，怎么验

**默认顺序：果冻脱模 → 毛绒地毯 → 雪景球。** 果冻和已观察到的食物、Q 弹解压信号最接近，且可将原型范围集中于一只模具；地毯更容易做出不同题材，但手感风险高；雪景球适合追求精致视觉，但素材和场景编辑量更大。

先只做一个 30 秒可玩原型，目标不是商城、图鉴和成长体系完整，而是核心动作令人愿意重复。

原型验证建议：

1. 找 5 位用户，不先讲解，观察是否在 3 秒内发现第一个动作。
2. 静音玩一次，检查形变和反馈能否独立成立。
3. 做完后不给“再来一次”任务，观察是否自然继续戳、修、摆或重新制作。
4. 记录“主动重玩”“主动展示成品”的行为，询问最舒服和最无聊的片段；不把礼貌夸赞当需求验证。
5. 若用户只是看完，优先修正操作与成品反馈；若只对默认成品满意，压缩编辑步骤。

完整开发再执行既有工程约束：内容只放本项目 `src/content/content.json`；静态构建，无必需外部 API、运行时 CDN、Service Worker 或未经确认的设备 API；不保存用户媒体或 Blob；本地仅持久化有上限的结构化状态。375 / 390 / 430 CSS px、非零顶部安全区和减少动态均需验证，sticky/fixed 顶部控件及锚点偏移叠加 `var(--safe-area-inset-top, env(safe-area-inset-top, 0px))`；在项目目录完成 `pnpm lint && pnpm test && pnpm build`。
