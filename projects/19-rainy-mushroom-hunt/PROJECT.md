# 项目19｜雨后找菌子：详细立项

> 首版范围更新：用户要求增加首版内容。正式交付数量与耐玩机制以 [CONTENT-PLAN.md](./CONTENT-PLAN.md) 为准；下文原小P0数量改作内部视觉/手感切片，不代表最终首版范围。原玩法规则继续生效。

日期：2026-09-19；状态：立项规划，尚未实现。定位为幻想化森林采集游戏，不承担野生菌识别/食用判断。概率与手感数值是待测试初值。

## 1. 核心体验

“我刚看到叶子下面有一点棕色；拨开之后是一整窝。”主要满足观察、逐层发现、轻轻摘取和装满篮子的快乐。避免屏幕上所有蘑菇发光等人点击，也不通过伤害耐久制造机械劳动。
一次林地探索3～5分钟，无强制倒计时；第一次15秒内拨开叶片、30秒内有首次发现。随时离开，篮子即时保留已采集结果。
P0一片林地的3个相邻小景：树根、落叶坡、倒木边；8种原创幻想菌外观（4常见/3少见/1特别），每种有大小和生长朝向变化。物种名称避免真实可食性暗示，图鉴注明游戏设定。

## 2. 状态与功能

进入林地→观察/移动→拨叶或移枝→发现→摘取→入篮→继续探索→收获展示。
- 开场就在可玩的林地，首次提示只显示手势轮廓，无长篇教程。
- 底部“看看左边/右边”切相邻小景，或拖动专门底部导航条。场景内拖动仅拨叶/采集，避免全屏平移和拨叶竞争。
- 篮子固定中下部安全区域；点开抽屉查看收获，可将观察过的小蜗牛记为“遇见”，不当作菌子装篮。
- 暂停允许切低动效、声音、辅助采集；结束生成篮子摆拍，可收起后继续未探索区域。
- 小景切换不刷新隐藏内容；“换一片林地”明确结束当前林地后生成新seed，已采集累计保留。

## 3. 探索和手势设计

| 操作 | 输入 | 反馈与规则 |
|---|---|---|
| 拨叶 | 按住落叶拖动，超8px判定动作 | 叶片跟手平移旋转，松手滑行80～180ms，摩擦后停下，不弹回原位 |
| 移枝 | 拖动可移动的小枯枝 | 先轻微受阻再绕接触点旋转，最多移动出一个空隙；大树根只是背景 |
| 摘菌 | 按住已显露菌体，再小幅左右晃动后向上提 | 菌柄弯曲、根部阴影松动，达到拔起阈值后带少量泥屑入篮 |
| 查看 | 点已采集物/篮内物 | 放大外观与发现地点，不提供食用建议 |
| 辅助摘取 | 已显露物上按住350ms，松手确认 | 完整拔起动画，免除晃动要求，奖励相同 |

摘取初值：暴露菌盖面积≥45%且触点可达才可锁定；两次累计横向位移各约菌盖宽的15%，随后向上移动菌高25%即可拔起。晃动不是节奏QTE，不要求特定速度；按住时显示根部松动程度而非数字进度条。
锁定后小范围移动归采集，不再拨下方叶片；pointercancel回到原位，不损失物件。过快动作最多产生轻微形变/土粒，不把珍稀菌随机弄坏。
按可见对象深度命中，小蘑菇命中扩展后若与邻居重叠，显示轻轮廓由玩家继续拖向选择，不能自动吸走另一个对象。
篮内物出现轻微挤压/落位，不模拟无限堆积刚体；超过展示量用分页摆放，统计保留。

## 4. 隐藏生成与发现层次

场景生成固定spawn slots，每个槽记录生境、遮挡物、可达性、视线线索。每张林地12～18个潜在采集点，约55%有菌；有菌条件下单株/小簇/大簇权重50/35/15，物种条件权重按生境配置。
- 首次教学槽固定可见菌盖一角，明示练习林地；普通生成不每次保底珍稀。
- 空点有真实场景反馈：湿叶、松针、虫爬过，不播放失败提示。
- 线索至少包含颜色露角、叶层隆起、菌柄投影之一；完全无提示的隐藏点占比≤20%，避免靠清屏擦除。
- 至少一条可达路径能移开遮挡物。生成后用简化可达性验证，不能把菌永久压在不可移动树根下。
- 菌簇揭晓分层：先见1株，再拨周边出现2～4株；同一簇种类/尺度相关，不能乱撒所有物种。
- 特别外观条件概率低但可解释为生境差异，收获取决于探索覆盖率，采集手法只影响节奏不随机扣成功率。
- 遮挡物是实体，暴露判定用CPU粗网格采样或多边形覆盖，不靠每帧像素读取。连续拨同一叶不会重复刷新奖励。

## 5. 视觉和触感设计

主色：苔绿#526847、湿土#4A372D、奶油菌盖#DFCCAA、锈红#A85C45、林隙光#E6D6A7。清晨雨后暖光从右上穿过，地面冷湿，避免整屏墨绿看不清。
构图：固定斜俯视近景，地面占约75%；树根/倒木建立尺度，少量前景叶构建纵深。可采集对象与背景同质感，通过接触阴影、轻微呼吸式环境风区分，而非统一描边。
- 叶片：正反面不同亮度，湿斑、缺口和主叶脉；拨动时水珠从低点滚走，不每张叶都触发水珠。
- 蘑菇：菌盖柔和高光、边缘透光感、菌柄接触阴影；拔起时根部的小面积土壤拉伸后散开。
- 露水：少数明亮点闪烁，阴影区不闪；不能用全屏粒子替代真实湿润材质。
- 拔取节奏：0～80ms跟手倾斜，80～220ms根部松动，越阈值后90ms轻弹，300～500ms落篮。时间为视觉调参起点。
- 音效：湿叶摩擦、软土松脱、轻碰竹篮、极低音量滴水；收获不使用赌场式奖励音。
- 5秒视觉切片必须包含：拨开湿叶→露出菌簇→摘下一株→竹篮落位。

## 6. 技术栈与资源方案

最佳适配为TypeScript + Canvas 2D多层绘制 + DOM/CSS，Rolldown IIFE。固定近景、局部遮挡与精灵形变用2D更直接；首版不引入WebGL/Three/Pixi。
层次：背景缓存画布→静态土壤/根→菌体→可移动遮挡叶→水珠土粒→前景光影；上下文层数控制在2～3个实际显示画布，其余用普通内存canvas缓存，不依赖OffscreenCanvas/Worker。
精灵由本地WebP/PNG图集提供，切片元数据归content.json；多角度菌盖可用少量图集加网格近似变形，首版用分段旋转和缩放，不做复杂骨骼系统。
- 每小景可移动叶≤60、菌实体≤35、活动粒子≤100，低档叶≤35/粒子≤30。
- 静态背景缓存，只有变动区重绘；低档减少水珠和光影动画，所有采集实体/遮挡规则保留。
- CPU空间网格用于命中与遮挡，60Hz采集模拟；阴影使用预绘精灵避免多层实时blur。
- 默认逻辑画布限制DPR≤1.5，图片解码预算≤32MiB。背景单张优先≤1536边，场景切换分批加载释放。
- 资产目标：3背景/局部图层、1叶片图集、1菌体图集、1工具篮子图集；纹理来源、裁切和授权记录在项目内。

## 7. 数据和存档

content.json：habitats、spawnSlots、species、clusterRules、occluders、gestureTuning、atlasFrames、copy、audio、layout、quality。
species：id、displayName、rarityClass、habitatWeights、sizeRange、paletteVariant、atlasFrames；不放毒性/食用字段。
进行中存档：林地seed与版本、已移叶片的简化变换、各点revealed/collected、篮内ID与尺寸、累计图鉴。少量节点保存结构化数据，不截图存档。
发现和采集分开记录，小蜗牛等观察事件不占篮子容量；篮子展示满不阻止继续采集。

## 8. 验收与范围

P0顺序：一片叶+一株菌手感→遮挡/可达性→单景完整循环→视觉样板→3景8种→图鉴/存档→兼容交付。
P1：细雨天气、更多菌簇形态、拍摄式图鉴构图；不加饥饿、烹饪、出售和真实物种识别。
专项测试：
1. 遮挡前无法隔叶采集，移叶后判定正确；可见部分点击不会穿透摘取后方物。
2. 1000个生成seed全部存在可达解；珍稀不出现在永久遮挡下。
3. 切景、暂停、画质、读档不重新生成；同一菌最多入篮一次。
4. 低档叶片表现减少时不改变逻辑遮挡；不同帧率不改变已采集集合。
5. pointercancel、拖动到宿主覆盖层、旋转和多指均不误采集。
6. 5名首次测试者至少4名能凭线索找到第一簇，至少3名会主动查看树根另一侧；记录搜索过难区域及第一次发现耗时。
7. 视觉录像中湿叶和菌盖质感协调、拔起受力清楚、没有揭露瞬间贴图跳变。
