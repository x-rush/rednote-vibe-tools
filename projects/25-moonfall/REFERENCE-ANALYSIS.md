# 月流参考图与实现

## 当前方向：黑山与错落银丝

最新节奏：流水用 22 秒徐徐展开；取消沿线扫过的短亮段，改为冷白小光点按实际路程缓慢下行，带柔和光晕与错相明灭。光点只在已流到的水路上出现，水路出画逻辑保留。

后续反馈要求支流继续流出屏幕：当前所有独立支流均越过画布左侧或底部，末端不再停留在山腰。路径整体重新计时，保留移动水滴，取消固定末端亮点。

用户不喜欢写实山体纹理，也不喜欢整齐的水幕，要求重新参考最早两张截图的流水。当前山体恢复近黑连续剪影，删除纹理和等距平台。水从月下宽源流出，在错落岩口处改变密度；中部水帘较长，下部向左分散，右侧保留长短不同的悬丝和末端亮点。每束独立生成起点、长度、轨迹和亮度，局部成簇、局部留黑，不采用等距平移整条河道的方式。早期参考里的小型暖白撞击亮点也以代码复现。

以下为前一版概念图的分析记录，山体材质方案已被本节取代。

## 最新参考：深夜山石、明月与层叠跌水

用户最新给出的图像为 3:4 画幅。作为构图、材质与光线参考，不作为页面背景、纹理或转场层。所有动画画面仍由代码生成。

- 月亮：右上大月轮，带灰蓝月海、明亮陨石坑、冷白边缘和克制的光晕。月下水源具有宽度，不能收束成尖点。
- 山体：由右上向左下递减；岩台顶面与垂直崖壁明暗不同。远山更柔、更浅，近景更深，谷间有薄雾形成距离感。
- 水路：连续的河道经过岩台横向绕行，随后垂直跌落。岩石遮住局部水线；落点形成水花与反光。主瀑、侧瀑、浅水和离散光点的密度不同。
- 夜色：深靛蓝与灰蓝，而非早先截图里的高饱和钴蓝。水和月亮是最亮的部分，山的亮边保持克制。
- 文字：左上「月流」，下方「流水今日，明月前身」。月亮停稳后标题浮现，水接近流满后诗句浮现。

## 代码设计

使用 900 × 1200 场景坐标。山体、月面和雾采用程序噪声在内存画布生成，绘制时叠加近远图层；不包含用户原图像素。

河道坐标存于 src/flow.js，共享累积路程时钟。所有水幕都根据同一进度依次出现，避免下游独立提前发光。根据用户对“七扭八歪”路线的反馈，主水路沿山势连续下行，移除重复左右折返；四段跌水的高度不等，中部水幕更长，底部渐宽。三个主要岩台与少量偏置石块决定局部分流。不同线条使用独立速度、亮度、细微偏移与水滴，落点叠加散射光、薄雾、泡沫和上扬水滴。

点击前是山体近景；点击后镜头拉远，月亮落下，再出现流水。该镜头叙事沿用用户先前要求，无法仅从静态参考图推断。

## 表现边界

当前是分层程序绘画，具备程序纹理和动态水线。参考图的摄影式碎石结构、复杂体积光和真实流体外观未逐像素复现。宣传概念图与网页实际录屏应明确区分。
