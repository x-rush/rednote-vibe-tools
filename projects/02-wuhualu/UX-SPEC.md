# 器华录：文物寻踪 UX Specification

状态：`SECOND-PASS UX SPEC`

## 1. 体验目标

- 5 秒：像进入闭馆后的博物档案室，而不是抽卡游戏。
- 30 秒：观察一件具体文物，理解“看线索会降低星级”的公平规则。
- 2–4 分钟：完成 5 件寻踪，看到文物从轮廓恢复原貌并进入图鉴。
- 完成后：知道图像性质、馆藏来源和一条真正值得记住的知识。

## 2. 页面与导航

```text
封面
├─ 今日寻踪 → 本轮藏品匣 → 猜谜 ×5 → 本轮总结 → 图鉴
├─ 继续本轮 → 当前文物
├─ 图鉴
└─ 设置/来源/数据

猜谜
├─ 直接作答（提交不可撤销）
├─ 查看线索（同一线索不重复扣星）
└─ 退出（保存题序、索引、线索和答案）
```

返回键：关闭藏品签/来源抽屉 → 回猜谜或图鉴 → 回封面。揭晓后不得返回修改答案。

## 3. 页面规格

### W01 封面｜首次

第一视觉：`器华录` 与一件被暗柜遮住的真实器型轮廓。\
第二信息：根据局部、轮廓和生活线索认出 5 件文物。  
主动作：`开启今日寻踪`。  
次动作：`查看图鉴`、`图片与资料说明`。

- 首屏说明 `5 件 · 约 3 分钟`。
- 不使用稀有度、卡池、十连等语言。
- 轮廓必须来自首发真实文物器型，但不泄露当轮答案。

### W02 封面｜本轮进行中

显示：`继续第 3 / 5 件`、当前可得星级、更新时间。  
重新开始需要确认，并说明今日 seed 局会被替换。

### W03 本轮藏品匣

五个档案位只显示编号和状态：未知、进行中、已揭晓。已揭晓可显示缩略和星级。

主动作：`观察第一件`。星级规则以一行说明：直接答对 3 星；每揭开一条线索降低一级，最低 1 星。

### W04 猜谜｜初始

层级：局次/星级 → 观察区 → 已有提示 → 4 个选项 → 线索入口。

- 观察区预留固定比例，避免图片加载造成跳动。
- 资源类型标签在观察区边缘显示：实物授权图 / 公共领域 / 自绘示意 / 创意重构。
- 4 个选项顺序由 seed 决定，同一局刷新不变。
- 选择后进入“待提交”，不立即判定。

### W05 猜谜｜线索展开

- 线索按 1→2→3 解锁。
- 点击未看线索先显示将从几星降到几星，再确认展开；同一线索再次查看不扣星。
- 线索出现后保持观察区和选项位置稳定。
- 第三条线索仍不直接写完整答案名称。

### W06 猜谜｜待提交

选中项显示档案夹签，不用绿色。主动作 `确认答案`；可改选。快速双击只提交一次。

### W07 揭晓｜正确

流程：轮廓/局部 → 聚光扫过 → 完整图；减少动画时直接交叉淡入。

首屏：正确状态、正式名称、年代/类别、获得星级。  
第二层：为什么能认出、核心看点。  
第三层：馆藏/出土/图片性质/来源。  
主动作：`收入器华录，下一件`。

### W08 揭晓｜错误

不扣额外星级，不羞辱。显示正确名称、干扰项为何容易混淆、同样的藏品知识。主动作仍是下一件。

### W09 本轮总结

五件纵向记录：缩略、名称、星级、使用线索数。第一视觉是本轮获得的总星和新增图鉴数，而不是失败数量。

主动作 `查看图鉴`；次动作 `再来一轮`（新 seed，避免立即重复）。

### W10 图鉴

状态：未解锁、1/2/3 星、内容更新。

- 未解锁显示准确轮廓和类别提示，不显示名称。
- 已解锁显示缩略、名称、年代和最佳星级。
- 支持类别/年代筛选；首发不做复杂搜索。
- 内容更新标记说明资料有修订，不清除原星级。

### W11 文物详情

详情采用独立“策展长卷”，不复用寻踪流程的五札长页：

- 首段用完整图、名称、年代、类别与图片性质建立文物主体，AI 重构标签必须紧邻主图。
- “一分钟看懂”把三处观察点改写为三张证据卡，保留部位名称与观察札记。
- “器物的一生”复用五段故事正文，但重新编排为“从形与工开始／回到它的时代／从出土走到今天”三章时间轴。
- 页尾依次收纳馆藏与资料状态、相关文物横向藏架、去重后的查证来源。
- 不出现五札编号导航、逐札确认按钮、离柜一问或记忆挑战；从图鉴进入后页面必须回到顶部。

### W12 空图鉴

文案：`器华录还是空的。完成第一件寻踪，就会在这里留下档案。` 主动作 `开始今日寻踪`。

### W13 图片失败

显示由实物轮廓核验制作的 SVG、资源性质、完整文字线索。允许作答和揭晓；揭晓页显示“图像暂未加载”，不把空白当谜面。

### W14 数据恢复

题序合法但当前资源缺失：继续文字模式。  
题序/答案结构损坏：回本轮藏品匣，保留已完成文物，重建未完成部分并说明。  
无法恢复：可重新开始，不清空图鉴。

### W15 设置/来源

动画、声音、图片性质说明、资料来源、清空当前局、清空图鉴。两个清空动作分开确认。

## 4. 状态矩阵

| 功能 | Loading | Empty | Error | Success | Partial |
|---|---|---|---|---|---|
| 今日局 | 编匣短状态 | 题库不足阻止开始 | 可重试/查看诊断 | 五件固定 | 图片不足时文字模式，不静默换文物 |
| 图片 | 固定比例骨架 | 不适用 | 轮廓+文字 | 实物/重构图 | 局部缺失时不把缺失图算线索 |
| 图鉴 | 本地即时 | 暖空态 | 修复单条/保留其他 | 可筛选 | 内容更新有标记 |
| 揭晓 | 先锁答案再显示 | 不适用 | 文字揭晓 | 收入图鉴 | 图片失败仍写解锁 |

## 5. 响应式与无障碍

- 375px：观察区高度不低于 260px；选项自然滚动。
- 390px：基准；主要动作首屏或一次短滚动可达。
- 430px：观察区可略增，正文不超过 390px。
- 桌面：移动画布居中；图鉴可切为最多 3 列。
- 图片 alt 描述器型，不直接泄露猜谜答案；作答后 alt 可更新为正式名称。
- 选项用单选语义；星级同时用数字文字，不只用星图形。

## 6. 页面反推的资源候选

| 槽位 | 媒介 | 数量判断 | 门禁 |
|---|---|---|---|
| 文物完整揭晓 | 合法实物图或明确 AI 重构 | 每件 1 | 具体馆藏/版本、版权和性质标签 |
| 局部谜面 | 从允许使用完整图裁切 | 每件 1–2，页面测试后冻结 | 不改变纹饰、缺损和比例 |
| 未解锁轮廓 | 核验 SVG | 每件 1 | 与实物器型一致 |
| 藏品签/星级/类别 | SVG/CSS | 系统级 | 无 AI 位图 |
| 展柜氛围 | CSS + 可选纹理 | 1 套 | 不遮挡观察区 |

## 7. 高保真前门槛

- [x] 五件局、线索扣星、不可撤销提交和图鉴状态完整。
- [x] 图片性质与失败降级进入主流程。
- [ ] 从 20 件库中选择青铜/陶瓷或玉器两个黄金样例。
- [ ] 为黄金样例确认馆藏、版权、实物图和准确轮廓。
- [ ] 完成 10 个关键状态高保真稿并实测三宽度。
