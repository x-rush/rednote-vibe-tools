# 闻山视觉参考证据包（生成前冻结）

## 角色目标

闻山是虚构的“山海司守卷人”，负责递卷、校读和解释事实层级。他不是官员、道士、国师、驯兽师或算命先生；视觉应传达长期与卷册、异兽图录和纸墨相处的安静可靠感。

## 真实图像参考

1. `references/wenshan/portrait-of-a-scholar-met-48941.jpg`：纽约大都会艺术博物馆藏《Portrait of a Scholar》，晚明至清初，公共领域，Object 48941。用于素色宽袍、黑色文士帽、端坐与克制配色；不把具体人物身份移植给闻山。
2. `references/wenshan/fu-sheng-transmitting-documents-met-39667.jpg`：纽约大都会艺术博物馆藏杜堇款《伏生授经图》，明代，公共领域，Object 39667。用于文士与展开卷册、低案、纸墨之间的动作关系及明代人物画线条；不复制伏生形象。
3. 同目录 JSON 保存博物馆 API 元数据和公共领域字段，便于复核对象编号、年代、材质和原图链接。

## 正式形象硬字段

- 原创中国青年男性守卷人，约二十七至三十二岁，沉静但不衰老；
- 黑色简素文士巾帽/软帽，深松绿色交领长袍，内层暖灰白，窄而可工作的袖口；不使用官服补子；
- 单手托一卷空白折页/卷册，另一手轻按卷边或做“请阅卷”手势；
- 腰间只允许一枚朴素木质卷签和细绳，不挂剑、葫芦、玉佩堆或法器；
- 背景为弱化的暖纸山海司藏卷架，不能生成可辨识伪汉字；
- 3:4 半身构图，双手与卷册结构可信，头像裁切保留帽、脸和松绿领口。

## 禁止

- 道士冠、阴阳八卦、法杖、拂尘、浮空符咒、仙侠披风、发光瞳孔；
- 高品官服、补子、冕冠、帝王金饰、武器或铠甲；
- 兽角、兽耳、把闻山画成某只异兽的主人；
- 伪汉字、卷册正文、印章文字、Logo、水印；
- 过度苍老、神秘反派、日漫阴阳师或 Q 版书童。

## 验收

- [ ] 文士衣冠、卷册与手部关系可信
- [ ] 一眼可辨为守卷/校读角色，而非官员、道士或战斗角色
- [ ] 无伪文字、无时代混搭、无诊断/算命暗示
- [ ] 900×1200 母版 ≤180 KB，头像与占位满足统一预算
- [ ] 装回首次引导、结果节点、帮助与异常状态后通过三宽二检
