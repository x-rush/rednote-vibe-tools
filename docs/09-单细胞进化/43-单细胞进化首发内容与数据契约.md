# 单细胞进化｜首发内容与数据契约

状态：**CONTENT CONTRACT READY / 待垂直切片校准数值**

本文件冻结首发内容规模、稳定 ID、字段和最低组合覆盖。具体数值可在手感测试后调整，但不得静默删除玩法类别或用纯数值升级替代可见器官。

## 1. 通用约束

- 所有内容为幻想微观世界，不宣称是真实细胞行为、医学、生物学或进化结论。
- 名称、轮廓、美术、技能与关卡不得复制已有商业游戏。
- 每个器官必须有视觉变化、玩法收益和明确代价。
- 每个敌人必须至少有一种可读预警和两种应对方式。
- 每个 Boss 必须支持战斗之外的通过路径。
- 内容数据进入 `src/content/content.json`；代码只引用稳定 ID。
- 展示文案短句化，战斗中不依赖长说明。

## 16. 内容完整性测试

- 所有引用 ID 存在且类型匹配。
- 每个器官存在合法锚点、视觉配方、代价和至少一个环境用途。
- 24 个器官八类完整覆盖，每类恰好 3 个。
- 12 个组合可由首发器官组成，不依赖未发布内容。
- 每个环境有资源、猎物、捕食者、事件和退出路径。
- 每个 Boss 至少有三种解决路径，且包含非战斗路径。
- 每个敌人具备预警，不以颜色作为唯一提示。
- 每个结局与死因均可由自动化测试触发。
- 固定种子在相同内容版本下生成相同关键序列。
- 文案长度符合少字宪法，长图鉴不会进入战斗 UI。

## 17. 数值校准门禁

正式数值在 M1 垂直切片后冻结，冻结前至少满足：

- 首次吞噬中位时间不超过 20 秒。
- 首次进化中位时间为 35–60 秒。
- 首局中位存活时间为 4–8 分钟。
- 熟练玩家普通局目标时长为 8–15 分钟。
- 任一单器官不得成为所有环境的最优解。
- 至少 4 条主要构筑路线能通过首发终局。
- 高风险稀有掉落不能成为唯一通关条件。
- 纯永久数值增益不能让开局捕食者失去威胁。
