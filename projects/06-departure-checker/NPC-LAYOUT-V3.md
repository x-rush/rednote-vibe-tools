# 出门检查官 V3 · 路岚陪伴式布局规格

状态：已实现并通过浏览器验收
日期：2026-08-26
范围：`projects/06-departure-checker/**`

## 1. 目标

在不改变确定性规则、存储和清单交互的前提下，重新组织主要页面布局，让路岚从“首次说明弹层里的角色”升级为持续可见的出门搭档。用户在首页、条件问答、清单、最后一分钟和完成结果中都能看到清晰的大幅立绘，同时关键操作不被图片遮挡。

## 2. 设计方向

采用“人物舞台 + 工作纸面”双层结构：

- 人物舞台使用现有 `guide-master-v2.webp`，通过不同 `object-position` 裁切复用同一角色身份。
- 工作纸面承载所有标题、选项、清单和按钮，保持文字为 DOM 内容。
- 主图不烘焙文案、不充当按钮，也不影响图片加载失败时的完整流程。
- 不新增第二张不同脸部或服装的立绘，避免 NPC 形象漂移和额外资源体积。

## 3. 页面布局

### 首页

- 品牌条下使用 196–218px 的路岚迎接舞台。
- 舞台左侧只保留眉题与“容易忘的，我陪你查。”两行短句；右侧约 66%–68% 显示头部至大腿中部的大立绘。
- 主标题“今天去哪儿？”下沉到场景纸面顶部，375／390／430px 均保持单行，不再与人物争抢横向空间。
- 人物舞台底部与场景选择纸面轻微重叠，形成明确的上下层级。
- 最近清单存在时置于舞台下方第一位；八场景继续使用两列网格。

### 条件问答

- 每一步顶部保留 170–205px 的陪伴舞台，大立绘固定在右侧约 46% 宽度。
- 左侧显示路岚身份和当前阶段短句，短句按问题类型本地映射，不新增业务判断。
- 问题卡上移 20px 覆盖舞台底缘；答案使用两列大按钮，布尔、单选和数字预设点击后直接进入下一题。
- 底部导航最多保留“上一题 / 跳过此题”两个按钮，不再重复显示“下一题”。
- 四步使用同一主图但调整裁切，避免每次翻页产生角色位置跳动。

### 清单工作台

- 顶部摘要改为 188–220px 的深森林绿人物横幅。
- 左侧展示场景、条件和剩余关键项；右侧显示约半身的大立绘，不再只显示 40px 头像。
- 点击人物区域打开升级后的“问路岚”大图帮助抽屉。
- 三视图标签紧接摘要横幅，减少原顶部文字块与标签间的割裂。

### 路岚帮助抽屉

- 帮助模式顶部加入 180–230px 大图，下面保留三个结构化解释入口。
- 首次引导和帮助模式已有大图，不再重复显示 48px 头像；最近清单和恢复页因没有大图而继续保留紧凑头像。
- 主图为展示内容，关闭按钮和帮助操作独立可聚焦。

### 最后一分钟

- 深绿模式顶部加入 120–150px 的路岚侧边舞台；人物不遮住“还剩 N 项”。
- 所有未完成关键项仍完整展示，人物只负责陪伴和降低紧迫感。

### 完成结果

- 完成章与路岚大立绘共同构成结束画面：人物约 210px 高，完成章叠在纸面而不是人物脸部或双手上。
- 保留回清单和回首页两个动作，不加入打卡、分享或积分。

### 最近清单与恢复状态

- 最近清单保留紧凑布局，只在标题区使用路岚头像，避免与记录列表争夺空间。
- 无精确匹配和部分可用状态加入路岚头像及低压力说明，不使用大立绘，以便错误信息优先。

## 4. 组件边界

- 新增 `GuidePortrait`：统一输出 `home`、`wizard`、`summary`、`urgent`、`completion`、`help` 六种裁切和装饰模式。
- `HomeScreen`、`ConditionWizard`、`ChecklistWorkspace`、`LastMinuteMode`、`CompletionScreen` 只负责提供文案和布局位置。
- `GuideSheet` 的 help 模式升级为带大图版本。
- 不改变 reducer、内容 JSON、生成引擎或存储 schema。

## 5. 响应式规则

- 375px：人物舞台不低于 170px；首页和清单立绘可见面积不少于容器的 42%。
- 390px：按基准尺寸呈现；场景网格仍为两列。
- 430px：人物舞台增高但最大内容宽度仍为 560px。
- 所有舞台使用 `overflow: hidden`、受控 `object-position` 和渐变遮罩；禁止用绝对定位把图片伸出文档宽度。
- 横屏或低高度视口压缩舞台高度，优先保留问题、选项和底部操作。

## 6. 动效与无障碍

- 页面进入时人物只做 8px、220ms 淡入；不做呼吸、漂浮或无限循环。
- `prefers-reduced-motion: reduce` 下完全静态。
- 首页首张人物图提供简短替代文本；其余重复立绘使用空 `alt`，避免屏幕阅读器反复播报。
- 可点击人物区域必须是带可访问名称的 `button`；纯展示立绘不得伪装成按钮。
- 图片加载失败时保留背景、身份标签和全部任务操作。

## 7. 验收标准

- 首页、四步问答、清单、帮助、最后一分钟、完成结果均能看到路岚。
- 首页、问答和清单至少展示半身级大图，不退化为头像。
- 375／390／430px 无横向溢出、0 断图，底部主操作完整可见。
- 清单状态、问题跳过、保存原位更新、显式覆盖和恢复路径不回归。
- `pnpm lint && pnpm test && pnpm build` 全部通过。

## 8. 实现结果

- 现有 900×1200 `guide-master-v2.webp` 已复用于首页、四步问答、清单摘要、帮助、最后一分钟和完成结果六类大图舞台；最近清单与可恢复状态复用 160×160 头像。
- 没有新增美术文件或依赖，同一张主图通过固定裁切和渐变形成连续角色身份。
- 清单人物区是带“打开路岚帮助”可访问名称的真实按钮；首页之外的重复立绘均为空替代文本。
- 最后一分钟挂载时会复位到页面顶部，避免从长清单底部进入后看不到人物和当前关键项。
- 首页在二次视觉复核后改为“人物舞台 + 纸面标题”：人物宽度提升至约三分之二，主标题移出舞台，解决大标题压缩人物视觉空间的问题。
- 条件问答改为答案直达下一题；末题使用合并后的最新条件生成，避免刚点击的值因状态批处理而遗漏。
- 首次引导与大图帮助移除重复小头像；问答答案和底部导航重排为更清晰的两列体系。
- 375×812、390×844、430×932 真实浏览器检查均为 `scrollWidth === clientWidth`、0 断图；控制台 0 error。
- 帮助面板初始焦点、Tab 闭环、Escape 关闭、触发点焦点恢复和 body 滚动恢复全部通过；减弱动态模式下人物舞台无位移。
- 自动门禁最终结果记录于 `PREP_REPORT.md` 与 `VISUAL-QA.md`。
