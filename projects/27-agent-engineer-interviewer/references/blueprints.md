# 岗位画像与选题蓝图

5个便利抽样招聘原文，包含企业官网与高校就业发布；中国市场与实习/校招为主，不代表全行业分布或持续招聘状态。仅提取职责方向，未获得这些公司的真实面试题；本包60个场景均原创，不宣称公司真题。算法岗训练框架、微调与研究要求是对照信息，不转成应用实习岗必备门槛。

## 应用开发实习

能实现小模块、接口联调和可验证实验；以清楚解释流程、边界与基本失败处理为目标，不假定有生产经验。

Python或TypeScript/API/Git、提示结构、基础RAG与工具、测试文档；项目可以课程或个人作品，明确本人负责部分。

## 初级Agent应用工程

在小范围任务上独立串联检索、工具和状态，能对效果、成本、故障和发布作具体取舍。

端到端链路、授权幂等、评估追踪、上线维护；junior锚点是本训练包解释层次，不等同这些公司官方录用标准。

## 算法/研究相邻岗

模型训练、框架与算法要求更强，本包只能覆盖应用工程部分；按用户JD说明尚需专项准备。

不把深度学习训练、论文或竞赛当所有Agent应用岗默认要求；研究方法是选修，不自动强迫多Agent。
