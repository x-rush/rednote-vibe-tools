## 2. 为什么是这 5 款

### 2.1 筛选漏斗

从 240+ 应用里过筛，每一关都要过：

1. **纯前端可落地**：无后端、无实时联网、无麦克风/摄像头、不吃用户图片。剔除 THIRD（联网房间）、
   404 号房间（3D）、声之growth（麦克风）、Sifu Camera Coach（相机）、Weekend Frames（用户图）、
   Petal Studio（分享墙后端）、Glimpse（人脸上传）等。
2. **零或近零素材**：所有美术走 Canvas/SVG 程序化绘制，不引入版权素材、不复用 23 号被拒教训里的历史条目素材。
3. **有目标与关卡循环**：纯物理演示没有复访理由，剔除 Critical Sand Pile、Metal Fatigue Bend、
   Film Latitude、Cochineal Extract 等科普向（可另做科学工具线，不进本批次）。
4. **与既有 30 个项目零重叠**：已占位主题为——13 果冻慢慢（凝固透明软体）、14/29 节奏闪避、
   17 捡手机文学（叙事）、18–22 自然收集系、23–25 水墨国风治愈系、28 人生指南、30 消消乐（网格消除连锁）。
   本批次 5 款落在**运动手作 / 物理关卡 / 治愈器物 / 几何弹射 / 竞速速降**五条新赛道上。
5. **一句话可讲清 + 首次 30–90 秒有结果**：符合 `docs/00-总控与共用/44` 号候选池的共用约束。

### 2.2 排序理由

- **毽子连击排第一**：童年运动是小红书的天然流量词（毽子/跳绳/丢沙包/翻花绳），"连击纪录"自带复访，
  且手感反馈是纯物理，一眼就会玩，最适合做系列打头。
- **蛋落地排第二**：竖屏点按就能玩，12 关递进，"轻轻放下不碎"是一个人人能理解且愿意晒的紧张感。
- **彩沙瓶排第三**：成品瓶本身就是传播物，和榜单"揭示瞬间"结构最贴。
- **弹珠神殿排第四**：8 房间 + 宝石图鉴提供收集维度，但解谜精度要求高，上线排在手作之后。
- **沙丘速降排最后**：竞速最耐玩也最难调手感，需要前面几款把渲染与手感底座跑顺。

## 3. 每款差异化红线

| 序 | 必须做到的差异 | 不能做成什么 |
|---|---|---|
| 1 | 毽子是有重心的飞行体，踢的角度决定去向；连击要靠"接住再起" | 不能做成点一下就有连击数字的点击器 |
| 2 | 落地速度决定碎不碎，要给玩家"读速度"的反馈（影子/裂痕预警） | 不能做成只有一上一下的两点弹跳 |
| 3 | 沙要有堆积坡度与滑落，塑形靠工具而非纯画 | 不能做成纯渐变矩形填充 |
| 4 | 反弹要吃角度与摩擦，宝石要留在可行位置 | 不能做成直接连线消除 |
| 5 | 雪崩是随时间推进的活物，减速即被追上 | 不能做成单纯的躲避固定障碍 |

## 4. 共用工程底座

每款都从 `projects/30-boba-pop` 复制底座后改写，字段名保持一致：

- `index.html` + `src/app.js` + `src/game.js` + `src/render.js` + `src/audio.js` + `src/storage.js` + `src/style.css`
- 经典脚本加载链（禁 `type="module"`、`import/export`、`eval`、内联脚本、行内事件）
- `src/content/content.json` 承载业务内容（关卡、文案、参数）
- `tools.mjs`（build/preview）、`pack.ps1`（打包 + 白名单 + SHA256）、`verify-artifact.cjs`
- 自检：`qa-mobile-check.cjs`（375/390/430 + 安全区 + 宿主按钮覆盖层 + 横屏）、`qa-flow.cjs`（全流程 + 状态不自行推进断言）
- 宿主按钮避让：`--host-side: 76px` / `--host-top: 56px`，顶部左右不放自己的热区
- 音效：Web Audio 实时合成，零音频文件，规避上传 ZIP 扩展名白名单
- 交付：`release/<slug>-v1.zip`，`index.html` 必须在 zip 根目录

### 4.1 每款提交前必跑

```
npm run lint && npm test && npm run build
node verify-artifact.cjs dist
node qa-mobile-check.cjs
node qa-flow.cjs
pwsh -NoProfile -ExecutionPolicy Bypass -File pack.ps1
```

## 5. 风险与止损

| 风险 | 处置 |
|---|---|
| 5 款铺开导致每款都半成品 | 每款必须独立通过全部门禁才进下一款；不达标就留在本款迭代 |
| 手感类（毽子、蛋、沙丘）调不准很难玩 | 每款单独写 `qa-*.cjs` 量化曲线回归，把参数写进 content.json |
| 与既有项目视觉撞脸 | 每款独立配色与材质体系，不复用 23–25 水墨资产，不复用 30 珍珠渲染 |
| 上架素材重复（23 号被拒教训） | logo 与封面逐款原创，512 PNG 单独出，不进 zip |
| 真机验收缺失 | 浏览器模拟与宿主真机验收分开记录，未做的明确标注 |
