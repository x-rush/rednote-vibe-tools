# 器华录：文物寻踪｜小红书小工具提交单

## 后台字段

- **小工具名称**：`器华录：文物寻踪`
- **Slogan（14 字以内）**：`循纹识器翻开沉睡千年文物档案`
- **简介**：`从局部纹饰、器形与结构线索中猜文物，揭晓后阅读年代、用途与看点，并逐步点亮 20 件首发图鉴。所有题库与记录都在本地运行；艺术图会明确标注为创意重构。`
- **平台图标**：`release-assets/tool-icon-v1.png`
- **运行包**：`器华录-文物寻踪-小工具包-20260826.zip`

## 上传前核对

1. 图标为 512 × 512 PNG，文件小于 5 MB；纸签、金色圆标与朱印完整处于安全区内。
2. ZIP 根目录直接包含 `index.html` 和 `assets/`，不能再包一层 `dist/`。
3. 上传后依次走完：许照引导 → 模式选择 → 线索 → 作答 → 揭晓 → 总结 → 图鉴。
4. 验证 10 件可玩静态文物、2 件文字兜底文物和 8 件待参考文物的状态边界正确。
5. 在 375、390、430 CSS px 下检查无横向滚动、图片不误裁、按钮与底部安全区可用。
6. 清除并重开工具，确认本地图鉴、进度与清除记录符合预期。

## 事实与合规边界

- 文物年代、材质、用途与馆藏信息以 `research/` 证据档案及内容字段为准。
- 创意重构不冒充博物馆实拍；界面中必须保留相应标注。
- 参考不足的文物不得偷偷用想象图替代，继续保持文字或“待补参考”状态。
- 不上传用户图片，不保存 Blob、Base64、音视频；仅在本地保存结构化进度。
- 无后端、运行时 CDN、必需外部 API 或登录依赖。

## 图标构成说明

图标使用已定稿的极简复古档案纸签设计 `public/assets/wuhualu/brand/app-icon-v2.png`。正式文件仅以 Lanczos 算法确定性缩小至 512×512，没有二次生成、重绘或添加文字；`qa-tool-icon-128.png` 与 `qa-tool-icon-64.png` 仅用于缩略验收，不上传后台。
