# 出门检查官 UX Specification

状态：`SECOND-PASS UX SPEC`

## 1. 体验目标

- 5 秒：立即选择出门场景，不阅读长说明。
- 30–90 秒：生成真正有优先级、可解释的清单。
- 核心高光：同一清单从重要程度切到家中空间巡视，勾选状态完全保留。
- 最后一分钟：一手操作，只显示仍未完成的关键项。

## 2. 流程

```text
封面 → 场景 → 条件 → 生成清单
→ 重要程度 / 类别 / 空间动线
→ 勾选与自定义 → 最后确认 → 最近三份
```

三种视图只改变分组/排序，不复制数据。条件改变后保留仍存在物品的勾选。

## 3. 页面规格

### C01 封面/场景

首屏直接显示 8 个场景大按钮和最近一份继续入口；产品说明缩成一句。场景按钮至少 76px 高，图标+文字，不只靠图。

### C02 条件

按必要性分 2–3 屏：时长/过夜、天气（用户选择）、同行对象、特殊活动。可以跳过非关键项。顶部始终能看到已选场景。

主动作 `生成我的清单`；不调用定位或天气 API。

### C03 生成结果｜重要程度

顶部固定：必带未完成数、场景、修改条件。正文按必带/建议/可选分组；每项有名称、类别和“为什么需要”。

勾选立即保存当前清单。关键项可以隐藏但需确认；普通内置项可隐藏并可恢复。

### C04 类别视图

同一 item ID 按证件、电子、衣物、卫生等分组。切换视图不改变勾选、隐藏和自定义状态。

### C05 空间动线

将仍存在项目按卧室→卫生间→厨房→门口等路线组织。第一视觉是“下一站”和未完成项目，而不是普通分组标题。

- 路线由规则映射，不读取户型。
- 同物品不能重复出现。
- 用户勾选后下一站自动更新，但允许回看。

### C06 最后一分钟

只显示未完成的必带/关键确认，字体与按钮增大；一手底部操作。显示 `退出最后一分钟` 返回完整清单。

全部完成时：完成印章、出门提示和返回清单，不制造连续打卡。

### C07 修改条件

修改后展示变更摘要：新增 N 项、移除 N 项、保留已勾选 N 项。被移除的用户自定义项不自动删除，进入“未分类自定义”。

### C08 自定义项

名称必填、可选类别/空间/优先级；可编辑和删除。删除二次确认仅针对自定义项；内置关键项使用隐藏确认。

### C09 最近三份

按更新时间；显示场景、完成比例、更新时间。第四份覆盖最旧记录前明确显示对象，可取消或选择覆盖。

### C10 空/错误

规则无精确结果：保留场景基础必带并解释条件过窄，可返回调整。  
规则引用错误：不显示坏项目，提示部分建议暂不可用。  
非法存储：恢复可识别 item ID；自定义文本损坏则舍弃单项，不清空全部。

## 4. 状态矩阵

| 功能 | Empty | Error | Success | Partial |
|---|---|---|---|---|
| 生成 | 基础清单+调整条件 | 部分规则不可用 | 可解释清单 | 某类为空不显示空组 |
| 空间路线 | 无空间映射则回类别 | 循环/重复检测 | 下一站明确 | 自定义项在未分类 |
| 最近三份 | “还没有最近清单”+选场景 | 修复单份 | 可继续 | 第四份覆盖确认 |
| 完成 | 仍有关键项 | 状态恢复 | 完成印章 | 非关键未完成允许结束并说明 |

## 5. 响应式/无障碍

- 375：场景 2 列；清单行至少 56px；最后一分钟按钮至少 64px。
- 390：基准；顶部关键摘要不超过 25% 视口。
- 430：场景仍 2 列，增加内边距避免图标过大。
- 桌面：内容最大 520px；最近清单可双列。
- 勾选使用原生语义；必带/建议/可选同时有文字。

## 6. 资源候选

- 8 场景图标、约 12 类别/空间图标、优先级、完成印章：统一 SVG。
- 所有有现实原型的图标先看实际物品/空间标识参考，但以抽象线性系统表现。
- 不为物品逐个生成位图；不需要 AI 封面插画才能成立。
