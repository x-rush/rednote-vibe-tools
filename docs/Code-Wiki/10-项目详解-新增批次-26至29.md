## 学习工具与 Skill 的区别

26 使用包内内容进行教学练习，不将展示的 Agent 工程知识描述成工具已在运行真实外部 SDK 或模型服务。构建环境的 Python / Pillow 与运行时离线能力分开；内容版本 2.1.0 与 package.json 0.1.0 采用不同口径。

27 面试官的 package.json 版本为 2.1.0，构建输出 Skill ZIP。项目 README 记录 2026-10-14 提交 SkillHub 审核以及历史已发布版本，不能据此宣布新提交已审核通过。27 静态原型不属于工作区包，也没有正式 H5 发布验收结论。

## 高性价比人生指南

28 当前项目说明为 1.3.5，导入上游 HowToLiveBetter 内容，保留来源归属；34 章、765 条内容，并提供筛选、目录和本地阅读进度。每一章头部仍有完整 banner 和小猫插画；首次打开首页从 banner 展示，切换章节通过锚点进入正文，向上仍可看到 banner。一个章节内自然上下阅读，章节切换后替换本章内容，不把多章追加成无限长页面。恢复进度与首次访问分开处理。

内容集中在 src/content/content.json，更新导入流程、来源记录、迁移与交付检查见项目自身说明。项目内浏览器检查不等于小红书真机已通过。

## 节奏游戏与版本说明
