# 出门检查官 V2 交互与动效规格

状态：已确认并完成实现
日期：2026-08-26

## 1. 原则

动效只解释状态变化，不延长任务、不制造紧迫感。所有循环动画都有静态替代；任何情况下都不使用倒计时、震动、警报闪烁或强制连续操作。

## 2. 时长与曲线

| 类型 | 时长 | 曲线 |
|---|---:|---|
| 按压反馈 | 90ms | `ease-out` |
| 标签选择 | 160ms | `cubic-bezier(.2,.8,.2,1)` |
| 列表插入／移除 | 220ms | `cubic-bezier(.2,.8,.2,1)` |
| 抽屉进入／退出 | 260ms | `cubic-bezier(.2,.8,.2,1)` |
| 路线推进 | 280ms | `cubic-bezier(.2,.8,.2,1)` |
| 完成章 | 420ms | `cubic-bezier(.18,.86,.28,1)` |

单次页面过渡总时长不超过 600ms。

## 3. 关键交互

### 场景选择

- 按下时卡片缩放至 `0.985`，松开恢复。
- 选中场景后边框和图标底色在 160ms 内变化。
- 首次使用时，路岚说明板从底部进入；关闭后焦点回到已选场景卡。

### 条件标签

- 选中标签只改变背景、边框和 2px 内部标记，不移动周围布局。
- 布尔、单选和数字预设点击后直接进入下一题；最后一题把刚选值合并后直接生成，不再要求重复点击“下一题”。
- 手动数字输入使用独立的“使用这个时长”确认；超出定义范围时保持禁用。
- 答案使用两列大按钮；底栏首题仅显示全宽“跳过此题”，后续题显示等宽“上一题 / 跳过此题”。
- 自动进入下一题后，焦点落到新题标题，让键盘和读屏用户立即获知题目已变化。
- 返回上一步保留原选择和焦点顺序。

### 生成过渡

- 使用三段静态文字与一条单向进度线，不使用无限旋转器。
- 标准模式依次显示“基础项”“条件项”“整理顺序”，每段 120–180ms。
- `prefers-reduced-motion` 下直接显示完整进度条并在下一帧进入结果。

### 清单勾选

- 原生复选框状态立即更新，行背景在 160ms 内变为浅绿。
- 文本删除线延迟 40ms 出现，避免复选框与文字同时突变。
- 不把完成行从当前视图即时移除；空间巡视在 280ms 后推进下一站。

### 三视图切换

- 标签指示条在 180ms 内移动。
- 列表只做 6px 淡入，不进行跨组物品飞行动画。
- 切换期间 checkbox 保持可访问名称和稳定 DOM key。

### 条件重算

- 变更摘要抽屉先出现计数，再显示代表项目。
- 确认后新增项从 8px 下方淡入；移除项只在摘要中淡出，不在工作台制造大面积位移。
- 保留勾选项短暂显示雾蓝描边 420ms，提示状态被保留。

### 空间巡视

- 当前站点圆点从雾蓝变为陶土橙；连接线只改变颜色，不增长模拟定位。
- 站点完成后标题折叠，下一站内容从 8px 下方进入。
- 用户手动展开旧站点时不改变“下一站”计算。

### 最后一分钟

- 进入时背景在 220ms 内变为深森林绿，关键卡片淡入。
- 主按钮勾选当前项后，新项替换使用 140ms 交叉淡化。
- 无晃动、急促脉冲、倒计时、声效或红色告警。

### 完成章

- 标准模式：透明度 `0→1`、缩放 `.92→1`、旋转 `-7deg→-4deg`。
- 不模拟真实印章撞击，不触发音效或震动。
- 减少动态效果时直接显示最终姿态。

## 4. 抽屉与对话框

- 项目解释、自定义编辑、路岚帮助和条件变更使用底部抽屉。
- 覆盖确认、删除自定义项、清空坏存档使用模态对话框。
- 打开时锁定背景滚动，焦点进入标题；关闭后恢复触发按钮和之前滚动位置。
- `Escape` 关闭非破坏性抽屉；破坏性确认对话框的 `Escape` 等同取消。

## 5. 手势与滚动

- 不依赖滑动手势完成关键操作。
- 底部操作条使用 `padding-bottom: env(safe-area-inset-bottom)`。
- 条件答案、手动数字确认、保存和最后一分钟主按钮始终可通过键盘和点击触发。
- 清单滚动时顶部摘要可以压缩，但高度不超过视口的 25%。

## 6. Reduced Motion

在 `prefers-reduced-motion: reduce` 下：

- 所有 `transform` 位移动画取消。
- 进度、勾选和视图切换只做不超过 80ms 的颜色变化，或完全静态。
- 生成过渡不轮换文本。
- 完成章无缩放和旋转变化。
- 功能顺序、焦点与通知内容保持不变。

## 7. 状态播报

- 勾选项目后不逐项打断屏幕阅读器；仅更新可查询的完成计数。
- 空间站点推进播报“下一站：位置名，还有 N 项”。
- 条件重算播报新增、移除、保留数量。
- 保存、覆盖、恢复和错误使用简短 `aria-live` 消息。
- 不播报装饰图标、完成章或路岚图片。
