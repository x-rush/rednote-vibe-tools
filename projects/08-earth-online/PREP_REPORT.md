## 交付结论

本轮在既有内容升级和抽取多样性优化之上完成 v3 任务库复审：先退出 20 个动作单一、结果感弱或同类重复的 v2 任务，替换为包含角色扮演、法庭、编队、速通、倒序动作、现实 Bug 报告和可信熟人主动邀请的 20 个新任务；随后针对“室外 + 夜间”覆盖缺口新增 12 个专用夜航任务，当前有效任务总数为 112。自愿社交现为 16 项，陌生人互动仍只有 2 项。

项目继续满足纯前端、本地运行约束：无后端、运行时 AI、定位、上传证明、用户图片、必需外部 API 或新增依赖。业务内容只存放在 `src/content/content.json`。

### 夜航任务扩展

“室外 + 夜间”曾因所有户外候选均带 `daylight-only` 而稳定进入无匹配。现新增 12 个不依赖定位的夜航任务：影子 Boss 停战、夜色采样、发光招牌密语、安全区声音雷达、临时星座、口袋博物馆、路线补丁说明、无回复安全信号、月亮任务日志、路灯气质投票、影子三幕剧组和封闭照明区远征。

这些任务只能在熟悉、照明稳定、公共且无需过马路的区域进行，使用 `night-safe`、`well-lit-only`、`familiar-area-only`、`public-area-only`、`no-road-crossing` 与 `skip-if-unsuitable` 标签；不得同时携带 `daylight-only`。天气、视线、身体状态或任何不安出现时必须返回室内或熟悉安全处。两项自愿社交任务只面向可信熟人，发送即完成，不要求回复、照片或实时位置。

优化原则：任务必须产生可感知的过程或结果；增加选择、组合、计时、记忆、调查、宾果、角色扮演、倒序复现和安全社交邀请等玩法；避免只换一句俏皮话的无意义改写。主动社交任务以可信熟人、同事和既有渠道为主，发出边界清楚的邀请即可完成，不要求回复或配合。全部当前任务拥有与具体任务边界对应的唯一退出规则和退出文案。

兼容规则：

- 历史记录保存不可变快照：标题、内容版本、类别、难度，不再依赖当前任务库反查。
- Schema v1 历史通过完整 v1 版本档案补齐快照并迁移为 v2。
- v1/v2 正在进行任务按 `questId + contentVersion` 解析，保留原文案、原版本和原 XP；无论 ID 是否在 v3 继续使用，界面都标记“经典任务”。
- 已退出任务不会出现在新推荐、最近推荐或换一个候选池中。
- 无法解析的旧活动任务视为损坏状态；无法解析的非关键旧历史安全丢弃。

## 匹配流程与评分

### 硬条件

依次检查审核状态与安全标签、时间上限、精力上限、室内/室外、昼夜、熟悉地点、社交偏好、预算和用户明确不适用条件。硬条件不通过的任务不会进入评分池。

基础评分：

| 条件 | 分值 |
|---|---:|
| 目标一致 | +40 |
| 精力完全一致 | +20 |
| 时间完全一致 | +20 |
| 不在最近 8 次推荐 | +30 |
| 在最近 8 次推荐 | 最旧 -10，之后每接近当前一次再 -30，最新 -220 |
| 最近 4 次每出现一次同类别 | -15 |
| 近 7 天放弃过 | -25 |
| 仍在任务冷却期 | -35 |
| 与上一任务同类 | -10 |
| 用户可撤销软避开该类 | -30 |

先确定最高分，再保留最高分向下 25 分内的高适配组，以分差作为权重进行 seed 选择。因此结果可复现，但不会永远锁死在单一最高分任务。最近推荐强排除窗口从 3 扩到 8；只要还有新鲜候选就不会回抽这 8 项。候选耗尽进入 `recent-relaxed` 后，位置衰减保证先回到最久未出现的一项。最近 4 次曝光还会累计类别疲劳，减少同类型连续出现，但这只是排序分，不会删除唯一安全候选。推荐解释会据实注明“近期没有出现过”与“换了一类冒险体验”。

### 永不放宽

- 审核状态与 `no-purchase`、`no-photo-required`、`no-personal-data` 等安全要求。
- 用户时间上限与精力上限。
- 明确不可用的环境、昼夜和地点条件；夜间不会放宽 `daylight-only`。
- “不花钱”不会推荐任何付费任务。
- “不社交”不会推荐需要互动的任务。
- 用户明确选择室内时不会推荐必须户外的任务。
- 用户选择的不适用条件。

### 逐级放宽顺序

1. `exact`：目标、精力、近期/冷却全部适配。
2. `goal-relaxed`：只放宽目标偏好。
3. `energy-relaxed`：允许低于当前可用精力的安全任务，绝不超出精力上限。
4. `recent-relaxed`：允许近期推荐或近 7 天放弃过的任务，仍排除冷却中的已完成任务。
5. `safe-fallback`：最后允许冷却任务回归，但所有硬条件与安全条件仍保持。

每一级返回阶段原因、实际放宽项和正向推荐理由；若硬条件池为空则返回明确无匹配状态和永不放宽条件。

### Seed 规则

字符串/数字 seed 先经 FNV-1a 32 位哈希，再使用确定性 PRNG 生成选择值；候选任务先按 `questId` 排序，保证相同任务库、偏好、上下文与 seed 得到相同结果。下一 RNG state 持久化，换一个时延续序列；初次状态的熵由浏览器 `crypto.getRandomValues` 提供。

近期去重与选择条件有关：时间、精力、环境、地点、社交、预算和不适用条件先决定硬条件池，目标与贴合度再决定评分。如果条件组合只能命中很少任务，系统会更早进入 `recent-relaxed`；多样性优化不会越过用户明确条件去扩大候选池。

## 接取、完成、放弃与进度

- 领取只产生 offer；接受后生成唯一 acceptance ID，不奖励 XP。
- 换一个会记录旧 offer 的处理状态并使用下一 seed；不会从经典任务池取任务。
- 放弃不扣 XP；历史保存当时任务快照。
- 完成按 acceptance ID 幂等：同一接取记录重复结算奖励 0。
- XP 与难度对应：`tiny=20`、`light=35`、`standard=55`、`brave=80`。
- 等级阈值：进入 L 级需要 `100 × (L-1) × L / 2` XP；例如 1 级 0、2 级 100、3 级 300、4 级 600。
- 连续记录使用显式 `YYYY-MM-DD` 完成日期；首次完成记 1，同一天重复完成不增加，下一自然日 +1，间隔超过一天则从 1 重启，历史最佳值只增不减。
- 所有时间逻辑由调用方传入时间或日期，测试不依赖真实当前时间。
- 任务历史上限 100 条；摘要按快照标题统计完成、放弃、更换和累计 XP。

## 徽章接口

徽章由类型化 `BadgeDefinition` 和纯函数规则判定，现有接口支持：累计完成数、连续天数、等级和指定类别完成数。首发 5 枚：首次完成、累计 5 项、连续 3 天、达到 3 级、完成 3 项运动任务。解锁使用集合去重，已有徽章不会重复授予；UI 当前只展示结构和占位资产 ID，不使用 emoji 充当最终徽章。

## 状态模型与本地存储

页面/交互状态覆盖：`guildHall`、`preferenceSelect`、`questOffer`、`questAccepted`、`questComplete`、`questAbandoned`、`adventurerProfile`、`questHistory`、`badgeList`、`error`，并处理今日已领、刷新恢复、换一个、无匹配和查看等级。

localStorage envelope：

- `schemaVersion: 2`
- `contentVersion`
- `updatedAt`
- `data.preference`
- `offeredQuestId`、`activeQuest`（含 `questContentVersion`）
- 最近推荐 ID（最多 10）与完成 ID
- 带不可变任务快照的历史（最多 100）
- XP、连续记录、已解锁徽章、RNG state、引导与软避开设置

读取时验证并清洗全部字段；活动任务必须以 ID 和版本同时命中版本化目录，结算也拒绝版本不一致的定义。损坏 JSON 返回可恢复错误，未知未来版本不会被覆盖，v1 自动迁移到 v2；迁移写回失败会进入现有临时模式/恢复路径，不会静默假装持久化成功。保存前递归拒绝图片、Base64、Blob、音视频、经纬度、定位数据和完成证明字段。项目不会隐式收集敏感信息。

### 旧档案按需加载

`src/content/content.json` 仍是唯一业务内容源。项目内 Vite 插件只在构建期拆分内容：当前模块包含 112 个活跃任务和空档案数组；archive 模块包含 40 个退役任务与 160 个 v1/v2 历史定义。标准 Web loader 动态导入 archive；小程序配置使用静态 eager loader，以保留单 IIFE 架构。

启动时只读取 localStorage envelope 的最小结构，不迁移也不写回。空存档、损坏 JSON、当前 v3 和未来未知版本不请求 archive；schema v1、版本不一致/不在当前目录的活动任务，以及包含非当前任务 ID 的完成集合会请求 archive。v2 历史已有不可变快照，单独出现旧历史不会触发加载。archive 加载或校验失败进入可重试内容错误页，并禁止 React 启动持久化覆盖旧存档。

## 安全规则

所有当前任务均要求不购买、不拍照证明、不提供个人信息。普通户外任务继续限制白天、熟悉区域和公共区域；只有 12 个通过夜航审核的任务可以在夜间出现，并额外要求稳定照明、无需过马路、可随时返回与不适立即停止。运动任务要求舒适活动范围并注明不适合即可跳过/停止。陌生人相关任务只有 2 个，均为短暂、自愿、可立即退出的正常互动；新增主动社交任务面向可信熟人或既有渠道，发送邀请即完成，对方不回复、拒绝或不参与时必须结束，不拍摄、不纠缠、不进入私人空间。

内容校验与 matcher 共同阻止违法、危险攀爬或交通行为、骚扰、隐私泄露、高额消费、定位、上传证明、不合理身体要求及医疗/心理治疗包装。
