# 项目22｜野塘钓鱼：详细立项

> 首版范围更新：用户要求增加首版内容。正式交付数量与耐玩机制以 [CONTENT-PLAN.md](./CONTENT-PLAN.md) 为准；下文原小P0数量改作内部视觉/手感切片，不代表最终首版范围。原玩法规则继续生效。

日期2026-09-19；状态：详细规划，尚未开发。为短时娱乐简化钓鱼过程；鱼种活动和时间为游戏设定，不使用定位/真实天气/实际鱼情数据。

## 1. 核心体验

夕阳野塘边，玩家看芦苇阴影、浮头小泡和水草空隙来选择落点。抛竿后看浮漂轻点、侧移、下顿，抓住有效咬口；中鱼后靠收放线把鱼带到近岸，最后才看清它的样子和大小。
核心悬念是“什么在试饵、什么时候提、这条到底多大”，操作乐趣是读漂和管理拉力，不是长时间挂机等待或狂点收鱼。
每竿约45～120秒，等待8～18秒为初值，首次引导缩短至4～8秒。每次最多等待25秒后给一次可辨识的鱼情反馈并允许换点，不故意让用户空看半分钟。
P0：1处黄昏野塘、3个钓位（水草边/开阔浅水/倒木旁）、2种饵型、6种淡水鱼外观、轻重两档个体表现；无商店/升级/竞技联网。

## 2. 完整流程与状态机

选点/饵→瞄准蓄力→抛竿→落漂稳定→候鱼→试口→有效咬口→提竿→遛鱼→近岸抄取→鱼获展示→记录放流/再钓。
所有失败都有可读原因与很短恢复：
- 空提：水花轻、钩空，提示“这次还只是试口”，立即允许再抛。
- 提晚：浮漂回平、鱼影离开，提示“它松口了”。
- 断线：拉力先进入高风险区且持续一段时间，出现线抖/竿弯预警才断，不能随机惩罚。
- 脱钩：长期过松并与鱼冲刺叠加，先有明显松线警示。
- 收竿/换点：明确按钮，取消本竿未完成收获；暂停与切后台只是冻结，不视作放弃。

## 3. 手势与手感

| 阶段 | 输入 | 即时反馈与初值 |
|---|---|---|
| 选点 | 点水面可钓区域 | 轻落点圈，水草深处/岸上为不可达区域而非隐形失败 |
| 抛竿 | 向后拖蓄力、左右调方位，松手 | 竿稍弯曲、线弧拉开，距离按拖动归一化；过小位移取消 |
| 提竿 | 按底部“提竿”或在专用区向上划 | 竿立即抬起，有鱼才持续弯曲；划动与按钮共用一次事件 |
| 遛鱼 | 按住“收线”，松手放松；横向拖调竿方向 | 线紧/松、竿弯、鱼向与拉力条一致，默认无需双手 |
| 抄鱼 | 鱼进入近岸圈后拖网对准 | 网口覆盖鱼体中心持续约300ms入网，辅助可点按钮 |

收线区为宽触区，横拖同时改变竿向±25°；轻拖与收线输入分离判定，手指遮不到浮漂和鱼冲刺方向。可选“收/放切换”无长按模式，适合手部不便者。
有效咬口窗口默认900～1400ms，练习/辅助1600～2200ms；物种调节有上限，不能只奖励极端反应速度。
视觉试口：小幅上下点1～3次、短侧移；有效口：明显持续下沉或稳定斜走，形态差异而非只改颜色。开启辅助后显示“现在提”的短提示，但不自动提竿。
提竿输入发生后≤80ms可见响应；竿身0～150ms蓄弯，线150～300ms拉直；水花在实际线端接触水面的坐标发生。
每条鱼冲刺之间有0.8～2秒喘息窗口，玩家能明显利用机会收线。失败后不强制看长动画。

## 4. 鱼情、未知与确定性

每个钓位进入时固定鱼池及活跃序列，抛竿落点、饵型影响候选鱼分布；候鱼开始固定潜在对象/试口计划，不能等玩家提竿成功后才随机决定鱼。
- 3钓位分别偏小鱼频繁、均衡、少见大个体；线索泡、草动与当前鱼情相关，但不直接揭示鱼种。
- 2饵型分“轻颗粒/软饵”游戏设定，影响条件权重与等待分布，无稀有饵付费。
- 鱼种稀有级条件权重普通70/少见25/特别5，按钓位可达鱼种重新归一化；尺寸另用有限分布，不能大鱼必然稀有。
- 每条潜在鱼有approach/inspect/nibble/commit/leave状态，等待与试口不等于已必钓中。
- 模型只有可见水面信号，玩家不读debug鱼信息；同seed可供开发复现，不在产品显示后台概率面板。
- 暂停、画质和看鱼册不抽新鱼；换点为新竿明确消耗当前计划，本地无反作弊承诺。

拉力模型：
线长L、竿尖位置、鱼位置/速度、松弛量s、线伸长extension决定T；T=clamp(k*extension+c*relativeSpeed,0,Tmax)，用钳制半隐式积分避免爆振。
按住收线使L按可配置速度减小，松手进入受控泄力；鱼由冲刺/侧摆/喘息状态输出有限力，不做随机瞬时传送。
鱼耐力只在合理拉力下逐渐下降；低拉力下降慢，高拉力会伤线但不额外速胜。示意安全区0.35～0.70，高风险>0.90持续700ms断线；过松<0.10持续1200ms且鱼处于挣脱动作才脱钩。均为初值，实际依据手感调整。
冲刺前150～250ms出现鱼向变化/水纹信号；不把所有鱼做成恒速左右摆动。成功由近岸距离+耐力+抄网条件决定，不按预设计时自动上鱼。

## 5. 视觉、水质与音画

色板：塘水灰绿#57766A、夕照#DBAB71、芦苇#687054、山岸#4C5B52、鱼鳞银#B8C7BC、浮漂橙#DB7043。
岸边第一人称，竿从下方伸出，浮漂处于中间可读区域，太阳与远岸在上部背景。选择钓点后镜头缓移保证浮漂屏幕高度≥约18px，逻辑命中不受视觉缩放影响。
- 静水：细波和芦苇倒影，风推反光缓慢移动；鱼靠近产生局部变化，避免背景浪把顿口淹没。
- 浮漂：吃铅线/露出高度清楚，试口导致真实水线变化；反射随波扭曲，漂旁涟漪不是固定循环。
- 竿线：线使用少量约束点/解析悬链近似，紧绷直、松弛弯；竿身分段曲线受力，不能拉力满格竿仍完全笔直。
- 鱼：水下看剪影与模糊反光，近岸才逐步显色；出水鳞片高光、鳍部透亮、少量滴水。避免在远处把稀有鱼完整发光展示。
- 大小：由竿弯幅、尾波和入网后相对网口尺寸体现；结果数字不能和模型大小矛盾。
- 音效：轻落水、浮漂小响可选、收线机轻转、冲刺水花；关闭声音仍能读懂有效口和风险。
- 样板必须展示静漂→试口→有效顿口→提竿弯曲→鱼冲刺水纹→松线回稳，重点验证时序和力度。

## 6. 技术选择

TypeScript+原生WebGL1水面渲染+2.5D鱼/竿线+DOM/CSS，Canvas2D降级；Rolldown IIFE。纯状态机+有限弹簧约束，避免引入刚体/绳索大引擎。
- 水面复用项目内实现思路，禁止跨项目运行时依赖；最多16波源，默认水粒子≤200、低档≤60。
- 一次只有1条被钓鱼和至多4个环境剪影；鱼外观用本地图集/简单网格，竿线≤20节点，迭代≤4次/步。
- 逻辑鱼位置、线张力、漂信号都独立于渲染；鱼影模糊用预制精灵，不依赖全屏后处理。
- 默认≤30 draw calls、20k三角形、32MiB纹理/FBO。低档去环境鱼、减少反光，保留试口/真口和拉力线。
- 高/低/Canvas切换沿用同一状态机时间；不把按键音回调作为提竿判定依据。

## 7. 数据和存档

content.json：spots、baits、fishSpecies、biteProfiles、fightProfiles、physicsTuning、inputTuning、catchRecords、copy、visuals、audio、layout、quality。
fishSpecies含id、displayName、sizeRange、spotWeights、baitWeights、biteProfileId、fightProfileId、visualKey；全部为游戏设定。
每竿存sessionId、seed、spot/bait、阶段、模拟时间、鱼参数/状态、线长/张力、耐力及是否已提交。持久化最多1竿逻辑状态，恢复后先暂停提示继续，给1秒准备时间再恢复窗口。
鱼册存发现次数、最大游戏长度/重量、外观变体；图鉴用数据重绘，不存照片。放流保留纪录，重复点击不重复统计。

## 8. 里程碑与验收

P0：浮漂信号与提竿窗口→一条鱼的拉力博弈→抛竿落点→单景水面/竿线切片→3位2饵6鱼→记录和恢复→跨端交付。
P1：夜钓灯光、雨天鱼情、不同浮漂外观；无联网鱼价、真实地理鱼情、装备养成链。
专项验收：
1. 试口/真口有可辨认区别，静音下5人中4人在三次内成功提鱼。
2. 拉力线、竿弯、鱼向一致；连续猛收有预警后才断，合理收放能稳定完成。
3. 过早、过晚、成功、断线、脱钩、放流全部有可复现seed测试。
4. 隐藏/暂停中咬口和线张力冻结，恢复给准备时间，不补算导致瞬间断线。
5. 同seed同输入在30/60fps与不同渲染档下鱼种/结局一致，漂显示误差不超一模拟步。
6. 读档、切饵、退出、音频解码取消不会迟到触发咬口或重复入册。
7. 指针取消立即停止收线、进入安全暂停，不等同永久长按。
8. 15分钟热机观察水面/输入性能，连续50竿无音频节点、粒子或鱼实体增长。
9. 至少3位测试者能描述下一竿想换哪里/什么时候松线，验证选择和技术可理解。

全部性能为预算，真机/活动合规待核验；通用构建、宿主和音频门禁见DELIVERY.md。
