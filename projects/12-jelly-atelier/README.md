# Jelly Atelier · 亲手做一只果冻

一款自由制作、轻松把玩的纯前端三维小玩具。选模具、倒入两层颜色、点放装饰，再把自己的作品脱模、戳动、收藏。完成制作本身就是体验，不要求拍摄或发布内容。

在本项目目录运行 `pnpm dev`，访问 `http://127.0.0.1:4312`。`pnpm build` 输出完全本地的静态 `dist/`；当前开发服务器也可通过 `/dist/` 查看构建产物。

## 制作流程

1. **选形状**：花瓣、爱心、星星，实时改变三维模具和成品轮廓。
2. **倒两层**：每层独立选择蜜桃乌龙、紫葡萄雾或橙光气泡。按住倒入、松手停止；第一层可控制在 20%～75%，第二层补满。也提供轻点加量和键盘长按。
3. **摆装饰**：选树莓、薄荷或金糖星，点击果冻顶面摆放。提供辅助摆放和逐颗撤回，最多 8 颗，也可以保留无装饰成品。
4. **脱模玩**：模具抬起、果冻拉伸、落盘回弹与糖浆液滴。轻触成品产生局部形变，拖动空白处调整观察角度。
5. **收进甜品柜**：保存完整形状、双色比例、装饰种类与坐标。刷新后可继续把玩原作品，支持旧版单口味记录迁移。也可重新制作。

## 视觉实现

奶油色摄影棚、酒红色排版、金边瓷盘、金属勺与原创程序化造型。Three.js 物理透射材质、厚度吸收、环境反射、柔晕、接触阴影和程序化焦散。倒液显示抬起的玻璃杯、液柱和随容量上升的液面；两层颜色使用同一个形变网格的高度分界着色，晃动时不会分离。

脱模按实际前台经过时间推进，目标编排时长 5.8 秒；后台暂停时重置帧时钟，避免返回页面后突然跳过过程。保留用户的减少动态偏好（简化为 2.2 秒），不按手机档次降低材质或像素比。

这是程序化视觉与交互动画，不是流体或软体物理求解器。所有模型、场景和纹理在本地生成，无运行时 CDN、外部图片或必需外部 API。

## 数据与边界

- 业务文案、模具、口味、装饰和制作规则集中在 `src/content/content.json`。
- 本地收藏使用 `jelly-atelier-v2`，最多 18 项；兼容读取旧版 `jelly-atelier-v1`。只保存经过白名单校验的结构化配方、ID 与日期，不保存图片、Base64、音视频或 Blob。
- 当前制作中的草稿不跨刷新保存；已收进甜品柜的成品会保留。
- Three.js 固定为 **0.180.0**，npm 官方包的分发文件及 MIT 许可证位于 `vendor/package/`。完整性记录在内容文件中。此次没有新增 npm 依赖。
- 浏览器需支持 WebGL 2；WebGL 不可用或上下文丢失时展示重新打开入口。
- 没有 Service Worker，不承诺关闭页面后在断网状态重新打开。

## 1.1.0 · 自己画模具

首页选择「自己画」。支持一笔回到起点、点选轮廓，以及键盘方向键移动 / 空格落点。接近起点会自动闭合；「闭合并预览」可以明确连接首尾。轮廓经过等距采样和两轮平滑，归一化后保存 96 个坐标点，沿用当前配色、分层、装饰、脱模与收藏流程。

- 支持无自交的单一闭合轮廓，包括凹形（例如 C 形、猫耳轮廓）；不支持交叉线和带孔形状。
- 未闭合、交叉、过小 / 过细的形状会给出提示并禁止使用；交叉线段标红。提供撤回、重新画、取消和三维预览。
- 画板采用等比例坐标映射，避免手机上的长方形画布拉伸用户图形。
- 凹轮廓使用三角剖分封顶和分层侧壁；液面与每层侧壁使用相同截面，凹口保持空缺。
- 手绘模具使用更容易看清顶面的镜头角度；液柱落在轮廓内部，装饰避开边缘和凹口。预览关闭后释放 GPU 资源。
- 收藏白名单新增 outline 坐标；原预设配方不变。损坏 / 过大 / 自交的已存轮廓会被拒绝，不保存图片或媒体。
- 最新上传包：`release/guodong-manman-1.1.0.zip`，656,882 字节。1.0.0 ZIP 保留作为旧版本。

主要代码：`src/contour.js`（清理、闭合、自交检测、平滑、内部位置判断）、`src/custom-geometry.js`（凹形网格）、`src/mold-editor.js`（画板与预览）。新增测试为 `tests/contour.test.mjs`。
