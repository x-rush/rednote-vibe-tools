# 交互与状态规格

## 1. 交互原则

整段体验只要求两个明确动作：

1. 首屏点击任意主要区域，让轮播减速并选中一句话。
2. 结果态点击“再听一次星空”，重置体验。

用户不需要精准点中某一句。点击表达的是“现在请星空为我停下一句话”，最终落句由系统从合理候选中随机决定。

## 2. 状态机

### `loading`：加载

- 准备首屏必要资源和内容。
- 先显示与主画面一致的深蓝背景，避免白屏。
- 不因音频加载失败阻塞进入。

### `spinning`：轮播

- 句子持续纵向轮播，中间句最清晰，上下句虚化。
- 主画面整体可点击，顶部音效按钮除外。
- 点击后立即锁定再次点击，并进入 `slowing`。

### `slowing`：减速

- 继续滚过 3–6 条句子，速度逐渐下降。
- 总时长 1.0–1.4 秒。
- 最终句子由点击时刻、随机数和短期去重共同决定，不承诺精准停在点击瞬间的句子。
- 用户连续点击不改变目标句，也不重复启动动画。

### `selected`：选中与阅读停顿

- 当前句子清晰、略微放大并发光。
- 上下候选句完全淡出。
- 停顿 0.6–0.8 秒后自动进入 `wind`。

### `wind`：风与帘子

- 帘子自动由弱到强摆动并向一侧飘开。
- 无手势提示，不接受拖动控制。
- 结束时自动进入 `window-opening`。

### `window-opening`：窗户打开

- 窗框轻微颤动，窗扇以铰链侧为轴向室内开启。
- 月光投射范围随开启角度扩大。
- 自动进入 `stars-entering`。

### `stars-entering`：星星进入

- 所有关键星粒子从窗框后方生成，穿过窗口裁切区进入室内。
- 星星与帘子、月光和句子发生视觉关联，但不能遮蔽文字。
- 自动进入 `result`。

### `result`：结果

- 句子稳定展示，主角星停在句尾或文字附近。
- 显示辅助文案和“再听一次星空”。
- 允许截图；不自动弹出分享面板。

### `resetting`：重置

- 结果控件立即锁定，避免重复重置。
- 星光淡出，窗扇合拢，帘子重新垂落。
- 重置后回到 `spinning`，尽量不重复刚刚出现的句子。

## 3. 点击与控件

- `spinning` 的点击热区至少覆盖除顶部工具以外的整个场景。
- 首次点击必须在 100ms 内产生可见反馈，例如轮播压缩、光圈或速度变化。
- 音效开关最小点击区域 44×44 CSS px，并考虑顶部安全区。
- “再听一次星空”最小点击区域 44px 高，但视觉可以保持轻盈。
- 动画过程中不显示“下一步”“确认”或手势箭头。

## 4. 随机与去重

- 一次体验开始时打乱候选池。
- 最近 8 次结果不重复；内容不足时再放宽。
- 同一浏览器会话可以记录近期句子 ID，刷新后不要求永久保留。
- 不使用“中奖”“概率”“稀有”等赌博式表达。

## 5. 音效

- 音效只作增强，静音状态必须能完整理解体验。
- 第一次用户点击可以解锁 Web Audio，再播放轻微星铃、风声和窗框声。
- 默认按钮清楚表示当前有声/静音状态。
- 不自动播放背景音乐，不循环播放长音频。
- 切到后台时暂停时间线和音效，回到前台时从一致状态继续或安全完成当前阶段。

## 6. 降低动态与性能回退

当 `prefers-reduced-motion: reduce` 时：

- 轮播速度降低，不使用强烈残影。
- 帘子只做短距离平滑偏移。
- 窗户使用淡入/角度变化的简化动画。
- 星星数量显著减少，取消高速拖尾和大范围旋转。
- 保留“窗外 → 窗口 → 室内 → 句子”的方向叙事。

性能不足时可以降低粒子数量和光晕质量，但不能删除选句流程、自动开窗或星星进入方向。

## 7. 响应式与安全区

- 设计基准为 390×844 CSS px 竖屏。
- 必测宽度：375、390、430 CSS px。
- 窗户和帘子应占上半屏主要区域；句子处于拇指不遮挡且易截图的位置。
- 短屏时优先缩小环境留白，不能压缩文字到不可读。
- 所有顶部固定控件使用 `calc(var(--safe-area-inset-top, env(safe-area-inset-top, 0px)) + …)`。
- 用非零模拟安全区验证顶部控件不被遮挡。
- 横屏可显示居中竖版舞台或给出柔和的旋转提示，但不得崩坏。

## 8. 异常场景

- 内容加载失败：使用打包在应用中的最小回退句库。
- 音效失败：自动静音，动画继续。
- 页面在动画中失焦：暂停统一时间线，不让 CSS 与 Canvas 各自跑到不同阶段。
- 用户连续点击：只接受状态允许的第一个动作。
- 重置中刷新：重新进入稳定首屏，不恢复半开的窗户。
