## 仓库速览

- **是什么**：面向小红书 vibecoding 平台的纯前端静态小工具合集，每个项目独立成目录，构建产物打包为离线 ZIP 上传平台容器运行。
- **规模**：25 个项目（01-11 为 React+TS+Vite；12-17 为零依赖原生 JS；18-25 为 TypeScript+Canvas2D/WebGL1 治愈收集与国风项目）。
- **硬约束**：纯前端静态、无后端无运行时 CDN、业务内容只放 `src/content/content.json`、不持久化用户媒体、宿主按钮避让、音频走 Base64+WebAudio 构建链路（详见 [02 分册](./02-工程规范与质量门禁.md)）。

## 写作约定

- 文内源码链接均为相对路径，从本目录（`docs/Code-Wiki/`）出发，可点击跳转。
- "关键函数"只收录经过阅读确认的导出；未逐行核实的部分明确标注"未逐行核实"。
- 各项目的完成度、发布状态不同，本 Wiki 描述的是**源码现状**，不代表全部已上线；发布情况以各项目交付文档为准（见 [docs 索引](../README.md)）。
- 引用总控文档时给出编号（如 47 号动效标准），编号对应 `docs/00-总控与共用/` 下的文件名前缀。
