# 雨后找菌子

六片雨后林地的纯前端探索游戏。当前首版包含 18 个小景、24 种原创菌、3 种真实有毒菌艺术观察对象、24 项挑战、6 种自然观察事件与 6 个摆篮主题。

## 怎么玩

- 拖开湿叶、松针、蕨叶、草叶或小枯枝，寻找露出的菌盖。
- 轻点已露出的菌子查看介绍，观察会留记录，菌子留在原处。
- 按住幻想菌，左右轻晃后向上提，采下后进入竹篮。设置可开启辅助长按。
- 有毒菌只能观察，不进入竹篮。艺术素材不用于现实识别和采食。
- 左下方小景箭头切换同一林地的三处区域；沿林寻觅可换林地，提供直接探索全部入口。
- 林间手记包含探索方式、挑战、观察册、真实菌类科普、林地足迹、收获与设置。
- 今日林地按设备本地日期生成，暂时离开后回来会恢复对象和进度。种子重玩不重复增加累计收获。
- 竹篮可查看收藏和寻找线索；摆篮可拖动位置，也支持点选后落位、键盘方向键微调。

## 本地运行与交付

在本项目执行 `pnpm lint`、`pnpm test`、`pnpm build`，随后 `pnpm preview`，默认 http://127.0.0.1:4323/ 。构建为经典 IIFE 脚本，离线运行，无后台、运行时 CDN 或外部 API。

执行 `python qa/package.py` 生成 `release/rainy-mushroom-hunt.zip`，入口位于 ZIP 根目录。音频来自 CC0 短录音，构建编码到 audio-data.js，WAV/OGG 不进 ZIP。
