# 汴京饮子铺 · 交互与动效规格

状态：待书面规格确认
日期：2026-08-26

## 原则

动效表达店铺时段、手作过程和纸面记账，不表达赌博、抽卡或金币奖励。任何动画都不能推迟关键操作超过 1.8 秒，且必须可跳过。

## 时序

| 场景 | 动效 | 时长 | 可跳过 | reduced-motion |
|---|---|---:|---|---|
| 封面 | 招幌轻摆、蒸汽缓升 | 4–7s 循环 | 不适用 | 静态 |
| 晨间 | 天光由冷至暖 | 450ms | 不适用 | 直接切换 |
| 开门 | 木门/布幌上提，场景轻推近 | 700ms | 是 | 120ms 淡入 |
| 营业 | 三段时刻交叉淡变，顾客滑入 | 每段 650ms | 是 | 静态分段文字 |
| 售出 | 饮子小图移向账筹，数字更新 | 320ms | 是 | 数字直接更新 |
| 事件 | 纸面层从下方展开 | 280ms | 不适用 | 直接显示 |
| 选项 | 边框压印、确认条出现 | 180ms | 不适用 | 无位移 |
| 日结 | 账页展开，明细逐行显现 | 500ms | 是 | 全部同时显示 |
| 里程碑 | 日数字淡入、印记落下 | 450ms | 是 | 静态 |
| 结局 | 黄昏覆盖层渐变、人物入场 | 900ms | 是 | 静态合成 |

## 交互状态

- 所有按钮包含默认、悬停、键盘焦点、按下、禁用和进行中状态。
- 开门与事件确认期间按钮进入 `aria-busy`，阻止重复提交。
- 商品步进器到达边界时禁用对应按钮；预算不足时保留当前值并解释原因。
- 事件选项第一次点击只选中；确认按钮出现后才允许提交。
- 营业演示支持“快速结算”，该动作只跳过视觉时序，不改变已确定的结果。
- 日结展开前就渲染完整语义内容，动画失败不影响屏幕阅读器读取。

## 场景层级

从后到前：主店铺背景 → 时段色层 → 天气层 → 顾客/阿沅 → 招幌文字 → 经营信息层。天气、蒸汽和光影层固定 `pointer-events: none`。

## 性能边界

- 只动画 `opacity` 和 `transform`。
- 不使用 canvas、视频、粒子库或持续 JavaScript 循环。
- 首屏仅加载店铺场景；顾客和商品图按页面需要加载。
- 低性能模式与 reduced-motion 使用同一静态降级路径。
