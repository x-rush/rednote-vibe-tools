# SBTI｜山海兽格：异兽候选池与 16 型最终映射

状态：CONTENT FROZEN / SOURCE REVIEWED（2026-08-23）

用途：冻结首发 16 型的异兽映射、原典依据、创作边界和结果卡文案骨架。本文件与 `15-SBTI首发48题与16型映射草案.md` 一起构成 SBTI 首发内容源；实现时转写到唯一业务数据文件 `src/content/content.json`。

## 1. 内容可信度规则

每个异兽相关字段必须带 `claimLevel`：

- `CLASSIC`：可由《山海经》正文或可靠古籍页直接支持。
- `COMMENTARY`：来自郭璞注、后世图赞或其他典籍，不得写成《山海经》正文。
- `PRODUCT`：SBTI 的人格化创作，只能使用“像是、我们把它想象为、你的兽格”一类表达。

统一禁区：不把佩戴、食用、疗疾等神话叙述改写为现实健康建议；不把后世“祥瑞、仁兽、信使”等印象倒灌为正文；不声称人格诊断；不把类型写成优劣排序。

## 6. 弱偏好与平分处理

1. 每维 `preference = abs(left-right) / questionCountOfDimension`。
2. `< 0.17` 显示“游移”；`0.17–0.49` 显示“轻偏”；`>= 0.50` 显示“明显偏好”。
3. 存在游移维度时，近邻型只翻转偏好最弱的一维。
4. 禁止偷偷随机破平；固定使用预先冻结的 `tieBreakerQuestionId`，仍平分则显示双结果卡。
5. 分享卡只显示主型；完整结果页显示维度条、游移提示和近邻型。
