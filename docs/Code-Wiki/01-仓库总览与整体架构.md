## 工作区与技术分布

根 [package.json](../../package.json) 声明 pnpm@11.19.0；[pnpm-workspace.yaml](../../pnpm-workspace.yaml) 收录 projects/* 下含 package.json 的工程，使用共享锁文件，不自动链接工作区包。29 个工作区包不等于 30 个目录。

| 范围 | 实现与说明 |
|---|---|
| 01–11 | React / TypeScript / Vite，Vitest |
| 12–17 | 原生 JavaScript 与自定义 Node 构建脚本；15 已是三维 ROOMISH，17 为捡手机文学局 |
| 18–25 | 自定义 TS / JS 构建与 Canvas / WebGL 等表现，25 内置本地 p5；工具依赖以各项目脚本为准 |
| 26、28、29 | 新增学习工具、分章阅读器和三维节奏游戏，见 10 分册 |
| 27 面试官 | Skill 源码、内容与 ZIP 分发；独立于 H5 容器规范 |
| 27 静态原型 | HTML 视觉/交互实验，没有工作区检查脚本 |

H5 项目运行时不互相引用源码。部分构建工具来自根工作区安装；不能从“运行时独立”推断“单独复制目录即可构建”。共享模式主要复制后在项目内演化，不存在统一发布的 tool-core 包。新增依赖按 AGENTS.md 由总控处理锁文件。

## H5 概念分层

~~~text
src/content/content.json → 内容校验 / 构建内联
                        → 逻辑与状态 → UI / Canvas / WebGL
                        → 结构化本地存储与迁移
源码 + 本地资源 → 静态构建 → dist → 项目专用打包 / 审计 → ZIP
~~~

此图描述应用工程约定，不强行套用到 Skill 或静态原型。项目 17 人物头像的本地持久化是窄口径例外，具体尺寸、长度、MIME 校验与失败提示见 AGENTS.md。原始音频在构建期转静态 JS 数据，运行期通过 Web Audio 解码；不是运行期用户媒体存储。
