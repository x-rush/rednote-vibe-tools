## 4. 事实证据与降级

- 八项目均存在 NPC 参考 dossier 和本地参考文件；古风项目以博物馆、历史图像和研究材料限定服饰、器物与身份，现代项目用真实日常服装、纸张、包具和手势照片限定结构。
- 所有角色对外均标记原创虚构角色或基于史料的创意重构，不声称历史人物复原，不复制参考真人。
- 八位正式 NPC 均有可解码占位 WebP：除沈砚为 72×90 外，其余为 72×96；单文件 488–1,422 bytes。
- 角色对话、隐私边界、事实说明与操作全部是 DOM 文本；角色图片失败不会阻止跳过、继续、复制、重试或返回安全节点。
- manifest 中已将四态标记为集成；仍保留 `real-app-dynamic-qa`，避免把静态设计预览冒充 WSL 真应用验收。
