# 果冻不能吃，但可以送你了🍮

一开始，只想做一只会晃的果冻。
戳一下，duang一下。
没了。

后来你们说，想多叠几层，想摆点装饰，想插蜡烛。
那就加。

做到第三版，
果冻可以转着看了，
蜡烛可以选数字了，
关了灯，还能坐那儿看一会儿烛光。

我本来只想试试效果。
结果给一颗树莓挪了半天位置。
左边一点，右边一点。
行，今天的正事又往后放了。

这次还可以把做好的果冻做成小卡片。
贴个小表情，写一句话，
存下来，发给想发的人。

比如：
“忙完就早点休息，明天再说。”

不用过生日，
也不用非得发生什么值得庆祝的事。
就是做了个好看的，想给你看看。

果冻依然不能吃。
但现在可以送你了。🍮
