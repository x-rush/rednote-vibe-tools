## 1. 发现的问题

八套预览在桌面画布使用 390px 手机模型。原移动端规则把网格改成 `grid-template-columns: 1fr`，但网格项目仍保留最小内容宽度，导致 375px 视口可能被 390px 手机模型撑宽。此前只观察单张截图不能可靠发现这个问题。

统一修正：

```css
grid-template-columns: minmax(0, 1fr);
.case { min-width: 0; }
```

SBTI 的容器名为 `.phones`，其余项目为 `.grid`。修正仅允许预览卡片正确收缩，不改变产品 UI 的信息层级与触控逻辑。

## 2. 自动回归方法

- 浏览器：本机 Chrome，无头模式，由 Playwright 驱动。
- 视口：`375×932`、`390×932`、`430×932`。
- 页面：八个 `design/preview.html`。
- 检查：文档 `scrollWidth`、全部 `.phone` 左右边界、图片 `complete/naturalWidth`、手机数量。
- 判定：`document.scrollWidth === viewportWidth`；任何手机的 `left < 0` 或 `right > viewportWidth` 均失败；任何 `<img>` 自然宽度为 0 均失败。
