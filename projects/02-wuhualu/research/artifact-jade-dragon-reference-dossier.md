- 馆方信息：新石器时代红山文化；高 26 厘米、重约 1000 克；1971 年内蒙古翁牛特旗三星塔拉出土；中国国家博物馆藏。

- 内部主参考：`official-primary.png`，用于核对完整反 C 形轮廓、吻部、眼、长鬣、尾和穿孔；不进入公开发布包。

## 2. 不可改变的器形

1. 由整块墨绿色玉料圆雕，整体为有力度的反 C／钩形；不能闭合成玉环，也不能改成常见 S 形飞龙。
2. 龙首短小，吻部向前并略上翘，口闭合，鼻端平齐微翘；细长眼朝前。
3. 颈背有一束夸张、后卷上扬的长鬣；不能画成角、翅膀或火焰。
4. 粗壮长身无角、无肢、无爪，尾部内屈朝向龙首；不得补出传统龙的腿、鳞片、须和宝珠。
5. 身体大部分光素无纹，只在额与颚底有细密方格网状纹；不得铺满云雷纹或鳞纹。
6. 脊背有穿孔，馆方说明穿绳悬挂时首尾可处于同一水平；穿孔位置不能变成眼睛或装饰孔。
7. 玉色为墨绿并有自然沁斑、磨痕和色差；不得处理成通透翡翠、纯黑塑料或发光水晶。

## 3. 解释与称号边界

- “中华第一龙”是馆方专题记录的美誉／公众称号，不作为排他性的学术结论。
- 龙原型存在多种假说；游戏不把蛇、猪、鹿或其他单一动物说写成确定答案。
- 可说明其为已知红山文化玉龙中体型最大的一件，并提供馆方来源；不延伸为未经证实的具体祭祀剧情。

## 4. 项目风格适配包

- `projectStyle`：现代博物档案室暗柜；以玉材质和反 C 轮廓建立识别，不做仙侠龙场景。
- `pageRole`：揭晓主图完整展示轮廓、吻、长鬣、尾和穿孔；局部线索从同一正式图派生。
- `interactionMoment`：用户由 C 形剪影和局部鬣纹锁定答案后，看清它为何不是玉猪龙或玉玦。
- `emotionalGoal`：沉静、古老、具有雕塑张力；不是神兽降临或祥瑞庆典。
- `seriesBaseline`：深炭灰柜体、暖聚光、象牙签；墨绿色玉体是唯一色彩主角。
- `avoid`：活体龙、祥云、山水卷轴、金龙、翡翠通透特效、四肢和鳞片、龙珠、SSR 光环、背景伪文字。
