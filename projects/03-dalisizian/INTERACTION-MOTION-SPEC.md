# 大理寺字案录 · 交互与动效规格

状态：`IMPLEMENTED / PRODUCTION QA PASSED`  
设计方向：`活案牍 · 手作推理台`

## 1. 原则

动效只回答三件事：玩家刚操作了什么、证据去了哪里、当前能否继续。纸张、批注、连线和朱印是反馈语言，不是持续播放的氛围装饰。

- 单次常规反馈 100–320ms。
- 页面级过渡不超过 420ms。
- 落印完整过程不超过 760ms，可跳过。
- 不使用持续漂浮粒子、血滤镜、呼吸闪烁或强制镜头摇晃。
- 动效结束状态必须与静态状态完全一致。
- 快速双击、重复触摸和过渡中点击不得重复提交。

## 2. 动效令牌

```css
--motion-instant: 100ms;
--motion-fast: 160ms;
--motion-base: 240ms;
--motion-slow: 360ms;
--motion-seal: 720ms;
--ease-paper: cubic-bezier(.22,.72,.18,1);
--ease-settle: cubic-bezier(.2,.8,.2,1);
--ease-linear: linear;
```

位移上限：常规 12px，翻卷 20px，落印 28px。除落印外不使用超过 `1.02` 的缩放。

## 3. 页面转场

### 卷宗展开

- 触发：领取案件或继续查案。
- 运动：封面纸层从下方上移 16px，同时透明度 0 → 1，240ms。
- 同步：案号签在 100ms 后淡入。
- 禁止：真实 3D 卷轴长时间展开、整屏横向飞入。

### 返回案库

- 当前纸层透明度降至 0.86 并下移 8px，160ms。
- 保存完成后再切换；保存失败时留在当前页显示恢复条。

### 抽屉

- 来源、帮助、证据簿使用底部抽屉。
- 抽屉最大高度 82dvh；背景不缩放，只增加 30% 墨色遮罩。
- 打开 240ms，关闭 180ms；焦点锁定并可用 Escape／返回键关闭。

## 4. 对话选择

### 默认

- 选项是案签形按钮，按压时下沉 1px，背景变为浅朱批色。
- 键盘焦点使用 3px 石青外框，不与选择态混用。

### 提交

1. 点击后立即锁定当前选项组。
2. 选中案签左侧绘出 24px 朱批线，160ms。
3. 其他选项透明度降至 0.55，100ms。
4. 240ms 后进入下一节点。

重复点击在第一步后无效。若节点加载失败，恢复按钮可用状态并保留已选项的本地视觉，不写进度。

### 新证词出现

- 新增段落使用 8px 下移归位和淡入，200ms。
- 已经读过的段落不重复播放。
- 关键事实旁的“记”签只闪现一次边框，不使用跳动红点。

## 5. 初判封存

- 选中判词后出现确认纸条，页面不自动提交。
- 确认时，一条细朱线从右向左划过选项标题，240ms。
- 右上角出现小型“初判已封”印记，缩放 `1.02 → 1`，160ms。
- 保存失败则印记变为琥珀色轮廓并显示“尚未入库”，不假装成功。

## 6. 证物检查

### 翻面

- 使用二维纸层替换，不做真实 3D 卡牌旋转。
- 正面沿 X 轴平移 -12px 并淡出 120ms；背面从 +12px 淡入 160ms。
- 翻面按钮文案在“查看背签／返回正面”之间切换。
- 屏幕阅读器只读当前面，状态通过 `aria-expanded` 暴露。

### 放大热点

- 玩家只能点内容定义的热点。
- 热点默认是 32px 透明触摸区与 16px 角标；聚焦后扩展为 44px。
- 图片在原位最大放大至 1.35，背景其余区域降低对比，不做全屏自由缩放。
- 细节说明从下方升起 10px，200ms。
- 关闭后回到原热点并恢复焦点。

### 收入证据簿

- 证据卡缩为右上角案签的路径用 240ms 位移表达；实际卡片不飞出屏幕。
- 证据计数 `2/4 → 3/4` 使用数字交叉淡化。
- 重复取得同一证据只显示“已归档”，不重播动画。

## 7. 字形时间线

- 切换阶段时只横向移动单个卡位 12px。
- 人工 SVG、数据库预览、待核占位使用不同边框和常驻文字标签。
- 不允许通过描边动画“补写”古文字。
- 选择“对照”后，两项并排淡入，中线标尺从上到下绘制 200ms；标尺不覆盖字形。

## 8. 矛盾标记

1. 玩家先选择证词片段。
2. 再选择可对照材料。
3. 两卡之间出现一条短虚线；关系未确认前保持琥珀色。
4. 选择“时间不合／材料越界／语义倒灌”等有限关系词。
5. 合法关系转为官署青实线并吸附，240ms。

错误组合不摇屏、不闪红。虚线轻微收回 8px，并显示具体边界说明；玩家可继续选择。

## 9. 关系板

### 点选模式（默认）

- 点证据 A → 点关系槽 → 点证据 B。
- 当前选中的证据抬高 2px，阴影加深。
- 可用目标显示石青角标；不可用目标不消失，但带“为何不可连”说明。

### 拖动模式（增强）

- 支持指针拖线，但不是唯一操作方式。
- 拖线端点距离合法目标 20px 时吸附。
- 吸附后播放 160ms 张力回弹，缩放最大 1.01。
- 取消拖动则线头回到起点，不改变数据。

### 连线语义

- `支持`：官署青实线。
- `补充`：石青双短线。
- `矛盾`：朱色短划线。
- `越界`：琥珀色点划线。
- 每条线必须同时有可读关系标签，不只靠颜色。

## 10. 证据链组合

- 下方证据池中的卡片可点选加入三个固定槽：`材料`、`解释`、`边界`。
- 加入后卡片淡入对应槽，180ms；原位置保留带“已用”标签的副本，避免布局跳动。
- 顺序调整使用上下按钮为基线；拖动排序是增强功能。
- 链条完整时，从左至右依次点亮三个节点，共 360ms。
- 缺项时主按钮保持可读禁用态，并明确列出缺少哪一类证据。

## 11. 定案与落印

### 定案确认

- 提交前把判词、矛盾解释和证据链集中显示在一张纸上。
- 玩家必须主动勾选“我确认这条证据链”，然后按钮可用。
- 关闭确认层不丢失组合。

### 正确或可成立链条

```text
0–160ms   印章轮廓出现
160–440ms 印章下移 28px，阴影收紧
440–560ms 接触纸面，朱色印纹显现
560–720ms 印章上移 10px，结案状态固定
```

不播放重击震动；可选短音效默认受静音设置控制。

### 不成立链条

- 不落正式结案印。
- 链条中不成立的一环转为琥珀点划线。
- 显示“这条材料还不能推出该结论”及原因。
- 玩家选择“回卷核验”后回到判前安全页，证据和调查位置保留。

## 12. 结案档案

- 初判与终判卡先静态呈现。
- 变化证据按玩家实际使用顺序逐条淡入，每条间隔 60ms，总时长不超过 360ms。
- “坚持初判”与“改变初判”使用同等视觉权重。
- 来源抽屉不自动弹出；结案主信息先可读。

## 13. 异常与恢复

### 图片失败

- 图片区域保持固定比例，120ms 内替换为文字核验卡。
- 不显示浏览器破图图标。
- “依据文字继续”是主动作，“重试图片”是次动作。

### 内容缺页

- 不播放错误震动。
- 当前卷页轻微退后 8px，完整恢复纸层从下方出现。
- 明确列出已保留内容与唯一会失去的未确认操作。

### 存储失败

- 顶部状态由“已入库”变为琥珀色“待保存”。
- 自动重试不超过一次；之后由用户选择重试或临时审案。
- 临时模式持续显示小型状态签，防止误以为已保存。

## 14. `prefers-reduced-motion`

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
    scroll-behavior: auto !important;
  }
}
```

减少动态模式下：

- 页面与抽屉直接交叉淡化，不位移。
- 证物翻面直接替换内容。
- 连线直接呈现最终样式。
- 落印只做 120ms 透明度变化。
- 所有结果仍通过文字、图标与边框表达。

## 15. 验收清单

- 过渡期间快速双击只提交一次。
- 返回键先关闭抽屉、热点或确认层，再返回安全页。
- 动画中断或切后台后能恢复到确定状态。
- 375 / 390 / 430 px 下没有位移导致的横向溢出。
- 长对话、长来源和系统字体放大后仍可滚动到全部操作。
- 所有拖动操作都有点选／按钮替代路径。
- 动效关闭后不丢失任何状态语义。

## 17. 生产动效验收 / 2026-08-26

- 对话选择先锁定、绘制朱批线，再推进节点；真实浏览器快速双击只记录一次推进。
- 落印按钮进入“正在落印…”锁定态，印章按 720ms 时间线完成后才写入结案并解锁后续案卷。
- 帮助与证据详情使用可关闭纸层；键盘焦点不会逃逸，关闭后归还原触发器。
- 顶部通知不拦截页面点击；调查、证据和错误回卷均保留已取得状态。
- `prefers-reduced-motion: reduce` 下人物和纸层动画为 `none`／近即时过渡，操作与结果文字保持完整。
- 375／390／430 CSS px 下动效前后均无横向溢出；图片请求被阻断时仍有可玩的文字路径。

## 18. 图鉴与分享卡动效

- 落印 720ms 完成后才写入图鉴并弹出战绩卡，避免卡片先于结案状态出现。
- 图鉴藏品使用一次性 12px 以内纸层入场；锁定槽位不做呼吸、闪烁或诱导点击。
- 分享卡打开为 280ms 淡入／上移；纯净截图模式直接隐藏工具栏，不缩放或重排卡片内部信息。
- Escape 在纯净模式下先恢复工具栏，再次按下关闭卡片；焦点始终限制在可见控件中并在关闭后归还。
- 减少动态模式禁用卡片入场动画，结案、图鉴解锁与分享信息仍由文字和朱印表达。
