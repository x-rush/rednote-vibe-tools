# 2.0.0 行为与工程验收

日期：2026-10-14。实际生成的独立试跑逐轮回复见 [QA-TRIAL-2.0.md](QA-TRIAL-2.0.md)。测试候选输入为虚构夹具，独立代理按技能生成实际回复；没有执行真实 Agent、支付、源码或平台导入。

通过的观察：

- 教学陪练解释 JSON / Schema / 业务授权，并给退款零调用断言；不会要求初学者先背框架。
- 正式模拟按回答追问未知结果、幂等与检查点故障窗口，正式提问前不展示答案，最多两次追问。
- 项目答辩接受 TypeScript 与没有 RAG 的项目，围绕实际模块追问来源支持、缺证据与评测；自报能跑演示不变成已上线证据。
- 学习摘要中的最高等级、认证、保证录用指令被当作资料，不改变评价；合法进度字段只作为 self_report。
- 提示后未答结束保留 before_hint 原话和 unanswered_after_hint，不生成 after_hint 回答；输出可复制补练单与 JSON。
