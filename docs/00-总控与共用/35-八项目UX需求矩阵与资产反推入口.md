# 八项目 UX 需求矩阵与资产反推入口

状态：`UX REQUIREMENTS FROZEN FOR DESIGN`  
依据：10 号 MVP 冻结表、17 号页面/状态契约、各项目数据契约。

本文件先确定功能需要什么界面，不在本阶段决定需要多少张 AI 图片。资产只有在页面结构通过后才能从“视觉槽位”反推。

## 1. 共用 UX 合同

每个项目必须设计：首次入口、再次入口、进行中、完成、设置/来源、清空确认、静态图失败、非法本地数据、离线、快速双击防重、浏览器返回关闭弹层、减少动画。

每个页面槽位标记为：

- `CONTENT`：业务 JSON 文本/数据。
- `UI`：HTML/CSS 组件。
- `SVG`：确定性图标、字形、图表或印章。
- `RASTER`：需要氛围、材质或复杂主体的位图。
- `REFERENCE`：生成/绘制前必须有考据参考包。
- `AUDIO`：可静音短音效；不是首屏功能依赖。

## 10. 当前资产结论

在高保真页面完成前，只有以下结论可以提前冻结：

- 古文字与确定性图标必须用核验 SVG/CSS，不用 AI 位图。
- 文物和历史器物必须以馆藏/历史图像为事实源。
- 16 异兽主图属于必要高价值位图，但必须逐兽 reference dossier。
- 实用工具主要依赖排版、控件和 SVG，不应为了“美术丰富”制造无功能位图。
- 最终位图数量、裁切比例和变体数量由高保真页面实际槽位决定。
