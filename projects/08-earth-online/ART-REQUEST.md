# 地球 Online｜美术资源制作清单

日期：2026-08-26
状态：待书面规格复核；确认后按本清单先生成资源，再开发界面

## 1. 总体方向

资源服务“会呼吸的现实冒险者公会”：温暖、可靠、有轻度 RPG 仪式感，但任务仍属于真实城市和日常生活。首屏品牌由弥拉、公告板、任务纸和统一徽记系统构成，不制作大型大厅背景图或 100 张任务插画。

原创边界：赛利亚只作为“温暖、可信赖、长期陪伴的大厅引导者”功能参考；不得复制其脸型、银灰发、绿色束身衣、羽毛领、红色展开披布、圆环饰件、姿势、台词或标志。不得出现其他商业游戏角色、Logo 或界面。

## 2. 位图资源｜使用 ImageGen

### A01 弥拉透明半身母版

- 路径：`public/assets/earth-online/guide/mira-master-v3.png`
- 目标画布：1536×2048，3:4，真实透明背景。
- 输出用途：首次引导、大厅柜台、恢复状态。
- 构图：成年原创女性，腰部以上至完整双手；面向用户，单手持空白羊皮任务簿，另一手做克制开放邀请手势；轮廓可裁头像。
- 外观：栗棕编发、榛色眼睛；午夜蓝与暖白的中世纪式层叠衣装、短酒红披肩、黄铜扣件、皮革腰包、原创四向路径黄铜胸针。
- 风格：高完成度 2D 编辑插画，柔和赛璐珞与细腻手绘纹理结合；温暖但不幼态、不性感化、不战斗化。
- 光线：左上暖光、右侧深蓝环境反光，与页面夜蓝/羊皮纸体系一致。
- 禁止：文字、Logo、水印、精灵耳、粉/银发、绿色束身衣、羽毛领、展开红披布、圆环腰饰、蕾丝女仆、武器、法杖、翅膀、现代制服、现代夹板、摄影写实。

### A02 弥拉头像

- 路径：`public/assets/earth-online/guide/mira-avatar-v3.webp`
- 规格：320×320 WebP，透明或纯净深蓝底，建议 ≤24KB。
- 来源：从通过验收的 A01 进行无生成漂移的裁切与压缩，不重新生成身份不同的头像。
- 用途：任务说明、帮助入口、恢复提示和日志节点。

### A03 弥拉低带宽占位

- 路径：`public/assets/earth-online/guide/mira-placeholder-v3.webp`
- 规格：144×192 WebP，建议 ≤8KB。
- 来源：A01 缩放与轻度降色；不得储存在 localStorage/IndexedDB。
- 用途：图片解码前占位和低性能降级。

### A04 异世界公会公告栏｜已完成

- 路径：`public/assets/earth-online/scenes/guild-notice-board-v1.webp`
- 规格：1152×864 WebP，透明外边缘，约 424KB。
- 构图：一张完整深色橡木与黄铜公告栏，画面内固定四张独立布告；不是四张切图，也不使用 SVG 拼装。
- 四张布告：角兽苔原悬赏、残月召唤阵警告、浮空商队路线、炼金异常与独眼软泥怪。
- 文字：只使用不可读的原创伪符文与印记，不承载业务信息；可访问内容仍由页面真实文本提供。
- 动效：整板召唤入场，法阵只作低频辉光叠层；开启减少动态效果时保持静态完整。

位图生成后必须检查：双手、任务簿、衣装连接和胸针结构可信；任务簿无伪文字；头像裁切仍能识别；无禁用 IP 特征。最终项目资源需落在上述目录，不能只保留在生成工具默认目录。

### B14–B18 状态图标

路径：`public/assets/earth-online/status/status-<id>.svg`

- `active`：被黄铜夹固定的任务纸。

- `abandoned`：纸张回到板上的回转箭头，不使用红叉。
- `unsuitable`：可撤销的偏好滑片。
- `temporary`：虚线纸张与小钟，不使用警报三角作为唯一语义。

### B19 完成印章底章

## 5. CSS/SVG 纹理

- 公告板：使用 A04 完整位图；CSS 只负责阴影、入场和法阵辉光，不重新绘制纸张或图案。
- 普通任务纸：暖白到羊皮纸渐变、轻微内阴影和 1px 边线。
- 回退任务纸：同一纸张体系增加灰蓝侧边签，不创建第二张大位图。
- 印泥墨迹：CSS radial-gradient；不使用持续粒子或视频。

## 6. 资源预算

- A01 主图建议压缩后 ≤350KB；如透明 PNG 超预算，保留 PNG 母版并生成项目消费用 WebP，但不得破坏透明边缘。
- A02 ≤24KB；A03 ≤8KB。
- 单枚 SVG 建议 ≤6KB；全部 SVG 建议 ≤140KB。
- 首屏实际传输资源目标 ≤450KB；非首屏成就和状态资源可延迟加载。
- 无远程 CDN、运行时 API 或外部字体。

## 7. 降级

- 弥拉位图失败：显示黄铜胸针 SVG、姓名与身份文字，不隐藏任务或操作。
- 类别图标失败：显示类别中文名和通用圆形底章。
- 动效关闭：静态任务纸、印章和徽章仍完整表达状态。
- 任何资源不得写入 localStorage、IndexedDB、Base64 字符串或 Blob 持久化。

## 8. 验收顺序

1. 生成并审核 A01；通过身份、手部、空白任务簿、原创边界后再裁 A02/A03。
2. 先制作 observe、tidy、connect 与 E/D/C 基准 SVG，在 20/32/48px 盲审。
3. 基准通过后完成其余类别、状态、完成印章和五枚成就。
4. 检查全部 XML、viewBox、title、线宽和断图。
5. 装入真实页面，在 375/390/430px、深浅表面和 reduced-motion 下复检。
