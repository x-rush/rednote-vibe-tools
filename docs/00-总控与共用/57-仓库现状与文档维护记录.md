## 当前共同规则

以 [AGENTS.md](../../AGENTS.md) 为准：只保留 main，直接开发、提交、推送；按用户授权范围工作，保留其他未提交修改。H5 纯静态离线；业务内容归本项目 content.json。用户运行期媒体默认不持久化，仅项目 17 人物库小尺寸头像有明确例外。音频构建期转静态 JS，运行时 Web Audio 解码播放；不得把原始音频装入 H5 上传 ZIP。

UI 检查至少包含 375 / 390 / 430 CSS px、非零系统安全区、左右宿主按钮覆盖层以及实际存在的横屏模式。浏览器模拟与宿主真机验收分开记录。
