# 星风来信｜设计与实现

## 核心体验

这是一个手机竖屏、一次点击触发的纯前端动画。首屏不展示候选星语；点击时随机锁定一句，风先从窗口上沿掀动线帘，随后月亮、星流与月光显现。单字作为模糊光迹和星星一起进入室内，最后在镜头前组成完整句子。

结果态不是静帧：帘子持续随风摆动，星流按固定上限持续补充，主星落到地面后化为星点消散，直到用户选择重播。

## 构图

- 固定窗框位于画面上半部偏右，保留明显的斜视透视和中间横栏。
- 不绘制活动玻璃、把手、铰链，也没有额外的开窗动作；风只负责揭开线帘。
- 初始室内无月光投射，仅有被帘线压暗的远处月影。
- 帘子由 64 根独立发光线构成，开启从顶部向控制点和尾端逐段传递。
- 地面两块几何亮区是被横栏切开的透视月光，不是书或纸张。
- 星语位于下方安静区域，最多两行，使用克制的宋体字形与柔和辉光。

## 分层

从后到前依次为：

1. `WindowLayer`：深蓝室内、固定窗框、月牙和分栏月光。
2. 外部粒子画布：仍位于窗口空间的星点。
3. `CurtainLayer`：线帘与持续风摆。
4. 内部粒子画布：穿过窗口后的星尘、拖尾与落地主星。
5. `StarbornePhrase`：逐字飞行并最终成句。
6. 点击入口、声音与重播控件。

## 状态与数据

体验状态只有 `idle → wind → curtain-opening → stars-and-letters → result`，重播经 `resetting` 回到 `idle`。结果时间不封顶，因此帘摆与粒子可以一直更新。

星语业务内容只来自 `src/content/content.json`。近期八次结果在内存中去重；静音偏好可写入 `localStorage`。项目不保存用户图片、音视频、Base64 或 Blob。

## 性能与无障碍

- 满画质粒子上限 132，降级模式上限 68；过期粒子会回收。
- `prefers-reduced-motion` 降低粒子密度、字的位移和旋转，但保留完整叙事。
- 飞行字符始终对辅助技术隐藏，只在完整句形成后通过独立 live region 播报一次。
- 顶部声音按钮叠加 `var(--safe-area-inset-top, env(safe-area-inset-top, 0px))`。
