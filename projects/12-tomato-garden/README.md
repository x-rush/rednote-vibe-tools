# 番茄小院

以专注时间培养植物的纯前端小工具。项目独立放在 `projects/12-tomato-garden`，无新增依赖、无运行时外部服务。

## 使用

在本目录运行 `pnpm dev`，打开 http://127.0.0.1:4311 。端口占用时可用 `PORT=4321 pnpm dev`。运行 `pnpm build` 后，将 `dist/` 作为静态站点目录发布（也支持子路径）。`pnpm preview` 预览构建产物。Node 仅用于本地开发、检查与构建；浏览器运行不依赖 Node。

## 植物与成长设计

|植物|解锁所需累计专注|五阶段及所需累计成长分钟|形态重点|
|---|---:|---|---|
|小番茄|0|种子 0 → 萌芽 15 → 展叶 50 → 开花 100 → 结果 150|分枝、黄色星花、红果|
|向日葵|60|种子 0 → 萌芽 15 → 拔高 60 → 花苞 120 → 盛放 180|挺拔茎秆、顶生花苞、金黄花盘|
|草莓|180|种子 0 → 萌芽 20 → 簇叶 70 → 白花 140 → 红果 210|低矮叶丛、白花、下垂果实|
|龟背竹|360|种子 0 → 萌芽 20 → 心叶 80 → 初裂 160 → 繁叶 240|从整叶到开裂，再到层叠大叶|
|薄荷|0|种子 0 → 新芽 10 → 对叶 25 → 分枝 55 → 清香 90|成对嫩叶、逐渐茂密的枝条|
|仙人掌|0|种子 0 → 冒芽 10 → 圆茎 35 → 侧芽 75 → 开花 120|柱形茎、侧枝和粉色小花|
|薰衣草|120|种子 0 → 萌芽 15 → 细叶 50 → 花穗 110 → 紫花 180|细长花枝、层叠紫色花穗|
|小雏菊|240|种子 0 → 萌芽 15 → 叶丛 45 → 花苞 95 → 花开 150|低矮叶丛、白色花瓣与金色花心|

成长周期是游戏设计，不代表现实植物生长时间。全部业务内容和阈值位于 `src/content/content.json`；本地 SVG 绘制负责表现形态，不调用图片接口。

## 已实现

- 15 / 25 / 45 分钟预设与 1–180 整数分钟自定义；可填写任务、使用阅读/学习/写作/工作快捷填充，暂停、恢复和提前结束。
- 待机时可开始 5 分钟短休息或 15 分钟长休息，专注结束可接续短休息；休息不奖励成长、不自动循环累计。
- 首页将时间和植物放在同一场景中并排展示，手机也不再上下堆叠；种子介绍采用对齐的图文与独立入口。
- 开始专注或休息后，自动切换为占满浏览器视口的独立计时页面，仅保留暂停/继续、停止两个控件；不渲染导航、设置、图鉴、退出入口，Esc 和背景点击不会离开专注。无需浏览器全屏权限。
- 生长光点、嫩芽呼吸与枝叶轻摆动画；真实专注分钟达到阈值时更新植物阶段，暂停时动画与时间一起冻结。动画预览不提前发放成长奖励，减少动态偏好会停用动画。
- 点击停止立即结算已完成的整分钟并展示结果；计时完成也自动结算。刷新后仍保持独立专注页面。
- 8 种植物，3 种初始可选；按解锁状态或品类筛选，可预览每种植物的五个成长阶段，未解锁植物仍可查看。
- 1 整分钟 = 1 成长值。提前结束保留整分钟，不计完整番茄次数；少于 1 分钟不写记录。
- 当前植物成长上限为成熟阈值；超出分钟仍计入累计和记录，不自动转给下一株。
- 成熟后手动收入小院再种植；每个品种保留独立未完成进度；计时期间禁止换种。
- 图鉴、解锁、小院收藏、最近七天柱状统计、最近 30 条记录展示。
- 暂停和运行状态都可刷新恢复；根据截止时间计算剩余时间，离开后最多结算当前这一轮。
- 以浏览器本地日期记录结算日，跨午夜整段归入结算当天。
- 本地结构化存储；无账号同步。存储不可用显示提示并以内存继续。
- 键盘操作、弹窗焦点约束、专注时 Tab 在两个控制按钮间循环、减少动画偏好、手机安全区。

## 检查

`pnpm lint` 检查 JavaScript 语法、JSON 格式及运行时代码外部 URL；`pnpm test` 运行 Node 内置测试；`pnpm build` 将固定模块图和内容 JSON 合并为离线经典脚本，生成纯静态产物。无需安装依赖或修改共享锁文件。浏览器回归使用已有 Playwright：`BASE_URL=http://127.0.0.1:4321 node scripts/browser-check.mjs <已安装的playwright模块绝对路径>`。默认测试地址为 4311；请确保指向当前源码或本次构建产物。

## 已知边界

- 不申请通知权限、不承诺锁屏响铃；重新打开页面后恢复正确状态。
- 手动修改系统时钟可能改变倒计时，不提供防作弊能力。
- 浏览器存储清理会清除小院；多标签同步通过 storage 事件实现，推荐只在一个标签操作计时，不作为并发事务系统。
- 未发布线上地址；本项目只提供本地预览和可部署的静态构建产物。

## 小工具提交产物

按仓库 `.codex/SKILL.md` 的 ZIP 规范执行 `pnpm package`，会重新构建并检查包结构、经典脚本、相对资源、禁用能力、体积及 ZIP 完整性。构建不新增依赖；打包使用本机 `zip` / `unzip`。

- `release-assets/tomato-garden-mini-tool-v1.zip`：可上传静态包，根目录直接包含 `index.html`，其余为包内经典脚本、CSS 与 favicon。
- `release-assets/tomato-garden-mini-tool-v1.zip.sha256`：包的 SHA-256 校验值。
- `release-assets/tomato-garden-icon.png`：1254×1254 PNG 提交图标，暖白底、番茄与花盆，无文字；作为平台图标单独上传。

业务内容仍以 `src/content/content.json` 为唯一编辑源；构建时自动内嵌到 `dist/assets/app.js`。开发入口可以使用模块，最终 ZIP 不包含模块、动态数据加载或开发文件。

离线回归：将 ZIP 解压到 `artifacts/offline-package/` 后运行：

```bash
OFFLINE_CHECK=1 BASE_URL=file:///绝对路径/artifacts/offline-package/index.html node scripts/browser-check.mjs <已安装的playwright模块绝对路径>
```

该模式关闭浏览器网络并禁用 `fetch` / `XMLHttpRequest`，直接从解压文件验证操作。尚未在小红书 PC 模拟器或实体 WebView 中运行。
