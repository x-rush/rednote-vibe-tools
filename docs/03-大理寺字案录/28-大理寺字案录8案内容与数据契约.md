# 大理寺字案录｜8 案首发内容与数据契约

状态：CONTENT READY / 待统一底本逐字核验、转 JSON 与节点可达性测试。

副标题：`查的不是人，是汉字的前世今生。`

固定声明：大理寺字案录是虚构的文字案件机构；人物、卷宗和审讯对话属于游戏叙事。字形与字义资料必须引用可靠数据库和出版物，不让玩家选择改变事实结论。

## 1. 共用案件结构

每案包含：

```text
传闻 → 三选一初判
→ 调查一：看字形
→ 调查二：查古书解释
→ 调查三：辨现代流传
→ 证据簿 → 四选一终判
→ 结案文书 → 来源与争议
```

调查顺序允许变化；每段 2–3 个预设选项。证据有 `direct-form`、`historical-gloss`、`later-interpretation`、`modern-folk` 四类。

判词枚举：

- `credible`：核心说法有较强证据支持。
- `partial`：抓住部分结构或传统解释，但表达过度确定。
- `uncertain`：材料或学界意见不足以排他定案。
- `myth`：与可核验材料明显冲突或纯属现代拆字附会。

## 2. 第一案：家字失踪案

- ID：`case-home-roof-pig`
- 传闻：“家”就是屋子里养猪，古人有猪才算有家。
- 初判选项：可信 / 有一点道理但太绝对 / 完全是现代段子。

### 三段调查

1. 看 `家` 的早期字形与不同字形构件，不允许只拆现代楷书。
2. 查《说文》：“家，居也。从宀，豭省声。”重点辨认其中包含声符解释，而不只是图画会意。[《说文解字·宀部》](https://ctext.org/shuo-wen-jie-zi/mian-bu/ens)
3. 比较“构件出现”“构件功能”“社会生活推断”三件不同的事。

### 证据

- `evidence-home-early-form`：早期字形确实需要逐形观察。
- `evidence-home-shuowen`：《说文》释义与构形说。
- `evidence-home-phonetic`：“豭省声”提示不能只按现代图像讲故事。
- `evidence-home-social-leap`：由一个构件推导“人人家中养猪”属于超出文字证据的社会史结论。

### 官方判词

`partial`。传闻可能抓住了字形中与豕相关的部分，却把复杂构形和社会历史压成一句必然结论。“屋里有猪才叫家”不能作为确定字源定论。

## 3. 第二案：休字树下案

- ID：`case-rest-under-tree`
- 传闻：“休”就是一个人靠在树旁休息，所有会意字都能像看图一样直接猜中。

### 三段调查

1. 观察早期与篆文字形中的人、木关系。
2. 查传统字书对“休”的解释，并比较“传统会意分析”和“所有会意字都可看图猜”是否等价。
3. 审问说书人：一个例子能否证明一种万能拆字方法。

### 证据

- `evidence-rest-components`：人、木构件关系是传统解释的重要部分。
- `evidence-rest-gloss`：传统字书与后世六书解释。
- `evidence-rest-method-limit`：个别直观案例不能推广为所有汉字的解法。
- `evidence-rest-modern-shape`：现代楷书形状可能掩盖历史变化。

### 官方判词

`partial`。把“休”解释为人依木具有深厚传统，但“所有汉字都能按现代部件画面猜本义”是错误的方法扩张。

## 4. 第三案：取字失耳案

- ID：`case-take-ear`
- 传闻：“取”从手从耳，是古代战争割耳计功，所以‘取得’天然带暴力含义。

### 三段调查

1. 看 `取` 的早期构件，辨手形与耳形。
2. 查传统字书和《周礼》相关“获者取左耳”的材料；区分构形解释、制度记载和现代常用义。[中国哲学书电子化计划“取”字资料](https://ctext.org/dictionary.pl?char=%E5%8F%96&if=en)
3. 比较“一个早期语境影响构形”与“今天所有取字词都带相同价值”的差别。

### 证据

- `evidence-take-form`：早期字形材料。
- `evidence-take-rite`：古代文本中取耳相关记录。
- `evidence-take-semantic-change`：字义会扩展、抽象和中性化。
- `evidence-take-moral-fallacy`：不能把构形历史当作现代词语的道德属性。

### 官方判词

`partial`。传闻可能关联到真实古代材料，但由此断言今天的“取得、采取”天然暴力，是忽略语义演变。

## 5. 第四案：采字摘叶案

- ID：`case-pick-from-tree`
- 传闻：“采”就是手在树上摘东西，因此“色彩”的“彩”也来自摘树叶的颜色。

### 三段调查

1. 对比 `采`、`釆`、`彩`，防止只因字形相近混为一字。
2. 查字书中“采”从木从爪的传统分析，以及 `釆` 的分别义材料。[《说文解字注》相关采字条](https://ctext.org/wiki.pl?chapter=348569&if=en&remap=gb)、[《说文解字·釆部》](https://ctext.org/shuo-wen-jie-zi/bian-bu/ens)
3. 追查“采取”“文采”“色彩”不同词义的发展，避免编造一条单线故事。

### 证据

- `evidence-pick-form`：采的构件与传统取物解释。
- `evidence-bian-distinction`：釆与采不可因简体显示相近混用。
- `evidence-cai-extensions`：采、彩相关义项需要分期说明。
- `evidence-leaf-color-story`：“摘彩叶所以有色彩”缺乏直接证据。

### 官方判词

`partial`。手取木上之物可作为传统构形解释，但把“彩”的全部来源讲成摘彩色树叶，是现代补写的故事。

## 6. 第五案：监字照盆案

- ID：`case-look-into-basin`
- 传闻：“监”的古字就是人低头照水盆，所以监视的本义就是照镜子。

### 三段调查

1. 查看 `監` 的早期字形中人目与器皿相关构件。
2. 查《说文》“監，臨下也”等传统解释，注意它强调从上临下观察，而不是简单等同现代照镜。[《说文解字·卧部》](https://ctext.org/shuo-wen-jie-zi/wo-bu)
3. 比较 `監`、`鑑/鉴` 的字形与词义关系，防止把后来的镜鉴概念倒灌成唯一原义。

### 证据

- `evidence-watch-form`：早期字形与器皿意象。
- `evidence-watch-gloss`：传统“临下”解释。
- `evidence-mirror-relation`：监、鉴存在历史关系但不能粗暴合一。
- `evidence-watch-modern-story`：“只是照镜子”过度缩窄。

### 官方判词

`partial`。临器俯视的意象有材料基础，但“监视本义就是照镜子”把复杂关系说得过于单一。

## 7. 第六案：武字止戈案

- ID：`case-martial-stop-spear`
- 传闻：“武”就是“停止战争”，因为拆开是止戈，所以武的本义完全反战。

### 三段调查

1. 查看早期 `武` 字形，讨论 `止` 在早期文字中与足、行进相关的材料。
2. 查《说文》所引“止戈为武”传统，以及它作为经典解释的历史地位。[《说文解字·戈部》](https://ctext.org/shuo-wen-jie-zi/ge-bu1/ens)
3. 区分“古代思想家对武的价值阐释”和“字形产生时唯一可证明的构形动机”。

### 证据

- `evidence-martial-form`：早期字形不能仅按现代“停止”义拆解。
- `evidence-martial-shuowen`：“止戈为武”是有历史来源的传统解释，不是现代网文凭空创造。
- `evidence-martial-foot`：止的早期字形与足、行进关系。
- `evidence-martial-value-vs-origin`：价值阐释不必等于排他的字源证明。

### 官方判词

`partial`。“止戈为武”是重要的古代解释传统，但把它直接当作毫无争议的最初造字原理，并把 `止` 只理解为现代“停止”，证据不足。

## 8. 第七案：法字流水案

- ID：`case-law-water-go`
- 传闻：“法”由三点水和去组成，意思是法律像水一样公平，把坏人去掉。

### 三段调查

1. 对比简体 `法`、繁体/古字 `灋` 及历史字形，发现现代简化字不能直接倒推最初构形。
2. 查《说文》对 `灋` 的解释，其中包括水、廌、去等复杂构件和“刑也”的释义。[中国哲学书电子化计划“灋”字资料](https://ctext.org/dictionary.pl?char=%E7%81%8B&if=en)
3. 审理“水代表公平、去代表去坏人”是否有直接早期材料，还是后世价值化拆字。

### 证据

- `evidence-law-old-form`：灋的历史形式比现代法复杂。
- `evidence-law-shuowen`：传统字书对构件的解释。
- `evidence-law-simplification`：现代字形不是最初造字现场。
- `evidence-law-water-fairness`：“水一样公平”属于流行阐释，不能冒充确定字源。

### 官方判词

`myth`。这句现代拆字格言表达了一种价值想象，但不能作为“法”的可靠造字来源。

## 9. 第八案：秋字虫火案

- ID：`case-autumn-insect-fire`
- 传闻：“秋”就是禾谷成熟后用火烧田；另有人说最早是烧一只蟋蟀，所以两个说法必有一个完全正确。

### 三段调查

1. 查看不同阶段 `秋` 的复杂字形和异体，注意早期材料可能含昆虫形、火等元素，不能只拆现代禾火。
2. 比较字书解释、甲骨文字形数据库和不同学者对构形的意见。[中央研究院“小学堂”甲骨文数据库](https://xiaoxue.iis.sinica.edu.tw/jiaguwen)
3. 区分“季节义”“收成活动”“虫与火的字形材料”之间哪些是事实、哪些是解释。

### 证据

- `evidence-autumn-variants`：秋存在多阶段、多异体材料。
- `evidence-autumn-insect-fire`：早期字形需要用数据库实形展示，不由 AI 生成。
- `evidence-autumn-modern-form`：现代禾火结构不能独自证明最初故事。
- `evidence-autumn-debate`：存在争议时应展示可信度而非强行选唯一故事。

### 官方判词

`uncertain`。两个传闻都可能抓住部分材料，但不能仅凭现代字形或单一图解排他定案；结果页展示主要解释及其证据范围。

## 12. 节点生成规则

- 每案三段调查，每段至少 3 个内容节点和 2 个选择节点。
- 一案预计 18–26 个节点，首发八案约 160–200 个节点。
- 选项影响调查顺序、证据获得时机和判案风格标签，不改变史料本身。
- 所有路径最终能获得必需证据；遗漏的补充证据可影响结案文书丰富度。
- 用户端不显示“官方答案”一词，使用“大理寺参考判词”，承认争议。

## 13. 来源与图形规则

- 早期字形以中央研究院“小学堂”等数据库或正式出版物核验。[小學堂甲骨文数据库](https://xiaoxue.iis.sinica.edu.tw/jiaguwen)
- 《说文》只是重要历史解释来源，不等于现代文字学最终结论；可用中国哲学书电子化计划定位底本。[《说文解字》总入口](https://ctext.org/shuo-wen-jie-zi/zhs)
- 字形图必须依据可追溯字形自绘或合法引用，禁止让 AI 自行发明甲骨文、金文。
- 正式入库前每案至少由两类资料交叉核验：早期字形数据库 + 字书/现代研究。

## 14. 验收

- 8 个案件 ID 唯一。
- 每案三段调查、四类证据、初判与终判。
- 所有互动均为预设选项。
- 节点图无死路、无无意循环、无缺失 nextNodeId。
- 事实不因选项改变；争议内容不伪装确定结论。
- 每个案件都有用户可见来源页。
