## 一句话定义

玩家从培养皿中的一个原始细胞开始，通过吞噬、逃生、分裂、合并和器官变异，穿越不同微观环境，形成独一无二的生命形态并挑战区域主宰。

## 核心承诺

- 3 秒理解：小的能吃，大的要躲。
- 单指可玩：拖动移动，点按或双击释放能力。
- 每 30–50 秒一次肉眼可见的变异。
- 每局 8–15 分钟，失败后仍带回有限基因样本。
- 不靠长文本、签到、在线排行或虚假多人制造留存。
- 结果页展示最终细胞大图、关键器官、最远环境与真实死因，可直接截图传播。
