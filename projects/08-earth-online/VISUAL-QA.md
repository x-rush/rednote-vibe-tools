# 地球 Online · 赛级 UI 视觉与交互验收

日期：2026-08-26
对象：Vite 生产界面（非独立静态概念稿）
结论：RPG 重构后的核心闭环、移动端边界、无遮挡导航、安全区、动效降级与存储恢复均通过。

## 已验收流程

- 首次三句弥拉引导 → 六组今日状态登记 → 真实条件匹配仪式。
- 任务揭晓 → 换任务 → 结构化“不适合”反馈 → 安全原因即时提示 → 撤销软偏好。
- 接取 → 刷新 → 进行中任务恢复 → 完成确认 → 单次 XP 与徽章结算 → 冒险日志。
- 放回确认与可选原因 → 不扣 XP 的完成态。
- 日志筛选、十类图鉴、五枚徽章、等级档案、弥拉帮助及焦点返回。
- 点击顶栏弥拉头像会打开全屏 NPC 会面：上半部完整立绘与召唤法阵，下半部羊皮纸对话框；五项话题可切换回答，Escape 或“结束交谈”关闭后焦点返回头像。
- 顶栏身份已拆分：玩家入口使用无人物头像的“冒险者”徽章、真实本级进度和 XP；NPC 入口使用带气泡尾角的羊皮纸组件，持续显示“弥拉 / 公会向导 / 交谈”，不再形成“玩家头像 + 经验条”的误读组合。
- 损坏 localStorage、写入失败临时模式、IndexedDB 不可用降级。

| 390×844 | 390 | 0 | 0 | 44px | 54px |

最长标题、简报、描述、五项任务事实、两条步骤与退出条件均自然换行；任务纸、弹层和操作区未越界。三档视口扫描到的可见叶子文本裁剪均为 0。

登记页六组标题已经从压住 `fieldset` 边框的 legend 改为卡片内部可见标题；语义 legend 仍保留给辅助技术。档案第五项统计跨满整行，不再留下假空格。进行中任务的“放回任务板”在深色背景上具有明确边框和可读文字。

## 安全区与滚动

- 在 `:root` 注入 `--safe-area-inset-top: 44px` 后，移动端先保留 48px 原生胶囊行，再整体放置 HUD：顶栏 top=44px、品牌栏 top=100px、导航 top=158px、HUD bottom=218px、主内容 top=218px。品牌、等级、弥拉头像和导航不再为右侧胶囊做横向挤压。
- 四项导航已经从 fixed 底栏迁入 sticky 安全区 HUD，计算样式为 `position: static`；375 / 390 / 430px 下固定覆盖元素与正文交叉数均为 0。
- 页面切换会回到顶部；`prefers-reduced-motion` 时使用即时回顶。
- 页面标题带安全区与顶栏高度组成的 `scroll-margin-top`；当前界面没有锚点跳转。
- 帮助与确认 sheet 的最大高度扣除顶部安全区，长内容可以自然滚动。

## 动效与无障碍

- 匹配只展示正在核对的真实条件标签，不显示虚假百分比；常规模式约 720ms，可随时跳过。
- reduced-motion 实测从提交到任务出现为 67ms；CSS 动画/过渡统一不超过 100ms，旋转与循环失效。
- 匹配符文阵、卷轴展开、任务气质章、公会简报、完成印章冲击波、XP 光束、徽章边缘、日志收入与纸张放回均不改变领域状态。
- reduced-motion 实测所有动画最长 `0.1s`、迭代次数均为 1，无无限动画残留。
- NPC 会面层的立绘召唤、法阵呼吸、对话框升起和回答墨迹切换均受 reduced-motion 约束；实测最长 `0.1s`、无限动画数为 0。
- 任务、弹层、导航使用 button/form/fieldset/legend/dialog/progress 等语义元素。
- 键盘顺序依次覆盖品牌、档案、弥拉、主次任务动作；弹层打开后焦点进入关闭按钮，帮助关闭后焦点回到弥拉触发按钮。
- 图标要么有可读上下文，要么使用空 alt；状态、等级与奖励都有文字，不依赖颜色。

## 存储与恢复实测

- active quest 接取后刷新仍恢复同一任务。
- 截断 JSON 在用户确认前保持原字符串不变；恢复页不会被首次引导遮挡；点击重置后才写入 schema v1 安全默认状态。
- 模拟 `Storage.setItem` 抛错时，界面不会宣布任务已保存；用户确认后进入会话临时任务，全程常驻关闭即消失提示，完成为 `+0 XP`，不写永久徽章或日志。
- 模拟 IndexedDB `open` 抛错时，localStorage 已完成结算保留 20 XP；日志页显示长期日志不可用提示，不回滚正确结算。
- IndexedDB 改为首次真实操作时惰性打开，失败后允许后续操作重新尝试，无提前未处理拒绝。

## 美术与性能

- 本地资源共 33 个：弥拉母版/头像/占位 3 个，类别 10 个，等级 3 个，状态与完成印章 6 个，徽章 5 个，小物件 6 个。
- 弥拉母版 1086×1448 RGBA；头像 24,332 bytes，占位 7,830 bytes，均在预算内。
- 30 个 SVG 均通过 title、48×48 viewBox 与 2.25 线宽契约检查；20/32/48px 联系表已目检。
- RPG 特效使用现有 33 项本地资源加 CSS/SVG 原生符文、粒子和冲击波，没有新增依赖或运行时资源。
- 最终构建：CSS 31.22 kB（gzip 7.53 kB），JS 431.69 kB（gzip 92.36 kB）。

## RPG 内容验收

- 100 条任务已重写；旧统一描述“今天只完成这一件小事”和统一收尾步骤出现次数均为 0。
- `absurd / courage / kindness / growth` 四种任务气质各 25 条。
- 8 条陌生人微互动任务都标记 `stranger-interaction`，社交值为 optional，并明确只进行一次、对方不回应或现场不合适就结束离开。
- 实测陌生人任务“自然说声你好”在 375px + 32px 安全区下，标题、一次可退出互动、步骤与退出条件完整可见。
