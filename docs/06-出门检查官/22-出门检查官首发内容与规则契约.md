# 出门检查官｜首发内容与规则契约

状态：CONTENT READY / 待转 JSON 与组合测试。

## 1. 八个首发场景

| ID | 名称 | 条件问题 |
|---|---|---|
| scenario-commute | 日常通勤 | 下雨、门禁、低电量、是否需服药 |
| scenario-short-trip | 周末短途 | 是否过夜、交通方式、户外活动、预订 |
| scenario-exercise | 运动健身 | 室内/户外、运动类型、补水、洗浴 |
| scenario-date | 约会见面 | 室内/户外、是否预订、是否带小礼物、返程时间 |
| scenario-with-child | 带娃出门 | 年龄段、时长、进食、换洗、交通 |
| scenario-with-pet | 带宠出门 | 宠物类型、时长、饮水、牵引/容器、清洁 |
| scenario-appointment | 就医或办事 | 机构类型、预约、纸质材料、空腹/检查要求 |
| scenario-event | 演出或活动 | 电子/纸质票、场地规则、返程、长时间站立 |

医疗与机构要求必须由用户根据正式通知确认；工具只提醒检查，不给医学或行政保证。

## 3. 优先级与位置

- `critical`：证件、票、钥匙、必要医疗/机构材料、安全牵引装备。
- `important`：手机、支付、饮水、天气用品、充电、换洗。
- `replaceable`：纸巾、零食、普通文具等较易补买物品。

空间位置枚举：`desk` 桌面、`charging` 充电处、`bedroom` 卧室、`bathroom` 卫生间、`fridge` 冰箱/饮水处、`entryway` 玄关、`documents` 文件收纳、`pet-area` 宠物区、`child-area` 儿童用品区。

## 4. 首发条件规则

```text
rain=true → umbrella OR raincoat
sunnyOutdoor=true → sun-protection, hat
battery=low → power-bank, cable
overnight=true → change-clothes, toiletries, charger
reservation=true → reservation
paperRequired=true → printed-form, copies, pen, folder
medicationReminder=true → regular-medicine
exercise=indoor → fitness-pass, sportswear, sports-shoes, towel
exercise=outdoor → sportswear, sports-shoes, water-bottle, sun/rain condition
exerciseNeedsShower=true → toiletries, change-clothes
withChild AND age=infant → diaper, child-wipes, child-change, comfort-item
withChild AND duration>120 → child-water, child-snack, small-toy
withPet → leash OR pet-carrier, pet-waste-bag
withPet AND duration>60 → pet-water
appointment=medical → id-card, reservation, medical-document
appointment=administrative → id-card, reservation, printed-form/copies when selected
event → ticket, seat-info, venue-rule, return-plan
event AND loud=true → ear-protection (optional)
return=late → return-plan, power-bank
```

`OR` 项不自动同时加入；让用户选择适合自己的一个或保留两者。任何医疗、证件和场馆规则都显示“以正式通知为准”。

## 5. 规则合并算法

```ts
type SelectedItem = {
  itemId: string;
  reasons: string[];
  priority: Priority;
  checked: boolean;
};
```

1. 加入场景基础项目。
2. 按条件规则加入项目。
3. 以 `itemId` 去重，合并 `reasons`。
4. 多规则优先级冲突时取更高等级。
5. 用户重新修改条件时，仍存在的项目保留勾选状态；消失的项目放入本次会话撤销区，不立即永久丢弃。
6. 没有规则结果时回退到场景基础项目。

## 7. 组合测试

- 通勤 + 雨 + 低电量：伞、充电宝只出现一次。
- 短途 + 过夜 + 雨 + 晚归：换洗、洗漱、充电、雨具、返程方案。
- 带娃 + 婴儿 + 3 小时：基础关键项、尿裤、湿巾、换洗、饮水、食物、安抚物。
- 带宠 + 30 分钟：牵引/容器、拾便袋；不强制加入宠物食物。
- 就医 + 无纸质要求：不自动加入复印件和印章。
- 演出 + 电子票 + 晚归：票、座位、规则、返程、充电；不默认加入不允许的应援物。
