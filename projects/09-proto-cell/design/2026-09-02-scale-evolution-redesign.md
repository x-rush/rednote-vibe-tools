# 《原生：一滴水的战争》尺度进化重构设计

状态：**DESIGN APPROVED / AWAITING DOCUMENT REVIEW**

日期：2026-09-02

适用工程：`projects/09-proto-cell`

本设计取代 `2026-09-01-ecology-roguelite-redesign.md` 中的六段旅程、五级抽象体态和固定阶段镜头方案。旧文档中关于移动操作、被动器官、生态 AI、结构化内容、静态前端和移动端门禁的约束继续有效。

## 1. 重构结论

当前版本把成长实现为同一细胞的无上限放大。玩家碰撞半径随累计生物质持续增长并跨环境保留，镜头只按抽象体态进行五档缩放，六个环境却共享 640×1100 的世界尺寸。后期玩家会占满屏幕，边界和收缩区域无法容纳身体，生成距离、敌人体型和真实视野也不再匹配。

首发版本改为一条简单、完整、可见的三段生命链：

1. 原始单细胞。
2. 聚合多细胞体。
3. 草履虫型复合体。

每个形态拥有自己的生态圈、地图尺度、食物链、运动表现和敌人关系。层内通过吞噬获得器官构筑和有限体型成长；层间通过完整蜕变进入更大的生态尺度。游戏不再允许碰撞体无限增长。

草履虫在现实中是单细胞生物。本作将终局形态描述为“草履虫型复合体”，属于显微生态幻想，不表达真实生物演化顺序。

## 2. 产品承诺

- 全程只需要移动；不增加主动技能按钮、连招或战斗背包。
- 3 秒内理解追小躲大，20 秒内完成首次吞噬。
- 每层至少两次三选一变异，每次选择改变自动行为、外形和代价。
- 玩家屏幕直径通常保持在短边的 16%–28%，任何正常成长状态不得超过 30%。
- 每次形态跃迁后，地图、背景、主要物种、危险关系和移动节奏同时变化。
- 上一生态的强敌可以在下一生态成为猎物，形成清楚的力量反转。
- 一局由三个完整生态圈组成，目标时长 8–12 分钟。
- 数字收益、伤害、连吞和进化进度继续保留，并配合短促、清晰的视觉与声音反馈。

## 3. 单局结构

| 生态圈 | 目标时长 | 玩家形态 | 主要目标 | 结束条件 |
| --- | ---: | --- | --- | --- |
| 原生微滴 | 2–3 分钟 | 原始单细胞 | 觅食、追逐小型细胞、建立第一组器官 | 进化压达到阈值并完成首次生态考验 |
| 聚合水层 | 3–4 分钟 | 聚合多细胞体 | 围猎单细胞群、利用纤维和酸域、形成构筑组合 | 进化压达到阈值并解决区域巨物 |
| 纤毛深域 | 3–5 分钟 | 草履虫型复合体 | 高速追猎、应对抗体和巨型捕食者、完成终局 | 击败、驱离、诱导或绕过最终主宰 |

单局流程：

```text
孵化
  → 吞噬与逃生
  → 变异一
  → 生态事件
  → 变异二
  → 生态考验
  → 形态跃迁
  → 更大尺度的新生态
  → 最终主宰
  → 结局或死亡
```

迁移不再只由固定倒计时强制触发。每层同时具有进化压和生态考验：进化压保证玩家需要参与捕食，生态考验保证玩家不能只在安全角落刷小食物。超过目标时长后，环境会逐步恶化并引导玩家完成考验，但不会把可活动空间压缩到无法容纳玩家。

## 4. 三种生命形态

### 4.1 原始单细胞

- 单核心、柔软膜、短纤毛或基础伪足。
- 主要吞食营养粒、细菌和更小的漂流细胞。
- 转向最灵活，惯性最小，承担无文字教学。
- 主要威胁为变形猎手、环形捕食者和抢食竞争者。
- 构筑重点为基础追击、包裹、脱离和代谢。

### 4.2 聚合多细胞体

- 由多个相连核心和共享外膜组成，视觉上明确不是“大号单细胞”。
- 玩家仍控制一个整体，不进行群体框选，也不突然分成多个独立控制单位。
- 运动带有队列延迟和形变，但方向响应仍然直接。
- 能够包围单细胞群、承受局部伤害并利用狭缝或流场。
- 上一层的环形捕食者会成为可猎目标；新威胁为寄生体、酸食者和纤维巨兽。
- 群体路线可以自动生成短时诱饵或局部分体，但主控和镜头不切换。

### 4.3 草履虫型复合体

- 形成长轴身体、密集纤毛、定向口沟和多个内部核心。
- 运动速度更高，前进方向更明确，但反向仍需在移动端可控。
- 能够吞食细胞聚落和中型捕食者，参与终局食物链。
- 主要威胁为抗体猎手、巨型吞噬者、环境清扫和区域主宰。
- 玩家之前选择的器官全部保留，并在终局形态上组成可见结构。

## 5. 成长与尺度模型

### 5.1 分离四个概念

- `biomass`：累计吞噬收益，用于分数、进化压和部分器官触发。
- `tierProgress`：当前生态圈内的进化进度，范围 0–1。
- `bodyRadius`：碰撞和包裹使用的有限物理半径。
- `formId`：决定形态、生态圈、运动基线、食谱和镜头目标。

不再直接使用 `sqrt(totalBiomass)` 作为无上限身体半径。层内半径使用有上限的缓出曲线：前半段吞噬能明显长大，接近上限后主要增加进化压和数值反馈。达到半径上限后继续吞噬仍有完整收益，不再扩大碰撞体。

建议首轮校准区间：

| 形态 | 层内物理半径 | 屏幕目标直径 |
| --- | ---: | ---: |
| 原始单细胞 | 12–22 | 16%–21% |
| 聚合多细胞体 | 18–32 | 19%–25% |
| 草履虫型复合体 | 24–40 | 22%–28% |

物理单位只在当前生态圈内有意义。形态跃迁会建立新世界并重新标定实体尺度，视觉演出保证玩家感受到继续长大，而不是缩回初始大小。

### 5.2 镜头

- 镜头缩放由玩家真实半径、形态的屏幕目标比例和当前视口共同计算。
- 缩放连续缓动，不再只按阶段使用固定常量。
- 成长过程中玩家不会突然跳变大小；形态跃迁使用约 1.2 秒拉远、重组和新生态显现。
- 镜头保留适度移动前视，但前视距离使用可见世界半径计算。
- 低动态模式使用短交叉淡化，不执行强烈缩放脉冲。

### 5.3 世界空间

- 三个生态圈分别生成独立世界，不复用同一固定矩形尺度。
- 世界的最小横向尺度以该层最大玩家直径的倍数定义；正常区域至少容纳 14 个最大玩家直径，终局区域至少容纳 10 个。
- 玩家任意位置至少保留可读的边界反馈；地图角落不能形成猎物永久不可达点。
- 环境收缩后的有效宽度不得小于 6 个当前玩家直径。
- 若配置违反空间不变量，内容校验和自动测试直接失败，而不是在运行时把玩家夹死。

## 6. 三个生态圈

首发活动路线复用三个语义匹配的稳定环境 ID：

- 原生微滴：`env-clear-drop`。
- 聚合水层：`env-fiber-maze`，并把酸域作为局部危险和事件。
- 纤毛深域：`env-abandoned-chamber`，并把抗体清扫作为终局事件。

`env-algae-glow`、`env-acid-vesicle` 和 `env-antibody-storm` 保留为旧生命档案和存档解码所需的稳定 ID，但不再作为首发活动路线中的独立关卡。它们的代表性机制分别并入三个新生态圈，不作为隐藏的旧六段旅程继续运行。

### 6.1 原生微滴

- 高可见度、柔和流场、少量软边界结构。
- 资源密集，首次可吞目标由确定性出生布局保证。
- 生物包括营养粒、细菌群、漂流细胞、竞争细胞、变形猎手和环形猎手。
- 生态事件包括营养爆发、细菌迁徙和大型阴影经过。

### 6.2 聚合水层

- 使用纤维束、酸泡和较强流场形成路线，而不是只有一条碰撞线段。
- 生物包括单细胞群、孢子聚落、拾荒群、寄生体、酸食者和纤维巨兽。
- 可利用事件包括捕食冲突、残骸争夺、移动安全区和纤维断裂。
- 小型单细胞不再逐个高精度运行；远景使用群体代理，靠近后才实例化。

### 6.3 纤毛深域

- 更大的开阔水域与周期性清扫带并存，强调高速路线选择。
- 生物包括能量囊、多细胞猎物、敌对聚落、抗体猎手和巨型吞噬者。
- 终局主宰至少支持正面吞噬、引入环境危险和利用构筑绕过三种解决方式。
- 终局不会仅以存活倒计时结束，必须产生可复述的生态结局。

每次跃迁后，普通物种至少替换 60%，背景主色、粒子运动、障碍结构和危险节奏必须同时改变。只换颜色或数值不算新生态圈。

## 7. 生态尺寸关系与生成

每个生态圈使用相对于该形态基准半径的尺寸带：

- 资源：0.12–0.32 倍。
- 猎物：0.35–0.75 倍。
- 竞争者：0.85–1.10 倍。
- 捕食者：1.20–1.60 倍。
- 巨物或主宰：1.80–2.40 倍。

敌人出生时不再根据玩家当前半径无限同比放大。形态跃迁后才切换到下一套生态尺寸。

生态导演必须接收镜头计算出的真实可见世界范围。生成与回收距离由真实视野派生：

- 普通补充群落在视野外 1.1–1.6 倍处生成并按正常速度活动。
- 大型威胁在视野外生成，通过液流、阴影或边缘标记预告后进入。
- 食物支援生成在玩家可在数秒内抵达的位置，但不直接贴脸出现。
- 同屏始终维持可追目标、应躲目标和可利用事件中的至少两类。

不同生态圈使用独立预算和行为池。导演只维持节奏和种群结构，不把所有生物持续送向玩家。

## 8. 移动、碰撞与边界

- 浮动摇杆继续作为唯一持续操作。
- 移动按屏幕空间校准：正常全速约为每秒 0.35–0.55 个屏幕短边，避免镜头拉远后角色看似不动。
- 原始单细胞转向最快；聚合体有可见形变延迟；草履虫型前进最快但转向半径略大。
- 大形态的迟钝只作为可学习的重量感，不能让反向、逃生或贴身调整失效。
- 障碍碰撞优先滑移和推离，不能永久清零速度。
- 环境障碍的通道宽度由当前形态尺寸校验；不合格的狭缝必须有明确的替代路线。
- 边界回推、环境收缩、障碍阻挡和敌人接触分别处理，避免多层约束同时把玩家锁死。

吞噬继续采用“明显更大且大部分覆盖”的规则。默认覆盖阈值保持约 65%–70%，不增加挣脱小游戏。可吞、危险和同级竞争关系必须通过轮廓与运动共同表达，不能只依赖颜色。

## 9. 肉鸽构筑

每个生态圈提供两次三选一变异，全局目标为六次选择。候选继续分为：

- 捕食：包裹、消化、连吞和追击。
- 生存：脱离包裹、减伤、修复和减速追兵。
- 群体：聚合防护、诱饵分体、围猎和融合收益。

所有器官由移动、接触、追逐、逃跑、包裹、受伤、环境或确定性冷却自动触发。任何器官不得要求新增主动按钮。

每个候选必须包含：

1. 一个可观察的行为变化。
2. 一个可见形态部件。
3. 一个明确代价。
4. 在当前或后续生态中至少一个可触发场景。

同路线器官形成专精，跨路线器官形成混合组合。形态跃迁不清空器官；同一构筑必须能够在三个生态尺度中产生不同用途。

## 10. 形态跃迁

跃迁由专门状态机负责：

```text
ready
  → freeze-input
  → contract
  → rebuild-form
  → pull-back-camera
  → reveal-ecology
  → resume
```

- 整段约 1.2 秒，期间模拟暂停，输入立即取消。
- 玩家核心、膜、器官和连接结构发生明确重组，不只是统一缩放和闪白。
- 新生态先展示边界、主要猎物和大型威胁剪影，再恢复控制。
- 恢复时玩家周围存在安全出生半径，不承受即时碰撞或环境伤害。
- 减少动态模式使用 180–240ms 交叉淡化，并保留形态名称和新食物链提示。

## 11. HUD 与生态雷达

战斗 HUD 保留最少信息：吞噬分、当前形态、进化压、膜完整度和暂停。

新增一个无交互的小型生态雷达，只显示：

- 玩家位置。
- 世界边界方向。
- 生态出口或考验方向。
- 已经预警的巨物方向。

雷达不显示全部食物和敌人，不代替观察。所有固定顶部 UI 继续叠加安全区变量；375、390、430 CSS px 下不得遮挡战场或产生横向溢出。

## 12. 美术与声音

三种玩家形态必须拥有独立骨架，而不是同一圆形换颜色：

- 原始单细胞：单核心、柔软非对称轮廓、少量纤毛。
- 聚合多细胞体：多个相连核心、共享膜、局部细胞节点和连接波动。
- 草履虫型复合体：长轴轮廓、口沟、密集纤毛、多个内部结构和明确前后方向。

每个生态圈使用独立背景构图和运动层。现有本地素材可复用为纹理来源，但最终画面必须重新组合，避免只是更换色相。

吞噬数字、连吞、伤害和进化收益继续保留。反馈必须短促，不能遮挡危险方向。形态跃迁使用独立音色层；静音、低闪烁和低粒子模式仍能通过轮廓、文字和运动读懂结果。

## 13. 数据与模块边界

所有业务配置继续只放在 `src/content/content.json`。新增建议数据：

```ts
type ScaleTierDefinition = {
  id: 'tier-single-cell' | 'tier-colony' | 'tier-ciliate';
  formId: 'form-primal-cell' | 'form-colony-body' | 'form-ciliate-composite';
  name: string;
  environmentId: EnvironmentId;
  targetDurationMs: number;
  radiusRange: [number, number];
  screenDiameterRange: [number, number];
  worldBodyWidths: number;
  minimumCollapsedBodyWidths: number;
  evolutionPressureTarget: number;
  ecologyBudgetId: string;
  encounterId: string;
};
```

模块职责：

- `evolution/lifecycle.ts`：形态、层内成长、进化压和跃迁条件。
- `evolution/build.ts`：器官路线、候选、组合和继承。
- `game/engine.ts`：固定步长编排，不再自行推导无限半径。
- `world/generator.ts`：依据形态和身体倍数生成世界、通道和出生布局。
- `world/ecology-director.ts`：依据真实视野和当前生态维持种群与事件。
- `rendering/camera.ts`：连续尺度镜头、前视和跃迁拉远。
- `rendering/morphology.ts`：三种骨架和器官组合。
- `rendering/metamorphosis.ts`：跃迁状态机的纯表现参数。
- `ui/Hud.tsx`：形态、进化压和生态雷达。

核心数据流：

```text
吞噬事件
  → biomass / evolutionPressure
  → lifecycle 计算有限 bodyRadius
  → engine 更新实体与形态状态
  → camera 使用真实半径和视口计算 zoom
  → ecology director 使用真实可见范围生成生态
  → renderer / HUD / audio 消费同一世界快照
```

## 14. 存档与兼容

- 提升内容版本，但不清空基因、图鉴、设置、挑战和生命档案。
- 旧的 `bodyStage` 仅用于历史展示：`microbe` 和 `hunter` 映射为原始单细胞，`specialist` 和 `dominant` 映射为聚合多细胞体，`ascendant` 映射为草履虫型复合体。
- 当前运行不持久化，因此无需恢复到旧版无限半径世界。
- 新生命档案记录最终 `formId`、生态圈、六个器官选择和真实结局。
- 导入校验拒绝未知形态、非法半径范围、无法容纳身体的地图配置和非有限数值。

## 15. 异常与防御

- 非有限生物质、进化压、半径、坐标、速度或镜头缩放不得进入模拟或 Canvas。
- 若形态配置缺失，开局显示可恢复内容错误，不降级到无限成长。
- 若生态导演无法找到合法出生点，本次生成取消并在下一固定周期重试，不把实体夹在边界。
- 若玩家进入环境时安全出生区不足，区域生成失败并重新使用同种子的备用布局。
- 单个异常非玩家实体可以隔离；玩家或世界尺度异常必须暂停并提供重建视野入口。

## 16. 自动化验收

### 16.1 成长和尺度

- 任意合法生物质输入都产生有限且位于当前形态区间内的半径。
- 达到半径上限后继续吞噬增加分数和进化压，但不扩大碰撞体。
- 375、390、430 CSS px 下，所有正常状态的玩家屏幕直径不超过短边 30%。
- 环境收缩后的有效宽度始终不少于 6 个玩家直径。

### 16.2 进化链

- 固定种子可完整经历单细胞、聚合多细胞体和草履虫型复合体。
- 每次跃迁同时改变 `formId`、环境、生态预算、身体骨架和镜头目标。
- 跨形态器官和组合完整继承。
- 三个生态圈的普通物种替换比例不少于 60%。

### 16.3 手感与生态

- 首次吞噬不晚于 20 秒，目标校准为 5–10 秒。
- 任意正常连续 8 秒内存在可追、可躲或可利用目标。
- 180 度反向、障碍滑移和边界回推在三种形态下均不会卡住。
- 大型威胁进入视野前具有至少一种非颜色预警。
- 生态导演的视野输入与相机实际可见世界范围一致。
- 上一生态至少一种主要威胁在下一生态成为可吞猎物。

### 16.4 完整单局

- 至少十个固定种子完成 8–12 分钟的三生态模拟，无非有限数值、实体泄漏和无法推进状态。
- 捕食、生存、群体和混合构筑均至少存在一个可完成终局的确定性样例。
- 结局使用结构化事件推导，并记录最终形态和实际主宰解决路径。

## 17. 浏览器验收

在 375×812、390×844、430×932 和 44px 模拟顶部安全区下，完整验证：

- 孵化、首次吞噬、两次普通变异。
- 单细胞到聚合多细胞体的跃迁。
- 聚合多细胞体到草履虫型复合体的跃迁。
- 每个生态圈的移动、追猎、逃生、障碍和边界。
- 暂停、失焦、旋转、调整尺寸和指针丢失后的输入取消。
- 生态雷达不遮挡 HUD 或关键战场区域。
- 低动态、低闪烁、低粒子和静音模式保留全部玩法信息。
- 控制台零错误；正常场景争取 60 FPS，压力场景不低于 30 FPS。

## 18. 实施顺序

1. 建立三段形态和有限成长模型，替换无上限半径。
2. 改造动态镜头、屏幕空间移动和边界不变量。
3. 将六段旅程收束为三个独立生态圈，并让导演使用真实视野。
4. 实现聚合多细胞体和草履虫型复合体骨架与跃迁演出。
5. 重配器官、敌人关系、生态考验、HUD 和雷达。
6. 完成存档迁移、完整单局模拟、三尺寸浏览器和性能验收。

每一阶段均使用测试先行，完成后运行项目级 `pnpm lint && pnpm test && pnpm build`。不得以删除测试、减少危险提示或增加主动操作来绕过问题。

## 19. 非目标

- 不做分支形态树；首发只交付一条清楚的三段生命链。
- 不做独立控制多个子体、群体框选或即时战略操作。
- 不做无限地图、真人联机、账号、云端服务或在线排行榜。
- 不把旧六段旅程继续保留为隐藏内容。
- 不用纯数字升级、纯换色背景或更高敌人速度冒充新生态。
- 不追求现实生物学演化准确性，但所有幻想名称必须明确且不冒充科普。

## 20. 完成定义

只有以下条件同时成立，尺度进化重构才算完成：

1. 玩家不会因成长占满屏幕或超过地图可容纳范围。
2. 三种生命形态在静态截图和实际运动中都能一眼区分。
3. 三个生态圈拥有不同的食物链、空间结构和主要压力。
4. 六次器官选择能够形成可感知的肉鸽构筑。
5. 全程只有移动操作，但追猎、逃生和路线选择持续成立。
6. 三尺寸真机等效浏览器流程、完整模拟、内容校验、性能和构建门禁全部通过。
