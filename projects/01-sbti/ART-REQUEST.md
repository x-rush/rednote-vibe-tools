# SBTI 闻山美术资源台账

用途：记录 Codex 内置图像生成结果、运行时接入状态和后续可选姿态。

2026-08-25 已生成并接入递卷、阅卷两种姿态。它们是视觉增强，不是流程前置条件；任一图片失败时仍按现有 placeholder → CSS 墨影降级。

## 统一角色锚点

闻山是“山海司守卷人”：年轻但沉静的中性文士形象，东方脸型，乌发束冠，深孔雀石绿交领长衣，朱砂色绶带或小印章，暖纸与墨线质感。气质可靠、克制、好奇，不神秘恐吓，不仙侠战斗化，不做心理医生或占卜师。

生成时应把项目现有闻山图作为角色一致性参考。保持脸型、发冠、领口、袖型、孔雀石绿—暖纸—朱砂配色和工笔纸墨质感一致。画面内禁止生成文字、英文字母、界面、二维码、水印或印章字样。

## 生成后验收清单

- 新图必须是同一位闻山：脸型、发冠、领口、袖型、配色一致。
- 手指数量、持卷关系、卷轴透视和衣物遮挡合理。
- 没有文字、字母、结果代码、水印、二维码或伪印章字。
- 没有算命、塔罗、仙侠战斗、医疗诊断或心理治疗暗示。
- 缩到 390 CSS px 手机预览时，脸、手和卷轴仍可辨识。
- 若要求透明，边缘不得有白边、黑硬边或大面积半透明脏像素；有背景版本须保持低细节。
- WebP 体积达到各项预算，保留原始高分辨率母版供后续重裁。
- 通过人工审核、体积检查和清单登记后才复制进运行时资源目录。
