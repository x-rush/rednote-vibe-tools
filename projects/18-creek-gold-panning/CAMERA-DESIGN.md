# 溪边淘金｜当前视角与运镜

2026-09-19。稳定第一人称斜俯视；当前为二维画布与材质合成，不是自由三维相机。

- 溪岸：三个砂纹取样点，不让镜头追着手指晃动。舀砂时铲头跟随，留下局部浅坑。
- 装盘：盘从下方进入、铲中砂流入盘底，约 1.2 秒完成；过渡期不接收淘洗。
- 浸盘：按下深度驱动盘体下移与接触波纹，水量增加。提盘后回到稳定操作中心。
- 淘洗：盘体有限位移与倾斜，水和砂保留各自惯性。绕圈转的是水砂，不是整张金属盘贴图跟着旋转。
- 拾取：按真实实体坐标画出约 580 ms 弧线，金粒到瓶、矿物到盒；入藏逻辑立即提交，刷新不因动画未完成而重复奖励。介绍在动画后展示并暂停操作。
- 关闭介绍：回到原盘中心与剩余物件。最后一颗收齐后轻点空盘回岸边。
- 减弱动画：取消大幅抬盘与拾取弧线，保留判断所需的水砂反馈；关闭介绍动画。

竖屏盘半径取 min(视口宽×0.43,视口高×0.33)，横屏重排提示至左侧，盘仍居中。宿主角落控件不与主场景交互入口重叠。横竖尺寸变化会终止当前手势并重建画布。

没有 CSS 模拟横屏入口；不能把实际横屏验收写成模拟旋转验收。未实现手部骨骼、镜头自由漫游、真正盘体三维遮挡。真机手感与完整录像仍须单独验收。
