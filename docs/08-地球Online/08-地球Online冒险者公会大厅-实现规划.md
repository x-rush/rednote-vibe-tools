# 地球 Online：冒险者公会大厅实现规划

## 产品定义

正式名：**《地球 Online：冒险者公会大厅》**。

主标语：**主线不用着急，先来领一个小任务。**

补充文案：**现实世界很大，今天完成一件小事就够了。**

一句话：用户以“地球 Online 冒险者”的身份登记当前时间、精力、金币预算和组队意愿，从公会大厅领取一个现在就能完成的现实支线任务。

参赛标签：`#小红书vibecoding大赛 #vibetool`。

## 纯前端可行性

完全可行。任务库内置为 JSON；运行时进行条件过滤、权重排序和种子随机。当前状态、收藏和少量历史可保存在 `localStorage`；当冒险日志数量增加、需要按日期或任务类型查询时，可迁移到 `IndexedDB` 保存结构化记录。天气和位置不自动获取，由用户手动选择。名称中的 `Online` 是现实 RPG 世界观，不代表工具依赖联网；启动页明确标注“任务均在本地生成”。

## MVP 范围

- 100 条人工审核的现实任务。
- 条件：5/15/30/60 分钟、低/中/高精力、0/20/50 元、室内/户外、独处/社交、白天/夜间、目标感受。
- 生成一个任务，提供任务等级和 2-4 个具体步骤。
- 完成、不适合、收藏、换一个；本地历史和任务偏好。
- 夜间、恶劣天气、低精力等安全过滤。

不做：定位、自动天气、地图、陌生人匹配、用户上传任务、在线排行、用户图片选择、图片上传或图片本地存储。

## 数据模型

```ts
type LifeQuest = {
  id: string;
  title: string;
  minutes: number;
  maxCost: number;
  energy: 1 | 2 | 3;
  environments: ("indoor" | "outdoor")[];
  social: "solo" | "optional" | "required";
  times: ("day" | "night")[];
  weather: string[];
  goals: string[];
  steps: string[];
  safetyTags: string[];
  cooldownDays: number;
  approved: boolean;
};
```

## 推荐算法

1. 硬过滤：时间、预算、环境、安全、社交意愿。
2. 软加权：目标感受匹配、用户收藏过的类别、最近没出现的类别。
3. 降权：用户点过“不适合”、最近完成、同类连续出现。
4. 用日期与本地随机种子选取，保证每日推荐稳定又可换一次。
5. 如果没有结果，逐层放宽软条件，绝不放宽安全条件。

## 任务质量标准

- 具体：不是“出去走走”，而是“找三种今天才注意到的影子”。
- 可完成：无需额外注册、预约或专业设备。
- 有轻微新鲜感，但不制造社交压力。
- 不要求拍摄、评价或骚扰陌生人。
- 不鼓励危险地点、违法进入、攀爬、冲动消费、饮酒或博彩。
- 不声称能治疗焦虑、抑郁或其他心理问题。

## UI

- 首屏设计为“冒险者状态登记”，用滑块/大按钮在 20 秒内完成条件输入。
- 任务揭晓来自“公会任务板”，像领取一张现实世界支线卡，但避免老虎机式刺激。
- 任务卡显示时间、预算、环境和退出条件。
- 完成动画轻量；奖励是收藏和回忆，不设计成强迫打卡。
- 本地历史命名为“冒险日志”，收藏命名为“已接取任务”。
- 冒险日志只保存任务 ID、完成时间、状态和有限长度的文字备注，不接受或保存用户图片。

## 测试

- 为关键条件建立测试矩阵：夜间独处、零预算低精力、雨天室内、白天社交、15 分钟。
- 任意合法组合都能返回任务或友好降级。
- 安全任务不会在错误时间/环境出现。
- 冷却和历史权重生效。
- 清空数据恢复默认推荐。

## 后续迭代

- 五分钟刷新、雨天、下班后、和朋友一起、城市观察、微型创作等任务包。
- 用户可在本地编写私人任务，但不上传公共库。
- “我完成过的生活切片”本地回顾。
