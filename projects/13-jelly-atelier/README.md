# 果冻慢慢 2.0.13

一款自由制作、轻松把玩的纯前端三维小玩具。选模具、叠颜色、摆装饰，再把作品脱模、揉动、收藏或做成一张小卡片。

## 制作与欣赏

1. 选择花瓣、爱心、星星或自己画闭合轮廓。手绘支持自动闭合、轻微回描修复和三维预览。
2. 按住倒入、松手暂停；切换颜色只影响后续液体。提供 9 种颜色，最多 32 个连续色层。
3. 从水果、奶油与糖果、花与叶、蜡烛中选择装饰，轻点果冻顶面放置；单个作品最多 18 件。
4. 点击已放置的装饰选中，拖动换位置，也可使用方向按钮微调、转向、三档缩放、复制和删除。越界时保持最后有效位置。
5. 数字蜡烛支持 0–9 和 1–3 位组合，组合可拆开移动。另有细长、螺旋、爱心、星星、小花蜡烛，提供 5 色、点亮与熄灭、动态火焰。
6. 脱模后“揉一揉”支持轻戳、持续按压和滑动；“拿起来欣赏”支持360 度水平环绕与俯仰调节（最低视角限制在盘子上方）、双指缩放和平移。桌面滚轮缩放；正面、俯视、侧面可快速复位。
7. 甜品柜记录名字和完整配方。旧作品可继续调整装饰，取消修改会恢复进入编辑前的配方；点击保存修改才更新收藏。
8. “做张小卡片”生成 1080×1440 图片，使用真实三维配方和所选视角，提供两种样式、60 句日常关心、自定义留言与作品名称。随机切换不会连续出现同一句。

## 本地运行和打包

在本项目目录运行 `pnpm dev`，访问 `http://127.0.0.1:4312`。

- `pnpm lint`：语法、内容和本地运行约束。
- `pnpm test`：40 项测试，覆盖手绘、分层、按压、音效、配方存储、装饰属性、边界、环视和句子切换。
- `pnpm build`：生成静态开发构建 `dist/`。
- `node scripts/package.mjs`：利用工作区已有 Rolldown 生成离线经典脚本包 `release/package/`，构建目标 ES2017 / Chrome 61，移除未使用的 XR 与网络加载路径。
- 发布包：`release/guodong-manman-2.0.13.zip`；入口 `index.html` 直接位于 ZIP 根目录。

## 数据与能力

业务内容在 `src/content/content.json`。Three.js 0.180.0 位于本地 `vendor/package/`，没有新增 npm 依赖。模型和纹理本地生成，不需要运行时 CDN、外部图片或后端。

本地收藏使用 `jelly-atelier-v2`，兼容旧版记录；只保存经过白名单清理的配方、装饰坐标、旋转、大小、数字、颜色、点亮状态与名字。不保存图片、Base64、音视频或 Blob。分享图片仅在当前弹层内存中生成，关闭后释放。

保存相册仅在用户点击后调用小红书 `window.xhs.miniTool.saveImageToPhotosAlbum`，普通浏览器显示预览及容器内保存提示。不会自动发布笔记。小红书真机相册、双指触控与旧 WebView 兼容性仍需在容器验收，桌面浏览器测试不能替代真机。
