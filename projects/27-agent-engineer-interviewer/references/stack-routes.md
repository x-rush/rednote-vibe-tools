# 技术路线

学习推荐不是全球使用率排名或录用门槛。

## 默认主修：LangGraph

学习状态、分支、持久化、恢复和人工审批；从简单工具循环开始，不强制使用LangChain。

[LangGraph官方概览](https://docs.langchain.com/oss/python/langgraph/overview)（核验 2026-10-14）

## 轻量SDK / TypeScript分支

OpenAI Agents SDK、PydanticAI、Vercel AI SDK或Mastra选一套理解工具、会话和流式交互；满足约束的替代方案同等评价。

[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)（核验 2026-10-14）、[Mastra官方文档](https://mastra.ai/docs)（核验 2026-10-14）

## 企业与低代码分支

Google ADK、Microsoft Agent Framework按团队生态选择；Dify/Coze熟悉一个演示工作流，但界面搭建不自动证明代码工程能力。

[Google ADK](https://adk.dev/)（核验 2026-10-14）、[Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/overview/)（核验 2026-10-14）

## 前沿harness与经典方法

Deep Agents / Claude Agent SDK作为长任务、工件、沙箱和上下文拓展。ReAct和Plan and Execute基础；Reflexion/Tree of Thoughts和多Agent选修，不作为所有初级岗硬门槛。

[Deep Agents官方概览](https://docs.langchain.com/oss/python/deepagents/overview)（核验 2026-10-14）、[Anthropic长任务harness工程](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)（核验 2026-10-14）

## 既有项目识读

AutoGen已维护模式，新项目优先核对Microsoft Agent Framework；Semantic Kernel放微软生态专题。具体迁移API需运行时核实。

[AutoGen官方仓库](https://github.com/microsoft/autogen)（核验 2026-10-14）、[Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/overview/)（核验 2026-10-14）

## 多Agent与运行环境比较

CrewAI、Agno了解任务分工与运行方式；必须比较单Agent基线、总预算、共享证据、权限与验证。增加Agent数量不是能力提升证据。

[CrewAI官方文档](https://docs.crewai.com/en/introduction)（核验 2026-10-14）、[Agno官方文档](https://docs.agno.com/)（核验 2026-10-14）
