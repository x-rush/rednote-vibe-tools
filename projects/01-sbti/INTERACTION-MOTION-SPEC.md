# SBTI 交互与动效规范

状态：已实现

## 原则

动效只承担四件事：确认操作、解释状态变化、连接章节、建立显形仪式。单次反馈短促、可跳过、可降级，不使用全屏粒子、持续弹跳或依赖动画才能理解的内容。

## 动效清单

| 场景 | 触发 | 视觉反馈 | 时长 | 语义终态 |
| --- | --- | --- | --- | --- |
| 行动签落印 | 选择任一行动 | 签条上移、底部墨线展开、朱印轻落 | 180–190ms | 选项保持“选”印和朱砂边 |
| 更换行动 | 选择另一行动 | 旧签回到闲置，新签执行落印 | 180–190ms | 仅新选项保持选中 |
| 闻山换句 | 进入题目、选择或返回 | 新台词轻微上移并由虚到实 | 160ms | 完整台词稳定显示 |
| 完成卷章 | 章节状态变为完成 | 卷印右上压下“印”字 | 260ms | 保留完成印与文字说明 |
| 递卷 / 收卷 | 章节过场出现 | 卷页由侧面展开，墨色稳定 | 380ms | 操作按钮立即可用 |
| 四维显形 | 完成第 24 题 | 四枚中文卷印错峰展开 | 320ms/枚，整体约 1.24s | 四维标题和两极全部可读 |
| 结果显影 | 点击展开兽志 | 标题、异兽、闻山、四维足迹分层出现 | 420ms/层 | 结果页完整稳定 |
| 帮助卷页 | 点击闻山 | 遮罩淡入、卷页上移 | 180–320ms | 焦点位于卷页内 |

实现中的关键帧与职责一一对应：

- `choice-ink-trace`：行动签底部墨线，190ms。
- `choice-seal-drop`：朱砂选择印，180ms。
- `guide-ink-swap`：闻山台词换墨，160ms。
- `guide-seal-ring`：选择后头像外缘一次朱砂回应，180ms。
- `button-curtain`：主按钮状态文字揭帘，160ms。
- `volume-seal-press`：完成卷章压印，260ms。
- `chapter-sheet-pass`：递卷 / 收卷，380ms。
- `dimension-unfurl`：中文维度印，320ms。
- `result-paper-reveal`：结果纸页分层显影，420ms。

## 状态接口

关键组件使用可检查的 `data-state`，让样式、测试和调试共享同一状态语言：

- `ChoiceSlip`：`idle` / `selected`
- `VolumeProgress`：`upcoming` / `current` / `completed`
- `GuidePresence`：`present` / `interactive`
- `ChapterInterlude`：`start` / `end`
- `RevealSequence`：`collecting` / `reading` / `complete`
- 显形单印：`waiting` / `revealed`
- `ResultPage`：`revealed`

状态属性不进入本地存储，不影响评分或页面路由。

## 交互细节

### 行动签

- 整张签条可点击，原生 radio 保留键盘和读屏语义。
- hover 只加强边框；focus-visible 使用 3px 赭金轮廓。
- 选中时不改变控件高度，避免按钮跳位。
- 用户仍需点击“落印，下一问”，不会选择即跳转。

### 闻山

- 常驻席台词变化只重绘文本，不推动页面整体位置。
- 可点击状态有明确按钮和无障碍名称。
- “问闻山 / 三问闻山”以三个固定主题切换回答；不伪装成聊天输入。
- 对话框打开时背景不可交互，Tab 留在卷页，Escape 和关闭按钮都能退出。

### 章节与显形

- 递卷和收卷按钮在动画开始时即可使用，无需等待。
- 跳过过场与主操作到达同一状态。
- 显形中的“跳过显形”直接进入 `complete`，随后由用户点击“展开兽志”。
- 四枚印只显示中文维度和两极，不显示内部字母或结果偏向。

## 减少动态

同时响应两种来源：

1. 系统 `prefers-reduced-motion: reduce`
2. 页面根节点 `data-reduced-motion="true"`

启用后：

- 取消选择、台词、卷印、过场、四维和结果显影的位移、缩放、裁切与淡入。
- 显形组件首次渲染即进入 `complete`。
- 保留选中边框、朱印、当前卷、完整中文维度、按钮和焦点顺序。
- 不用极短动画模拟“关闭”，而是直接呈现终态。

## 性能预算

- 动画优先使用 `opacity`、`transform` 和小范围 `clip-path`。
- 不为短反馈创建 JavaScript 帧循环。
- 唯一的流程定时器属于显形状态推进，并可跳过；减少动态时不创建定时推进。
- 新增效果不加载图片、字体、视频、音频或第三方脚本。

## 验收

- 375 / 390 / 430 CSS px 无横向溢出或操作遮挡。
- 快速更换选项后，视觉选中与 radio 选中一致。
- 返回旧题时旧答案可见、可改，闻山不评价具体选择。
- 连续跳过章节和显形不会卡死或重复提交。
- 打开减少动态后，所有流程仍可完成且信息不缺失。
- 键盘与触屏都能完成选择、改选、帮助切换、过场和结果阅读。
