# 当时这样说就好了 · Interaction & Motion Spec

状态：`APPROVED DESIGN`

## 1. 原则

动效用于说明句子结构变化，不用于奖励、评分或制造紧张。所有信息都有静态文字等价；安全提示不闪烁、不震屏、不倒计时。

## 2. 页面切换

- 普通步骤进入：透明度 `0 → 1`，纸面纵向位移不超过 8px，160–200ms。
- 返回上一步：不反向播放复杂动画，直接恢复选择并聚焦页面标题。
- 页面滚动遵循用户操作，不使用自动长距离平滑滚动。
- reduced-motion：禁用位移，只保留立即显示。

## 3. 事实到推测

### 标准运动

1. 用户拖动纸条，或点击“移到推测”。
2. 原位置的重复文本先降低透明度。
3. 纸条沿短直线路径移动到推测栏，时长 220ms，允许范围 180–260ms。
4. 目标栏边线短暂加深，不发光、不弹跳。
5. 分类理由立即出现，焦点移动到理由标题，`aria-live` 宣告移动结果。

### 键盘操作

- 纸条为可聚焦元素。
- Enter 打开操作，方向键选择目标栏，Enter 确认，Escape 取消。
- 每张已移动纸条提供明确的“撤回事实栏”按钮。
- 拖动不是完成流程的必要条件。

### Reduced motion

直接显示静态前后对照：原事实栏文字划去，推测栏出现同句，并用箭头和文字说明分类原因。焦点行为与标准运动相同。

## 4. 选择反馈

- 选项状态在 120–160ms 内改变边线、纸面底色和勾选标记。
- 不使用缩放弹跳、震动或彩纸。
- 感受强度不改变为红／黄／绿，也不增加分数式进度。
- 五步完成标记始终配步骤文字。

## 5. 三语气

- 三个页签保持相同尺寸、字重和默认视觉权重。
- 切换时只替换稿纸正文和修订标记，时长 140–180ms。
- 坚定版不使用危险色，柔和版不使用成功色。
- 缺少某种语气时回退综合稿，并明确说明内容不可用；不显示空卡。

## 6. 迟言

- 首次引导人物只做 160–200ms 淡入。
- 节点头像和批注不漂浮、不呼吸、不循环播放。
- 帮助层打开后聚焦标题，关闭后恢复触发按钮焦点。
- 图片失败不影响文字引导和主要动作。

## 7. 安全与错误

- 安全页面立即显示，无入场震动、闪烁或警报声。
- 保存失败使用静态批注展开；保留当前选择并将焦点移到错误标题。
- 状态消息通过 `role=status` 宣告，危险或即时错误按实际语义使用 `role=alert`。

## 8. Sticky、锚点与安全区

顶栏偏移：

```css
top: var(--safe-area-inset-top, env(safe-area-inset-top, 0px));
```

锚点目标的 `scroll-margin-top` 必须包含同一安全区变量与顶栏实际高度。验收时设置 `--safe-area-inset-top: 32px`，检查顶栏、页面标题、分类理由和错误标题不被遮挡。

## 9. 性能

- 只动画 `transform` 和 `opacity`；边线变化不做长时间过渡。
- 不使用大面积滤镜、视频、Canvas 循环或 JavaScript 逐帧动画。
- 迟言主图提供明确宽高，避免布局跳动。
- 资源加载失败不触发重复请求循环。
