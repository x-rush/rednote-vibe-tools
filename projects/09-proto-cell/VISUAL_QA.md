## 实测检查

- 三个竖屏宽度的 `documentElement.scrollWidth` 均未超过 `clientWidth`；当前页面全部可见按钮的包围盒宽高均不小于 44 CSS px。
- 430 × 932 平衡画质下，120 帧无头 Chromium 采样为平均 28.58ms、P95 33.40ms，观测带约 30–36 FPS；该 GPU 关闭的测试环境在持续采样中保持不低于 30 FPS。正常硬件浏览器目标为 60 FPS。
- 932 × 430 横屏切换后 Canvas 包围盒为 932 × 430，页面无横向溢出；恢复 430 × 932 后继续正常渲染。
- 指针按下、拖动、抬起的真实浏览器路径令生物质从 144 增至 147；取消、失焦、隐藏页暂停和恢复不补算由输入、控制器和引擎测试覆盖。
- 暂停模态首次聚焦“继续游动”，Tab 移至“重新孵化”，焦点保持在模态内；结果页首个且最大的操作是“再次孵化”。
- 设置页实测音乐/音效开关、减少动态、减少粒子和低画质；重新载入后设置仍存在。音频在首次用户手势前保持锁定，静音启动不会创建声音输出。
- 损坏导入 `{"schemaVersion":999}` 显示“存档不兼容或内容损坏”，保留可导出的恢复数据；旧 v1 数据库会升级到 v2 并补建 recovery store，不再误报存储失效。
- 禁用 IndexedDB 的独立页面进入临时会话并展示恢复入口；原页面和持久化数据不受影响。
- 静态预览控制台为 0 error / 0 warning，运行时请求均为本地构建资源，没有外部 API、CDN 或媒体请求。
- 进化、裂隙和 Boss 截图使用发布构建中正在运行的真实控制器、引擎快照与 Canvas 渲染器；Playwright 将固定种子推进到指定检查点后冻结画面，产品代码未加入 QA 或调试入口。

## 自动化与代码级交叉检查

- 进化选择层、路线裂隙、三类 Boss 状态条与结算路径同时由发布构建截图、UI/世界生成/引擎测试和全路线审计覆盖；十个固定种子、五种选择策略与全部声明的 Boss 解法均通过真实状态机。
- 危险预告使用收缩虚线环，不只依赖颜色；灰度下仍能通过线型、宽度和收缩方向区分预告与激活。
- 减少动态只冻结装饰时间，危险预告继续使用真实 `elapsedMs`；减少闪烁只降低透明度，不缩短 420ms 预告窗口。
- 压力测试运行 18,000 个固定步，实体硬上限为 180，检查空间索引无重复、数值有限且平均模拟步低于 0.8ms。
- 立即重开会销毁上一引擎；用户暂停与页面隐藏暂停相互独立，恢复时不会补算离开期间的时间。

首发移动端、安全区、可访问性、失败恢复、静态资源和性能门槛通过。随机流程中的进化层、路线与 Boss 既有固定种子的真实发布构建截图，也有确定性状态机测试作为可重复证据。
