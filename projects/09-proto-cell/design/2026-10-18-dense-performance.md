# 后期密集场景性能与完整流程验证

本轮仅修改项目 09。延续三生态圈、新形态、品系和终局巨物设计，优化大量敌人追击时的 CPU 热点。未新增依赖，未调整敌人数量、AI 更新频率、攻击节奏、形态采样精度、画布 DPR 或已有精细绘制预算。所有修改仍为离线纯前端。

## 已落实的优化

- 空间索引使用数字行列索引，直接跳过空行，减少大范围感知中的字符串分配、回调和空桶查找。保留旧索引的实体引用、去重、遍历次序、负坐标和边界计算。
- 敌对猎食者、伏击者及巨物的候选感知和敌对碰撞只查询原本能发生交互的阵营；移动前、移动后的两次索引重建均保留。资源仍保持原先漂移行为，直接跳过不会读取的邻居查询。
- 提前排除不发生交互的同阵营配对，避免密集敌群对无效配对反复排序、拼接键。纤维遮蔽检查和事件吸引场数据在每个模拟步复用。
- 身份与角度产生的固定膜相位、固定调色结果使用有容量上限的缓存。时间、位置、形态、转向、脉动和碰撞几何继续按当前状态计算。
- 同一绘制帧中复用玩家膜的边界和内接半径；关系提示仍使用精确几何判定。
- 通过 `Path2D` 保留完整矢量轮廓和关系提示路径，相同且与身份无关的形态共享路径；每个缓存键只保留当前时间的一条路径，最多 512 项。缺少 `Path2D` 时继续原绘制路径。膜渐变、描边和虚线都做相应坐标换算，内核、器官及轮廓精度保持原样。

## 视觉复核和额外修复

真实 Chrome Canvas 对照完整 `drawCell` 的 Path2D 与原路径，覆盖三形态 × 原生、dart、bastion、bloom 四种外观，共 12 组。最大平均通道差 `0.0003765625/255`；640,000 个通道中，差异超过 2 的最多 20 个，仅为少量边缘栅格化差异。详见 `dense-2026-10-18/visual-equivalence.json`。

复核捕获并修正了路径缩放会连带放大渐变的问题，新增渐变坐标回归。曾探测关闭警戒圈、关闭吞噬数字的收益，结果不足以支持删减视觉；两项均未进入生产代码。

完整 UI 流程还重现了终结吞噬同帧解锁第六次进化，进化选项立刻遮挡吞噬演出的问题。已让该选项在 `lateEcology.leviathan.finaleMs` 指定的演出时长之后出现；奖励和成长照常生效，普通吞噬的突变时机不变。修复前 UI 断言失败，bastion seed728 的正常品系通关回归也捕获到同帧 `mutation-ready`；修复后回归通过。

## 测量口径与限制

使用独立安装的桌面 Chrome、390×844 CSS px、DPR2、balanced 画质，分别测量 1× 和 4× CPU 降速。每例先预热 30 帧。记录的是更新和 Canvas 指令提交耗时，以及真实 RAF 间隔，不能把 CPU 耗时直接换算成手机 FPS。

同口径基准位于 `late-2026-10-18/performance-dense-before.json`，优化后原始记录包括 `performance-dense-final.json`、`performance-dense-repeat.json` 及最终代码的 `performance-dense-verified.json`。其中 dense 会初始化 179 个真实世界实体，再独立制造 180 个全部可见的绘制对象；这些绘制对象不冒充额外真实 AI。世界实体数量另行记录，约 187–191。

前两次优化后测量，4× CPU 下普通后期场景平均更新加绘制约 4.6–6.5ms；180 个可见细胞的平均耗时约 28.4–39.5ms，优化前约 44.3ms。密集模拟更新部分从 13.6/17.4ms 降到约 6–8ms。重复记录保留波动与长帧，没有只挑最好的一次。

最终代码的 4× 测量：普通聚合层/深域平均更新加绘制 4.37/6.70ms；180 可见细胞为 30.91/28.03ms，较本轮基准降低约 30%/37%。120 真实 AI 追击组合固定步长例平均 18.13ms，P95 28.80ms，RAF 间隔 P95 33.40ms，128 次吞噬、1 次破壁、47 帧三类事件重叠，测量期无长任务。完整数据与重复测量说明见 [最终性能明细](dense-2026-10-18/PERFORMANCE.md)。

另用 `dense-2026-10-18/battle.cjs` 创建 120 个真实来源 AI 追击者，使用真实破壁、吞噬事件和实际渲染；只有 QA 初始成熟状态、补充食物与防止死亡中断的保护在内存编译夹具中注入。成熟组合场景统计到破壁、持续吞噬、最多 120 个追击者，以及三者同时发生的帧；最终记录见 `battle-combined-verified.json`。这项是压力夹具，不能作为普通玩家成长通关证据。

早期 `battle-before.json` 的空间索引采用 `grid-before.ts` 编译覆盖，原始 sourceHashes 中的 grid 项并非实际覆盖文件的哈希，不能据此声称其为完整源快照。早期 catch-up 夹具曾因玩家被吞中断，后续增加 QA 存活保护；调整前后的 catch-up 结果不作为严格同条件对比。早期命名为 final 的短夹具未产生破壁，亦不作为三类事件同时出现的证明。以成熟 combined 记录为准。`.js.txt` 是生成代码快照，不是产品脚本；交付清理时已移入不纳入Git的本地归档，测量JSON、夹具源码和最终证明继续保留。

4× CPU 极端全屏密集测试仍可能出现超过 50ms 的长帧。这些结果表明 CPU 热点明显减轻，不代表所有低端手机稳定 60FPS。真实手机 GPU、温控和小红书宿主性能尚未实测。

## 交付验证

最终执行 `pnpm lint`、`pnpm test`、`pnpm build`，测试共 87 文件、542 项。最终构建及流程元数据见 `dense-2026-10-18/acceptance.json`。

实际生产 App UI 分别运行默认模式和同时减少动态、闪烁、震动的模式。从新局 seed727 开始，仅用方向输入和固定步长加速推进，不改实体、数值或奖励；完成六次进化选择、三层环境与形态变化、成熟破壁、巨物装甲/露核/吞噬、终局暂停恢复和结局。新增断言要求终结吞入初期不出现进化遮挡。

每个模式检查聚合层、深域、巨物露核三种状态的 375/390/430 宽度及 844×390 横屏，共 24 个布局组合；系统安全区模拟为 44px，并叠加左右宿主按钮覆盖层。无横向溢出、交互按钮遮挡或 HUD 与目标面板重叠。当前产品没有 CSS 旋转模拟横屏功能。浏览器覆盖模拟与宿主真机验收分别记录，未声称真机无遮挡。

产物扩展名、体积与入口在 acceptance 中记录；目录审计为 79 文件、0 警告。构建仍存在单包超过 500kB 与已有 inlineDynamicImports 配置警告，未屏蔽。未创建 ZIP、提交、推送或发布。
