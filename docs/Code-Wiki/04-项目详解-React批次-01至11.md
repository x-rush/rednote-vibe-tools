# 04 · 项目详解 · React 批次（01-11）

11 个项目共用同一技术栈：**React 19 + TypeScript + Vite 8 + Vitest + oxlint**，命令 `dev / build(tsc -b && vite build) / lint(oxlint) / test(vitest run) / preview`，运行时依赖仅 `react`、`react-dom`。测试文件与源码同目录（`*.test.ts(x)`）。

各项目均为：`import content.json → 校验 → 状态机 → React 组件渲染 → storage 信封持久化`。以下按项目列出定位、结构与关键模块。

## 01-sbti · SBTI 山海兽格测试

- **定位**：24 题四选一趣味测试，映射 16 型山海异兽人格；含 NPC 引导、章节过场、分享卡。
- **结构**：`app/`（应用状态）、`quiz/`（题库逻辑）、`guide/`（引导系统）、`components/`（页面组件）、`share/`（分享卡）、`ui/`（资产与 reducedMotion）、`content/`、`storage/`。
- **关键模块**：
  - [src/app/state.ts](../../projects/01-sbti/src/app/state.ts) + `useShbtiApp.ts` — 应用状态机 `idle → briefing → answering → chapterTransition → revealing → completed`（19 号文档定义）。
  - [src/quiz/scoring.ts](../../projects/01-sbti/src/quiz/scoring.ts) / `selection.ts` / `presentation.ts` / `revealMotion.ts` — 计分、按配额抽题（seed 复现）、结果呈现动效。
  - [src/guide/guideState.ts](../../projects/01-sbti/src/guide/guideState.ts) / `journey.ts` / `interludeState.ts` / `mediaFallback.ts` — NPC 四态引导（39/40 号文档的设计落地）。
  - [src/share/shareCardRenderer.ts](../../projects/01-sbti/src/share/shareCardRenderer.ts) — 分享卡渲染。
- **存储**：localStorage `xhs-tool:shbti:state:v1`（本轮与最近结果）。

  - [src/narrative/narrative.ts](../../projects/02-wuhualu/src/narrative/narrative.ts) — 叙事插叙。
  - `ui/ArtifactMedia.tsx`、`SpotlightStage.tsx`、`RevealCabinet.tsx`、`SetCollection.tsx` — 文物展示与图鉴柜。

## 03-dalisizian · 大理寺字案录

- **定位**：调查汉字证据、完成案卷推理的探案游戏。
- **结构**：`content/`（含 `graph.ts` 剧情图）、`game/`（引擎）、`evidence/`（证物可视化组件）、`storage/`（含 IndexedDB）。
- **关键模块**：
  - [src/game/engine.ts](../../projects/03-dalisizian/src/game/engine.ts) — `CaseRuntimeState`：节点跳转、线索/证物/场景解锁、初判→终判。
  - [src/game/conditions.ts](../../projects/03-dalisizian/src/game/conditions.ts) — `evaluateCondition`（`all/any/not/field`）、`getAvailableOptions`。
  - [src/content/graph.ts](../../projects/03-dalisizian/src/content/graph.ts) — 案件节点图与可达性校验。
  - `evidence/GlyphTimelineArtifact.tsx`、`LexiconScrollArtifact.tsx`、`SemanticMapArtifact.tsx` — 字形时间轴、字书卷轴、语义地图等证物展示。
  - [src/storage/indexedDb.ts](../../projects/03-dalisizian/src/storage/indexedDb.ts) — 案件进度与判词的 IndexedDB 封装。
- **存储**：localStorage 入口状态 + IndexedDB 案件进度/判词。

## 04-bianjing-drink-shop · 汴京饮子铺：开店一百天

- **定位**：古风饮子铺经营模拟，仓库内**逻辑最重**的 React 项目。
- **结构**：`domain/`（RNG 与数值）、`engine/`（15+ 模拟模块）、`state/`（游戏状态机）、`storage/`（IndexedDB + 四版迁移）、`platform/`（minitool 桥）、`ui/`、`tests/`。
- **关键模块**：
  - [src/engine/simulator.ts](../../projects/04-bianjing-drink-shop/src/engine/simulator.ts) — 日结算主模拟器；周边 `economy / demand / events / endings / forecast / modifiers / effects / campaign / financial-health / balance-audit` 等模块各司其职（均有对应测试）。
  - [src/domain/rng.ts](../../projects/04-bianjing-drink-shop/src/domain/rng.ts) — seed 注入随机。
  - [src/state/game-machine.ts](../../projects/04-bianjing-drink-shop/src/state/game-machine.ts) — `noSave → morning → configured → event → resolving → daySummary → ending`。
  - [src/storage/migrate-v1..v4.ts](../../projects/04-bianjing-drink-shop/src/storage/) — 逐版迁移链，仓库迁移范式。
  - [src/platform/minitool-bridge.ts](../../projects/04-bianjing-drink-shop/src/platform/minitool-bridge.ts) — 平台桥接。
- **专属命令**：`build:minitool`（vite minitool 模式 + prepare-minitool 脚本）。
