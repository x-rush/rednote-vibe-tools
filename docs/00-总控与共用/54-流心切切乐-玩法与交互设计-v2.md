## 1. 体验三原则（本轮反馈直接推导）

1. **全貌始终可见**：任何时刻都能看到"桌 + 盘 + 糕点"的完整构图（美食视频机位）。糕点永远是主角但不是全部——盘沿、桌面暗部都是构图的呼吸空间，也让"切完摆盘"有舞台感。
2. **每一刀必须可感**：手势 = 刀。刀要看得见（刀光轨迹 + 3D 刀刃扫过）、切缝要看得见（表面亮缝 + 截面立即露出）、结果要看得见（两半明显分开、外倾展示截面、流心涌出）。切完不需要等"揭示"——**截面在刀落下的瞬间就露出来**，运镜只是锦上添花。
3. **即时响应**：所有反馈在下刀后 100ms 内开始；动画在任何环境下推进（rAF 被节流的环境用兜底时钟驱动，见 §5.6）。

## 2. 三机位构图（全部竖屏单手）

| 机位 | 场景 | 视角 | 构图 |
|---|---|---|---|
| **A 切割台**（默认） | 选好糕点上台 | 斜俯视 ~30°，**拉远到全景** | 深色木桌 + 白瓷盘完整可见；糕点占屏宽 ~40-45%，中心在屏高 46%；微呼吸 sway |
| **B 展示运镜**（最后一刀后自动 1.2s） | 切开瞬间 | 抬升至 ~60° 俯视 + 轻推 | 看清两半截面全家福与流心，随即回落 |
| **C 摆盘停留** | 等待下一步 | 俯视 ~55° | 两半在盘中摆开、流心留盘；下方操作按钮 |

机位间用缓动过渡（≤0.6s），绝不硬切。

## 3. 切割交互（核心，重设计）

**手势**：按下 → 出现刀尖落点微光圈；拖动 → 虚线瞄准线实时跟随（糕点表面的投影线）；松手 → 成刀或拒绝。

**成刀链**（全程 ≤1.6s，每步可感）：

1. **刀刃扫过**（0-160ms）：一把 3D 刀刃沿切线从头扫到尾 + 屏幕空间刀光轨迹；伴随"噗"声与 100ms 屏幕微震；
2. **定格**（160-240ms）：hit-stop，切缝在糕点表面亮起一条细线；
3. **分开**（240ms 起）：两半沿切线法向分开 0.2R，**各向外倾 ~14°**（像翻开的书，截面转向镜头），软体颤动衰减；
4. **流心**（~300ms 起）：流心从切面涌出、滴落盘面。

**拒绝反馈**（滑动太短/角度太近）：糕点整体轻颤一下，无切缝、无声——明确的"没切上"，不是无响应。

**多刀**：首发每糕 1-2 刀；第二刀在第一刀结果上继续（已有几何支持）。

## 4. 玩法循环（定稿）

```text
货架（3D 卡片墙，锁定灰/点亮彩）
  → 切割台（机位 A；按刀数切，每刀即时反馈）
  → 最后一刀 → 展示运镜 B（1.2s）→ 摆盘 C（点亮图鉴）
  → [下一件] / [回架子] / [图鉴]
```

- **图鉴**：切过即点亮；摆盘画面即传播素材（P1 加标题字与计数角标）。
- **轻目标（P1）**："正中一刀"：切线过中心 ±0.08R 内 → 图鉴星标；给复切理由，零额外系统。
- **内容边界**：首发 11 款 1-2 刀糕点不变；音效三段不变。

## 5. 本轮实现清单（v2.2）

1. 机位 A 拉远（dist 3.5→4.7、fov 30→34），糕点 ~42% 屏宽；
2. 3D 刀刃 SDF（金属材质）沿切线扫过 160ms；
3. 屏幕空间刀光轨迹 + 拖动瞄准虚线（射线-线段距离发光，shader 内实现）；
4. 切缝高亮（切开瞬间切面边缘辉光脉冲）；
5. 两半分离 0.2R + 各向外倾 14°（SDF 绕切线 Rodrigues 旋转，随分离进度渐开）；
6. **rAF 看门狗**：100ms 无 rAF 帧即用定时器兜底驱动（修内置浏览器/节流环境"松手后动画冻结"）；
7. 拒绝颤动、屏幕微震（相机抖动 3px/100ms）；
8. 展示运镜缩短为 1.2s 不阻塞（截面即时可见）。
