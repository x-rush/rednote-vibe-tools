# 《流心蜜桃》H5 捏捏 · 极致体验设计稿

> 版本 v1（2026-10-11）· 状态：待用户门禁（通过 / 修改 / 打回）
> 前置资产：2D 软体 demo、3D 凹陷软体 demo、切开流心 demo（均已验收）——本设计是在三个已验证门禁之上的能力上限版。

## 0. 一句话定义

一只可以无限揉捏、一刀切开爆浆流心的虚拟蜜桃捏捏——在 H5 里做到最接近真手感、最像真奶油的解压玩具。

**为什么是蜜桃**（选题即能力上限的一半）：
- 捏捏界的图腾品类，实物 700+ 款中的经典；天然有"桃缝"，切割叙事顺理成章；
- 哑光绒面是所有捏捏材质中最适合 H5 风格化渲染的（参照金句："Glossy squishies bounce glare; a peach glows"——亮面反眩光，桃子是发光）；
- 切面天然是三层解剖结构（皮 / 肉 / 流心），一屏之内视觉信息量最大。

## 1. 触感设计（手感即玩法）

五个交互动词，每个都有独立的力曲线、音效层、反馈链：

| 动词 | 手势 | 力学行为 | 声音 | 触觉 |
|---|---|---|---|---|
| 揉 | 单指按住揉 | 凹陷 50ms 半衰期跟手 + 按住蠕变 +30%；**速度粘度差**：快戳=Q弹晃、慢压=深坑（记忆棉感） | 挤压层随速度 | 按下 8ms |
| 捏 | 双指对挤 | 体积守恒→两指间隆起；**挤到 90% 阈值奶油从桃缝挤出一小坨**（流心预演） | 闷 squish | 10ms |
| 拉 | 表面拖拽 | 网格局部拉长、阻力随速度增大，松手 2-3 次递减晃动 | 摩擦层 | — |
| 切 | 快速划过 | 0.15s 预感帧 → 干净两半 + 滑开过冲 + **流心从切面涌出** | squelch | [15,30,10] |
| 流 | 切开后全交互升级 | 按压切面=奶油挤出更多；两半合拢再拉开=**粘稠拉丝桥**；静置=挂垂滴落+地面奶油滩 | 滴落 plip（音调随滴大小） | 断离 12ms |

**"活"感的三个不完美通道**（真材质都有，普通实现都没有）：
1. **塑性记忆**：每个凹陷 85% 弹性恢复 + 15% 记忆恢复（3-8 秒真实慢回弹），捏多轮后桃身留下浅浅的手感痕迹——慢回弹捏捏的灵魂；
2. **迟滞**：按压阈值高于释放阈值，软材料的"路感"；
3. **全身联动**：任何局部扰动都注入 2.7Hz 欠阻尼全身晃动弹簧。

## 2. 视觉设计（哑光粉彩 · 渲染能力上限清单）

**A. 桃身（哑光绒面）**
- wrap-diffuse 三色渐变：深红边 → 蜜桃 → 奶黄高光区；
- **绒毛边缘（新增）**：fresnel 边缘光叠加 micro-noise 闪烁——桃毛的视觉签名，上一版 demo 没有；
- 高光沿最大形变方向移动（哑光但"活"）；
- 捏痕红晕：捏深处轻微血色加深（已有 vDent 通道，加强）。

**B. 切面（三层解剖）**
- 皮环（哑光深红+微绒）→ 肉环（奶黄→橙放射渐变）→ 流心核（流动噪声流场+中心鼓包）；
- 流心**湿地反光**（wet sheen）：切面永远"湿"的错觉。

**C. 流心流体（本设计的能力上限核心）**
- 泪滴网格滴落（已有）+ **断离回缩弹跳**（表面张力记忆）；
- **地面奶油滩**：滴落在接触阴影处汇成缓慢生长的椭圆滩，带镜面高光；
- **挤出奶油**：按压切面时奶油实时挤出成新挂垂——交互×流体闭环，全程最强的一笔。

**D. 氛围**
- 接触阴影随形变实时变形（已有）；奶油底+点阵纹理背景（已有）+ 极轻 vignette；字距排印标题 + 首次引导动效。

## 3. 声音（ASMR 三层 + 事件层）

按仓库规则执行：CC0 实录采样（Freesound/Pixabay 源已定位）→ 构建期 base64 → 单段 ≤100KB → Web Audio decodeAudioData。挤压/摩擦/回弹三层与物理状态同变量驱动；事件层：切割 squelch、滴落 plip、爆浆 pop。静音开关常驻，无声路径完整可用。

## 4. 技术预算（中端安卓 60fps）

- WebGL1 风格化路线（明确不写实）；壳 2.5k 顶点 ×2 pass + 切面双圆盘 + 泪滴 ≤4 + 奶油滩 1 椭圆；每帧 JS <1ms，填充率 ≈2.2 屏/帧（全不透明，无全屏后处理）；
- 包体：单 HTML + base64 音频 ≈ 300-500KB；
- 防御性工程全套继承：呼吸式 pump、输入同步推帧、__ff 快进钩子、GL 上下文自动恢复、命中 NaN 护栏。

## 5. 美术闭环（质感的第一责任人）

1. 情绪板先行：CSS 色板三方向（蜜桃粉 / 奶茶杏 / 抹茶奶绿）用户挑；
2. 参照图 10-20 张驱动验收（用户拍实物照最佳，否则按已定位的 funnysquishy 参照）；
3. 真 GPU 截图 vs 参照图对比，两轮 P0 不达标即换方向（既有纪律）。

## 6. 暂不做清单
