# 06 · 项目详解 · 治愈收集与国风批次（18-25）

第三代技术栈：**TypeScript strict + Canvas2D/WebGL1 + tools.mjs 构建**（rolldown `target:'chrome61'` 输出 IIFE，构建末尾自动产物审计，详见 [03 分册 §7](./03-共享架构模式与技术方案.md)）。命令统一：`lint / test / build / preview` 均 `node tools.mjs <cmd>`。

每个项目根目录都有完整的工程文档（`PROJECT.md` / `DELIVERY.md` / `README.md` / `CAMERA-DESIGN.md` / `AUDIO-DESIGN.md` 等），是了解该项目的第一手资料——本批项目文档密度为全仓库最高。

共同架构要点（18-25 通用）：

- `src/content/content.json` 唯一内容源，构建时内联或编译为 `dist/content.js`，运行时不 fetch。
- 固定时间步模拟（1/60s）+ `seed / contentVersion / simulationVersion` 三要素复现。
- WebGL1 不可用时降级 Canvas2D（保逻辑、降视觉）。
- localStorage 结构化存档，key 由 content.json 的 `storageKey` 字段派生。
- 逻辑（model）与渲染（render）分离；qa/ 目录浏览器检查脚本。

## 18-creek-gold-panning · 溪边淘金

- **定位**：溪水淘洗沙金、收集矿物标本；自然系收集玩法首作。
- **结构**：`src/core/model.ts`（状态+固定时间步）、`src/render/`（高低画质两套渲染）、`src/ui/`（图鉴/结果/设置）、`src/storage.ts`、`src/audio.ts`。
- **要点**：淘洗手感调参全部在 content.json（物种/物件/场景/挑战）；粒子池 + typed arrays 复用；禁止逐帧 readPixels/toDataURL。

## 19-rainy-mushroom-hunt · 雨后找菌子

- **定位**：雨后林地采菌子，遮挡揭示 + 图鉴。
- **结构**：Canvas 2D **分层绘制**（背景缓存 → 静态土壤/根 → 菌体 → 移动遮挡叶 → 水珠土粒 → 前景光影）；CPU 空间网格做命中与遮挡查询。
- **content.json 顶层**：`habitats / spawnSlots / species / clusterRules / occluders / gestureTuning / atlasFrames / copy / audio / layout / quality`。
- **要点**：静态背景烘焙缓存 + 变动区重绘；低画质减少水珠/光影但保留采集规则。

## 20-tidal-beachcombing · 退潮赶海

- **定位**：退潮滩涂赶海收集。
- **结构**：WebGL1 2.5D 渲染 + CPU **96×96 高度网格**记录地形（局部更新/上传遮罩）；生物状态机 `hidden → startled → moving → caught/released`。
- **要点**：沙粒 ≤ 350、网格更新 ≤ 20Hz、输入/模拟 60Hz；`storageKey: "tidal-beach:current"`。

## 21-lakeside-stone-skipping · 湖边打水漂

- **定位**：打水漂物理小游戏，本地纪录挑战。
- **关键函数**（[src/app.ts](../../projects/21-lakeside-stone-skipping/src/app.ts)）：`createFlight / stepFlight`（固定时间步抛物线+弹跳）、`readRecord / commitRecord`（纪录读写）。
- **结构**：WebGL1 水面 + Canvas2D 石头/粒子；WebGL 失败降级简化水面。
- **content.json 顶层**：`meta / copy / stones / physics / practiceGoals / records`。
- **tools.mjs**：本批构建脚本的标准范例（[03 分册 §7](./03-共享架构模式与技术方案.md) 有逐行解读）；额外提供 `qa`（`qa/browser-check.mjs`）。

## 22-wild-pond-fishing · 野塘钓鱼

- **定位**：抛竿→等待→咬口→搏斗→起网的完整钓鱼流程。
- **结构**：WebGL1 水面 + 2.5D 鱼/竿线 + DOM/CSS；纯状态机 + **有限弹簧/张力约束**（不引入刚体/绳索引擎）。
- **content.json 顶层**：`title / storageKey / visuals / layout / spots / baits / fishSpecies / biteProfiles / fightProfiles / physicsTuning / inputTuning / catchRecords`。
- **存储**：`storageKey: "wild-pond:current"`，最多保存 1 竿逻辑状态（阶段、鱼参数、线张力、耐力）。

## 23-lanxiang-choices · 一枝春信（兰香别枝）

- **定位**：国风视觉互动小说（分支叙事 + 收藏线索物品）。
- **结构**：经典 JS（`engine.js / storage.js / audio.js / app.js`）+ `dist/content.js` 注入 `window.STORY_CONTENT`。
- **content.json 顶层**：`version / title / subtitle / brief / hook / intro / ui / sources / items / start / nodes`——剧情节点、选项、物品、UI 文案全部集中配置。
- **专属命令**：`build:single`（单文件构建）、`qa / qa:single / qa:audio`——QA 覆盖 **264 条剧情路径**。
- **红线教训**：本项目遭遇平台上架拒审（旧素材复用），催生"不复用旧条目历史素材"规则。

## 24-ming-garden · 一庭春慢

- **定位**：国风造园经营：庭院布局、植物图鉴、经济养成。
- **结构**：经典 JS；`src/engine.js`（核心交互/经济/布局）+ `src/app.js`（读取 `window.GARDEN_CONTENT` 初始化引擎、存档、相机、抽屉、放置、撤销/重做）。
- **content.json 顶层**：`title / tagline / storageKey / version / art / economy / tiers / areas / expansions / offline / items / combos`。
- **存储**：`storageKey: "ming-garden-v1"`（等级、资金、物品、布局、收藏、收益）。
- **QA 最重**：`pnpm qa` 串联 11 个浏览器检查（browser/camera/landscape/editor/journey/harbor/ui-audit/photo-regression/orientation-regression/growth-experience/focus-affordance）。
- **构建**（[tools.mjs](../../projects/24-ming-garden/tools.mjs)）：复制引擎文件 + WebP 资产 → content.json 编译为 `dist/content.js` → release ZIP。

## 25-moonfall · 月流

- **定位**：国风艺术向动态画作（月落山景 + 流水演出），非交互收集类。
- **技术栈**：**p5.js 1.11.11（本地 vendor，不走 CDN）** + Canvas2D + 经典 JS。
- **关键模块**：
  - [src/sketch.js](../../projects/25-moonfall/src/sketch.js) — p5 入口：canvas 创建、frameRate、`MoonTerrain` 与 sparkle canvas 初始化，draw 循环按 `filmTime/ease` 控制镜头缩放/平移/背景。
  - [src/flow.js](../../projects/25-moonfall/src/flow.js) — `MoonFlow.create / route / sections / pools / ledges / rockProfile`（水流路径与岩台剖面）。
  - [src/terrain.js](../../projects/25-moonfall/src/terrain.js) — Canvas2D 山脉剪影、岩台、月亮、薄雾。
- **content.json 顶层**：`brand`（toolName/tagline/logo/xiaohongshuCover）+ `xiaohongshuDraft`（title/body/hashtags/video/status）——服务发布物料。
- **交付**：`scripts/package.ps1`（PowerShell 打包）。
