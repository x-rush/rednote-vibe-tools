# 人生指南实施计划

用户已确认蓝白 UI、小猫插画、全量导入与原筛选功能，授权本轮完成小工具。所有写入仅在 projects/28-life-guide 内。

## 验收约定

- 上游固定提交；全量章节/条目/README 说明/术语/附文/更新数据进入 src/content/content.json。
- 保留搜索（所有词 AND）、各筛选维度、特殊人群组合、成本权重性价比、章节目录、术语解释、交叉引用和附文阅读。
- 白蓝界面、小猫原画、连续阅读全文、底部筛选及目录；不新增账号、AI、任务打卡或网络依赖。
- 业务数据只在 content.json 维护；构建转为经典 JS。localStorage 仅存筛选、阅读进度和偏好。
- ES2017 经典脚本、Chrome 61 基线 CSS 与能力回退；无 fetch/module/外链资源/动态代码/Service Worker。
- 375/390/430、24px 非零安全区、左右宿主遮罩、真实横屏检查；无 CSS 模拟旋转功能。
- lint/test/build、源数据一致性与筛选对照、离线浏览器功能、ZIP 白名单/根目录/10MiB 门禁。
- 创服模拟器、Android/iOS 真机由用户上传后验收，浏览器检查不能代替。

## 文件与顺序

1. scripts/import-upstream.mjs + src/content/content.json：锁版本，复用上游解析算法，生成完整性报告。
2. src/model.js + tests/model.test.mjs：筛选、规范化、搜索及存储校验，使用上游解析数据对照。
3. index.html + src/app.js + src/render.js + src/style.css + assets/cat-reading.png：实现阅读与全部面板。
4. tools.mjs：离线构建、许可说明、压缩 ZIP、写后检查；不添加依赖。
5. qa/browser-check.mjs：真实浏览器多尺寸/遮罩/筛选/持久化/跳转/全部章节/附文/失败路径，保存截图及报告。
6. README.md + release/VERIFY.md：交付入口、版本、包体、已验证与待真机验证清单。

## 重点失败模式

人群 AND/OR 组合；全部条件清空与临时筛选取消；来源独占搜索结果；旧存储及写入失败；筛选外目标跳转和返回；文档嵌套返回；长文本/字号/横屏；宿主遮罩；无 IntersectionObserver 回退；源数据缺字段不得静默丢失。
