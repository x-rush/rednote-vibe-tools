# 捡手机文学局

来电聊天朋友圈，轻松写故事。纯前端静态工具，无必需外部 API。

## 当前功能

- **人物库**：默认 16 位人物，可新建、改名、修改关系、选择 24 张同系列手绘头像或临时上传自己的头像。来电人、聊天对象、右侧角色、消息发送者、朋友圈发布者、点赞人及评论人都引用人物 ID，改名或换头像同步生效。新建人物从 32 个虚构昵称中选择未使用名字，优先分配未使用头像；编辑中可点“换个昵称”。最多 60 人；正在使用的人物需先解除引用才能删除。
- **来电与通话**：六套固定录音脚本；支持立即或延迟来电、接听、拒绝、计时、声音开关、任意时刻挂断、只播开场或完整通话。播放结束后再计算句间停顿；脚本可自动结束或保持通话。台词默认隐藏，可在设置中显示。来电铃声默认开启，支持在更多设置中关闭；延迟期间静音，到时响铃，接听、拒绝和退出时停止。不采集麦克风。拒绝、挂断或对方结束后直接返回来电人的聊天框，追加拒接或通话时长记录；切换来电人时保留其他人的聊天草稿。
- **聊天**：支持单聊、群聊及各自草稿。消息类型包括文字、语音图标与转文字、图片、定位、转账、红包、旁白、人物名片和通话记录。每条可选发言人、调顺序及删除。语音可选1–60秒、未读红点、转文字显示状态；图片保留横竖比例，支持查看大图；定位可写地点和地址并临时上传地图截图；转账可选待收款、已收款、已退还，按发送方向显示状态文案；红包为基础未领取/已领取样式，尚待红包实图校准。名片引用人物库，可填微信号；旁白居中灰字无头像。单聊、群聊、来电返回与图片导出共用消息渲染。
- **朋友圈**：选择发布者，编辑正文和时间，临时添加封面和最多九张照片；点赞支持人物多选，评论逐条指定人物，支持随机填充。预览采用文字点赞与评论布局。

## 保存图片与打包

聊天和朋友圈预览底部可保存图片。原生容器通过 `window.xhs.miniTool.saveImageToPhotosAlbum({filePath})` 保存 PNG；普通浏览器展示图片预览，可在电脑上右键另存为。图片不进入浏览器存储。按当前预览的 CSS 宽度排版，以 2 倍像素输出（375/390/430 对应 750/780/860 px），完整内容超长时按段落或消息边界分张，每张高度最多 3600 px。无网络截图依赖。

Logo 为原创手机与对话气泡图形，矢量文件 `assets/logo.svg`，512 px PNG 文件 `assets/logo.png`。简介（含逗号共 13 字符）：来电聊天朋友圈，轻松写故事。

依照仓库 `.codex/SKILL.md`（minitool-zip-builder 1.6.0）构建：复用工作区已有 Rolldown 转译至 Chrome 61，生成经典 `app.js`，内容在构建期打入，不再 fetch JSON；参考项目 14，音频在构建时编码为 JS 数据，由 Web Audio decodeAudioData 解码；ZIP 不再包含 MP3 文件，不使用 data/blob 媒体源。每段原始音频限制 1 MiB，当前最大剧情片段 54,203 字节，铃声 25,513 字节。当前 ZIP 为 700,825 字节，低于建议的 2 MiB。构建对上传文件后缀执行白名单检查。ZIP 根目录包含 index.html。构建无新增依赖。

## 配音制作

直接使用 [AUDIO-PROMPTS.md](AUDIO-PROMPTS.md)：六套豆包 TTS 2.0 人物音色、16 段朗读文本、准确文件名和停顿节奏。六套配音及来电铃声均已内置；原始音频保存在 `assets/audio/doubao-source/`，分段音频在 `assets/audio/`。生成时保留自然语速，句间等待由程序控制。挂断后释放解码缓存；播放失败会提示并保留无声体验。

## 本地运行

项目目录执行 `pnpm dev`；预览地址 `http://127.0.0.1:4317`。
交付检查：`pnpm lint`、`pnpm test`、`pnpm build`。
若4317已占用，可通过环境变量 PORT=4318 启动预览。验证脚本支持 PREVIEW_URL=http://127.0.0.1:4318。
浏览器验证：构建后启动预览，再执行 `node qa/browser-check.mjs`（需要本机 Chrome 与 Node 24）。

## 文件与存储

- `src/app.mjs` 为当前页面入口，`src/model.mjs` 负责共享人物数据，`src/call-player.mjs` 负责录音播放调度。
- 业务内容、配音提示词和台词均在 `src/content/content.json`；`AUDIO-PROMPTS.md` 是对应的人类可读制作单。
- localStorage 仅保存人物 ID、姓名、内置头像 ID、文本及选项。所有上传照片只用内存中的 object URL，不保存 Base64、图片、音频或 Blob，刷新后恢复内置头像，动态照片需重新选择。
- 没有真实微信连接、消息发送或朋友圈发布。
