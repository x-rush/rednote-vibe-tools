# 出门检查官：实现规划

## 产品定义

一句话：根据场景生成真正有优先级的出门清单，并按家中路线完成最后巡视。

参赛标签：`#小红书vibecoding大赛 #vibetool`。

## 差异化

普通清单按“衣物/电子产品”分类；本工具提供两种更符合实际遗忘行为的视图：

- 按忘记后的损失：绝对不能忘、忘了很麻烦、现场可以买。
- 按出门巡视路线：床头、插座、卫生间、书桌、冰箱、玄关。

## MVP 范围

- 8 个场景：上班、一日短途、周末旅行、出差、看演出、考试、露营、就医。
- 条件：时长、交通、是否过夜、天气由用户选择、是否带孩子/宠物、特殊任务。
- 生成清单、勾选、增删自定义项、本地保存最近 3 份。
- 三种视图：优先级、类别、空间巡视。

不做：自动天气、定位、账号同步、在线模板市场。

## 数据模型

```ts
type ChecklistItem = {
  id: string;
  label: string;
  scenarios: string[];
  conditions?: Record<string, string[]>;
  priority: "critical" | "important" | "replaceable";
  category: string;
  location: string;
  reminder?: string;
};
```

## 规则引擎

- 先按场景加入基础项，再根据条件增加或删除。
- 冲突规则有明确优先级；例如“不过夜”排除睡眠用品。
- 关键项不能因用户少选一个条件而消失。
- 输出解释为何加入特殊项，例如“乘飞机：充电宝请随身携带”。涉及规则性信息时需保守表述并提示以运营方规定为准。

## UI

- 首屏 30 秒内完成条件选择。
- 关键项固定在顶部并使用文字标签，不只靠颜色。
- “最后一分钟”模式使用超大按钮，适合一手操作。
- 所有清单都能重命名、继续勾选和删除。

## 测试

- 建立典型组合快照：一日高铁、三日飞机出差、雨天演出、露营过夜、就医。
- 检查互斥条件和关键项缺失。
- 自定义项、排序、勾选和最近清单恢复。
- 数据损坏时回退到默认模板。
