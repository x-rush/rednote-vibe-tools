# 退潮赶海 · 当前交付实现

更新：2026-09-20。当前交付内容以此文件、qa/FINAL-ACCEPTANCE.md 和 release/manifest.json 为准。

六种海岸、24 类发现、24 项目标。翻石、划沙、浅水捞取、拾取、拖入小桶、观察介绍与放回；发现事先生成，空处和藏物点都有可能。

湿沙区域连续划动都留下有上限的持久挖痕和砂粒反馈；不再要求每次先命中预设藏物点。暗坑柔边、湿痕和小孔弱化奖励暗示，水域内持续反光。

普通拖动无藏物的湿沙得到暂未发现提示；实际划沙露出细长贝，换手点击后打开介绍。刷新保留已挖痕迹和收获，未重新生成奖励。

技术：TypeScript 严格检查、Canvas/WebGL 局部动态渲染、语义化 DOM、本地素材与经典 IIFE 脚本。纯前端离线运行，无新增依赖、后端、运行时 CDN 或必需外部 API。内置音效通过 Web Audio 字节解码，原始音频不进入 ZIP。
