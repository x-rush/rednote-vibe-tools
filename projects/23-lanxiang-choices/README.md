# 一枝春信

架空古风互动故事。知枝与青禾在顾府做事，陆府秋宴将近，一册旧账和两边交接不清的差事让她们必须商量去处。主篇围绕传话、接应与共同选择展开；家庭番外讲知枝与父母如何安排离府后的生活。游戏文案的唯一来源是 `src/content/content.json`，`STORY.md` 是由它生成的阅读稿。

## 已实现

- 34 个叙事节点、19 个结局、388 条可终止的完整选择路径。选择改变接应、调差、信任与后续生活，不使用随机数或付费门槛。
- 九名人物立绘、表情差分、四类场景和两张事件画卷；逐段对话、回看、重选、已读跳过、自动阅读与结局信截图。
- 结构化本地存档、大字与静止画面设置；两首短配乐及三段语气音均为内置素材，可分别关闭。
- 纯前端离线构建。上传 ZIP 仅含平台允许的静态文件，`index.html` 位于根目录。

这次独立改写使用新的存档键，旧版本进度不会混入新人物的故事。旧存档文件不会被删除。

## 运行与验证

在本项目目录运行 `pnpm lint && pnpm test && pnpm build`。`pnpm preview` 在 `http://127.0.0.1:4326/` 开启预览，`pnpm qa` 检查常用屏宽、横屏、所有结局及页面错误，`pnpm qa:audio` 检查音频链路。当前上传文件、标题、简介和校验值见 `release/上架资料.md`。

普通浏览器检查不能代替小红书创服平台模拟器、Android 与 iOS 真机验收。平台此前只返回“内容未通过平台综合审核”，没有给出具体驳回点；本次改写不构成审核通过的保证。

## 工程边界

业务文本仅在 `src/content/content.json` 中维护。浏览器交付使用经典 JS、相对路径与内置图片，不依赖运行时网络。用户存档仅保存篇章、路径、已读状态及偏好，不保存媒体。上传包中的音频由构建期写入经典 JS，运行时经 Web Audio 解码。历史研发资料保留在项目目录供内部追溯，不随 ZIP 上传。
