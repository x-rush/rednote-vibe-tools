# Design System — 我希望被这样对待

状态：`VISUAL DIRECTION APPROVED`

## 视觉命题

**被认真修改过的一封信**：温柔、成熟、清楚，有批注、折页和小印记，但不做粉色情感营销模板。

## 色彩

```css
--paper:#f7f1e7; --paper-deep:#eadfce; --ink:#303735;
--sage:#788d7d; --brick:#a86155; --blue-pencil:#657c8a;
--highlight:#d5b879; --muted:#747872;
```

## 字体

- 标题/信件段落：Noto Serif SC。
- 问题、选项、编辑控制：Noto Sans SC。
- 不使用少女手写体作为正文。

## 布局

- 问卷每屏只处理一个关系主题。
- 结果像一封可整理的信：陪伴、安慰、分歧、边界、承诺分节。
- 分享卡使用手机截图比例，重点是第一人称表达，不依赖插画。
- “仅保存在本设备”始终可见但不制造警报。

## 动效与资产

- 180ms 纸页切换和批注出现；不做心形爆炸。
- 位图最多一张封面；其余使用 CSS 纸纹和项目内 SVG 符号。
- 纹样可有植物/信笺来源参考，但不需伪装历史文物。

## 禁止

粉色渐变、恋爱测试标签、情侣剪影、诊断图表、红绿人格评分、幼态贴纸堆叠。

## 引导角色

关系卡片整理员**小满**帮助把需要写清楚，但不裁判关系；角色保持日常编辑搭档感，完整规范见 `NPC-SPEC.md`。
