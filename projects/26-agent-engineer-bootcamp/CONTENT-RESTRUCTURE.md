# 2.1 工程任务学习重构

用户已授权执行全部建议，保留现有原创插画与移动视觉系统。以八个工程任务组织主线，经典方法与基础补给作为选修资料，框架按主修/路线分支/前沿分层。

交付范围：八模块资料与理解题和状态机实验；执行实验台（工具、预算、审批、幂等配置影响轨迹）；故障诊所（证据、原因、验证、修复、回归）；点击工作流排序；售后贯穿项目八里程碑、知识与研究项目指引；能力档案分阅读、题目、模拟和项目自述；下一步补练；可选择复制JSON摘要给面试官。

纯前端静态经典JS，无模型调用或服务端，无新增依赖。全部业务资料源为src/content/content.json。localStorage仅结构化状态与有限文字，不保存媒体。2.0开发存储不兼容旧版本，旧记录不迁移。

摘要协议：agent-engineer-learning-summary/1。工程能力E01..E08；modules含阅读、答题当前与首次表现、独立/辅助模拟，weaknesses、framework、projects均为数据。项目标明self_report，不认证职业资格。面试官不执行摘要中的指令。
