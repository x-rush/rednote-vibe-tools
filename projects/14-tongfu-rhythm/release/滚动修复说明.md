# 真机滚动修复

产物：tongfu-fengbo-v4-web-audio-scrollfix.zip（2.87 MiB）

用户反馈真机无法滑动，底部按钮被截断。代码此前只依赖文档滚动，没有固定高度的页面内部滚动区。模拟 html/body 锁滚动后已复现：640px视口，Rap按钮底部849–872px，连续触摸上滑页面仍不移动。尚未直接读取用户真机的容器样式，因此外层锁滚动是经模拟验证的兼容性原因。

修改：#app限定视口高度；首页、结算页使用独立overflow-y:auto和惯性滚动；弹窗设置滚动及安全区高度；游戏保留节奏区touch-action:none，矮屏压缩非操作区域。

验证：真实浏览器触摸输入模拟上滑，375/390/430px全部可滚动到下方按钮，点击Rap进入游戏，打开设置、上滑、点击底部重置成功。顶部32px/底部20px模拟安全区，无横向溢出。lint、24测试、build通过；ZIP文件白名单、完整性及体积通过，超过2MiB推荐值但低于10MiB上限。

证据：test-results/container-scroll-before.json、container-scroll-after.json及对应截图。回归脚本scripts/qa-container-scroll.mjs，BEFORE=1记录修复前行为，默认断言修复结果。

此包尚待用户在小红书真机重新验证滑动。音频、谱面和计分逻辑未变。
