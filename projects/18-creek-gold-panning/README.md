# 溪边淘金

项目 18，2026-09-19。当前提供可运行的离线验收包，宿主真机验收待完成。

运行预览：http://127.0.0.1:4322/ 。上传候选包：`release/creek-gold-panning.zip`；校验清单：`release/manifest.json`。

## 操作

在溪岸的三处砂纹中选择一点，按住划动舀砂。半铲即可松手，也可以继续舀满。装盘动画结束后，按住盘心向下拖入水中，浸满后松手提盘。

盘内缓慢绕圈让重物沉底，从靠近自己的盘沿向下拖住倾洗，松手回平。水少时从远侧盘沿向下拖，重新浸水。粗砾需要分层后短促倾洗，浮叶会先随水流出。洗净后逐颗点击发现物；金粒落向收藏瓶，其他矿物进入收藏盒，随后介绍形态与游戏内收藏价值。空处可以继续轻洗，提高洁净度，但猛倾仍可能失去金粒。

左侧手记选择地点、挑战、今日样本和最近记录；右侧小瓶查看金样，旁边小盒查看矿物。场景中没有倾洗、批量收集、自动演示或下一盘快捷按钮。收齐后轻点空盘，再去取砂。

## 当前内容

- 6 处独立溪岸背景，每处 3 个取样点；不同砂量、粗砾、浮叶及生成池。
- 8 种金样、10 种伴生物，写实标本图与各自介绍。
- 24 项技巧挑战、6 条收藏系列、最近 20 盘记录、个人最好洁净度/最大金粒/无流失盘数。
- 自由探索、固定挑战、本地日期生成的今日样本、同 seed 重洗。重洗不重复入藏；固定样本奖励另记领取位图。
- 完成一颗即保存；途中刷新可继续。静音、减弱动画、慢速辅助均从手记设置。
- WebGL 1 溪水折射与 Canvas 2D 砂层、盘体、颗粒；无 GL 或持续低帧率时有简化绘制。不是三维流体求解器。
- 9 段 CC0 真实拟音剪辑，构建为静态 JS 音频数据，由 Web Audio 解码播放。

## 构建与验证

在本项目目录依次执行 `pnpm lint`、`pnpm test`、`pnpm build`。工具固定使用工作区已有 TypeScript 6.0.3、Rolldown 1.2.5，测试用 Node 原生测试器；没有新增运行时依赖或修改根锁文件。

使用 Python 3 执行 `python qa/package.py` 生成并审计 ZIP，再执行仓库 `.codex/scripts/audit_artifact.py` 对 dist 和 ZIP 分别审计。只压缩 dist 内文件，源图、原始音频、测试和文档均不进入包。

测试明细、实际检查与未实测项见 [qa/RELEASE-QA.md](qa/RELEASE-QA.md)。玩法以 [PROJECT.md](PROJECT.md) 为准，完整内容目标保留在 [CONTENT-PLAN.md](CONTENT-PLAN.md)。
