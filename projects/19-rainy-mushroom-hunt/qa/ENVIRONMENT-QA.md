# 雨后找菌子 · 环境动态与交互复核

日期：2026-09-20

## 本轮实现

湿叶高光、边缘细草摆动、叶尖滴水及接触涟漪加入森林；刷泥时小泥屑脱落。新林地菌窝从规则两排三列改为带最小间距的自然散布，独立随机序列不改变隐藏奖励，已有存档原样保留。拨查、蹲下、轻晃提起、刷净、入篮有连续操作提示。四张初始菌子贴图裁切框恢复完整菌帽。

## 实测记录

390 像素左侧草叶区域相隔 900ms 帧差 14.82%，平均 RGB 差 3.97；正常模型、PointerEvent 手势回放走通拨叶→左右轻晃→上提→刷泥→入篮，竹篮由 0 变为 1，并打开奶油伞介绍卡确认完整轮廓。375 / 390 / 430、844×390 与非零安全区、左右宿主占位检查。新林地散布额外测试 200 个种子。

帧差仅证明指定画面区域确实在变化，不代表水体物理精度、画质评分或设备性能。辅助工具位于 qa/，通过 prepare-environment.mjs 生成独立 .cache/environment-preview；正式 dist 和 ZIP 不包含这些入口。
