# 动画与分镜规格

## 1. 空间关系

场景是一个深蓝色室内空间，必须延续 `references/` 三张图的侧面斜视构图，不能退化成正对墙面的普通矩形窗户。摄像机位于窗户左前下方，能同时看见窗框正面、右侧纵深和向室内开启的窗扇；窗框在透视中形成略向右上收束的斜线。窗户位于画面上半部偏右，窗外有月亮、深空和密集但克制的星点。发光线帘从窗帘杆垂下，初始覆盖大部分窗口。室内下方保留句子与结果展示空间。

动画叙事必须让用户看清四个空间层级：

1. 窗外深空和星星。
2. 窗框与可开启窗扇。
3. 窗前线帘。
4. 室内、句子和前景星尘。

只有穿过窗框开口之后，星星才进入室内层。

## 2. 总时间线

轮播阶段持续到用户点击。点击后的目标时长约 7.5 秒，允许在 6.5–9 秒范围内微调。

| 相对时间 | 阶段 | 关键动作 |
|---|---|---|
| 0.00–1.20s | 轮播减速 | 再经过 3–6 句，最后一句进入中心并清晰停止 |
| 1.20–1.90s | 阅读停顿 | 句子发光，窗外一颗星闪亮，帘子首次轻动 |
| 1.90–3.40s | 第一阵风 | 帘线由局部到底部再到整体传播，逐渐飘向一侧 |
| 3.40–4.30s | 第二阵风与开窗 | 窗框轻颤，窗扇向室内打开，月光束扩大 |
| 4.30–6.40s | 星星进入 | 星尘、拖尾粒子和主角星分批从窗外穿窗而入 |
| 6.40–7.50s | 星语形成 | 星星减速、环绕句子、主角星落位，结果控件出现 |

## 3. 线帘

- 视觉由约 50–90 根独立细线构成，而不是一整块半透明矩形。
- 每根线有轻微不同的长度、亮度、摆幅和延迟。
- 顶端固定，越接近底端位移越大。
- 初始只有很轻的呼吸摆动，不能抢夺轮播文字注意力。
- 第一阵风先影响靠窗或迎风侧的帘线，再横向传播。
- 风加强后线条向一侧汇聚，但保留层次和回弹，不能整齐地同步平移。
- 星粒子擦过帘线时允许局部瞬时增亮，但不能使整片帘子爆白。

## 4. 窗户

- 窗户初始明确关闭；不能只靠星星出现来暗示开窗。
- 开启前窗框产生 80–150ms 的小幅颤动，表达风压。
- 窗扇以可辨认的铰链为轴向室内打开约 55–70 度。
- 打开采用先加速后缓冲的重量感，不能像 UI 面板一样匀速旋转。
- 月光投射范围与窗扇开启角度同步扩大。
- 结果态保持打开，直到用户点击重播。
- 开窗动作必须让人感觉风从窗外压入室内：窗扇向观看者与画面左下方旋出，而不是像页面翻转一样原地缩放。

## 5. 风的可视化

风本身不画成卡通箭头。通过以下元素共同表达：

- 帘线的传播性变形。
- 少量半透明蓝白流线。
- 月光束内的星尘方向。
- 星星的曲线轨迹和拖尾。
- 窗框声音与窗扇惯性。

风向应统一从窗外经过窗口进入室内，并在室内形成轻微旋涡。

## 6. 星星三层系统

### A. 星尘层

- 约 45–90 个微小光点，性能不足时优先减少。
- 最先从窗外聚向窗口，进入后沿光束扩散。
- 生命周期短，主要负责建立风的体积和方向。

### B. 拖尾粒子层

- 约 15–30 个细长光粒。
- 速度较快，带短拖尾，以弧线穿过窗框。
- 部分从句子后方掠过，但绝不覆盖整行文字。

### C. 主角星层

- 约 5–12 颗可辨认的星星。
- 速度较慢、大小有层次，颜色与句子类别关联。
- 最亮的一颗最后停在句尾或文字附近，成为结果锚点。

## 7. 星星进入方向的硬性验收

- 每个主角星出生点必须位于窗框后方的“窗外区域”。
- 窗户未打开到阈值前，主角星不得穿过窗口。
- 粒子穿过窗口时必须受窗口形状裁切，不能出现在墙体上。
- 至少一批星星有连续可追踪轨迹：窗外可见 → 接近窗口 → 穿过窗框 → 到达室内。
- 不能在室内突然淡入一批星星冒充“吹进来”。
- 不能让主体粒子从室内飞向窗外。

## 8. 句子与粒子的层级

- 轮播时文字是除窗户外的第二视觉焦点。
- 选中后文字保持静止和清晰，不随风漂走。
- 星星是从外面来到这句话身边，不是文字变成星星。
- 粒子可以从文字后方和周围经过，文字前景应有必要的对比保护。
- 最终结果适合直接截屏，不能有残留调试提示、操作箭头或遮挡层。

## 9. 重置动画

- 重置总时长控制在 1.2–2.0 秒。
- 主角星淡出或退到环境层，不反向飞出窗外。
- 窗户合拢，月光缩小，帘线带余波重新垂落。
- 新轮播开始前场景必须回到统一首帧，避免残余粒子和半开窗状态。
