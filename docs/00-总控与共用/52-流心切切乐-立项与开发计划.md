## 2. 产品定义（承接 48 号 §5 B4，不再重述数据）

- **定位**：滑动下刀切开糕点，截面揭示是核心（月饼流心淌出、蛋糕露夹层、汤圆爆浆），切完摆盘收图鉴。解压赛道"切糕"细分。
- **核心循环**：选糕点 → 下刀（首发限一刀或两刀）→ 截面揭示动画（分层露出 + 流心粒子）→ 摆盘 → 图鉴点亮 → 下一件。
- **手势与反馈（三连反馈，48 号 §3.3）**：下刀瞬间 = 刀痕形变（分离微位移 + 微颤）+ 截面粒子（流心液滴 / 碎屑）+ 状态变化（两半分开、内层可见）；无音效，纯视觉反馈必须完整。
- **魔法时刻**：月饼流心缓缓淌出的截面特写。
- **截图产物**：整套餐点图鉴（摆盘全家福）+ 切面特写卡。
- **差异化分界（写入 DELIVERY.md 自查）**：13 号果冻 = 凝固的透明（倒/静置/嵌物，成品静态）；28 号捏捏 = 自制软体（揉/包芯/合模）；本品 = **固定造型的糕点 + 切面揭示**，制作动词只有"切"，三者无重叠。

## 4. 界面地图与状态机

五个页面状态，全部纳入 qa 截图对照与宿主覆盖层验证：

```text
[S1 糕点架]  --选糕点-->  [S2 切割台]  --下刀-->  [S3 截面特写]
    ^                                                       |
    |                    --摆盘-->              [S4 摆盘完成] |
    +------ 图鉴入口 ------+                                  |
[S5 图鉴册] <---------------------------------- 点亮通知 ----+
```

- **S1 糕点架**：糕点卡片网格（未解锁灰剪影 / 已解锁原色），底部或中部放图鉴入口与说明按钮。**左右上角为宿主返回/操作按钮占位区，不放任何交互热区**；标题文字居中且避开两角。
- **S2 切割台**：糕点单件特写居中；切割手势全屏可用；刀数提示（1/2 刀）以小标签呈现；退出/换糕点入口放底部安全区。
- **S3 截面特写**：揭示动画（两半分离微颤 → 夹层可见 → 流心粒子从切面发射淌出）；镜头轻微推近；完成自动进 S4。
- **S4 摆盘**：已切件按摆位参数落到盘内（DOM/CSS 层）；"下一件"与"看图鉴"按钮在下方安全区。
- **S5 图鉴册**：4 族聚合 + 款明细；点亮态发光；截图传播位（全家福构图预留）。

宿主避让三态（竖屏 / 真实横屏 / CSS 旋转模拟横屏）中，模拟横屏需把宿主占位区映射到旋转后坐标（根 AGENTS.md 强约束），S1/S2/S5 为重点核查页。

## 5. Phase 0（由 26 承载，产出即回抄模板）

1. **工程骨架**：复制 [21 号 tools.mjs](../../projects/21-lakeside-stone-skipping/tools.mjs)（rolldown `chrome61` IIFE + ZIP 白名单审计 + 禁 fetch/eval 扫描 + 静态服务）、tsconfig（strict）、qa/browser-check.mjs 骨架。目录布局按 Wiki 09 §1。
2. **宿主避让参数系统**：content.json `hostAvoid` 段（左/右按钮占位区宽高 + 触摸余量，全参数化不写死像素）+ `hostSafeArea()` 工具函数 + CSS 变量；默认保守值，真机校准后回填。qa 脚本内置左右按钮覆盖层模拟与三态截图。
3. **切切样板 = 26 核心模块**（不是弃子）：一枚月饼的分层绘制 + 一次切割 + 截面揭示 + 流心粒子，按 47 号 §7"暂停看材质"做视觉对照验收（G0 条件③前半）。
4. **粒子池基线**：复制 10/11 号粒子系统为模板模块；quality 档位（高低两档：粒子数上限、DPR、滤镜降级顺序）入 content.json；低端机档位跑 G0 基线。
5. **content.json Schema 约定**：统一顶层 `title / storageKey / version / copy / quality / hostAvoid` + 业务段（§6）。

捏捏形变样板（G0 条件③后半）与 26 无耦合，按 50 号 Phase 1 图注与 28 同步设计并行，最迟 G3（28 编码前）通过验收——建议总控将 50 号 G0 条件③澄清为"切切样板为 G0 硬条件，捏捏样板为 G3 前置"（见 §10 待确认项）。

## 6. content.json Schema 终稿草案

顶层：`title`、`storageKey: "liuxin-slice-v1"`、`version`、`copy`、`quality`、`hostAvoid` + 业务段：

| 段 | 字段 | 说明 |
|---|---|---|
| `pastries[]` | `id / name(≤5字) / family(月饼\|汤圆\|青团\|蛋糕) / skin`（皮色、纹理参数） | 每款糕点 |
| | `layers[]`（自外向内：类型 皮/馅/夹层/流心、色、厚度比例） | 截面揭示的层序，单测断言与渲染一致 |
| | `flow`（有无流心、粘度、粒子速率/数量系数）、`cuts`（1 或 2） | 手感差异参数 |
| `cutting` | `gestureTuning`（跟手灵敏度、最小划动距离）、`separation`（分离位移、微颤幅度/时长，参照 47 号 §4 受力阶段） | 全局切割手感 |
| `plating` | `plate`（盘样式）、`slots[]`（摆位） | S4 摆盘 |
| `collection` | `byKind[]`、`limit`（上限清洗）、`unlockRule`（切过即点亮） | 图鉴 |
| `quality` | `tiers.high/low`（流心粒子上限、碎屑上限、DPR、滤镜降级顺序） | 初始预算：流心 ≤240/≤130、碎屑 ≤120/≤60，G0 校准 |

## 7. 技术方案与复用

- **绘制**：糕点 = 离屏 Canvas 分层（皮/夹层/流心层各自成层）；切割 = 切割线两侧 clip 分离（轮廓裁切几何复用 [13 号 contour](../../projects/13-jelly-atelier/src/)）+ 分离微位移 + 微颤（47 号 §4 阶段表：触碰 0-80ms / 回弹 450ms / 余振 900ms 的同款纪律）。
- **流心**：粒子液滴从切面发射，粘度/速率参数化（每款 `flow` 独立）；粒子池复用 10/11 号。
- **逻辑**：model.ts 纯函数 + 固定时间步 1/60s + mulberry32 seed 状态内嵌（16 号模式）——**同 seed + 同糕点 + 同切序 = 同结果**，QA 可指定 seed 复现；存储信封（schemaVersion + 迁移函数）+ 图鉴上限清洗（13 号 cleanCollection）。
- **摆盘**：DOM/CSS 层，不进 Canvas。

| 需求 | 复用来源（Wiki 09 §2 B4） |
|---|---|
| 分层绘制 + 裁切遮罩 | 19 号 Canvas 分层纪律；13 号 contour.js |
| 流心粒子液滴 | 10/11 号粒子系统 |
| 整套餐点图鉴 | 18-22 号图鉴模式（点亮/聚合/上限清洗） |

## 9. 验收清单（通用矩阵 + 专项）

通用（50 号 §9 全矩阵）：单元 / 内容 / 工程（`pnpm lint && pnpm test && pnpm build`）/ 响应式 375-390-430 / 非零安全区（sticky 叠加 `var(--safe-area-inset-top, env(safe-area-inset-top, 0px))`）/ 宿主覆盖层 × 五页 × 三态 / 视觉动效（47 号矩阵）/ 性能（60fps 预算 + quality 档位断言）/ 打包 / 平台三步（用户执行）。

专项（50 号 §6.1 展开）：

- [ ] 切割手势跟手 ≤1 帧延迟；轻点不误触发下刀（最小划动距离生效）
- [ ] 截面层数、层序与 content `layers[]` 完全一致（单测断言 + 截图对照）
- [ ] 流心粒子总量不超 quality 档位；低端档玩法完整（降密度不降反馈）
- [ ] 一刀/两刀均正确分离；连续快切不丢刀、不跳变、无穿透错层
- [ ] 图鉴去重与上限清洗；切过即点亮无漏
- [ ] 同 seed 回放与首次结果一致（QA 脚本指定 seed 验证）
- [ ] 摆盘件数与刀数一致；S4→S1 状态恢复正确
- [ ] 横竖屏/模拟横屏下宿主占位区无交互热区（S1/S2/S5 重点）
