## 9. 全局存储规则

- `localStorage`：小体积、读取简单、可整体替换的当前状态。
- `IndexedDB`：数量较多、需要索引查询或独立更新的结构化记录。
- 禁止持久化用户图片、视频、音频、Base64 图片和不可控 Blob。
- 所有结构化数据包含 `schemaVersion`、更新时间、条数/长度上限和清空入口。
- 不承诺永久保存或跨设备同步。

## 10. 全局变更控制

以下属于重大变更，实施前必须重新打开规划：

- 改变核心玩法循环。
- 增加后端、账号、定位、实时 API 或用户文件上传。
- 首发内容量增加 25% 以上。
- 从单局工具改成社区、多人或排行榜产品。
- 修改关键数据实体，导致已生成内容或美术无法兼容。

以下属于实施期可接受的小调整：

- 页面文案、按钮名称、颜色和动效时长。
- 在冻结数量内替换题目、任务、文物或事件。
- 不改变数据模型的小字段补充。
- 性能降级、无障碍和错误恢复优化。
