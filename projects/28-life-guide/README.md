## 功能

一章一页，章内自然上下滚动。正文只挂载当前完整章节，滚到底后仍停在章末；点击章末大按钮或底部“下一章”时，新章替换当前章，回到章首，不追加其他章节。底部常驻上一章、目录、设置、说明、下一章，以及本章阅读百分比、“回到章首”和阅读状态下的“首页”入口。首末章对应方向禁用。

恢复原有大标题、两行封面 banner 和大尺寸原创读书小猫。封面和搜索框在正常文档流中，向下阅读时自然滑出屏幕；章节与筛选工具栏吸顶。没有动态折叠高度造成的阅读跳动。每章都保留完整封面与搜索框。切章、目录选章或点击“回到章首”时，仅将页面滚动锚点定位到章节标题；向上滑即可看到完整 banner，底部“首页”也只是滚动到页面顶部。阅读状态不会再决定 banner 的显隐。

章内滚动停止后保存 chapterId、scrollY、布局签名及条目内文字锚点，离开页面时再次同步记录。相同宽度/字号/安全区重入恢复精确滚动位置；字号或横竖屏变化时用文字锚点定位原文附近。兼容原滚动记录及 1.2.0 按屏记录，不会把旧页码解释为新页码。首页调整字号仍保留封面。

导读、原始出处和附文放入独立阅读面板，面板内部可上下滚动。鼠标/触摸不显示焦点边框，键盘 Tab 保留焦点提示。长章节标题省略显示，筛选按钮固定占位且不换行。

全文搜索（含来源、多关键词全部匹配）、条目目录、完整多维筛选、人群组合和年龄继承、作者性价比算法、争议与待核实、最近更新、交叉引用预览/跳转/回原位、术语解释、9 篇附文、完整 README 和许可说明、浅色/深色/跟随系统、16/18/20 字号全部保留。

搜索/筛选默认覆盖全书，结果仍按章查看；读完一章后只进入下一个有匹配结果的章节。目录选择章节不隐含增加章节筛选；如该章没有匹配内容，会提示并清空条件后显示完整章。需要原版章节范围限制时，在完整筛选中的“查找范围”选择具体章，或恢复“全书章节”。横屏时可在筛选面板中搜索。

筛选面板中的修改暂不影响正文，按“查看结果”应用；关闭取消本次修改。重置保留当前搜索词，清空所有标签及章节；主页面“清空筛选”同时清空搜索词。

来源外链不能在容器中打开，因此显示完整可选地址。核实记录属于外部出处，保留上游固定版本地址；9 篇用户阅读附文全部包内可读。未加入上游独立的 selfcheck 应用、AI skill、广告、赞赏和其他语言版本。

## 内容版本与更新

固定上游：https://github.com/eternity4719/HowToLiveBetter/tree/5f210ca953b7b538c042ad8515d5c355b766a194

业务内容唯一源为 `src/content/content.json`；开发导入脚本读取固定 `.upstream` checkout，逐行识别正文并拒绝未知字段/未解析内容。`release/import-report.json` 记录数量、源 Markdown SHA256。`reference/upstream-parser.js` 是已审阅的原解析器，只供开发测试，不入上传包。

重新取源时先在本项目内准备 `.upstream` checkout，再 checkout 上述提交，运行 `node scripts/import-upstream.mjs`。脚本拒绝非锁定提交；升级时明确修改固定提交，审阅差异后重新导入和全套验证。

构建将 JSON 序列化为包内经典 `content.js`；无 module、运行时请求、CDN、eval、Worker 或 Service Worker。全文不写入持久存储。使用文档列出的 `xhs.miniTool` Storage API（存在时），同时即时写本机 localStorage 检查点；读取时选择时间较新的有效数据，避免桥接异步写入尚未完成时丢失最新阅读位置。只存筛选、chapterId、章内滚动位置/文字锚点和偏好，全部存储失败会提示。内容版本变化时丢弃旧阅读位置，保留合法偏好/筛选。

构建自行递归检查扩展名、生成 deflate ZIP，并从最终文件读取中央目录、解压和 CRC 验证所有条目。10 个包内文件，无开发资料/源码映射/不支持后缀。完整正文 JS 大于 2 MiB，已保留全量需求并记录解析/内存风险；只有当前完整章进入 DOM，真实低端机性能仍需实测。当前 QA 为 `qa/chapter-reader-check.mjs`。历史 QA 保存在 `qa/paged-browser-check.mjs`（1.2.0）和 `qa/legacy-scroll-check-1.1.0.mjs`（1.1.0），保留用于追溯，不代表当前交互预期。

## 安全区与宿主避让

`src/style.css` 中 `--host-clearance` 默认 56px、`--host-side-clearance` 默认 94px，与系统安全区分开配置。顶部居中标题、下方搜索和吸顶工具栏避开两角；滚动时顶部遮挡带阻止正文热点进入宿主按钮区域。底部面板关闭/确认始终在底部安全区。可在真机校准这两个参数。

无 CSS 模拟旋转功能，使用设备真实横屏时重新排版。QA 在 375/390/430 竖屏、844×390 与 932×430 横屏注入 24px 顶部/20px 底部安全区及左右 82×42 遮罩；不得据此宣称所有宿主版本真机合格。

许可及素材来源见 `ASSET-SOURCES.md`、`reference/LICENSE`、`reference/LICENSE-CODE` 和包内“指南说明”。
