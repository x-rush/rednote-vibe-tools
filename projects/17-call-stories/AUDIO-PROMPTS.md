# 捡手机文学局 · 豆包配音交付单

使用豆包 TTS 2.0，音色、台词和语气指令以本文件及 src/content/content.json 为准。此前 ElevenLabs 小样只作历史候选，不进入发布包。

## 制作方法

- 只录来电者一人的声音。用户回应或沉默，都不影响下一句成立。
- 同一场景整段生成后在自然句间裁切，保持同一音色和连贯表演。音高、语速、音量均使用生成时的默认值；不做变速、升调、混响或电话失真。
- 已下载源文件为 24 kHz 单声道、64 kbps MP3。保留源文件及 AIGC 元数据；开发素材不直接进入 ZIP。
- 几秒的回应空隙由程序插入，不把等待指令读进录音。
- 构建时转成经典 JS 静态数据，由 Web Audio 在本地解码播放。
