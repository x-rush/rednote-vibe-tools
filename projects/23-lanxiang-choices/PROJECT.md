# 一枝春信 · 产品与实现

本项目是一部独立的架空古风互动故事。玩家扮演在顾府做针线的许知枝，与同住的青禾一起面对交接不清的差事。陆府秋宴前，一册数目不合的旧账把知枝卷入顾景衡与陆清晏之间的传话；玩家选择是否告知青禾、怎样争取接应、能否找到公开且可兑现的去处。家庭番外则从父母想先送知枝离府的分歧展开。

核心体验是逐段阅读、观察人物反应、作出具体选择，并承担不同的关系和生活后果。青禾有独立的判断与行动，顾景衡和陆清晏各有利益与限制；不能靠一句承诺让问题自动解决。故事不使用好感数值或随机结局。34 个节点与 19 个结局的运行文本都存于 `src/content/content.json`。

视觉沿用墨蓝、雨青、窗灯金与纸白；AI 插画为架空人物和院景，不使用演员肖像或影视截图。手机人物在上、对白在下，真实横屏人物在左、对白在右。顶部控件避开小红书宿主返回与操作按钮，保留非零安全区。模拟旋转横屏功能不存在。

技术为纯前端离线 H5：Node 构建生成经典脚本、图片随 ZIP 打包、无运行时网络。存档只保存结构化状态，新版使用独立存档键，不读取旧故事进度。上传包以 `release/上架资料.md` 为准。交付前运行 `pnpm lint && pnpm test && pnpm build`，再核验构建目录、ZIP 和浏览器流程；平台模拟器及 Android、iOS 真机另行验收。
