# 配音修订版

使用 `更新了第二版-配音底片-无字幕无音乐.mp4` 替换之前的视频。它保留43.6秒实际游戏画面，去掉后期烧录的标题、说明和字幕，没有音轨。游戏自身UI文字仍保留；封面继续使用上级目录的原封面。

## 在剪映里替换

1. 复制一份原草稿，再删除旧的15条配音和字幕轨，避免旧内容继续叠加。
2. 导入新底片；复制 `简短配音稿.txt`，按完整段落生成配音，先试听实际语速。
3. 如果整段配音一次生成，按7个自然句在建议时间轴上分开摆放，让停顿落在句子之间。不要将旧的15个字幕块再逐条转配音，也不要让相邻语音重叠。
4. 字幕只保留一套：优先对新配音做一次语音识别；若使用 `可选字幕-7句不重叠.srt`，就不要再叠加另一套自动字幕。SRT是建议落点，需要随实际配音时长调整。
5. 字幕放在下方深色留白区，单行优先、最多两行；可用白字加细黑描边。以画面宽1080、高1920为准，字幕中心约在 y=1790，距离底部约100px，不压游戏里的成长信息面板。
