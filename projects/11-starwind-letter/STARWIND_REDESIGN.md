# 星风来信：星语随风入室重构规格

## 1. 规格地位

本规格记录 2026-09-01 确认的新主流程，并覆盖项目旧文档中与以下内容相关的描述：首屏文字轮播、轮播减速选句、可开启窗扇、开窗动作、结果态粒子停止。未被本规格修改的内容约束、安全区、纯前端限制、无障碍和质量要求继续有效。

## 2. 体验目标

“星风来信”不再先展示或轮播候选句。用户面对一幅安静、昏暗的深蓝房间：固定窗框与中间横栏藏在银蓝线帘后，帘后有月亮和夜空，但室内尚未被月光照亮。

用户点击一次后，风从帘子顶部切入并向下传播，把线帘拉成向室内延伸的三维弧面。随着帘子打开，漂亮的月牙、明亮夜空和被横栏分隔的两块透视月光显露。星星持续沿风道飘入室内；随机星语的单字混在星流中，越靠近镜头越清晰，最终在下方组成完整句子。结果态不是静帧：帘子持续摆动，星星继续错峰进入、落地闪烁并消散，直到用户重播。

## 3. 明确取舍

- 保留固定窗框、中间横栏、窗帘杆、线帘、月亮和窗洞。
- 删除可开启窗扇、玻璃面、把手、铰链、投影及整个开窗动作。
- 地面的几何形是月光穿过窗框并被中间横栏切开的光影，不是书或纸张。
- 删除首屏文字轮盘、候选字形和点击后的减速选句画面。
- 不添加书本、翻页或文字从书页飞出的叙事。
- 星语仍从 `src/content/content.json` 随机选择，并保持近期结果去重。

## 4. 分镜与时间线

| 相对时间 | 阶段 | 画面与动作 |
|---|---|---|
| 点击前 | `idle` | 房间昏暗；帘线完整垂落并轻微呼吸；窗框和月亮只在帘后若隐若现；不显示候选星语。 |
| 0.00–0.30s | `wind` | 点击立即锁定随机星语；帘杆附近先出现风压，顶部帘线收紧。 |
| 0.30–1.80s | `curtain-opening` | 风由上向下传播，帘线逐段掀开；顶部先收拢，帘身形成三维弧面，下半部慢半拍甩向室内。 |
| 0.80–2.20s | 月光显露 | 月牙逐渐完整显露，月光快速增亮；横栏把地面光束切成前后两块斜向透视光面。 |
| 1.50–5.00s | `stars-and-letters` | 星尘、短拖尾和主星沿同一风道持续进入；单字光片混在星流中，穿窗时低亮、虚焦且不可组成完整句子。 |
| 4.00–6.50s | 字符落位 | 单字靠近镜头后降低旋转与模糊，按原句顺序在下方依次落位；星星从文字后方继续掠过。 |
| 6.50s 后 | `result` | 完整星语稳定可读；月光保持明亮；帘子持续随风摆动；小批星星持续进入、落地闪烁并消散。 |

上述时间可在视觉调试中微调，但必须保留“顶部先动 → 变化向下传播 → 月光显露 → 星与字共同入室 → 字符落位 → 持续余韵”的顺序。

## 5. 构图与视觉层级

### 5.1 固定窗框与月亮

固定窗框位于上半屏偏右，镜头继续从左前下方斜看窗口。窗框上沿、中间横栏和帘杆使用一致的透视方向。窗洞不表现封闭玻璃，星星和风可以直接穿过。

月亮位于窗洞上半部偏左，采用清晰月牙、柔和外晕和少量环境星点。月心不得过曝成白团，月牙轮廓在最亮阶段仍需清楚。

### 5.2 分段月光

月光从窗洞投向室内左下前景。中间横栏在光束中形成明确的暗分隔，使地面出现前后两块透视光面。光面只使用渐变、柔边和地面透视，不绘制纸张边框、折痕或书脊。

### 5.3 线帘

帘子由约 64 根独立银蓝纤维构成。每根帘线保留长度、亮度、相位和响应差异。强阵风使用纵向传播延迟：靠近顶部的路径段先发生明显位移，越靠近底部越晚达到峰值。结果态叠加低频呼吸和偶发小阵风，帘束不能停止，也不能冻结成整齐直线。

### 5.4 星星与文字

星粒子继续分为微小星尘、短拖尾和少量暖白或银白主星。第一波形成视觉高潮；结果态以更低密度持续生成，疏密随小阵风变化，不表现成匀速喷泉。

飞行文字使用独立字符层。字符从窗洞附近出生，沿星星相同的右上至左下风道错峰移动。穿窗时字符低亮、虚焦并带轻微旋转，不能提前读出整句；接近下方前景时逐步清晰、停止旋转并按原顺序落位。最终文字无卡片、书页或实体容器，新进入的星星不得撞散已经完成的句子。

## 6. 状态与数据流

主状态为：

`idle → wind → curtain-opening → stars-and-letters → result → resetting → idle`

- `idle` 只接受第一次主场景点击。
- 点击时通过现有随机与近期去重规则锁定星语，但不立即显示完整文字。
- 统一动画时钟驱动帘子、月光、星粒子和字符轨迹。
- 结果态保持时钟运行，用于持续帘摆和循环星流。
- 页面进入后台时暂停时钟与音效，恢复后从一致进度继续。
- `resetting` 清空粒子、字符轨迹和上一轮星语，收回月光并让帘线重新垂落。

## 7. 渲染职责

- 固定窗框、月亮和分段月光：SVG。
- 线帘：SVG 贝塞尔路径，路径采样支持顶部到下部的传播相位和结果态持续风。
- 星尘、拖尾和主星：Canvas 粒子系统。
- 飞行字符与最终星语：DOM 字符层；飞行时 `aria-hidden`，完成落位后通过 `aria-live="polite"` 公布完整句子。
- React 只管理稳定状态、随机结果、统一时间采样和语义控件。

不新增依赖，不使用运行时 CDN、后端、外部 API、Service Worker 或设备权限。

## 8. 持续动画与性能

第一波粒子沿现有叙事时间进入。结果态使用受限循环生成器：按错峰批次补充星尘、拖尾和主星；已消散粒子从活动集合移除或复用；活动粒子总数设置硬上限。运行时间增长不能导致数组、历史轨迹或定时器数量无限增长。

结果态主星仍需经过“窗外 → 窗洞 → 室内 → 落地 → 消散”的连续路径。持续粒子不得在室内凭空生成，也不得从文字中爆出。

`prefers-reduced-motion: reduce` 保留完整方向叙事，但降低帘摆幅度、持续生成密度、拖尾速度和字符旋转。Canvas 有效 DPR 继续限制为 2。

## 9. 音效与控制

首次点击后播放轻微选中反馈和短风声；帘子强阵风与星流进入可使用现有合成音色增强节奏。结果态不循环播放长风声或背景音乐，避免持续噪音。音效失败或静音不影响视觉流程。

结果态保留“再听一次星空”。重播期间立即锁定重复点击，完成重置后才重新开放首屏点击。

## 10. 验收标准

- 首屏 DOM 与画面均没有候选星语轮播。
- 画面不存在窗扇、把手、铰链或开窗动画；固定窗框与中间横栏仍清晰可辨。
- 帘子可观察到顶部先动、变化向下传播，不能整片同步平移。
- 月牙轮廓清楚，月光足够明亮，并由横栏在地面形成两块明显分隔的透视光面。
- 每个飞行字符从窗洞附近进入，沿星星相同风道运动，最后按原句顺序落位。
- 结果态运行至少 60 秒后仍有新星进入、帘子仍在摆动，且活动粒子数量不超过上限。
- 重播后粒子、字符和光线全部重置，不残留半句、上一轮星星或持续生成器。
- 自动测试覆盖状态机、帘子纵向传播、持续粒子上限、字符轨迹、后台暂停和重置。
- Chromium 真实浏览器验证 375×812、390×844、430×932 CSS px、32px 顶部安全区和降低动态模式。
- 视觉截图至少覆盖首屏、帘子上部先开、分段月光铺地、字随星入室、最终成句和 60 秒持续结果态。
