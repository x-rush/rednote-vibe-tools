# 当时这样说就好了 · Art Request

状态：`COMPLETE · 26/26 ASSETS ACCEPTED`

完成日期：2026-08-26。3 个 WebP 与 17 个 SVG 已在应用代码开发前全部生成并通过独立资源板验收。

## 1. 制作目标

为“安静的纸面编辑台”提供确有交互用途的角色、步骤、隐私、语气、编辑和安全资源。资源全部随静态构建打包；资源完成并验收后才进入应用代码开发。

## 2. 位图资源

### 2.1 迟言主形象

- 文件建议：`public/assets/guide/chiyan-guide-master.webp`
- 数量：1
- 构图：3:4 竖幅，完整头顶、双手、木色铅笔和横向分栏便签本，人物自然裁切到大腿中部。
- 角色：原创虚构中国年轻男性编辑，沉静、诚实、温和专注；深海军蓝薄外套／衬衫，暖灰内搭。
- 本子：一道中央分栏线、恰好四块完全空白纸条、两枚无文字的细线重排箭头。

禁止文字、伪字、聊天气泡、消息截图、分数、红绿对错、咨询室、白大褂、法袍、客服耳麦、围裙、咖啡设备、AI 机器人、情侣冲突、品牌和现实人物复刻。

## 3. SVG 资源

统一要求：`24×24 viewBox`、`2px` 线宽、圆角线端、`currentColor`、内置 `<title>`，不使用填满大色块。每个图标验证 16／24／32px。

### 五步符号（5）

- `step-fact.svg`：可核验记录／观察框，不用相机品牌造型。
- `step-feeling.svg`：中性身体感受与波纹，不用爱心或表情脸。
- `step-inference.svg`：两栏之间的分类移动，不用脑袋或心理诊断符号。
- `step-need.svg`：留白中心与支撑结构，不用许愿星。
- `step-request.svg`：内容进入可执行行动，不用聊天气泡。

### 隐私符号（2）

- `privacy-ephemeral.svg`：记录页退出后清除，不用帽子眼镜隐身俗套。
- `privacy-local.svg`：仅在当前设备保存，不使用云朵。

### 三语气符号（3）

- `tone-gentle.svg`
- `tone-direct.svg`
- `tone-firm.svg`

三者使用相同基础句线，通过边缘、间距和边界线表达差异，视觉重量完全同级。

### 编辑标记（5）

- `edit-note.svg`
- `edit-hide.svg`
- `edit-delete.svg`
- `edit-reorder.svg`
- `edit-undo.svg`

### 其他（2）

- `safety-priority.svg`：稳定盾形与确认线，克制且无警报感。
- `guide-help.svg`：铅笔与页边批注入口，不用机器人或问答气泡。

SVG 总计：17 个。
