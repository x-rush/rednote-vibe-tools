# 朏朏正式画像参考档案

状态：GOLDEN V2 + PAGE QA PASSED / 2026-08-24

目标类型：HVES「安忧型」。洞察未说出口的情绪、以稳定陪伴提供支点是产品演绎；狸形、白尾、有鬣及“养之可以已忧”来自原典，但不得转写为真实心理疗效。

## 1. 原典事实

- 原典：`《山海经·中山经》`霍山条。
- 冻结原文结构：**有兽焉，其状如狸，而白尾有鬣，名曰朏朏，养之可以已忧。**
- 形貌不可变项：小型狸类整体轮廓；恰好一条以白色为主的尾；颈背存在清楚但不过度夸张的鬣毛。
- “养之可以已忧”保留为古籍神话叙述。产品可将其转译为陪伴意象，但不得承诺缓解抑郁、焦虑或替代专业帮助。
- “安忧型”是 SHBTI 游戏化人格映射，不是古籍已有分类。

## 4. 项目与页面风格适配

- 项目风格：SHBTI 已冻结的山海卷轴、矿物色、工笔墨线和克制云山；不得改成普通萌宠插画、治愈系贴纸、3D 盒景或现代人格测试品牌仿作。
- 页面角色：HVES 结果页主画像，承担“古籍异兽身份识别 + 安静陪伴气质”，不是医疗宣传图，也不是抢夺结果标题的复杂叙事场景。
- 情绪目标：温和、可靠、安静靠近，但仍保留野生异兽的独立性和距离感。
- 系列基准：沿用鹿蜀、精卫、开明兽、烛阴的 4:5 纸本工笔体系；主体清楚、背景克制、无可读文字。
- 移动端目标：160px 缩略时仍可一眼辨认颈背鬣毛和单一白尾；4:5 结果卡不切掉耳、爪或尾端。

## 5. 形貌与生成门禁

1. 单一四足狸形兽，可信小型猫科／狸兽骨架；一头、两耳、四足，恰好一条尾。
2. 尾巴必须以白色为主并完整可见；可以有极少量根部暖灰过渡，但不得变成多尾、环纹尾、狐尾扇或仅白色尾尖。
3. “有鬣”通过颈后至肩背的一列较长鬣毛表现；长度适中、走向清楚，不画成雄狮大鬃、马鬃、朋克刺或火焰。
4. 面部可适度圆润、美化以避免历史图中的猪鼻感，但必须保持短吻狸兽／小型猫科结构，不画成人脸、家猫幼崽或狐狸。
5. 毛色使用暖灰、浅赭、墨褐与白尾；身体纹样克制，不能靠豹纹把它直接等同豹猫。
6. 画面不出现被安慰的人、药物、医疗符号、爱心、眼泪、治疗前后对比或“治愈”文字。
7. 4:5 竖幅，耳、四足、鬣线、白尾与尾端全部在安全区；伏卧或慢行均可，自然远侧肢体遮挡可接受，但四足结构不能产生缺失歧义。
