# Agent 工程师训练营：移动学习APP交互原型

内容版本1.2.0，原型迭代2026-10-14。用户拒绝旧版网页目录感，明确要求参考成熟手机学习APP，使用珊瑚橙进度hero、四项统计、2×2彩色快捷入口和固定底部导航。此次重做交互结构与视觉，保留课程内容与离线约束。没有正式发布ZIP。

## 用户与目标
学生通过碎片学习达到Agent应用开发实习/初级岗位所需能力。A工程基础、B模型应用、C知识检索、DAgent执行、E可靠性交付为核心，F进阶选修。阅读、题目表现与实践自报分别记录；课程进度不代表岗位资格认证。

## 内容
30能力节点A01..F05不改ID；每节点包含目标、机制、执行步骤、失败边界、问答、示例代码/数据、误区、实践与验收、来源核对日期。60独立练习带解析，12故障trace案例含3个假设、根因、修复与回归。知识库工单助手贯穿六阶段，校园报修迁移任务要求重定义领域规则、资料、权限和评估。全部内容唯一来源src/content/content.json，学习无需打开外链。

## 四个主screen
- 首页：问候、真实核心已读进度圈（25项）、全部已读/已练/故障/实践统计、递归前置的继续学习卡、知识路线/专项练习/故障挑战/错题本2×2入口、可配置每日目标与真实唯一事件、阶段推荐、贯穿项目入口。
- 课程：A-F按阶段进度分组折叠、搜索。节点详情为独立screen，讲解/例子/实践/来源四分节；讲解目录可跳转、上一/下一节、底部标记阅读与去练习。实践表单从阅读分离，未保存note或勾选离开会提示保留继续编辑或放弃。
- 训练：阶段专项与错题复习为单题session，题号、进度、选择、确认、解析、下一题、结果。确认前不写成绩；确认后保留首次正确状态。未完成session切tab或离开需确认，目标tab保持，已确认题保留、未确认不计成绩。起点诊断为五道代表题及背景选择的规则建议，不写练习成绩。故障挑战为现场记录、三假设、确认、根因修复回归、完成复盘结果screen。
- 我的：真实统计和首次/当前题目表现、学习事件记录、实践证据编辑、每日目标、可选面试摘要、JSON备份恢复、清空确认。备份粘贴后校验、预览计数，确认才覆盖。

## 状态与兼容
localStorage只保存结构化IDs、阅读标记、答题次数和首次正确、实践文本/自报、故障复盘、每日事件与目标。不得保存媒体。未发布开发版本不迁移旧记录；仅接受当前内容版本。损坏/不可用存储提示并保持当前会话可学习。导入忽略非法ID/字段并限制实践长度；拒绝不支持版本和错误形状。

每日目标支持1/3/5/8。阅读完成、确认作答、故障复盘、实践自报各为任务事件；同日期、类型和ID只计一次，重答和重复标记不刷目标。历史事件表示曾完成，不因撤销当前阅读状态而假装未发生。首次答错后复习答对仍保留首次错误，当前错题则移出。

## 运行与验收
纯前端静态、经典JS，无后端/API/CDN/运行时fetch/模块/ServiceWorker。无图片媒体或新依赖。文本复制通过可选择textarea，不调用受禁剪贴板。顶部物理宿主按钮区与系统safe-area分别处理，主内容独立滚动，固定底部导航加safe-area。375/390/430与844×390横屏检查，无CSS旋转。

当前交互原型待用户确认体验、资料深度与训练颗粒度。普通浏览器检查不代替平台模拟器、小红书Android/iOS真机和Chrome61实际设备验收。
