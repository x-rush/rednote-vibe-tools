# 月流

一幅使用 p5.js 制作的 3:4 动态画作：初始镜头贴近山体；轻触画面后缓缓拉远，月亮从夜空落到山脊，停稳后银白水线才从月下沿山势逐渐流开。夜色、月轮、山体和流水全部由代码绘制。用户图片仅供人工分析构图与颜色，不作为纹理、背景或转场图层加载，也不包含在构建产物中。

名称定为「月流」，标语为「流水今日，明月前身」。`assets/brand/` 中的 Logo 与小红书封面是独立生成的宣传图片；视频 `exports/moonfall-xiaohongshu.mp4` 才是实际 p5.js 作品的录屏。封面表达同一主题，但不代表动画逐帧画质。

## 运行

在本目录运行 `pnpm preview`，打开 `http://127.0.0.1:4175`。页面只依赖本地文件，不使用运行时 CDN。轻触或按 Enter / 空格触发完整演出；演出结束后可再次触发。系统启用“减少动态效果”时，触发后直接显示静态完整画面。

`pnpm lint && pnpm test && pnpm build` 生成 `dist/`，可直接作为静态站点文件使用。p5.js 1.11.11 的运行文件和许可文件放在 `vendor/`。`src/flow.js` 保存手绘河床节点，并生成有不同宽度、亮度和流速的独立水线；`src/sketch.js` 绘制场景及演出时序。水线随时间持续运动，结束后仍可重播。

运行 `./scripts/package.ps1` 得到两个包：`exports/yueliu-minitool-upload.zip` 只含静态网页允许的文件，`index.html` 位于 ZIP 根目录；`exports/yueliu-promo-kit.zip` 含 Logo、3:4 笔记封面、竖屏录屏和从 `src/content/content.json` 生成的笔记文案。视频仅在宣传素材包中。脚本会检查小工具包的扩展名、入口文件和 10 MiB 体积上限。
