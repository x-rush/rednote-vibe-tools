## 匹配评分

硬过滤完成后计算整数分：

- 目标匹配：`+40`
- 精力完全相等：`+20`
- 时间成本等于可用时间：`+10`
- 未在最近三次展示：`+30`
- 近期放弃：`-25`
- 完成冷却尚未结束但已进入最后回退：`-35`
- 与上次同类别：`-10`

先取最高分组，再按任务 ID 排序并用 seed 在组内选择。返回值包含任务、分数、匹配阶段、推荐原因、已放宽项和下一 RNG 状态。

## 永不放宽条件

- 内容审核与全部安全标签；
- 用户可用时间上限；
- 用户当前明确可用的室内/户外环境；
- 白天/夜间，以及户外任务的白天限制；
- 任务精力不得超过用户当前精力；
- 用户选择不花钱时费用必须为 0；
- 用户选择不社交时只允许 solo；
- 用户明确选择的不适用条件；
- 户外的熟悉、安全、公开区域要求。

只有 cooldown 与软偏好能被后续阶段放宽。若全部硬条件下没有候选，返回 `no-match`，不伪造或恢复危险任务。

## 逐级放宽顺序

1. `exact`：目标、精力贴合、近期去重全部满足。
2. `goal-relaxed`：目标不再必须命中，但仍参与最高软权重。
3. `energy-relaxed`：允许更低精力任务，仍禁止超过当前精力。
4. `recent-relaxed`：放宽近期展示和放弃记录，完成冷却仍排除。
5. `safe-fallback`：忽略目标、精力贴合和 cooldown，只从仍满足全部硬条件的安全池选择。

每个阶段均返回对应中文解释；安全、时间、地点、预算与社交硬条件在解释中列为未放宽项。

## seed 与去重规则

seed 字符串先经 FNV-1a 32 位哈希，再使用确定性整数 PRNG。候选先按稳定任务 ID 排序，因此相同内容、偏好、历史与 seed 不受 JSON 数组顺序影响，结果可复现。

每次 offer 保存 `nextSeed`；换一个会记录旧 offer、推进 seed 并把刚展示任务加入最近 10 项列表。正常阶段排除最近 3 次展示、7 天内放弃及任务自身 `cooldownDays` 内的完成记录；池耗尽后只按上述放宽顺序释放。

## XP、等级与完成幂等

首发 tiny/E 级任务为 20 XP，light/D 级任务为 35 XP。每次接取产生 `acceptanceId`；同一接取实例重复触发完成时奖励为 0，且不会新增完成历史。任务在 cooldown 后可以作为新的接取实例再次完成。

等级累计阈值：达到等级 `L + 1` 需要 `100 × L × (L + 1) / 2` XP。等级 1、2、3、4 起点分别为 0、100、300、600 XP。档案 ViewModel 同时给出当前级起点、下一级阈值、级内 XP 和距升级 XP。

## 连续完成规则

连续记录函数只接收显式 `YYYY-MM-DD`，不读取测试运行时的真实时间：

- 首次完成：1 天；
- 同一自然日再次完成：保持不变；
- 紧邻下一自然日：加 1；
- 间隔一天以上：重置为 1；
- 放弃、更换：不改变连续记录；
- `best` 只增不减。

自动测试覆盖同日、普通隔日、月末、年末和断档。

## 徽章接口

`BadgeDefinition` 支持 `completed-count`、`streak`、`level`、`category-count` 四种结构化规则。`unlockedBadges` 输入徽章定义、进度摘要和当前解锁 ID，输出去重后的只增集合；任务完成结果另返回本次新增徽章 ID。

首发提供首次完成、累计五项、连续三日、等级三级和三项轻微运动五个文字徽章。当前页面使用“印记”文字占位，不以 emoji 代替未来美术。

## 本地存储 Schema

localStorage key：`xhs-tool:earth-online:state:v1`。

```text
StorageEnvelope
  schemaVersion: 1
  contentVersion: string
  updatedAt: ISO 8601
  data:
    preference
    offeredQuestId / activeQuest
    recentQuestIds       最多 10
    completedQuestIds    去重稳定 ID
    history              最多 100
    xp / streak / unlockedBadgeIds
    rngState
```

等级由 XP 派生，不重复保存。读取按 JSON 解析、版本、字段类型、内容引用与上限依次校验；截断 JSON、未来版本、失效关键任务引用和错误类型返回可恢复结果。容量失败返回 `quota-or-unavailable`。递归白名单拒绝图片、Base64、Blob、音视频、经纬度和完成证明字段。

长期日志接口使用 IndexedDB 数据库 `xhs_earth_online`，object store 为 `adventureLogs` 与 `questFeedback`。接口失败转为 `storage-unavailable`；localStorage 的有限历史仍可维持主流程。
